历史图谱 设计系统提案

墨色 #4A3F3F 为唯一品牌色；所有彩色收进「绢帛六色」母色板，变体一律由透明度阶叠加在纸底上生成。墨色管操作，六色管数据，透明度管层次。

改造范围：只改视觉，不改交互。字体 / 颜色 / 选中态 / 圆角 / 阴影按本规范替换；页面布局、时间轴、画布滑动、导航索引等交互结构一律保持现状。

06

页面模拟 · 五个核心页，布局与交互完全不动，只换色

首页保留左侧时间轴刻度列、右缘朝代导航索引与「收起 / 展开」交互：收起态一个朝代一张色块；展开态帝王卡纵向堆叠，同朝代所有帝王共用该朝代的时代色（8% 底），卡与卡之间靠纸底缝隙分隔；乱世容器（春秋 / 战国 / 三国 / 南北朝）保持「一级容器色 + 二级中性白卡」结构，白卡不带色相、压在容器淡色上对比更清晰。详情页保留现有平铺画布与左右滑动，仅左缘类目细条与事略标签换成绢帛六色；搜索 / 会员 / 我的三页去掉全部砖红与金色渐变，操作元素统一墨色系。
