# 关系数据整理提示词

## 适用范围

**仅适用于人物类史略**：君王、宗戚、文臣、武将、宦官、庶众。

以下类型**不收集、不整理**关系数据：事略、典制、论著、蕃祚。

---

## 总则

1. 关系图谱只收 **五大一级分类**：**家庭、同僚、敌对、师徒、好友**。
2. 除**好友**外，每个一级分类下须有**二级分类枢纽节点**；好友无二级，一级分类直连具体人物。
3. **关系类别**（家庭 / 同僚 / 敌对 / 师徒 / 好友）是一级分组字段；二级分类枢纽写入 JSON，`节点类型` 为 `二级分类`。
4. 同层可并列多个节点（多位配偶、多位子女、多位臣子等），**不得**为凑层级而机械扩展。
5. 无可靠史料支撑的节点**不写入**；不适用的子类**不建枢纽**。
6. **展开深度**：除「配偶 → 子女」外，二级分类下的具体人物均为叶节点，不再向下展开（无孙辈、无徒孙链）。

### 字段对应

| 字段 | 含义 |
|------|------|
| `关系类别` | 家庭 / 同僚 / 敌对 / 师徒 / 好友 |
| `关系层级` | 一级 / 二级 / 三级（本规范最多三级：二级枢纽 → 人物 → 配偶子女） |
| `节点类型` | 二级分类枢纽填 `二级分类`；具体人物可省略或填 `人物` |
| `上级连接线标题` | 与上一节点的边标签；无标题时填空字符串 `""` |
| `所属一级关系` | 层级 ≥ 二级时必填；值为**上一级节点标题** |
| `所属二级关系` | 层级 ≥ 三级时必填 |
| `所属三级关系` | 本规范一般不用（无四级展开） |

### 树形呈现（连接线标题规则）

```
史略人物 ── 家庭 ── 父母 ── 具体人物（边标题：父亲 / 母亲；一方不详则不建该分支）
史略人物 ── 家庭 ── 配偶 ── 具体人物（边标题：正妻 / 妾 / 嫔妃 / 丈夫）── 子女（边标题：子 / 女）
史略人物 ── 家庭 ── 兄弟姐妹 ── 具体人物（边标题：兄 / 弟 / 姐 / 妹；不详则边标题为空）
史略人物 ── 同僚 ── 君王|同僚|臣子 ── 具体人物（二级→人物：无边标题）
史略人物 ── 敌对 ── 内敌|外敌 ── 具体人物（二级→人物：无边标题）
史略人物 ── 师徒 ── 老师|学生 ── 具体人物（二级→人物：无边标题）
史略人物 ── 好友 ── 具体人物（一级→人物：无边标题）
```

一级分类 → 二级枢纽：边标题为空（枢纽节点名即分类名）。

---

## 一、家庭

家庭下设三个**平行**二级分类：**父母、配偶、兄弟姐妹**。

每个二级分类先写一条枢纽记录（`关系层级=一级`，`节点类型=二级分类`，`上级连接线标题=""`），再挂具体人物。

### 1.1 父母

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「父母」 | `""` | — |
| 二级 | 父亲、母亲（有几位写几位；不详则不写该分支） | `父亲` / `母亲` | **否**（叶节点） |

### 1.2 配偶

每位配偶各走一条独立分支；**仅此子类**可再挂子女。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「配偶」 | `""` | — |
| 二级 | 各配偶 | **必填** `正妻` / `妾` / `嫔妃` / `丈夫`（**站在条目主人公视角**：对方是主人公的正妻/妾/嫔妃，或主人公的丈夫） | 是（仅子女） |
| 三级 | 该配偶所出子女 | `子` / `女` | **否**（叶节点；不写孙辈） |

**禁止重复挂载**：婚姻配偶关系**只**写在「家庭 · 配偶」。同一人物不得再挂到「同僚 · 君王/同僚/臣子」或「好友」（班次、德行等写进 `关系简述` 即可）。

### 1.3 兄弟姐妹

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「兄弟姐妹」 | `""` | — |
| 二级 | 各位兄弟姐妹（并列） | `兄` / `弟` / `姐` / `妹`；不详则 `""` | **否**（叶节点；不写其子女） |

### 家庭示例

**周文王 · 配偶支**

```
关系类别：家庭
一级枢纽：配偶
  → 二级：太姒（正妻）→ 三级：武王发（子）
  → 二级：帝乙之妹（妾）
```

---

## 二、同僚

适用于在朝政 / 政治体系中与他人产生共事关系的人物。下设三个**平行**二级分类：**君王、同僚、臣子**。

> 同朝政敌、外部敌人**不归入**本节，归入 **敌对**（第三节）。

### 2.1 君王

主题人物**曾作为臣子**时所效忠的君主（可不唯一）。

- 例：舜既是君王，也是尧的臣子 → 在舜的图谱中，**君王**下写 **尧**。
- 若主题从未为臣，不建此枢纽。

### 2.2 同僚

主题人物为文臣武将时的同时、同阵营合作者（非敌对）。

### 2.3 臣子

主题人物**作为君王**时的臣属。

- 若主题从未为君，不建此枢纽。

### 同僚层级（三类通用）

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「君王」/「同僚」/「臣子」 | `""` | — |
| 二级 | 具体人物（可并列多位） | `""` | **否**（叶节点） |

---

## 三、敌对

下设两个**平行**二级分类：**内敌、外敌**。

### 3.1 内敌

同朝政敌、权斗对手、共事体系内的明确敌对者。

### 3.2 外敌

外部阵营对手：敌国君主、敌营将领、戎狄方国等。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「内敌」/「外敌」 | `""` | — |
| 二级 | 具体人物或敌对实体 | `""` | **否**（叶节点） |

---

## 四、师徒

下设两个**平行**二级分类：**老师、学生**。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「老师」/「学生」 | `""` | — |
| 二级 | 各位老师或学生（并列） | `""` | **否**（叶节点；不写徒孙） |

---

## 五、好友

**私人情谊、交游、知交、游伴**，与同僚（政治共事）、师徒、家庭（血缘姻亲）、敌对严格区分。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 具体好友人物（直接挂在一级分类「好友」下，**无二级枢纽**） | `""` | **否** |

- **适用**：史料明确记载私交、同游、唱和、刎颈之交等非职务情谊。
- **不适用**：政治盟友 / 同朝共事 → **同僚**；门生弟子 → **师徒**；亲属 → **家庭**；敌对者 → **敌对**。

---

## 停止展开规则

满足任意一项，即停止继续向下展开：

1. 已是叶节点（父母/兄弟姐妹/同僚类/敌对/师徒/好友下的人物；配偶下的子女）。
2. 后续节点无可靠史料。
3. 后续节点已有独立人物史略，可由其自身关系图继续展开。
4. 继续展开不能增加对当前主题人物的理解。
5. **禁止**为凑层级写孙辈、徒孙、兄弟姐妹之子女。

---

## 完整性要求

- 遵循 **「宁可完整，不可无限扩张」** 原则。
- 每个适用二级分类优先保证枢纽与直接关联人物完整。
- 不得编造节点；不得因机械套用模板而遗漏关键人物。

## 旧类别迁移对照

| 旧写法 | 新写法 |
|--------|--------|
| 师从 | 师徒（二级：老师 / 学生；旧「徒弟」→「学生」） |
| 外敌（一级分类） | 敌对 → 外敌（二级枢纽） |
| 同僚·敌对 / 政敌 | 敌对 → 内敌 |
| 妻妾 | 配偶 |
| 正室 / 正妃 | 正妻 |
| 小妾 / 侧室 | 妾 |
| 儿子 / 女儿 | 子 / 女 |
| 君臣 | 同僚 |
