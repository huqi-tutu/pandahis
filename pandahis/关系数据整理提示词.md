# 关系数据整理提示词

## 适用范围

**仅适用于人物类史略**：君王、宗戚、文臣、武将、宦官、庶众。

以下类型**不收集、不整理**关系数据：事略、典制、论著、蕃祚。

---

## 总则

1. 关系图谱只收 **五大一级分类**：**家庭、同僚、敌对、师徒、好友**。
2. **每个一级分类下均须有二级分类枢纽节点**（含好友：一级名与二级枢纽名同为「好友」）。
3. **关系类别**（家庭 / 同僚 / 敌对 / 师徒 / 好友）是一级分组字段；前端**不展示**一级分类标题，仅用其决定主题色与扇区。
4. 二级分类枢纽写入 JSON，`节点类型` 为 `二级分类`；**无具体人物（或子树）的二级枢纽不写**。枢纽名（父母/配偶/臣子/外敌等）**禁止**再作为人物叶子节点标题；`所属二级/三级关系` 必须是人名或「不详」，不得填枢纽名。
5. 同层可并列多个节点，**不得**为凑层级而机械扩展。
6. 无可靠史料支撑的节点**不写入**。
7. **二级枢纽人数上限（强制）**：每个二级分类枢纽下的**直接关联人物**（`关系层级=二级`）**最多 10 人**。超出时只保留对该主题人物最重要的 10 人，其余**不提取、不入库、不展示**。
   - 优选：史料笔墨多、官职/战事/功业关键、已有独立人物史略、对理解主题不可或缺者。
   - 不满 10 人不必凑数；满朝文武类（臣子/同僚等）尤须严选，禁止堆砌。
   - 本上限约束枢纽→直接人物；配偶下子女/孙辈仍按其展开规则，但每位配偶仍计入该枢纽的 10 人名额。
8. **展开深度**（家庭·配偶支最多四级圈层）：
   - 圈1：二级枢纽
   - 圈2：直接关联人物（每枢纽 ≤10）
   - 圈3：子女（挂在配偶下）
   - 圈4：孙辈（子女的子女）
   - 禁止徒孙链、兄弟姐妹之子女、第五级。

### 字段对应

| 字段 | 含义 |
|------|------|
| `关系类别` | 家庭 / 同僚 / 敌对 / 师徒 / 好友 |
| `关系层级` | 一级 / 二级 / 三级 / 四级（二级枢纽 → 人物 → 子女 → 孙辈） |
| `节点类型` | 二级分类枢纽填 `二级分类`；具体人物可省略或填 `人物` |
| `上级连接线标题` | 与上一节点的边标签；无标题时填空字符串 `""` |
| `所属一级关系` | 层级 ≥ 二级时必填；值为**上一级节点标题** |
| `所属二级关系` | 层级 ≥ 三级时必填 |
| `所属三级关系` | 层级 ≥ 四级时必填（孙辈） |

### 树形呈现（连接线标题规则）

```
史略人物 ──〔家庭〕── 父母 ── 人物（边：父 / 母）
史略人物 ──〔家庭〕── 配偶 ── 人物（边：妻 / 妾 / 妃 / 夫）
                              └── 子女（边：子 / 女）
                                    └── 孙辈（边：子 / 女）
史略人物 ──〔家庭〕── 兄弟姐妹 ── 人物（边：兄 / 弟 / 姐 / 妹；分不清则兄弟 / 姐妹）
史略人物 ──〔同僚〕── 君王|同僚|臣子 ── 人物（无边标题）
史略人物 ──〔敌对〕── 内敌|外敌 ── 人物（无边标题）
史略人物 ──〔师徒〕── 老师|学生 ── 人物（无边标题）
史略人物 ──〔好友〕── 好友 ── 人物（无边标题）
```

说明：〔〕内一级分类仅作后端分组，图谱圈1只画二级枢纽名。

### 家庭边标题（白名单）

| 场景 | 允许值 |
|------|--------|
| 父母 | `父` / `母` |
| 配偶 | `妻` / `妾` / `妃` / `夫`（主人公视角） |
| 兄弟姐妹 | `兄` / `弟` / `姐` / `妹`；分不清性别序齿时用 `兄弟` / `姐妹` |
| 子女 / 孙辈 | `子` / `女` |

同僚 / 敌对 / 师徒 / 好友：人物边标题一律 `""`。

### 互斥归类（强制）

同一人物标题在同一张关系表中：

| 冲突 | 保留 | 删除 |
|------|------|------|
| 家庭 ∩ 同僚 | 家庭 | 同僚中的该人 |
| 家庭 ∩ 好友 | 家庭 | 好友中的该人 |
| 家庭 ∩ 师徒 | 家庭 | 师徒中的该人 |
| 同僚 ∩ 好友 | 同僚 | 好友中的该人 |

其余组合**可共现**（如家庭∩敌对、同僚∩敌对、同僚∩师徒、敌对∩好友等）。

优先级口诀：**家庭 > 同僚 > 好友**；家庭亦排斥师徒；敌对不参与互斥。

---

## 一、家庭

家庭下设三个**平行**二级分类：**父母、配偶、兄弟姐妹**。

每个二级分类先写一条枢纽记录（`关系层级=一级`，`节点类型=二级分类`，`上级连接线标题=""`），再挂具体人物。

### 1.1 父母

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「父母」 | `""` | — |
| 二级 | 父亲、母亲（有几位写几位；不详则不写该分支） | `父` / `母` | **否**（叶节点） |

### 1.2 配偶

每位配偶各走一条独立分支；**仅此子类**可再挂子女与孙辈。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「配偶」 | `""` | — |
| 二级 | 各配偶 | **必填** `妻` / `妾` / `妃` / `夫` | 是（子女） |
| 三级 | 该配偶所出子女 | `子` / `女` | 是（孙辈） |
| 四级 | 该子女所出孙辈 | `子` / `女` | **否**（叶；不写曾孙） |

**生母不详**：仍保留配偶节点，标题写 **`不详`**，边标题按角色尽量判定（无法判定时用 `妻`）；子女挂在「不详」下。

**禁止重复挂载**：婚姻配偶关系**只**写在「家庭 · 配偶」。同一人物不得再挂到「同僚」或「好友」（班次、德行等写进 `关系简述`）。

### 1.3 兄弟姐妹

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「兄弟姐妹」 | `""` | — |
| 二级 | 各位兄弟姐妹（并列） | `兄` / `弟` / `姐` / `妹`；分不清则 `兄弟` / `姐妹` | **否** |

### 家庭示例

**黄帝 · 配偶支（含孙辈）**

```
关系类别：家庭
一级枢纽：配偶
  → 二级：嫘祖（妻）
       → 三级：昌意（子）→ 四级：颛顼（子）
       → 三级：玄嚣（子）→ 四级：蟜极（子）
  → 二级：嫫母（妾）
```

## 二、同僚

适用于在朝政 / 政治体系中与他人产生共事关系的人物。下设三个**平行**二级分类：**君王、同僚、臣子**。

> 同朝政敌、外部敌人**不归入**本节，归入 **敌对**（第三节）。

### 2.1 君王

主题人物**曾作为臣子**时所效忠的君主（可不唯一）。

### 2.2 同僚

主题人物为文臣武将时的同时、同阵营合作者（非敌对）。

### 2.3 臣子

主题人物**作为君王**时的臣属。

### 同僚层级（三类通用）

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「君王」/「同僚」/「臣子」 | `""` | — |
| 二级 | 具体人物（可并列多位） | `""` | **否** |

---

## 三、敌对

下设两个**平行**二级分类：**内敌、外敌**。

### 3.1 内敌

同朝政敌、权斗对手、共事体系内的明确敌对者。

### 3.2 外敌

外部阵营对手：敌国**具体君主/将领/首领**等**具名人物**。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「内敌」/「外敌」 | `""` | — |
| 二级 | **具体人物** | `""` | **否** |

### 3.3 节点资格（全类别通用，敌对尤严）

关系图谱叶子节点**只收可指认的具体人物**（含史书常用家族/氏姓指称，见下）。

| 类型 | 是否可写 | 示例 |
|------|----------|------|
| 具名人物 | ✅ | 纣、蚩尤、吴起、白起 |
| 家族 / 氏姓指称（可作人物集合的习惯称谓） | ✅ | 鲍氏、高氏、崔氏 |
| 国家 / 政权 / 方国名 | ❌ | 秦国、齐国、奄、中山 |
| 少数民族 / 部族 / 部落联盟 | ❌ | 犬戎、淮夷、三苗、东夷、猃狁、姜氏之戎 |
| 职衔式空名（非具体人名） | ❌ | 东周君、中山国君、某国国君 |
| 战役 / 事件名 | ❌ | 不得作节点或边标题 |

- 敌对外敌**不得**用「××国 / ××戎 / ××夷」代替对手；应写具体君主或将领；名失载则**不写该节点**。
- 「××氏」若史料中指**氏族/家族群体**且可作关系对象 → **可保留**；若实为方国/部族政权代称且无法落到人 → **不写**（存疑时交 LLM 审核，见 skill）。

---

## 四、师徒

下设两个**平行**二级分类：**老师、学生**。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「老师」/「学生」 | `""` | — |
| 二级 | 各位老师或学生（并列） | `""` | **否**（叶；不写徒孙） |

---

## 五、好友

**私人情谊、交游、知交、游伴**，与同僚（政治共事）、师徒、家庭（血缘姻亲）严格区分。

须先写二级枢纽「好友」（名称与一级相同），再挂具体人物。

| 层级 | 内容 | 边标题 | 是否继续展开 |
|------|------|--------|--------------|
| 一级 | 枢纽「好友」 | `""` | — |
| 二级 | 具体好友人物 | `""` | **否** |

- **适用**：史料明确记载私交、同游、唱和、刎颈之交等非职务情谊。
- **不适用**：政治盟友 / 同朝共事 → **同僚**；门生弟子 → **师徒**；亲属 → **家庭**；敌对者 → **敌对**。
- 已在同僚出现的人物，按互斥规则**不得**再写入好友。

---

## 停止展开规则

满足任意一项，即停止继续向下展开：

1. 已是叶节点（父母/兄弟姐妹/同僚类/敌对/师徒/好友下的人物；配偶支下的孙辈）。
2. 后续节点无可靠史料。
3. 后续节点已有独立人物史略，可由其自身关系图继续展开（但主题人物图谱仍可写其作为子女/孙辈的一环）。
4. 继续展开不能增加对当前主题人物的理解。
5. **禁止**曾孙、徒孙、兄弟姐妹之子女。

---

## 完整性要求

- 遵循 **「宁可完整，不可无限扩张」** 原则。
- 每个适用二级分类优先保证枢纽与直接关联人物完整；配偶支有据则补子女与孙辈。
- 不得编造节点；不得因机械套用模板而遗漏关键人物。

| 外敌（一级分类） | 敌对 → 外敌（二级枢纽） |
| 同僚·敌对 / 政敌 | 敌对 → 内敌 |
| 妻妾 | 配偶 |
| 正室 / 正妃 / 正妻 | 妻 |
| 小妾 / 侧室 | 妾 |
| 嫔妃 | 妃 |
| 丈夫 | 夫 |
| 父亲 / 母亲 | 父 / 母 |
| 儿子 / 女儿 | 子 / 女 |
| 君臣 | 同僚 |
| 好友人物直挂一级（无枢纽） | 先写二级枢纽「好友」，再挂人物 |
