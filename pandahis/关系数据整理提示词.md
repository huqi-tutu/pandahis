# 关系数据整理提示词

## 适用范围

**仅适用于人物类史略**：君王、宗戚、文臣、武将、宦官、庶众。

以下类型**不收集、不整理**关系数据：事略、典制、论著、蕃祚。

---

## 总则

1. 关系图谱只收 **五大关系类别**：**家庭、同僚、师从、外敌、好友**。
2. 从**史略主题人物**起算，任意一条展开路径**最多四级**（一级 → 二级 → 三级 → 四级）。
3. **关系类别**（家庭 / 同僚 / 师从 / 外敌 / 好友）是分组字段，**不计入**上述四级。
4. 同层可并列多个节点（多位配偶、多位子女、多位臣子等），**不得**为凑层级而机械扩展。
5. 无可靠史料支撑的节点**不写入**；不适用的子类**留空**。

### 字段对应

| 字段 | 含义 |
|------|------|
| `关系类别` | 家庭 / 同僚 / 师从 / 外敌 / 好友 |
| `关系层级` | 一级 / 二级 / 三级 / 四级 |
| `所属一级关系` | 该类别下的子类（见下文各节） |
| `所属二级关系` | 上一级节点名称 |
| `所属三级关系` | 上两级节点名称 |
| `所属四级关系` | 上三级节点名称 |

---

## 一、家庭

家庭下设三个**平行**子类：**父母、配偶、兄弟姐妹**。

### 1.1 父母

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 父母 | — |
| 二级 | 父亲、母亲 | **否**（叶节点） |

### 1.2 配偶

每位配偶各走一条独立分支。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 配偶 | — |
| 二级 | 各配偶（丈夫 / 妻子 / 正妻 / 侧室 / 妃嫔等，有几位写几位） | 是 |
| 三级 | 该配偶所属之子嗣（每位子女单独成节点） | 是 |
| 四级 | 该子女的子女（孙辈） | **否**（叶节点） |

### 1.3 兄弟姐妹

兄弟姐妹**不与父母合并**，与父母、配偶**平行**成类；以其后代向下展开。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 兄弟姐妹 | — |
| 二级 | 各位兄弟姐妹（并列） | 是 |
| 三级 | 该兄弟姐妹的子女 | 是 |
| 四级 | 该子女的子女（孙辈） | **否**（叶节点） |

### 家庭示例

**黄帝 · 配偶支**

```
关系类别：家庭
一级：配偶 → 二级：嫘祖 → 三级：昌意 → 四级：（昌意之子，若有可靠史料）
```

**某人物 · 兄弟姐妹支**

```
关系类别：家庭
一级：兄弟姐妹 → 二级：×× → 三级：××之子 → 四级：××之孙
```

---

## 二、同僚

适用于在朝政 / 政治体系中与他人产生共事关系的人物。下设四个**平行**子类：**君王、臣子、同僚、敌对**。

> **与同僚·敌对的区别**：本节「敌对」指**共事体系内部**的敌人；**外部阵营**的对手归入 **外敌**（第四节）。

### 2.1 君王

主题人物**曾作为臣子**时所效忠的君主。

- 例：舜既是君王，也是尧的臣子 → 在舜的图谱中，**君王**子类下写 **尧**。
- 若主题从未为臣，此子类留空。

### 2.2 臣子

主题人物**作为君主**时的臣属。

- 例：舜为君时，**臣子**子类下写禹等大臣。
- 若主题从未为君，此子类留空。

### 2.3 同僚

与主题**共事**、且**非敌对**的人物（同朝同僚、同阵营合作者等）。  
**判定**：在同一政治 / 共事体系内，只要不是敌对，就归入同僚。

### 2.4 敌对

与主题**共事**（同一政治体系 / 同一职场），但属**明确敌对关系**的人物（政敌、权斗对手、同朝相争者等）。

### 同僚层级（四类通用）

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 君王 / 臣子 / 同僚 / 敌对 | — |
| 二级 | 具体人物（可并列多位） | **否**（叶节点） |

同一人物可同时出现在不同子类（如舜：君王子类填尧，臣子子类填禹）。

---

## 三、师从

下设两个**平行**子类：**老师、徒弟**。

### 3.1 老师

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 老师 | — |
| 二级 | 各位老师（并列） | 是 |
| 三级 | 该老师的徒弟 | 是 |
| 四级 | 上述徒弟的徒弟 | **否**（叶节点） |

### 3.2 徒弟

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 徒弟 | — |
| 二级 | 各位直接徒弟（并列） | 是 |
| 三级 | 该徒弟的徒弟 | 是 |
| 四级 | 上述徒弟的徒弟 | **否**（叶节点） |

### 师从示例

**孔子 · 徒弟支**

```
关系类别：师从
一级：徒弟 → 二级：子路 → 三级：子路门下某弟子 → 四级：该弟子之徒弟
```

**孔子 · 老师支**

```
关系类别：师从
一级：老师 → 二级：老子 → 三级：老子门下某弟子 → 四级：该弟子之徒弟
```

---

## 四、外敌

**外部**敌对阵营人物，与 **同僚·敌对**（身边共事之敌）严格区分。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 外敌 | — |
| 二级 | 具体外敌人物（敌国君主、敌营将领、明确属外部阵营的对手；可并列多位） | **否**（叶节点） |

适用：敌国、敌营、明确外部阵营的对立者。  
不适用：同朝政敌、同朝权斗对手 → 归入 **同僚·敌对**。

---

## 五、好友

**私人情谊、交游、知交、游伴**，与同僚（政治共事）、师从（师徒）、家庭（血缘姻亲）严格区分。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 好友 | — |
| 二级 | 具体好友人物（可并列多位） | **否**（叶节点） |

- **边标签示例**：`好友`、`知交`、`游伴`、`契友`、`莫逆`、`同游` 等。
- **适用**：史料明确记载私交、同游、唱和、刎颈之交等非职务情谊。
- **不适用**：政治盟友 / 同朝共事 → **同僚**；门生弟子 → **师从**；亲属 → **家庭**；敌国对手 → **外敌**。

---

## 停止展开规则

满足任意一项，即停止继续向下展开：

1. 已达到四级。
2. 该子类规则规定为叶节点（父母二级、同僚二级、外敌二级等）。
3. 后续节点无可靠史料。
4. 后续节点已有独立人物史略，可由其自身关系图继续展开。
5. 继续展开不能增加对当前主题人物的理解。

---

## 完整性要求

- 遵循 **「宁可完整，不可无限扩张」** 原则。
- 每个适用子类优先保证 **一级、二级** 完整（该写的直接关联人物不遗漏）。
- 家庭、师从按上表规则决定是否展开至三级、四级。
- 同僚、外敌、好友以 **二级人物并列** 为主，不向下递归。
- 不得为凑满四级而编造节点；不得因机械套用模板而遗漏关键人物。
