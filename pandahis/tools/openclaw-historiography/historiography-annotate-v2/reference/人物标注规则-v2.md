# 人物标注规则（v2.5 · 新版史料标注）

**生效范围**：`historiography-annotate-v2` 专用。历史 v1 规则见 `historiography-annotate/reference/人物标注规则.md`（只读对照，非 Agent 入口）。

**架构**：Step1a 锁主轴 → Step1b **整卷划块** → 脚本展开 `segment_attribution`。  
**不是** v1 原样回归（宽 exclude、无 gate）；**不是** 旧 v2 的 hezhuan 逐段填表。

---

## 一、Step1a：卷主轴（不读段落）

### 输出字段

| 字段 | 要求 |
|------|------|
| `name` | 对齐 `帝王.json`「帝王」（君王/诸侯） |
| `category` | 八类之一 |
| `rationale` | 一句说明 |

### 人数（硬）

| narrative_mode | 人数 |
|----------------|------|
| single | 1 |
| hezhuan | 2–5（区间内即通过） |
| fanzuo | 1 |
| skip | 0 |

全局默认 **≤5**；超出取 Top5。  
**例外**：《周本纪》可 **6** 人（文/武/成/**穆**/厉/幽），见 `protagonists_cap_note`。

### volume_subtype（Step1a 或 Step1b 必填）

| volume_subtype | 典型卷 | Step1b 卷型参数 |
|----------------|--------|-----------------|
| `benji_multi` | 五帝本纪 | 开传=`帝X者`/`X者名曰`；更替归**前帝收束** |
| `benji_single` | 秦始皇本纪 | 整卷单 block（除 exclude） |
| `liezhuan_hezhuan` | 屈原贾生列传 | 过渡句归**后传主**；正式开传=`X名Y`/里居 |
| `liezhuan_single` | 项羽本纪 | single 机械 |
| `shijia_zhuhou` | 齐太公世家 | 按世系开传点划块；Top5 君主 |
| `fanzuo` | 匈奴列传 | fanzuo 机械 |

**禁止**用分类链猜「本卷写谁」。

## 二、Step1b：整卷划块

### benji_multi / shijia：逐段主语 → 聚合（强制）

多君主本纪、诸侯世家 **必须先** Step1b-α 逐段判「本段主要在记述谁」，再 Step1b-β 聚合 blocks。

| 易错 | 正确 |
|------|------|
| exclude 洞之间整块贴给最近 Top5 | 仅主语 ∈ Top5 的连续段合并为 block |
| 崩逝/禅让段因末句「立 X」整段归 X 或标世系链 | 主功能收束前君 → **outgoing**；若同段直连两 Top「卒+立」→ **双挂**（见下） |
| incoming block 从「前君崩」起 | 从**正式开传句**起（穆公 P30；启 P39）；交接双挂段可同时算双方边界 |
| 卷首远祖谱归第一个 protagonist | 世系链 exclude |
| 「X卒，中间君立」双挂 X+隔代主轴 | **禁止**；中间君无条则世系链 / 单挂 |

**两主轴直连交接（强制双挂）**

同段正文同时点名 **前 Top 卒/崩** 与 **后 Top 立/是为** →

- Step1b-α：`primary_subject=后君`，`co_owner=前君`
- β → `multi_owner_segments`；expand 后 `segment_attribution.owners` 含二人
- entry `paragraphs` 双方均覆盖该段（边界可重叠）

例：`威王卒，子宣王辟彊立` → 齐威王 + 齐宣王。  
反例：`襄公卒，子成公立`而下一主轴是宋文公 → **不可**双挂襄公+文公。

**纪年锚点**：段落在 Top5 君主纪年内（含他国大事编年）→ 归该 Top5；在非 Top5 小君纪年内 → 世系链。

### 流程（hezhuan）

```
读 P1..PN 全文
  → 识别结构位（开传/收束/摄政/过渡/共段/论赞）
  → 划 blocks + excludes（± boundary_evidence）
  → v2_blocks_gate
  → v2_expand_to_skeleton
```

### 结构位优先（强制顺序）

判定 owner **之前**先贴结构位：

| 结构位 | 信号 | 归属倾向 |
|--------|------|----------|
| 正式开传 | `帝X者` / `X者，名曰` / `X名Y，…人` | 新传主 |
| 前代收束 | 崩/薨/禅让/逊；末句「是为帝Y」但未开传 | **前帝** |
| 摄政/代理 | 命舜摄/言於**帝** | **在位之帝** |
| 合传过渡 | 「汉有贾生…」类；下段起正式传记 | **后传主** |
| 传内叙事 | 已在某 block 内 | 块主人 |
| 共段总述 | 多主轴**并列**点名/总述，无单一叙事主角 | **exclude（共段总述）** |
| 无关世系 | 享国纪年/「X公立…生Y」罗列**他君**，与主轴无直接身世关系 | **exclude（世系链）** |
| exclude | 卷首标题、论赞 | 无 owner |

**结构位 > 段内行动者。** 本纪摄政段不因舜在做事而归舜。

### 多人本纪 vs 列传合传

| | benji_multi | liezhuan_hezhuan |
|--|-------------|------------------|
| 开传 | `帝X者` / `X者名曰` | `X者…` / `X名Y` |
| 更替 | 崩禅逊葬/授政段归**前帝**；下一人 block 自正式开传起 | 过渡归**后传主** |
| 误用 | 勿用合传「段内主角」套本纪 | 勿用「帝X者」套合传 |

## 三、exclude（v2 白名单 · 硬）

| exclude_reason | 适用 |
|----------------|------|
| 卷首标题 | 汉书等 P1 篇名行 |
| 太史公曰 | 《史记》论赞 |
| 论赞 / 赞曰 | 《汉书》等 |
| **评曰** | 《三国志》陈寿卷末论赞；**不建条目、不划入事略**；只 exclude 该段 |
| **共段总述** | 段内**并列**点名 Step1a 中**多位**主轴，**无单一叙事主角**（如五帝本纪 P40） |
| **世系链** | **与主轴无直接关系的**族谱/享国纪年/「X公立…生Y」罗列他君（如秦始皇本纪 P93–135 秦君年表）；**不**含本传主开篇身世、父母、直系子嗣收束 |

### 世系链 · 归谁 vs exclude（硬）

| 情形 | 处理 | 示例 |
|------|------|------|
| 开篇定语、父母、直系子嗣/继位在本传内 | **归 block 主人** | P1 庄襄王生始皇；舜 P28 七世父系 |
| 传内子嗣概数、婚配收束 | **归 block 主人** | 「二十五子，得姓者十四人」 |
| 全卷附录式他君享国纪年、与主轴无直接身世关系 | **exclude 世系链** | 006 P93–135 襄公至二世年表 |
| 纯「A生B生C」无行动、且非本传主直系 | **exclude 世系链** | 中间夹心纯谱系 |

**禁止 exclude（v1 滥用，仍禁用）**：过渡叙事、无故事弧、纯纪年（作标签）、篇内小标题、其他。

- 怀沙赋、制度嵌入 → **归 block 主人**
- **并列总述多主轴** → **共段总述 exclude**
- **无关他君世系/享国表** → **世系链 exclude**，不归本卷主人公
- 史记本纪/列传 **P1 通常不是** 卷首标题

### 论赞 / 太史公曰 · 不得盲延（gate 硬失败 `LUNZAN_OVERREACH`）

**禁止**：见「太史公曰」或「论赞」就把其后段落**全部**标 exclude，直到卷末。

须先判 **结构位**：

| 类型 | 特征 | exclude 范围 |
|------|------|--------------|
| **夹叙评论** | 叙事进行中插入议论，**下一段回归编年/行动** | **通常仅 P(n) 单段** `太史公曰` |
| **卷末论赞块** | P(n−1) 叙事**已收束**；P(n) 起论；**后续无传主叙事回归** | P(n) `太史公曰` + 续段 `论赞`/`赞曰` 至评论收束；《三国志》通常 **仅 P(n)** `评曰`（其后裴注上表不是评曰续段） |

**硬规则**：

1. 若 P(n−1) 与 P(n+1) **同一 owner block**，中间 **多段** 论赞类 exclude → **错误**（应只 exclude 夹叙单段，或改归 owner）
2. 论赞 exclude 区间内，段首若似 **编年叙事续写**（明年/其年/春…/秦王…攻立巡崩）→ **错误**
3. 多段论赞块之后 **不得** 再出现 **同一传主** block（叙事回归 = 论赞区间划错）

**006 卷末论赞（合法范例）**：P76 秦始皇叙事收束 → P77 `太史公曰` → P78–P92 `论赞`（司马迁论 + 贾生《过秦论》）→ P93 起 **世系链**（非秦始皇叙事回归）。

### 夹心 exclude（gate 硬失败）

若 P(n−1) 与 P(n+1) **同一 owner**，P(n) 被 exclude → **错误**，须改归该 owner。  
**例外**：P(n) 为 `共段总述` / **单段** `太史公曰` 时，前后可仍属同一传主 block（如 P39 舜 · P40 共段总述 · P41 太史公曰）。

## 四、blocks 与展开

- 每段恰被 **一个 block** 或 **exclude** 覆盖
- 块 `name` ∈ Step1a 名单
- `boundary_evidence.open_phrase` 须为原文子串
- 块内 **不再** 逐段 LLM

---

## 五、与翻译层分工

- 标注按结构位划段；交接可双挂（前君卒+后君立同段）
- 翻译按本传主镜头：后君开篇压缩前君侧为过渡；前君篇末条件补叙仅当本 entry 无退场时补 1 句（见 `翻译规则.md`）
- **禁止**为翻译完整而改 segment 归属
