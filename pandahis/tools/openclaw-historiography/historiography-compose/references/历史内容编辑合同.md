# 时络历史｜历史内容编辑合同（QA 标准）

> **产品级、跨文明、跨人物**的内容质量控制 SSOT。  
> 不随具体人物（高祖、武帝、太宗…）改写条款；病例只作回归测试，不作规则正文。  
> 与 `翻译规则.md`（写作细则）、**`历史翻译质量宪法.md`（八大守恒 · Phase2 新增三条 · Evidence Backtrace）** 并用：  
> 合同管**失败模式 A–G**；宪法管**语义守恒总原则**；规则管顺译/说书写法。

---

## 一、十条编辑合同（硬）

1. **史实优先** — 历史准确性高于叙事流畅、文学性与说书效果。  
2. **时间不让步** — 不得为流畅改变事件真实先后、人物身份阶段或因果方向；正文凡写年号年 / 帝纪年 / 国号纪年，**每一个这样的年份**须紧随并注公历（前N年 / 公元N年），禁止只给个别年注公元；换算须准，不准则【待核实】。  
3. **实体不合并** — 相似姓名、称谓、官爵、地名，无证据不得自动视为同一实体。  
4. **制度有作用域** — 制度/规则/周期/政策须绑定具体时间与适用范围，不得跨节点泛化。  
5. **来源不混淆** — 原典事实、原典转述、其他史源、编辑解释、说书评论须保持认知边界。**内容可混合，认知来源不能混合。**  
6. **传说不冒充史实** — 神话、祥瑞、方士之言、异闻、传闻须保留原有认知地位。  
7. **压缩不改结构** — 可简化表达、可删字压缩描写，不得改变数量、步骤、范围、归属、时间与因果关系；**禁止整段删母本情节**。  
8. **重复要标记，不要误删** — 同一母题再现时用时间或回合区分；不得因语义相似误判为双写而删原典。  
9. **评论不冒充史实** — 编辑解释与说书评论可以存在，不得伪装成原典结论。  
10. **修复只做定向修改** — 骨架成立时禁止整篇重生成；只修已确认问题，并做修复后复检。

## 二、信息认知层级（L1–L5）

| 层级 | 名称 | 定义 | 正文要求 |
|------|------|------|----------|
| **L1** | 史源事实 | 核心原典作者直接叙述的事件 | 可作确定叙述 |
| **L2** | 原典转述/传闻/异说 | 「某人曰」「或曰」「传闻」「方士说」等 | **必须保留来源限定** |
| **L3** | 跨史源补充 | 他书/他卷可靠记载 | 不得假装来自核心原典 |
| **L4** | 编辑解释 | 「这意味着」「换句话说」等助读 | 软语气；勿冒充 L1 |
| **L5** | 说书评论 | 态度、幽默、临场感 | 软语气；勿冒充 L1 |

L2 与 L3 必须分开：  
「原典里某人说的话」≠「另一部史书的补充记载」。

Phase2 构成原则（在 **L1 覆盖完整且顺序正确** 的前提下）：  
以 L1 为骨架；L3（跨书增量）与 L4（讲解）是**补充维度，不是篇幅/占比指标**——读者理解当前事件确实需要时再加；L5 说书评论作调味，勿压过讲解。  
**禁止用压缩或蒸发母本事件来换取讲解篇幅**；体量长短本身不是质量目标。仍须遵守十条合同（时间/实体/认知边界不让步）。

## 三、七类通用失败模式（A–G）

| 类型 | 模式 | 核心检查 |
|------|------|----------|
| **A** | 实体串并 | 人物/地点/官爵/机构是否被错误合并；实体身份须带**时间状态**（同一人不同阶段的称谓不得提前） |
| **B** | 制度/规则越界 | 某节点规则是否被泛化为长期总规则 |
| **C** | 叙述层揉合 | 原典叙述、人物话语、传说框、后续叙事是否被熔接成伪因果 |
| **D** | 认知地位丢失 | 传说/异闻/祥瑞是否被写成确定史实 |
| **E** | 信息压缩失真 | 概括时是否改掉：①数量 ②步骤 ③范围（一次→从此）④归属（某人说→史书说） |
| **F** | 作者层越权 | 推测/评论/心理是否伪装成史实 |
| **G** | 时间/事件链错位 | ①时间先后 ②人物当时身份状态 ③事件依赖 ④因果方向（禁止后见之明写成当时动机）⑤**纪年缺公元并注**或公元换算错误 |

**G 与 B 不同**：B 管「规则作用域」；G 管「事件链与身份阶段」。二者均为 P0/P1 级核心项。

**纪年并注（G⑤，写法统一）**  
- 格式：`汉二年（前205年）` / `贞观三年（公元629年）`  
- 范围：每一个「×元年 / ×二年 / 建元×年」等显式纪年都要注；同场景内已注年后的「十一月」可不再注。  
- 「次年 / 是岁」若对不上公历，应补出或改成显式纪年+公元。

**重复母题**：重复事件不是问题；**重复而不标识历史回合**才是问题。事件去重 ≠ 重复事件识别，须分开。

## 四、与 Phase1–5 的对应

| 阶段 | 目标 | 主防 |
|------|------|------|
| Phase1 母本顺译 | 准确骨架；零说书、零他书 | A / C / D / G |
| Phase2 整篇润色 | L1 事件/顺序守恒优先；按需 L3/L4；自挖补充须可溯源 | C / D / E / F / G（兼 A/B） |
| Phase3 历史质检 | 按 A–G + 八大守恒；高风险句 Evidence Backtrace；**只找问题不改正文** | A–G 全开 + ③⑦ 等 |
| Phase4 定向修复 | 只改已确认项；禁止整篇重生成 | 防修复引入新 A–G |
| Phase5 最终验收 | 修对了吗？有无新伤？ | Entity / Temporal / Source / Epistemic / Narrative Integrity |

## 五、使用约定

- 改提示词、质检清单、程序预检时：**只增加可泛化条款**，禁止把单篇病例写成全局 if-else。  
- 单篇回归（如某帝某王）放测试集，不进本文件正文。  
- 程序预检优先做**模式检测**（近名邻接、文内制度周期自相矛盾、神异段缺限定、事件链倒流线索），词表可配置、文明可扩展。
