# 史略翻译规则

> **唯一 SSOT** — compose 与 translate 共用本文件。  
> 风格参考：《明朝那些事儿》| 共十二条写作原则 + 第零部分流水线约定。  
> 总目标：以母本为底本顺译，吸收索引补充与必要的有出处外部史料，完整、流畅、有据地呈现一个史略。

---
## 第零部分：流水线约定

> translate 编排器注入节选；手工 compose 读本节 + 相关规则章。十二条原则见规则一至十二。

### 执行优先级

规则冲突时从高到低（每条含可执行释义；细节见对应规则章）：

1. **母本完整覆盖**（信息 100%、句序不乱）— 见规则十  
   本批 plan「母本逐句清单」每条 M 均须在成稿中有对应白话；允许合段表达，**禁止跳号、漏句、把后续 M 提前写进本批**。
2. **逐句顺译**（不跳句、不提前、不延后、不重组）— 见规则十、规则四  
   严格按 M001→M… 顺序推进；**名句/金句/关键评价**须「」摘录原文再白话解释（非每句都引，见规则四「何时引」）；不得为求流畅把后文事件挪到前文。
3. **数据准确**（人物、事件、数字、年代不编造不概括）— 见规则三  
   「九年」不写「很久」；不得编造母本未载的硬史实；他书补充须有《书名·卷篇》。
4. **多史料融合**（成稿时按锚点融入，异说独立呈现）— 见规则四  
   顺译中遇异说/背景/母本未载细节，在对应句后插入 1–3 句并标《书名·卷篇》，**回主线**，禁止另起百科段。
5. **风格优化**（口语叙事、明朝那些事儿笔调）— 见规则一  
   朋友讲史式短句与破折号转折；禁止论文摘要腔与百科条目腔。
6. **幽默表达**（自然观察，不硬塞）— 见规则一  
   幽默来自史实反差/荒诞；本批至少 1 处、全书 2–4 处；避开崩薨与盖棺定论。
7. **延伸补充**（有确凿史料且挂母本锚点）— 见下文「外部补全与多源融入」  
   补充不得替代母本句序；无《书名·卷篇》不得写进正文。

### 禁止事项

- **AI 文学腔**：见规则一 + `shared/ai_flavor_words.py` — 同一篇合计或单词 **≥5 次**即 verify fail。
- **结构重组**：不做「先交代背景再讲正文」；开篇大段脱离母本另起叙事。
- **无出处发挥**：外部补全、重要故事、关键评价须有著作 + 卷/篇名。
- **调和异说**：须母本先述，再独立交代《某书》之说 — 见规则四。
- **资料拼接**：无重复、无语义打架、无批注式【】、无百科体。
- **段末破折号**：非 verify 硬失败，仍宜自然收束。

### 程序化硬检 SSOT

| 检查项 | 代码 | 触发 |
|--------|------|------|
| AI 腔词频 | `shared/ai_flavor_words.py` | 终检 `verify_output` |
| 传说/二手表述 | `shared/legend_quota.py` | 同上（无《》的「传说/据说/有人说」等，默认 ≤5 次） |

**不以 prompt 自检替代 verify。**

### 术语

| 说法 | 含义 |
|------|------|
| **母本** | `paragraphs[]` 中 `role=母本` 的 block，经段落索引召回；`母本著作` 标明著作 |
| **补充** | 同条目 `role=补充` 的 block（跨著作合并）；单源条目通常仅母本 |
| **外部补全** | 模型补入的其他著作故事/评论/异说/上下文；须标明著作与卷/篇名；**分批成稿执行见 P2「跨著作补充」** |

### 顺译的定义

**权威定义见规则十。** 简言之：句序守恒、信息点守恒（M001…）、表达可白话重写；段内拆句在 plan「母本逐句清单」完成。

### 文言虚词误读陷阱

判断句结构词（「是为」「是谓」「是乃」等）易被误读为专名。**「是为 X」= 这就是 X**，不是名叫「是为X」。

| 结构 | 含义 | 禁止误读为 |
|------|------|-----------|
| 是为 X | 这就是 X | 地名叫「是为X」 |
| 是谓 X | 这叫做 X | 术语含「是谓」 |
| 是乃 X | 这便是 X | 人名含「是乃」 |
| 此之谓 X | 这就叫做 X | 修饰前缀 |
| 命之曰 X / 号之曰 X | 命名为/号为 X | 专名含该结构 |

自检：译文中若出现 `「是为零陵」` 类引号包裹，几乎 100% 误读，须改白话判断句。

### GLBL 入口与召回纪律

编排器按 GLBL 索引召回；翻译**只使用** `recall` 结果，禁止对拆分 txt 自行切分或扩缩段界。细节见 `historiography-translate/SKILL.md`。

### 太史公曰 / 司马迁评述

标注环节不返工。翻译时：

1. **直引并顺译**原意，不得改成译者盖棺定论。
2. **史家第三人称**：✅「司马迁在《史记》中写到…」「在本传论赞中说…」｜❌「司马迁说…」（像在场者）、论赞改对话。
3. 论赞前可轻过渡，不替代传主生平收尾；禁止译者元叙述（「注意，这里太史公曰…」）。

### 精简四步成稿（默认）

`TRANSLATE_PIPELINE=streamlined`（默认）；legacy 见 SKILL.md。

| 步骤 | 要点 |
|------|------|
| **1 Coverage Ledger** | 程序生成 M 清单（分句、分批、覆盖率） |
| **2 分批成稿** | 一次 call = 本批顺译 + 成稿时自行补他书（提示词驱动） |
| **3 终稿装配** | 两次短 call：`translate_intro.md`（60–250）+ `translate_ending.md`（100–250）；**程序**拼引入+正文+结尾 |
| **4 终检** | verify；语义覆盖仅终稿（长文内部分批） |

**分批**：`TRANSLATE_MOTHER_BATCH` 默认 18 条 M，切批时**优先在母本段落 P 边界**断开（单段过长则段内硬切）。  
**批间衔接**（第 2 批起）：程序注入批次定位 + 上批末段白话（≤600 字）+ 母本前情摘句（默认 5 条 M）；成稿须连续叙事、勿重写前情。  
**出处**：正文须有 **《书名·卷篇》**；异说分述。  
**promote/sync 分离**：试跑 `pending_review`，人工 promote 后再 sync。

**叙述者 framing**：正文分批成稿注入三层——**叙述者**（语气/受众）→ **本步任务**（输入输出）→ **冲突时优先级**（7 条）；硬禁令与术语见 P0 摘要。SSOT：`narrator_framing.py` + `rule_bundle.py`。不用「资深研究员」学术人设。

> Legacy（ABCD / 两阶段 / 比稿 / 必现词）：见 SKILL.md。

### 外部补全与多源融入（权威）

**三层来源：**

| 层级 | 来源 | 要求 |
|------|------|------|
| 母本层 | `work == 母本著作` 召回文本 | 底本主线；100% 覆盖、句序不乱 |
| 索引补充层 | `work != 母本著作` | 仅不同观点/评价或新增故事/视角；锚点插入、去重 |
| 外部补全层 | 可标明出处的史料 | 必要上下文/故事/评价；须著作+卷篇；禁编造硬史实 |

不按固定篇幅比例写作。补充与母本同事实不写；冲突则母本为准、句末异说。成稿须一段一事、无重复、无语义打架。

**母本去重门禁（写前必问）：** 拟补充的每条，先对照 **当前母本著作、当前卷** 召回原文——该事实/细节/背景是否 **已有且够清楚**？已有详述 → **不补**；未载或仅一笔带过、读者会懵 → 可从他书补（须《书名·卷篇》）。异说仅在与他书 **确有不同** 时写。

**准入场景（仅此五类）：** 缺事件背景｜缺人物首现介绍｜缺叙事承接｜母本无结局但正史有｜后世公认影响助理解人物。除此之外不主动扩写。

**锚点原则：** 所有补充依附某句母本；禁止连续大段脱离母本另起叙事；补完即回主线。

**防幻觉（成稿）：**

| 阶段 | 纪律 |
|------|------|
| **成稿** | 母本信息点 100% 覆盖；他书补充须《书名·卷篇》；禁无《》的「据说/相传」；禁跨时代拼接；禁与母本同事实的重复叙述 |

**补充三级：** 一级（必）背景/人物/地名/制度｜二级（荐）影响/同时代/评价，有出处且挂锚点｜三级（慎用）学界延伸，仅母本过短且仍挂锚点。

### 重复判定

主体、事件、结果一致 → 重复，不得再写。仅当有**新细节/评价/时间/原因/史料观点**时可再叙述。

### 允许压缩（表达层）

压缩表达不压缩信息；M 清单仍须逐句 √。

**可压：** 重复修辞、套话、重复问答。  
**禁压：** 人物、事件、地点、数字、制度、评价、结论。

## 规则一：风格定位

**核心：** 《明朝那些事儿》笔调 — 现代口语讲古代故事，非论文、非文言直译、非百科条目。

**具体要做到：**
- 饭桌上讲史式口语；短句+破折号转折+偶尔反问
- 现代比喻适度（「这要放今天早被撤职了」），勿过度现代化
- **收着写**：幽默来自史实反差/荒诞/巧合，慎用「居然」「简直」等程度副词

**引号规范（硬约束）：**
- **起草：** 引用母本/史料原文 → 直角引号「」；白话改写、术语/概念 → 弯引号“”。书名 → 《》。
- **落盘校验（程序）：** 对照 `史料原文` 复核引号内文本——能在母本找到的改为「」，找不到的改为“”；各类误用引号（含白角/弯引/ASCII）由终检程序统一纠偏，不依赖模型自改。
- 禁 `「"…"」` 嵌套；禁 Markdown `**` 加粗（小程序只对「」内原文自动加粗）。

**加粗（小程序 SSOT）：** 仅「」内史料自动加粗；**禁止**正文用 `**…**` 手动加粗。

**AI 腔（频次硬检）：** 「此外」「值得注意的是」「历史长河」「命运齿轮」「注定」「必然」等 — 见 `shared/ai_flavor_words.py`，≥5 次 fail。

**译者隐身：** 禁「我们来看看」「今天要聊」；禁旁白式开篇（「在司马迁的笔下…」）；✅ 直接切入人物或母本首句。不禁正常时空定位的「在…」。

**示例：** ✅「轩辕的办法很粗暴——原文写「习用干戈，以征不享」，谁不来朝贡就打谁。」｜❌「轩辕采取军事手段，诸侯纷纷归附。」

### 幽默规范

幽默来自史实本身的荒诞/无奈/巧合，非硬塞笑话。**调味料不是主菜。**

**密度：** 短篇 1–2 处、长篇 2–4 处，均匀中段；避开开篇、崩薨、伤亡、盖棺定论、篇末。

**示例：** ✅「九年过去，水一点没治好——这要放今天早被撤职了。」｜❌「这位爷二话不说就冲」「居然…可真是…」（油腻）

**分批成稿阶段就要口语化**，不要等终稿装配再润色。

## 规则二：结构完整

**核心：** 有头有尾 — 家世出身 → 时间线事迹 → 去世与身后事。

**过渡性人物开篇：** 回答「为什么要读他」— 定位/矛盾/后世影响，不必论文腔。

**无去世信息：** 自然收束，如「此后记载就少了」。

### 本传主退场完整性

**原则：** 每位主人公须有退场落点；**同篇退场事实只写一次**；正文已写退场则禁止篇末再补。

| 检测 | 动作 |
|------|------|
| 母本**已有**退场（崩/薨/卒/自沈/诛等） | 禁止尾部再补退场；收尾只做情节/分量收束 |
| 母本**未有**退场，正史有载 | 篇末 **1 句**白话收束，禁止发挥扩写葬地细节 |
| 均无记载 | 可「史载此后不详」；禁编造崩葬细节 |

**示例：** 黄帝母本无崩 → 篇末 1 句补崩葬｜屈原母本已写自沉 → 禁止篇末再写｜颛顼开篇交接段：前君卒/立压一两句，不展开前君小传。

编排器注入退场补全的实现细节见 `historiography-translate/SKILL.md`。

### 交接双挂段（镜头不对称）

标注双挂 ≠ 两边都展开。卒/立事实不丢；**非本传主侧压过渡，本传主侧展开。**

| 角色 | 位置 | 写法 |
|------|------|------|
| 后君 | 开篇 | 前君卒/立一两句 → 立刻进本君本事 |
| 前君 | 结尾 | 详写本君退场；后君「立」一带而过 |

❌ 开篇写前君长篇政绩再提后君立｜✅「威王去世，子宣王立。」然后接宣王本事。

**短条目（母本 < 10 句）：** 补充挂锚点不阻断节奏；外部补全段数 ≤ 母本句数；段间须有叙事承接，禁「此外《某书》还记载…」拼接。

### 内容延伸

服从优先级第 7 位与锚点原则：挂母本句、补完回主线。

**铁律：** 仅确凿史实｜禁编造事件｜禁替古人加内心戏｜禁硬凑典故｜禁强行升华。无材料则忠实顺译，不强拉硬扯。

## 规则三：内容完整性与数据准确

人物、事迹、数字、年代一个不能少；不概括、不编造。

- 「九年」不写「很久」；递进数字完整保留
- 不确定写「大约」「据《史记》记载」；原文没有的不编
- 禁脑补评价；亲属关系须来自母本/补充，不确定宁可不写

---

## 规则四：原文融入与引用规范

**核心：** 关键原文自然穿插白话叙事；非每句都引。禁【】引文标记。

### 何时引 / 何时不引

**不引（直接白话）：** 姓名、家世、基本身份官职封地。

**可引并注明出处：** 金句、关键评价、精妙不可替代表述、异说差异。

**优先级：** 名句 > 历史评价 > 精彩表达 > 多版本差异 > 其余白话叙述。

**频率：** 长篇约 10–15 处；短篇只留最关键，不凑数。

**口诀：** 不引只损失「原文怎么说」→ 不引；损失情感冲击或判断精确性 → 须引。

### 异说（P0 硬约束）

> 分批成稿：异说分述纪律已并入 P2「跨著作补充」专节；本节为全书 SSOT，注入时不重复展开。

- **禁止**融合折中版本；母本先述，再「《某书》则认为…」
- 成稿时遇异说须分述呈现，禁止调和成一个版本

### 出处格式

- ✅「《史记·五帝本纪》原文说「生而神灵」」（顺译母本用**母本卷全名**）「《尚书·尧典》则…」「《汉书·高帝纪下》载…」
- ❌ 顺译母本时泛称「《史记》说…」（应写具体卷篇，如《史记·孝武本纪》）
- ❌ 无《》的「有资料说」「据说」「原文说」（人物对话叙事转述除外）

**引出方式：** 「按《某书》的写法…」「《某书》原文说「…」——」「《某书·某卷》补了一层意思…」

**执行：** 搜【须为 0】；搜「原文说」检查是否误引基本信息。禁批注循环「原文说…就是说…」。

## 规则五：人物刻画

不神化不矮化；写出弱点、矛盾、决策纠结（正史有暗示可合理推测，禁虚构）。

**指代轮换：** 姓名 > 官职/身份 > 代词；描述性称呼（这家伙/这位爷）全文 ≤3 次，同段 ≤1 次。

---

## 规则六：纯叙事

全文叙事体；禁小标题、分节号、列表符号。正文首段禁 markdown 标记；第一句须叙事句非译者评论。

### 前置引入（权威）

**作用：** 笼统定位朝代/人物/出处，自然过渡到母本；**不展开**正文将写的具体事件。引入不计入母本覆盖。

**篇幅：** 一段，60–250 字（薄母本 1–2 句）；超 250 字或两段旁白 → 结构重组。

**写作提示词：** `historiography-translate/prompts/translate_intro.md`（注入文明/朝代/名称/出处；**不用** plan「前置引入素材」程序套模板）。末句落到完整卷篇名即可；**换说法、换重心，禁止固定收束公式**（禁「对某某生平的描写」「从家世才名写起」「记下了这个人」等）。

禁元叙述（「本条 N 段」）、禁分节（「一、背景 二、事迹」）、禁在引入里讲完第一件大事。

**结尾：** 见 `prompts/translate_ending.md`——凭史略名称/文明/朝代写人物总结（100–250 字）；**不注入正文**；不报著作卷篇；禁「这一跳」类悬空指代。

### 段落节奏

| 阶段 | 默认 |
|------|------|

## 规则七：六类触发条件（含现代地名标注）

遇以下六类须自动处理：

**一、制度** — 禅让、封禅、巡狩、五刑、四岳等解释背景  
**二、地名** — 格式「古名（今…）」；首次标注；不确定写「约在今…」  
常用地名：涿鹿→河北涿鹿，空桐→甘肃平凉崆峒山，幽陵→北京以北，交阯→越南北部，流沙→甘肃西北，旸谷→山东日照，昧谷→甘肃一带，崇山→湖南张家界，三危→甘肃敦煌，羽山→江苏连云港，妫汭→山西永济，苍梧之野→湖南宁远九嶷山，零陵→湖南永州，岱宗→山东泰山，江水→四川一带，若水→四川雅砻江  
**三、人名** — 首次简要介绍  
**四、器物** — 璿玑玉衡、五瑞、六宗等  
**五、事件** — 阪泉之战、涿鹿之战等背景  
**六、补充** — 长补充须出处；不确定写「一说…」

## 规则九：通假字处理

首次出现可标 `原字（通「今字」）` 或直接顺译今字。**已顺译今字不再加通假标注。**

- 二选一：保留原字+标注，或顺译 — **不得** `擒（通「擒」）`
- 同一通假字一篇只标一次；点明原字可用「《史记》作「禽杀」，即擒杀」

## 规则十：逐句顺译原则（灵魂规则）

**最重要的一条。** 顺译 ≠ 字对字直译。

**三层次：** ❌ 硬直译（翻译腔）｜❌ 意译跳句重组｜✅ 顺译（句序+信息+口语重写）

1. **句序守恒** — 母本先说什么先译什么  
2. **信息点守恒** — 每句 M 须传达；表达层压缩见第零部分，禁压实质信息  
3. **引用≠逐句引用** — 见规则四  
4. **三层区分** — 母本顺译｜索引补充（锚点+异说）｜外部补全（出处+卷篇）

**内部 Checklist（不写正文）：** 顺序｜覆盖｜不提前/延后/跳句｜事实不变｜清单 √

**三关自检：** ① 清单全 √ ② 无【】/批注式 ③ 地名/通假已处理

**口诀：** 原文前后内容对调位置 = 违反顺译。

## 规则十一：完成标准（Definition of Done）

写完后逐条勾选（可先段内自查）。

### 验收 Checklist

- ✓ **前置引入** — 见规则六
- ✓ **母本 100% 覆盖、顺序一致、无漏句** — 见规则十
- ✓ **异说分述** — 冲突观点独立呈现，见规则四
- ✓ **无重复、无事实冲突** — 见第零部分重复判定、规则三
- ✓ **引用有出处** — 《书名·卷篇》，见规则四
- ✓ **无 AI 腔、无百科体、无翻译腔、像原创散文** — 见规则一、四
- ✓ **退场不重复** — 见规则二
- ✓ **文风词表** — `ai_flavor_words.py`，≥5 次须改
- ✓ **通假** — 禁 `A（通「A」）`，见规则九
- ✓ **参考著作** — **程序拼接**（模型勿手写）：母本卷为首，其余取正文《》出现顺序去重编号；独立成段：

```
参考著作：
1. 《书名·卷篇》
```

**粒度：** 每条须为《书名·卷篇》；禁仅母书名（如《史记》《汉书》）。同一母书多卷分别列条；若已有任一卷篇，裸母书名不得入列（程序 `dedupe_reference_works` 去重）。顺译母本引用正文时也应用母本卷全名，避免泛称污染列表。

禁 `*参考著作：*`；正文末段后空一行再写「参考著作：」。

### 程序复检

终检 `verify_output` 覆盖字段、字数、参考著作、禁词、传说配额等 — **不以人工 checklist 替代 verify**。

## 规则十二：JSON 产出与汇总规范

**唯一交付物是 JSON。**

### 单条 JSON

- 路径（现行）：`data/11新标注条目翻译/{史略ID}_{史略名称}.json`
- 版本归档：`data/11新标注条目翻译/_versions/{史略ID}_{史略名称}/`
- 历史留档（V1，不再写入）：`data/04史料翻译/`
- 字段：`史略ID`、`翻译详情`（Markdown + 文末「参考著作」）；编排器写入 `史料原文`、`原文出处`
- 写入后须 `verify`

### 汇总 JSON

- 路径（V1 历史）：`data/04史料翻译/史略翻译_汇总.json`
- V2 顺译不写汇总；verify 后 `promote` 至 `_versions/`

### 完整性

JSON 可解析无截断后标记 done；长文 `翻译详情` 须完整；汇总重建失败不覆盖旧文件。

### 编排器分块与喊数

- 长文超阈自动分块（`TRANSLATE_CHUNK_*`）；可从已完成块续跑
- 动笔前可自检一行喊数，**禁止**写入 `翻译详情`
