# 史略翻译规则

> **写作 SSOT** — compose 与 translate 共用本文件前半「写作规则」。  
> **历史内容 QA / 认知边界** — [`历史内容编辑合同.md`](./历史内容编辑合同.md)（十条 · L1–L5 · A–G）。  
> **语义守恒** — [`历史翻译质量宪法.md`](./历史翻译质量宪法.md)（八大守恒）。  
> 冲突时：史实 / 时间线 / 认知边界以**合同 + 质量宪法**为准；怎么写以**本文件**为准。  
> 风格参考：现代中文**历史叙事文**的节奏与画面感（可读如《明朝那些事儿》的信息密度，但**作者不出场**）。共十二条写作原则 + 第零部分流水线约定。  
> 总目标：以母本为底本顺译；在有可靠增量时用他书丰富；完整、流畅、有据。  
> **自然 ≠ 说书场；生动 ≠ 戏谑；有温度 ≠ 对读者喊话；现代 ≠ 网络化。**  
> 读者应感到「这是一篇好读的历史文章」，而不是「有人在台上跟我说书」。
> **编排器路径 / 分块 / JSON 字段细则**见文末「附录：编排器与运维」（默认不注入写作 prompt）。

## 第零部分：流水线约定

> translate 编排器与 compose 手工翻译共用本节；**十二条原则见下文规则一至十二**。  
> **三层勿混用：**（1）终稿质量维度 （2）阶段职责 （3）冲突裁决序——见下列各小节。

### 终稿质量维度（七项）

> 标题兼容旧称「成稿硬门槛」；下列是**终稿**应同时具备的质量维度，**不是**「每一阶段都必须全部做完」的任务清单。

1. **母本信息完整** — 有效信息点不得无故遗漏；人物/事件/地点/时间/数字/因果/评价/结果不因润色消失。信息守恒 ≠ 逐句字面翻译。  
2. **顺序与结构守恒** — 母本主线按原先后推进；不因说书把后文提前；补充可挂锚点，不得改主线时间/因果。  
3. **事实与史源准确** — 不编造；外部硬史实须出处；异说分述、禁止调和。  
4. **原文与白话自然融合** — 默认流畅白话；金句/诗词/誓词「概括主旨 + 直角「」保留文言」；禁止整段白话译诗交差；禁止「原文→同义白话」对照作业体主腔。  
5. **有价值的史料增量** — 有可靠且有阅读价值的异说/背景/异评时，应主动融入；**没有有价值增量时，不得为「丰富」硬补**；不以补全书目数量、篇幅比例为 KPI。  
6. **内容可读** — 完整但非资料堆砌；转折清楚；不因口语牺牲事实/顺序/因果。  
7. **现代叙事质感** — 第三人称历史叙事；节奏/场面/旁白是手段，**不是**对读者喊话或说书场表演（见规则一）。

> **第 5 与第 6**：第 5 管「多书怎么摆、有无增量」；第 6 管「读感」。  
> **阶段分工：** Phase1 主责维度 1–4 的骨架（本阶段不写他书、不强制幽默）；Phase2 `polish` 完成说书润色，并在有价值时补 5，落实 6–7。**终稿按七维验收**；不得因「七维全满」要求 Phase1 提前做 Phase2 的事。

### 冲突裁决序

当两个要求无法同时满足时，按下列顺序裁决（**不是**「低层可随意牺牲」）：

**历史事实准确性 > 时间线与因果准确性 > 史源与证据边界 > 母本核心信息覆盖 > 信息关系与顺序守恒 > 阅读清晰度 > 现代叙事质感 > 文学修辞**

例：不能为流畅改时间线；不能为幽默删关键事实；不能为丰富加无出处史实；不能为「生动」重排核心事件或对读者喊话；不能为保字面牺牲基本可读。

### 禁止事项（硬 / 软）

**硬禁止（违反即失败或必须改掉）：**

- 无出处发挥硬史实；外部补全无《书·卷》
- 调和异说成一个折中版本
- 用正在翻译的**母本同一卷**作外部补全
- 结构重组：开篇大段脱离母本另起叙事
- 为「写厚 / 丰富」整段删母本情节或以一句概括顶替连续多段
- 正文 Markdown `**加粗**` 或章节标题（`#` / `##`）；为加粗把白话塞进「」
- **成文洁净（读者正文硬禁止）：**  
  - 禁止说书场身份：`诸位看官` / `列位看官` / `各位听客` / `今儿个` / `接着上回` / `上回讲到` / `下回再说` / `您说邪门`  
  - 禁止加工元叙述：`本篇以…为主线` / `异同处参看` / `关键关节按时间线` / `以母本为准` / `结构账本` / `Phase2` 等编排说明（书目只留文末「参考著作」）  
  - 禁止市井称谓：`这位爷` / `这位主儿` / `他娘`（作母亲俗称）/ `这哥们` 等网络化称呼  
- 资料拼接感：批注式【】、百科条目体、同事实换说法双写
- **标点硬错（程序可愈合，写作仍须避免）：**  
  - 禁止 `：，` / `:，`（冒号后不得紧跟逗号）  
  - 禁止段首 `——`（破折号不得开段；评论接在上段句后或删掉破折号留正文）  
  - 禁止 `」` / `”` 后多写逗号再破折号：应为 `……。」——点评`，不得 `……。」，——点评`  
  - **禁止句末引号外再加逗号**（对齐 GB/T 15834）：引语内已有 `。？！` 收束时，后引号外不得再加 `，`（也不得加 `。`）。  
    - ❌ `……所以我哭。”，“你儿子为什么被杀？”，老妇人答道：`  
    - ✅ `……所以我哭。”“你儿子为什么被杀？”老妇人答道：`（连引无叙述语，直接衔接下一条前引号）  
    - ✅ `……所以我哭。”旁人又问：“你儿子为什么被杀？”`（中间加叙述语时，后引号外同样不加逗号）  
    - ✅ 短语作句子成分时才可在后引号外加逗号：`所谓“假齐王”，本质就是挟势邀封。`（引内无句末点号）

**软约束（宜遵守；段末破折号等不再作 verify 硬失败）：**

- 少用 AI 文学腔（频次见下表；≥5 次硬失败）
- 段末不宜滥用破折号收束
- 少用「说白了」等**无意义过场词**（滥用即失败倾向）；释义旁白须自然接叙，见规则一
- 引号后破折号：忌同义回声作业体；宜融入叙述（偶发增量破折号可保留，verify 软警告不硬拦）；**有增量时用 `」——` 直连，不要 `」，——`**

### 写作纪律与程序阈值（模型必知）

> **门禁是兜底，不是替你记规则。** 下表数字是**程序失败阈值**，不是写作 KPI（勿为凑命中而砌句）。

**纪律（先记这些）：**

1. 母本有效信息都要传到译文；按 M 清单推进，不跳过核心信息。  
2. 必现词在白话里**自然出现**；禁止为凑锚点砌大量短「」。  
3. 直角「」只装史料原文；白话对话用 “”；**未译加工、直接引用的原话（含某人曰）必须「」**；诗赋/誓词先概括再「」引文言。  
4. 他书补全挂母本锚点，只写相对母本的增量；禁母本同一卷。  
5. 无《》锚点时少用「传说/据说/相传/有人说」。  
6. 不为篇幅、幽默次数、旁白长度、引用书目数量而硬加内容。

**阈值表（与程序硬检对齐 · 防遗漏门禁，非写作目标）：**

| 项 | 阈值 / 门槛 | 代码或阶段 |
|----|-------------|------------|
| AI 腔词 | 单词或合计 **≥5 次** → fail | `shared/ai_flavor_words.py`；Phase2 + 终检 |
| 传说等二手表述 | 无同句《》时合计默认 **≤5** | `shared/legend_quota.py` |
| 必现词 | ≤4 个/条；默认每项 ≤4 字（氏名 ≤5）；L0 禁释词不入选 | plan 落盘程序提取 |
| 硬锚点命中 | 全局 **<65%** 才阻断（长条 ≥80M 为 60%） | Phase1 / 终检 |
| 批内语义覆盖 | 传达率 **≥90%** 或未传达 ≤1 | Phase1 每批 |
| 全篇语义覆盖 | 传达率 **≥80%** 或未传达 ≤3 | 合并后轻量补验 |
| 「这家伙/这位爷」 | 全文 **≤3** | Phase2 |
| plan 白名单外《》 | 默认 polish **不**作必须覆盖清单；质检警告 | enrich / 终检 |

### 术语

| 说法 | 含义 |
|------|------|
| **母本** | `role=母本` 的召回正文；`母本著作` 如 `01史记` |
| **补充** | 同条目 `role=补充` 的跨著作块 |
| **外部补全** | 从**母本卷以外**正式史著选取的增量；须《书·卷》；**禁止**同卷再「补」 |
| **信息守恒** | 母本事实、关系、因果、结论等有效信息不被无故删除 |
| **顺序守恒** | 母本主线先后不被改写 |
| **表达重写** | 可改句式/口吻/段落，不得改信息与关系 |

### 顺译的定义

**顺译 ≠ 字对字直译。** 权威展开见规则十。  
核心：**信息守恒 + 顺序守恒 + 关系守恒 + 表达可重写**（现代叙事口语质感）。  
允许合并修辞重复、拆长句、调现代汉语句法；不允许删有效信息、提前/延后核心事件、偷换主客体、改因果。

### 文言虚词误读陷阱

「是为 X」=「这就是 X」，**不是**名叫「是为X」。同理：是谓 / 是乃 / 此之谓 / 命之曰 / 号之曰。

- ❌ 「是为零陵」当地名一整串  
- ✅ 「这就是零陵」  
译文里若用「」包住「是为…」几乎必是误读。

### 翻译总流程

**默认路径（现行）：**  
`recall → source_plan（默认不挖外部补全）→ Phase1 draft_mother → Phase2 polish（整篇一次）→ Phase3 qa → Phase4 repair → Phase5 recheck → verify/sync`

写作侧可记为：

0. **前置引入**（约 100–250 字，软范围）：首段精简概括、直接入题；禁「今天要讲」类场次元；不展开正文情节。  
1. **Phase1 母本顺译**：骨架；信息覆盖、顺序不乱；**本阶段不写他书、不强制幽默**。  
2. **Phase2 整篇润色**：说书化；可压缩措辞；**禁止整段删情节**；有可靠增量时自挖他书并挂锚点；文末列实际用到的参考著作。  
3. **Phase3–5**：质检 → 定向修复 → 复检。

旧「plan 选题 + enrich 打卡」为可选回退，见下节。

### 成稿与质检修复 SOP（translate）

**冲突裁决**见上文「冲突裁决序」。流畅性不得凌驾于时间真实性。

**纪年并注公元（硬）**：正文写出年号年 / 帝纪年 / 国号纪年时，**每一个这样的年份**都紧随并注公历，格式统一为 `汉二年（前205年）` / `贞观三年（公元629年）`；禁止只给个别年注公元。详见《历史内容编辑合同》G⑤。

| 阶段 | 产出 | 要点 |
|------|------|------|
| Phase1 `draft_mother` | 母本顺译 | 仅母本；信息覆盖与顺序优先；不写他书 |
| Phase2 `polish` | 翻译详情 | **默认整篇一次**说书润色；可自挖有价值补充；可压缩措辞、**禁止整段删母本情节**；漏段由程序**定位夹缝**，模型按当前文风补情节（**禁止**理解为程序把母本原文粘贴回正文）；有补充须列「参考著作」；**不注 plan 补全清单、不分章** |
| Phase3 `qa` | `*.qa.md` + `*.qa.json` | **只找问题、不改正文** |
| Phase4 `repair` | 修复后成稿 + `*.repair.md` | **定向修复**；禁止大幅重写 |
| Phase5 `recheck` | `*.recheck.md` + `*.recheck.json` | 复核；通过才建议入库 |

**策略**：轻前序控制、重质检。`source_plan` **默认不再挖外部补全**（仅程序生成母本清单骨架）；补充交 Phase2，史源/时间线交 Phase3–5。  
若需旧「plan 选题 + 锚点打卡」：`TRANSLATE_PLAN_EXTERNAL=1` 且 `TRANSLATE_PHASE2_MODE=enrich`（**非默认**）。

### 内容层级与取舍

| 层级 | 要求 |
|------|------|
| 母本层 | 底本主线；100% 覆盖、句序不乱 |
| 索引补充层 | 异说或新故事；锚点插入、去重 |
| 外部补全层 | 母本卷以外正式史著；主动丰富；禁同卷 |

不按固定篇幅比例。无增量不写；冲突则母本先述、另句异说。

### 外部补全与锚点原则（唯一完整定义）

**目的：给读者「知识增量」**，不是给母本故事雕花、凑热闹。读者价值优先于「他书也写过」。

**当用三类（硬优先）：**

1. **异说 / 冲突记载** — 他书与母本对同一事的**说法实质不同**（人物、因果、结果、时间、制度结论有分歧），须分述，不调和  
2. **背景** — 母本未交代或一句带过的时势、制度前提、人物关系、地理/政局语境（读完能更好理解主线）  
3. **评价差异** — 史家臧否、论赞、后世史评与母本评价立场不同  

**慎用 / 默认 false：**

- **场面雕花**：母本已有完整事件，他书只是把对话、动作、气氛写得更细——**无阅读价值，勿采用**  
- **更简平行纪**：他书对同一事写得比母本更短、无新信息（常见《史记》详而《汉书》略）——**简略不是补充**  
- **无实质异文**：仅用字/通假/称谓差异（如蛟龙↔交龙）而史实结论相同——**不得**当异说  
- **同书互抄同情节**：把《史记》《汉书》里同一故事换出处再讲一遍——**不得**当补全  

**真正的补充：** 更新的信息、更丰富的信息、不一样的视角、实质冲突的另说、异评。  

**检索机制（第一层 · 如何找）：**  
通道只是搜索路径，**不是**「每条通道都要交采用项」：A 同书非本传 → B 近时杂史辑佚 → C 外传故事 → D 近古议论批判 → E 类书引佚。挖不到可跳过。  

**重要性门槛（第二层 · 防回形针灌水）：**  
采用:true 还必须挂住主轴理解的一轴：开国合法性 / 重大制度政策 / 关键战局用人 / 历史评价冲突 / 政治神话的构造或辩伪。  
挂不上 → false（碎闻、猎奇神异、配角八卦、为凑通道硬凑者一律否）。  
**宁缺毋滥**：少而重要优于多为灌水；神话志怪默认 false，仅当关涉合法性叙事或有近古辩伪时才可 true。  
先古代材料，禁止今人观点；简略平行纪不是补充。

**准入：** 正式史著有《书·卷》+ 相对**全书母本**（整份 M 清单，含后文）属于上列当用三类 → 可 `采用:true`；主体/事件/结果与母本任一处相同且无分歧 → 重复，勿再写；**禁止**前半锚点用他书预写母本后文；**出处不得为正在翻译的同一卷**（同书他卷仅当确有冲突/另说/背景/异评时可用）。

**补充范围限定（硬）：** 只补「冲突 · 另说 · 背景 · 异评」；不要补母本已有同情节的细描，也不要补无史实分歧的异文。

**锚点：** 补全须挂某句母本；补完立刻回主线，不得连续大段另起炉灶。

**防幻觉：** plan 列候选再标采用，不确定 → false；enrich 事实边界 = 母本顺译 + plan 已采用项；禁 plan 外硬史实；禁无《》的「据说/相传」撑史实。

### 重复判定

主体 + 事件 + 结果一致且无分歧 → 视为重复，不得再写。仅当有**冲突另说 / 背景 / 评价差异**（或改变理解的另说细节）时允许再述。  
判重范围是**全书母本**（含锚点之后的后文），不是「只和锚点前后几句比」。  
编排侧（默认 polish）：**plan 不挖外部补全**；Phase2 润色自挖补充并须列「参考著作」；Phase3–5 质检收口。  
旧路径（`TRANSLATE_PLAN_EXTERNAL=1` + enrich）：宏观选题 → 全书母本判重 → 挂锚嵌入。  
已判重降级项不得被长文配额 floor 翻回。

### 允许压缩（表达层）

压缩修辞性重复，**不压缩**人物、事件、地点、数字、制度、评价、结论。清单编号仍须逐句 √。

## 规则一：风格定位

**核心：** 现代中文**历史叙事文**——第三人称、作者隐身、历史显身。可读、有画面、有节奏；**不是**论文、不是文言对照、不是百科，也**不是**说书人上台对观众讲话。

> **总纲：** 自然，不等于口语表演；生动，不等于戏谑；有温度，不等于与读者对话；现代，不等于网络化。  
> 自然感来自**句法和叙事**（拆长句、场面、因果递进），**不来自俚语和看官套话**。

- 短句、场面、转折清楚  
- 偶尔现代比喻，不过度现代化、不网络化  
- 幽默来自史实反差，不硬塞、不调侃人物（见下）
- **遇生僻/古怪处要加释义旁白**（见下）：叙述中自然点破，非干译了事；旁白仍是第三人称，不是「您看/您说」

### 成文洁净（硬）

最终正文只能有**读者需要知道的信息**。禁止把加工过程写进文章。

| 禁止 | 例 |
|------|-----|
| 说书场喊话 | 诸位看官、列位看官、各位听客、今儿个咱要讲、接着上回、下回再说 |
| 加工说明 | 本篇以《…》为主线、异同处参看、关键关节按时间线铺开、专名以母本为准 |
| 市井称谓 | 这位爷、这位主儿、他娘（俗称母亲）、这哥们、忽悠住了 |
| 提示词泄漏 | 编辑已就位、结构账本、Phase2、八大守恒 |

史源异说若进入正文，须是**情节所需的分述**（如「一说…」挂认知边界），不是「本文综合了哪些书」的编辑备注。书目统一放文末「参考著作」。

### 释义旁白（硬鼓励 · 与 L0「禁释」不冲突）

**判准一句话：** 今人读白话仍可能卡住、误解或觉得离谱 → 加旁白；人人都懂的基础文言 → **直接顺译，禁止再解释**。旁白是**条件触发**，不是「见生僻必写」。

**该加（触发 · 可补充你原先未列全的）：**

| 触发 | 说明 | 例方向 |
|------|------|--------|
| 生僻字 / 生僻词 | 今人不熟的字形、词义 | 通『擒』、僄悍、阬 |
| 古文词 / 古语 | 文言固定说法、古称谓 | 太公、刘媪、足下 |
| 古官职 / 古制度（首次） | 不知职权就听不懂情节 | 亭长今比；禅让一句说清 |
| 人名身份（首次生僻） | 只出名字不知是谁 | 某为某地守将/某客；生僻读音可括注 `郦食其（食其，音 yì-jī）` |
| 地名（首次须今地） | 见规则七 | `幽陵（今…）` |
| 器物 / 礼制动作 | 今人不熟 | 璿玑玉衡；面北称臣 |
| 异名 / 改名 / 谐音 | 不点破会对不上号 | 郦邑改新丰；柏人↔迫人 |
| 看起来奇怪 | 名号怪、记载玄、表述突兀 | 龙气、左股七十二黑子 |
| 不符合常理 / 易误解 | 今人直觉不通 | 无名氏称谓透出寒微 |
| **著名典故 / 成语出处** | 正文已写出情节，且该情节确已凝固为**通行**熟语时，宜点破「这就是后来常说的××」；**不为凑标签而找成语** | 斩蛇起义、约法三章、破釜沉舟、背水一战、四面楚歌、鸿门宴等 |

**绝不加旁白（L0 · 过度解释即失败）：**  
下列词**直接写成白话**，禁止「X 就是 Y / X——Y」式拆词注释，也禁止为它们单开旁白：

| 类 | 词例 | 正确做法 |
|----|------|----------|
| 死讯用语 | 崩、薨、卒、殂 | 直接写去世/死了（可按身份选词，但勿注释「崩就是天子死」） |
| 即位套语 | 立、即位、登位 | 直接写立为…/登上… |
| 「是为」系 | 是为、是谓、是乃、此之谓、命之曰、号之曰 | **正确顺译**（「这就是…」「称作…」）；禁止解释「是为」二字，更禁止把「是为X」当成地名整串 |
| 范围/否定虚词 | 咸、弗、莫、皆、悉、乃、遂、于是、既、已、未 | 融入句子（都/不/于是…） |
| 通识政治词 | 诸侯、天子、天下、百姓、万民、帝王 | 直接用，勿「天子就是皇帝」 |
| 浅显应答 | 善、诺、唯、然、否、可 | 直接写成好/行；禁「「善」——好」 |
| 已是白话的句子 | — | 禁止再旁白复述一遍 |

> 记法：旁白解释的是**读者可能不懂的名物称谓、古怪处，以及「情节写了但没对上号」的著名典故/成语**；不是给中学文言文虚词做词典。

#### 著名典故 / 成语旁白（宜 · 条件触发）

母本常只记事件过程，不标后世成语名。读者读完白话仍可能不知道「这就是××」。

**何时加：**

1. 该情节在后世已凝固为**通行成语 / 典故名**（中学课本、日常用语常见）。  
2. 正文已把经过写清楚，但**未出现**该熟语字面，或出现了却未点明「即此典故」。  
3. 本传主镜头下的标志性事件优先（如高祖：斩蛇、约法三章；项羽：破釜沉舟、四面楚歌）。

**何时不加：**

- 冷僻书袋、生造标签、非通行熟语 → 不加。  
- 同一典故在本篇已点破过 → 后文再遇只顺叙，不重复旁白。  
- 禁止用典故旁白替代情节本身（先叙事，后点名；或短句嵌名后接叙）。

**写法：**

1. **先叙后点**（优先）：情节写完，接一句点破。  
   - ✅ `……跟随的人也一天比一天敬畏他。后人把这件事叫「斩蛇起义」——汉朝开国传说里最响亮的一笔神异。`  
   - ✅ `……其余秦法一概废除。——这便是后来人人皆知的「约法三章」。`  
2. **嵌入熟语**：若自然，可在叙述中直接用成语，再半句补足所指。  
   - ✅ `项羽下令砸锅沉船，这就是后来常说的「破釜沉舟」。`  
3. **篇幅**：点名 + 半句分量即可，通常 **≤40 字**；单处旁白 **≤200 字是防失控上限，不是写作目标**。  
4. **标点**：点出典故名可用直角「」（作熟语标签，非史料长引）；勿另起「注释段」、勿百科词条体。  
5. **禁止**：只写情节不点名（通行典故）；或反过来只甩成语不交代经过；或借典故发长篇议论；或冷僻/生造标签。

**写法（硬 · 通则）：**

1. **自然融入**：旁白嵌在叙述里，像叙述者随口点一句；忌词条注解体、忌另起「注释段」、忌「您看/您说」。  
2. **过渡要自然**：用接叙、破折号点破、短句补一句即可。  
   - ❌ 滥用无信息量的过场词：`说白了` / `这么说很明白` / `换句话说` / `说实话` / `你想啊`  
   - ✅ `这名字听着就不像正经名字——太公就是“刘老头”……`  
3. **篇幅**：单处旁白 **≤200 字（上限，非常规目标）**；典故点名类宜更短（见上）。勿借题发挥。  
4. **内容**：只做**事实性白描**；❌ 长篇议论、道德评判、空泛感叹、编剧式心理。  
5. **出处**：释义旁白**不强制**挂《书·卷》；掺他书异说/硬史实增量则仍须出处。典故点名本身不强制出处。

**正例：**  
`他爹叫太公，娘叫刘媪。这名字听着就不像正经名字——太公就是“刘老头”，刘媪就是“刘老太”，连个正式名字都没留下。可见这家人在乡里实在不起眼。`  
`泗水亭长——搁今天，差不多等于乡镇派出所所长兼招待所所长。`  
`柏人，谐音就是“迫人”，被人逼迫的意思。`  
`那年太上皇去世。`（✅ 不写「崩，就是天子死了」）  
`……其余的秦朝法令，一概废除。——这便是后来人人皆知的「约法三章」。`（✅ 典故点名）  
`后人把这件事叫「斩蛇起义」。`（✅ 情节已写清后再点破）

**反例：**

| 类型 | 例 |
|------|----|
| L0 过度解释 | `崩，就是天子去世`；`「薨」——诸侯死`；`「卒」就是死` |
| 「是为」误释 | `「是为」的意思是这就是`；把「是为零陵」当地名 |
| 同义回声作业体 | `「壮士行，何畏！」——壮士出门怕什么`（无增量） |
| 空过场堆砌 | 句句先来一个 `说白了` |
| 旁白过长 / 发议论 | 借一词写两百字以上感慨 |
| 场次元叙述 | `今天要讲的这位` |
| 典故漏点名 | 通行典故情节写完且读者易漏对号，却通篇不见熟语字样 |
| 典故空挂 | 甩出「破釜沉舟」却不写砸锅沉船经过 |

**边界：** `太公就是“刘老头”` ✅；`崩就是去世` / `是为就是这就是` ❌。

**引号（硬）：**

| 用途 | 用什么 |
|------|--------|
| 史料原文 / 经典摘句 / **未译的原话对白** | 直角「」 |
| 白话对话 / 已译现代汉语 | 弯引号“” |
| 誓词 / 诗赋歌辞 | **先概括主旨，再「」保留文言** |
| 术语概念 | “禅让”等 |
| 书名篇名 | 《》 |

- **判定（硬）**：对照物是成稿 JSON 的 **`史料原文` 全文**（plan「原文摘句」只作补充）。框内仍是本篇著作原文 →「」；已译白话 →“”。某人曰/怒曰/骂曰后若照录原文 → 「」；若整句已译成白话 → “”。他书未译金句仍可用「」，须带《书·卷》。  
- **闭合纪律（硬 · 对话尤甚）**：引语内已用 `。？！` 收束 → 后引号外**不加**逗号/句号；连续对话可 `。” “` 直连，或加「某某又问」类叙述语，**不要**写成 `。”，` / `？”，` / `！”，`。  
- ❌ 弯引“”装未译原文（如 `"壮士行，何畏！"`、`"诚如此，天下危矣。"`）  
- ❌ 整段白话译诗交差  
- ❌ `老妇人说：“……哭。”，“你儿子为什么被杀？”，`（句末引号外多余逗号）  
- ✅ `亭长拔剑喝道：「壮士行，何畏！」`（照录原文）  
- ✅ `亭长拔剑喝道：“壮士出门，怕什么！”`（已译白话）  
- ✅ `屈原把悲愤写进诗里，大意是呼问天地、自明心志，原文作「……」。`  
- 禁止把已译白话再塞进「」

**原文露出与破折号（克制，不是全禁）：**

- **绝大多数句子**直接白话，不贴原文。直角「」只留给**金句、名言、诏令、誓词、诗赋歌辞、气势不可替代的原文措辞**；姓名家世官职等一律白话。
- 用了「」之后，**优先把意思融进前后叙述**（接叙、点破画面、点明分量），让读感连贯。
- **反对的是默认作业体**：句句「贴原文 → 破折号同义再译一遍」，或弯引“”后再 `——` 解释。那会把说书打断成对照练习。
- **不反对**偶发、有增量的破折号：`「…」——` 或 `“…。”——` 后面若是画面/反差/解读（不是同义回声），可用，但全篇克制，勿成主腔。  
- **标点硬错：** `」`/`”` 与 `——` 之间**不得**再插逗号（❌ `……。」，——` → ✅ `……。」——`）；禁止 `：，`；禁止段首 `——`；禁止句末引号外逗号（❌ `……。」，` / `……。”，` → ✅ 去掉该逗号）。
- 白话对话用弯引“”；**禁止用弯引装未译史料原文**（质检硬拦，并可自动改回「」）；禁止把已译白话再塞进「」。

**其它硬约束：** 禁元评论过场词；禁 `**`；AI 腔见阈值表；译者隐身（禁「我们来看看」「今天要讲的这位」「咱们就按着…说来」等导航/场次元叙述）。

### 幽默规范

幽默是调味料，**不是配额**：**有自然反差再用，没有就不写**；勿为凑「每篇几处」硬塞。  
开篇/结尾/驾崩伤亡/制度核心/盖棺定论不加。好的是点破时间跨度或身份反差；坏的是编油腻台词、程度副词堆砌、无据心理玩笑。

## 规则二：结构完整

**核心：** 有完整叙事，而不是机械套模板。人物条目通常可成：背景 → 行动 → 关键事件 → 后果 → 身后/历史位置；**实际结构服从母本**，不要求每篇硬套「出生—事迹—死亡」。

过渡性人物开篇要回答「为什么读他」（定位/矛盾/后世影响），不要写成说明书。

无去世记载可用「此后记载就少了」一类收束。

### 本传主退场完整性（条件补叙）

| 检测 | 动作 |
|------|------|
| 母本已有本传主退场 | **禁止**篇末再补同义退场 |
| 母本无退场且 plan 有采用的退场补全 | 篇末 **1 句**，优先采用 snippet，禁止发挥 |
| 确无材料 | 「史载此后不详」一句；禁编造崩葬 |

同篇退场事实只出现一次。Phase1 已写清 → enrich 跳过误标采用项。

### 交接双挂 · 角色不对称

标注双挂 ≠ 两边都展开。后君开篇：前君卒/立压成一两句过渡；前君收尾：详写本君退场，后君「立」点到为止。

### 短条目（母本 < 10 句）

优先：**母本完整 > 清楚 > 自然 > 有价值增量**。补充只能挂锚点；**不为篇幅短而硬塞外部材料**（不按「补全段数 ≤ 母本句数」等配额写作）。用承接句，杜绝「此外《某书》还记载」拼接感。

### 延伸（并入：原「内容延伸」）

挂母本锚点补背景/影响，用来丰富；不得破坏覆盖/顺译/数据准确/原文白话融合，也不得借「保主线」丢掉应有的丰富与现代叙事质感。  
铁律：只写有据史实；不编事件；不幻想无据心理；不硬凑典故；不强行升华鸡汤。无材料则忠实顺译，不硬延伸。

## 规则三：内容完整性与数据准确

姓名、字号、家世、关键事迹、性格、影响、去世信息能写则写全。数字年代精确保留，不概括成「好几年」。

- 不脑补无据历史评价  
- 不确定写「一说 / 据《某书》」  
- **禁止编造亲属关系**；无出处宁可不写  

---

## 规则四：原文融入与引用规范

**核心：** 关键原文自然穿插在白话里。不是每句都引。禁止【】打断阅读。

**一般不引、直接白话：** 姓名、字号、家世、基本身份官职。  
**宜引：** 金句、关键判断、精妙不可替代的措辞、多版本差异处的原句。

**优先级：** 名句 → 历史评价 → 精彩表达 → 多版本差异 → 其余白话。

**异说：** 禁止折中；母本先述，再「《某书》则……」。  
- **enrich / 显式 plan 补全路径：** plan 已 `采用:true` 的异说须全部呈现（P0）。  
- **默认 polish：** 不以 plan 异说清单打卡；**已写入正文的补充不得遗漏**；没有可靠增量 ≠ 失败。

**出处：** 外部补全须著作+卷/篇；禁无《》的「据说/有资料说」。

**自然引出（与现行引号纪律一致）：**

1. 「按《某书》的写法，……」（白话融入）  
2. 先点明分量，再直角「」镶嵌金句/原文，**优先接叙融合**（偶可用——点破增量画面，勿同义再译）  
3. 「《某书·某卷》还补了一层：……」

**正例：**

- ✅ `刚生下来就透着灵气。《史记》写他「生而神灵，弱而能言」——别的婴儿还在哭和吃奶时，他就能开口说话了。`（——后有增量画面，不是同义翻译）  
- ✅ `司马迁在论赞里留下一句很重的话：「动静之物，大小之神，日月所照，莫不砥属。」日月能照到的地方，没有不归属他的。`（「」后直接融合，无破折号）  
- ❌ `《史记》原文说：「黄帝者，少典之子。」就是说，黄帝他爹是少典。`（批注体；家世也不该贴原文）  
- ❌ 句句「原文说→——同义白话」循环（对照作业体）  

写完搜索【；搜「原文说」是否在引姓名/家世（若是则改掉）。

## 规则五：人物刻画

把人当人写：**不脸谱化**；决策可有纠结。正史有暗示可合理推测，**不虚构无据内心戏**（禁「他当时一定想…」）。

**指代：** 姓名 / 身份 / 代词轮换。  
同段描述性称呼最多一次；一句里已有姓名不要再用描述性称呼叠床架屋。  
**禁止**市井称谓：`这位爷` / `这位主儿` / `这家伙` / `他娘`（作母亲俗称）/ `他爹`（宜写其父/太公/姓名）。

## 规则六：纯叙事

无小标题、分节号、列表符号；正文首段不得以 `#` `-` 等 markdown 开头；第一句须是叙事句。

### 前置引入（硬）

正文**必须**以独立首段做**宏观阅读框架**（约 **100–250 字**），段后**空一行**，再进入母本开篇顺叙。  
有头有尾：开篇宏观定位 + 篇末人物收束，缺一不可（薄母本「一句过渡」档可缩短引入，但仍须独立成段）。

**引入段只写：**

1. 此人是谁（姓名/通行称呼、时代或朝代位置）  
2. 为何重要 / 一生主线一句话（宏观，不写具体情节链）  
3. 自然过渡到下文（勿喊「原文如下」）

**引入段禁止：**

- 展开母本即将开写的具体情节（封王、立太子、出生异兆、斩蛇、起兵过程等）  
- 时间倒挂钩子（如先写「登基那年…新气象」，再补「他是谁、怎么当上太子」）  
- 说书场：`诸位看官` / `今天要讲`  
- 加工说明：`本篇以…为主线` / `以母本为准` / 书目编排说明（书目只在文末「参考著作」）

- ✅ `汉武帝刘彻，汉景帝之子，西汉在位最久的皇帝之一。他在位五十余年，外事四夷、内兴制度，也把求仙封禅一路推到极致。`  
- ✅ `汉高祖刘邦，中国历史上第一个布衣天子。他出身农家，提三尺剑定天下，开两汉基业。`  
- ❌ 把「孝景四年封胶东王→废太子→立太子→敬鬼神」整段写进首段（那是母本起传，须另起第二段）  
- ❌ `武帝登基那年，宫里宫外都是一股新气象。要说这位孝武皇帝，乃是……`（气氛钩子叠起传，逻辑倒置）

素材来自 plan「前置引入素材」；禁元叙述喊数。独立成段 → **空一行** → 母本开篇。

禁「第一/第二」「一、背景二、事迹」；用自然过渡句切换话题。

**段落：** 按场景/话题/时间切换自然分段；**不以「每段必须 3–8 句」为硬 KPI**。

### 篇末收束（硬）

母本身后事（崩葬、即位、子嗣、晚年定论等）写完后，**必须另起一段**做全文收束（约 **80–220 字**），再接「参考著作」。

收束写：**此人历史位置 + 一生主线收科感**（可点主题，勿新开情节）。

- 母本最后一句写完就停 = 不合格（确无材料可自然结束，勿空泛升华凑字）  
- 禁止论文腔「综上所述」；禁止看官喊话收科  
- 禁「《史记》又记」模板段

---

## 规则七：六类触发条件

遇到下列六类：**命中且不处理会明显影响理解时**须处理；不是「出现一次就必须写百科」。  
例外（硬）：对照表内地名首次出现须标今地（见下）；显式纪年并注公元（见合同 G⑤）。

1. **制度** → 一句说清（禅让、封禅、巡狩、五刑、四岳等）；可用今比，勿写成词条  
2. **地名** → 首次标今地：**只用括号**，格式 `幽陵（今北京以北一带）`；不确定用「约在今…」；同名/极知名可不标。  
   - ✅ `定都盱台（今江苏盱眙一带）`  
   - ❌ `定都盱台——就是今天江苏盱眙那一带——`（地名今地禁止破折号夹注）  
   - 对照表见同目录 [`古地名今地对照.md`](./古地名今地对照.md)：这是**已核实今地缓存**，不是二十四史全库。只强制表内、≥2 字、非「可不标」的专名在正文**首次**出现时紧跟 `（今…）`；表外不确定标【待核实】，禁止臆造今地。  
3. **人名** → 首次一句身份（如蚩尤：最残暴的部落首领之一）；生僻称谓按规则一**释义旁白**（≤200 字上限，事实白描，不强制出处）；生僻读音可在首次括注，如 `郦食其（食其，音 yì-jī）`  
4. **器物** → 一句是什么（璿玑玉衡等）  
5. **事件** → 一句背景（阪泉、涿鹿等）；若该事件已成**通行典故/成语**，按规则一「著名典故 / 成语旁白」宜点名（先叙后点；不为凑标签）  
6. **补充信息** → 他书异说/硬增量须《书·卷》；**释义旁白与一两句常识解释不强制出处**；超一段硬史实必须有出处  

> 规则七与规则一旁白同向：生僻/古怪处要讲；**通行典故宜对上号**；禁止用堆「说白了」代替真正解释；也禁止对崩/薨/卒/是为等 L0 基础词做旁白拆词。

## 规则八：太史公曰 / 论赞

标注不返工段界。翻译时若母本含「太史公曰」或卷末论赞：

1. 直引并顺译其评价、感叹、史观，不改成译者盖棺定论。  
2. **史家第三人称**：✅「司马迁在《史记》中写到…」「在本传论赞中说…」；❌ 易读成在场的「司马迁说…」；❌ 改成与传主对话。  
3. 论赞前可一句轻过渡，随即引述；不用论赞替代传主生平收尾。  
4. 禁元叙述（「注意这里太史公曰」）。

---

## 规则九：通假字处理

首次需要时：`禽（通『擒』）`；已顺译今字则**不再**加通假标注。  
**硬：** 禁止 `擒（通『擒』）`；二选一：保留原字+标注，或直接今字。

---

## 规则十：逐句顺译原则（灵魂规则）

**核心：** 在硬直译与随意意译之间：保留母本**信息、关系与顺序**，语言改为可读的现代历史叙事。  
（「逐句」指对照信息清单推进，**不要求**一句原文对应一句译文。）

1. 不重组原文先后。  
2. 每项有效信息覆盖；不可因「不重要」跳过；表达可压缩修辞但清单编号须全 √。  
3. **覆盖信息 ≠ 每句引用原文。** 绝大多数白话；关键处才「」。  
4. 母本 / 索引补充 / 外部补全分层：补充与补全挂锚点，不打乱母本序，不重复同一事实。

**正例：**  
`高辛生来就不普通。《史记》写「生而神灵，自言其名」——和黄帝开篇相似，但多了「生下来就能说出自己的名字」这层。`

**反例：**  
硬直译腔；打乱顺序的读书笔记式意译；句句 `「原文」——同义白话` 当主腔（对照作业体，不连贯）；`「原文」，——` 多插逗号。

**内部流程：** 对照信息清单逐项确认 → 覆盖 / 流畅 / 地名通假三关自检。

---

## 规则十一：完成标准（Definition of Done）

须**同时**满足适用项。写完逐条勾选。

### 验收 Checklist

- 有前置引入（约 100–250 字精简概括、直接入题；无「今天要讲」；不为凑字）  
- 有篇末收束总结（母本身后事之后、参考著作之前；确无材料可自然结束）  
- 母本核心信息完整、主线顺序一致、无整段情节蒸发  
- **补充：** 默认 polish 不因「无 plan 外部补全」失败；任务范围内已采用/已写入的补充不得遗漏；enrich 路径 plan `采用:true` 项须呈现  
- 无重复信息、无事实冲突  
- 引用/外部补全有出处；无母本同卷冒充补全  
- 无现代 AI 腔爆表、无百科体、无翻译腔/批注体  
- **无标点硬错：** 无 `：，`；无段首 `——`；无 `」/”，——`；无句末引号外逗号（`。”，` / `？」，` 等）
- 读起来像现代历史叙事文（作者隐身）；生僻/古怪处有**必要**释义旁白（≤200 字上限）；**通行典故**情节写完后宜点名；非干译、非空「说白了」、非凑幽默/凑旁白；**禁止看官套话与加工说明入正文**

### 写作后自检（12 项）

1. 母本覆盖 — 信息清单全部 √  
2. 补充融入 — 有价值增量挂锚点；无拼接；无增量不强补  
3. 外部补全有据 — 《书·卷》；无出处则删  
4. 行文流畅 — 无【】、无批注式、标点硬错已清  
5. 地名 — 规则七 + 对照表  
6. 收尾自然 — 有篇末收束总结；禁「《史记》又记」模板段  
7. 退场不重复 — 规则二  
8. 引用自然 — 不为凑数  
9. 文风词汇 — AI 腔词频表  
10. 前置引入 — 直接入题；未展开具体事件；无「今天要讲」  
11. 通假 — 禁 A 通 A  
12. 参考著作 — **正文实际用到的**外部出处文末均有；独立成段；空一行后：

```
参考著作：
1. 《书名·卷篇》
```

硬上限 **≤10**：只列最重要、正文实际使用的书目；禁止凑数；**不要求与 plan 清单机械一致**。  
禁止 `*参考著作：*` 星号包裹。
