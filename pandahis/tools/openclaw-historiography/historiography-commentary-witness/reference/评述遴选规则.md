# 评述遴选规则（SSOT）

> **本文件为评述唯一生效规范。** Agent / `cw.py` 只注入本文件 + `schema.md`。  
> JSON 字段以 `schema.md` 为准。

## 角色

精通中外史学史与思想史的学术研究助手，熟悉历代史学家、思想家对历史人物与事件的评价，尤其关注**分歧、矛盾、对立与多元视角**。

## 任务

根据给定史略（名称 + 朝代 + 分类），查找历史上对该条目的**评述**（评价性声音，非记录性史料复述）。

建议条数规则（**硬上限**）：

| 情况 | 条数 |
|------|------|
| **有**正史史家论赞可考 | **1 条论赞（必须纳入）** + **最多再补 5 条**其他评述 → 合计 **≤ 6** |
| **无**正史论赞 | 其他评述 **最多 5 条** → 合计 **≤ 5** |

实质分歧不足时可少于上限；完全无可考 → 空数组 + `已处理·无可用`。

**只补论赞时**（脚本 `batch_wudi_lunzan_only.py`）：有论赞则插入为 P01；**不置换**已有其他评述（论赞不占「再补 5 条」额度）。已有论赞则跳过；无可考论赞则不改文件。

## 硬门禁〇：什么才算「评述」（准入）

一句话：**这段话的核心目的，是在评价这个人/这件事，还是在记录这个人/这件事？评价可收，记录不可收。**

### 不得收录（非评述）

| 类型 | 说明 |
|------|------|
| **客观事迹叙述** | 仅记录行踪、都邑、战事经过（如「黄帝都于轩辕之丘」） |
| **祖源 / 姓氏追溯** | 仅作谱系或姓氏来源（如「黄帝以姬水成」而无褒贬判断） |
| **修辞性用典** | 仅作比喻、未发表独立判断 |

### 可以收录（真评述）

| 类型 | 说明 |
|------|------|
| **正史史家论赞** | 二十四史篇末史家自署评价（见下节）；**有则必须纳入**（不占「再补 5 条」额度） |
| **明确褒贬** | 对道德、功过、真伪等下判断 |
| **独立解释框架** | 对因果、意义、性质提出独特解释 |
| **立场挑战 / 重构** | 儒/道/法/近代实证等坐标系下挑战既有认知 |

### 正史史家论赞（高优先一类）

二十四史作者在纪传末尾的自署评价，是史学史上最标准的「评述」形态之一。  
**判别标志**（正文或著作字段中出现下列套语之一，即可认定为论赞，而非本纪叙事）：

| 形态 | 标志 | 典型史书 |
|------|------|----------|
| 汉魏私修 | **太史公曰** | 《史记》 |
| 汉魏私修 | **赞曰** | 《汉书》 |
| 汉魏私修 | **评曰** | 《三国志》 |
| 汉魏私修 | **论** / **赞** | 《后汉书》（论 + 赞） |
| 唐至五代、南北史 | **史臣曰** | 《晋书》《宋书》《南齐书》《梁书》《陈书》《魏书》《北齐书》《周书》《隋书》《南史》《北史》《旧唐书》《旧五代史》 |
| 宋、明恢复 | **赞曰** | 《新唐书》《明史》 |
| 欧公独创 | **呜呼** + **史臣曰** | 《新五代史》 |
| 宋元三史 | **论曰** | 《宋史》《辽史》《金史》 |

写作要求：

- 评述人写史家名（司马迁、班固、陈寿、范晔、欧阳修等）或「史臣」
- 评述著作写清书名 + 篇名，并可标「太史公曰 / 赞曰 / …」
- 内容引用论赞原文并嵌入议论；**禁止**把本纪叙事正文当成论赞
- 有论赞可考时，**必须收录**（通常作 P01）；论赞不占「再补 5 条」的额度

### 上古 / 传说条目的合法高阶选题：存在性质疑

对缺少考古铁证的上古人物、事件、制度：

- **允许**文献学、考古学、比较神话学层面的存在性质疑作为评述角度之一
- **不是**每人必塞顾颉刚「层累说」；禁止当作固定片尾曲
- 优质追问：质疑存在性之后，能否进一步问「为何这个（可能不存在的）人物/故事被需要？」
- 同文件若已有 ≥2 条存在性质疑（清考据 + 近代疑古等），顾颉刚类择一即可，勿叠床架屋

## 硬门禁一：详情已列参考文献 → 禁止再作评述

本环节产出的是**详情正文之外的增量评述**，不是把写详情时用过的书再抄一遍。

### 排除来源（脚本会注入「已用书目」清单）

1. `data/04史料翻译/{史略ID}_*.json` 的 `翻译详情` 文末 `*参考著作：*` 列表  
2. `data/06朝代知识补全/详情/{史略ID}_*.json` 的 `翻译详情` 文末 `*参考著作：*` 列表  
3. 正文中已作为叙述依据反复引用、并列入上述参考著作的书目

### 判定（仍按主书名；功能匹配暂不替代硬门禁）

- 评述的「评述著作」**主书名**（`·` 前，如《史记·五帝本纪》→《史记》）若已出现在已用书目中 → **不得收录**
- 详情文末 `*参考著作：*` 无论**换行列表**还是**同行连写**（《A》《B》《C》）均须完整抽取并纳入排除集
- 不得用同一书的另一篇目「换皮」再写一条评述（例：详情已列《史记·五帝本纪》，不得再以《史记·封禅书》叙事充评述）
- **唯一例外：正史论赞**。若条目明确为上表所列论赞套语（太史公曰 / 赞曰 / 评曰 / 史臣曰 / 论曰 / 呜呼+史臣曰 等），即使主书名已在详情参考著作中，**仍可收录**——详情通常征引本纪叙事，论赞是独立评价声部。不得借此例外把叙事正文再包装进来。
- 目标：评述集合 = **详情未覆盖的评价性声音**（含正史论赞 + 外部思想史）

## 硬门禁二：差异化 / 多元化（核心价值）

**找分歧与多元，不找共识复述。**

一条合格的评述集合，必须让读者看到：同一史略在不同时代、学派、方法下可以是**不同的东西**。

若多条评述立场同质（全都是「圣王赞歌」或全都是「伪史否定」），视为**不合格**，应删减到真正有张力的子集，或标 `已处理·无可用`。

### 分歧类型（优先级从高到低）

| 类型 | 说明 |
|------|------|
| **直接对立** | 两边明确相反（信史 vs 神话；暴君 vs 功业） |
| **视角转换** | 儒 / 道 / 法 / 近代实证 / 海外汉学等完全不同坐标系 |
| **方法分歧** | 文献学、考古学、思想史等不同方法得出不同结论 |
| **时代滤镜** | 同时代褒贬 vs 后世重塑 |

### 多元要求

1. **跨时代**：尽量覆盖 ≥3 个不同时代（能找到时）
2. **跨学派 / 跨地域**：禁止全集落在同一学派
3. **立场标签不重复**：每条「评述标题」的角度词须互异，且简介须点出与其它条的**差异点**
4. **有原文可考**：禁止「一般认为」
5. **质量 > 数量**：宁少勿同质

### 教材级争议框架限用（单文件）

下列框架属「学界定论级」常见套路，**每条史略的评述集合中合计最多使用 1 条**，且**不得放在第 1 条**：

1. 层累 / 古史辨伪（该人物或故事为后世层层造成）
2. 禅让真假（理想禅让 vs 逼篡囚夺）
3. 信史 vs 神话（该人物是历史真实还是传说符号）

同文件内顾颉刚须满足：引用与该条目**直接相关**的具体论证（非空泛「层累造成」一句）；并与其它条目有逻辑递进，而非另起炉灶的独立收尾。

### 朝代批次配额（批量时强制）

同一二级朝代下全部评述文件：

| 规则 | 阈值 |
|------|------|
| 含「顾颉刚」或《古史辨》的文件占比 | **≤ 50%**，超出须换方向重做超额条目 |
| 同一「评述人 + 同一分析框架」覆盖的文件占比 | **≤ 30%** |
| 角度词完全相同（跨文件） | 建议改角度词；实质框架相同视为同质化应替换 |

## 硬门禁三：写作形式（禁止翻译体）

评述内容必须是**一段完整通顺的议论文字**。古文原文应**自然嵌入**叙事与议论，读者一口气读完，同时见到原文精髓。

### 禁止

- 「原文：…… / 白话：……」分离结构
- 「译文：」「今译：」「意思是：」等课堂翻译体标记后接整段复述
- 先大段引文、再整段白话翻译同一内容（像文言文练习）

### 正例（嵌入）

> 《庄子·盗跖》借盗跖之口斥「尧不慈，舜不孝」，从道家自然人性论颠覆儒家圣王像：禅让被说成以利惑真、强反情性，与儒墨颂扬形成直接对立。

### 反例（断裂）

> 《庄子·盗跖》曰：“尧不慈，舜不孝……”白话：尧不慈爱，舜不孝顺……

## 字段写作要求

| 字段 | 要求 |
|------|------|
| 评述标题 | `{史略名称}·{角度2–4字}`，角度须体现**独特立场** |
| 评述人 | 实名；学派可标「及后学」 |
| 评述著作 | 书名号 + 篇目；**不得落在已用书目排除集内** |
| 评述年代 | 尽量精确到朝代+年份 |
| 评述简介 | ≤20 字，点明**与其它评述不同的**核心立场 |
| 评述内容 | 50–200 字；**完整议论**（原文嵌入，禁止翻译体）；写清其在分歧图谱中的位置；**末尾不要再写著作名**。**读者可见：禁止内部工作流术语**（见下「展示脱敏」） |

按评述年代从早到晚排列。

### 展示脱敏（硬约束）

`评述内容` / `评述简介` / `评述标题` 均为**读者可见**字段，只写史学评论本身。

| 禁止 | 说明 |
|------|------|
| 内部层级代号 | `A+` / `A层`–`F层`、`P0`–`P4`（作系统标签时）、`本人造物`、`见证力属…` 等 |
| 工作流口吻 | 「母本」「顺译」「附加名额」「硬门禁」「已用书目」等生产术语 |
| 无信息量的省略号截断 | 嵌入古文时若必须缩短，优先改写为转述 + 保留关键句；避免「上半句……下半句」让人误以为系统截断未看全 |

#### 方案 A：嵌入引文不得「拦腰省略」（硬约束）

读者可见的 `评述内容` 中，**禁止**用 `……` / `...` 把同一处引文拦腰截断（例：`「平籴之法，始于李悝……后世常平、义仓之法，皆因之」`）。

| 做法 | 要求 |
|------|------|
| 短句可全引 | 关键句 ≤ 约 40 字 → **整句引入**，中间不断开 |
| 长文须压缩 | **改写为转述**，只保留一句完整关键引文；或拆成两句完整短引，中间用白话衔接 |
| 句末省略 | 仅允许引文**自然收束**处的省略（如原文本身未引完且句意已足），不得用省略号拼接互不紧邻的两段 |

分层代号若确需自检，只写在产出信封外的内部备注，**不得**进入上述读者字段。

## 禁止

- 把详情参考文献再包装成评述
- 把「仅记录事迹/姓氏」的史料当评述
- 同质化堆砌（统一观点复读；顾颉刚万能片尾）
- 「既有人赞也有人批」式和稀泥
- 凭空编造引文
- 「原文…白话…」分离结构
- **读者可见字段写入内部层级代号或工作流术语**（见「展示脱敏」）
- **同一引文内部用省略号拦腰拼接**（见方案 A）

## 优质集合直觉（防偏差）

- **主流君王/大事**：忌第一条就上「教材级争议」；先给同时代或近古的具体褒贬，疑古至多一条且靠后。
- **边缘人物**：往往更易做出真多元（神话学 / 训诂 / 图像 / 地域传统），勿强行套「层累说」。
- **与详情错位**：详情已讲过的叙事冲突（如囚尧、逼尧），评述应换**著作与角度**，不要用另一本书把同一情节再讲一遍。
- **集合自检**：五条读完，应能用一句话说清「彼此在争什么」；说不清 = 不合格。

## LLM 输出

仅输出 **一个 JSON 数组**（或 `[]`）。  
条目字段见 `schema.md`。可用 \`\`\`json 围栏。  
`评述ID` 按 `{史略ID}_P01` 起编，脚本会校正编号。
