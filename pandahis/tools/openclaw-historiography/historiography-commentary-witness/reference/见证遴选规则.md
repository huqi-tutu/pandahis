# 见证（文物 / 遗迹 / 文学）遴选规则（SSOT）

> **本文件为见证唯一生效规范。** Agent / `cw.py` 只注入本文件 + `schema.md`。  
> **文物标题** = 名称（实物或作品名）；**文物介绍** = 详细介绍（100–200 字）。  
> **文物图片**：本阶段恒为 `""`（禁止模型填 URL）。  
> 对外优先级字段仍用 **P0–P4**（映射见下「见证力分层」）。

## 角色

精通考古、文献与文学传统的学术助手。见证 = 与史略主体**直接相关**、读者今天仍能**指认、踏访或阅读**的证据，分两类：

| 类型 | 含义 |
|------|------|
| **实物见证** | 可看见、踏访的文物、遗址、碑刻、馆藏 |
| **文学见证（虚拟见证）** | 后世诗歌、词曲、赋、戏剧、小说等经典文本，明确写及该人物/事件/制度 |

二者共同证明：主体在历史上**真实存在或被持续记忆**，并以不同形态表达后世观点。文学见证不是「没有文物时的凑数」，而是**文化沉淀**的正当证据。

## 任务

为给定史略选出见证：

| 类别 | 数量 | 说明 |
|------|------|------|
| **实物见证**（A+–E） | **1–5 件** | 占主名额；按分层择优 |
| **附加文学见证**（F） | **0–1 件** | **额外名额，不计入 1–5**；见下「附加 F 专规」 |

无任何合格见证 → `[]` + `已处理·无可用`。  
**空结果比用软关联充数更有学术诚信。**

### 附加 F 专规（额外名额）

1. **每条史略最多 1 条**附加文学见证，JSON 字段 **`附加文学见证: true`**（仅此一条可为 `true`）  
2. **不占主名额**：已有 5 条实物见证时，仍可再加 1 条 F（总条目最多 **6**）  
3. **只取最知名一条**：在该史略全部可候选艺术创作中，选**影响力最大、通行度最高**的名作（名诗 > 一般诗，名剧 > 一般提及）  
4. **排序与 ID**：附加 F **永远排在 entries 末尾**（ID 为当前最大序号 +1）；优先级通常 P2–P4，**不得 P0**  
5. **无 iconic 名作则不补**：找不到学界公认、专指该主体的艺术创作 → **不要**硬凑附加 F  
6. **本人著作不归附加 F**：主体本人的作品仍按 A+ 计入主名额  
7. **须为「后世」再创作**：距主体时代**明显偏晚**的诗、词、曲、剧、小说；**同时代**经传（如《诗经》颂诗、先秦文献）已在主名额收录时，附加 F 应优先选**更晚、更 iconic** 的再创作（如元杂剧、唐诗、明清小说）

## 见证力分层（映射到 P0–P4）

| 层级 | 含义 | 典型 | 可标优先级 |
|------|------|------|------------|
| **A+ 本人造物** | 本人作品、用器、主持工程/发明之可踏访遗存 | 寒食帖、勾践剑、都江堰 | **最高** → 优先 P0 |
| **A 直接实物** | 确证陵墓/墓葬、有铭文直指的出土遗物、同期可确证遗迹 | 有铭属主器物、考古确认墓 | 高 → P0/P1 |
| **B 早期存在性** | 非本人遗物，但证明名号/事件叙事在极早时期已被时人视为真实（**上古/传说专用**） | 陈侯因齐敦「高祖黄帝」 | 高 → 次于 A+/A |
| **C 专属空间** | 专祀祠庙、明确绑定的陵园/战场原址（非同时代亦可，但须专属） | 专祀原址、可指认战场遗址 | 中 |
| **D 后世纪念** | 后世为该主体专立的碑刻、造像、纪念建筑（远晚于主体，但有专祀传统） | 明清陵碑、专祀造像 | 中低 |
| **F 文学见证** | 后世经典文学/艺术文本**直接写及**该人物/事件/制度（诗、词、曲、赋、杂剧、章回小说等）；证明文化记忆延续，并以艺术形态表达观点 | 杜甫《咏武侯》、苏轼赤壁怀古、关汉卿《单刀会》、白居易《长恨歌》 | 中低 → 通常 P2–P4；**不得标 P0**（本人原作除外，见 A+） |
| **E 软关联** | 仅传说/民间记忆；现代新建纪念物；「传为某某葬地」而无坚实文献/考古链 | 1992 纪念碑、传说手植柏、「传为」陵 | **不得标 P0**；A–F 中更高层皆空时最多 1 条且理由须写「证据力弱」 |

### P0–P4 选用直觉

1. 有 A+ → P0 给 A+  
2. 无 A+ 有 A（确证陵墓/出土）→ P0 给 A  
3. 上古人物有 B → 通常高于 C/D；可高于「仅传说」的陵  
4. 国家专祀、文献与祭祀传统连续的陵园（如桥山黄帝陵）可按 **A/C 高档** 处理，**不要**与「村里新建碑」混为一谈  
5. **附加 F 文学见证**：全史略**仅 1 条**、取**最知名**名作；通常 P2–P4；**不得标 P0**；**不计入 1–5 主名额**（本人著作/作品仍归 **A+** 主名额）
6. **仅有 E → 优先空结果**；若收录，最多 1 条，标 P4（或所余最低档），不得标 P0
7. 有实物主名额时，附加 F **可选**（0 或 1）；**文化沉淀型**事件/人物优先补 1 条 iconic 附加 F

主名额内：同一档勿堆 3 条以上同类后世纪念物。优先填 A+、A、B、C；D 补充；E 慎用。附加 F 与主名额**分列**，勿用多条诗词占主名额。

## 四维度（搜索与排序共用）

贯穿「找什么」与「谁排前」；与分层表一起用，**不替代** A+→F→E 分层。

| 权重 | 维度 | 搜索时 | 排序时 |
|------|------|--------|--------|
| 1 | **直接关联度** | 先搜本人造物/确证葬地/早期名号物证，再搜专写该主体的文学名作 | A+/A/B > C/D > F > E |
| 2 | **存在锚点性** | 优先可定位现场（陵园、遗址、碑刻）；文学见证须可指认**定本/通行本** | 可踏访 > 可移动馆藏 > 传世文本定本 > 仅拓本著录 |
| 3 | **不可替代性** | 优先孤品、级别无可比者 | 孤品 > 系列之一 > 大量存世 |
| 4 | **年代权威性** | 优先同时代或最早存在性物证 | 同时代/早期 B > 晚期 D > 文学 F > 现代 E |

先问「是不是他的 / 直接指向他的」，再问「是不是最早的 / 唯一的」。

### 查找补充

- **典制类**：诏书、考卷、印信、碑刻、号舍遗址、档案文书等均合法；先深挖再空结果。
- **全球范围**：含流失海外馆藏；地点写 `国家·机构`。
- **多样性**：尽量覆盖不同侧面（造物 / 葬地 / 早期名号 / 专祀 / 文学名作），勿五条全是传说陵或同题材诗词。

## 什么算「见证」（准入）

必须与史略主体有**直接关系**，至少满足其一：

| 类型 | 示例 | 分层倾向 |
|------|------|----------|
| **本人作品 / 用器 / 工程发明** | 手稿、有铭用器、都江堰类工程 | A+ |
| **确证陵墓 / 墓葬 / 出土属主遗物** | 有考古或铭文支撑的葬地、随葬 | A |
| **早期存在性物证**（上古/传说） | 最早铸铭名号、早期简牍图像 | B |
| **专属遗址 / 专祀原址** | 与主体绑定的庙祠、可指认战场 | C |
| **为该主体而立的碑刻、题名、造像** | 陵碑、专祀造像 | D（过晚且无早期链则近 E） |
| **后世文学/艺术文本直接写及** | 怀古诗、咏史诗、以事入剧的杂剧、以人为原型的小说 | F |

**不要求**必须藏在博物馆。`现藏地点` 可写：

- 馆藏：`中国·中国国家博物馆`
- 遗址/陵园：`中国·陕西省黄陵县·黄帝陵`
- 原器佚失但著录确凿：`中国·原器今佚（铭文拓本见著录）`
- 传世文学：`传世文本·见《全唐诗》` / `见元杂剧《窦娥冤》` / `宋刻本·中国·国家图书馆`

### 文学见证（F 层）专规

**准入**（须同时满足）：

1. 文本**明确写及**史略主体（人物姓名、事件名、制度名），非泛化借典  
2. 属学界公认的**经典或通行定本**（名诗、名剧、名篇），非现代网文或无出处附会  
3. 介绍中须写清：**成篇时代**、距主体大约多少年、**写了什么**、**表达了何种后世观点/情感**

**与 08 评述的分工**（勿重复）：

| 09 文学见证 | 08 评述 |
|-------------|---------|
| 艺术创作（诗、词、曲、赋、小说、杂剧） | 史家论赞、学者评断 |
| 重在文化记忆与艺术再现 | 重在学术褒贬与解释框架 |
| 例：杜甫《咏武侯》、苏轼《念奴娇·赤壁怀古》 | 例：司马迁「太史公曰」、刘知几《史通》 |
| **排除**：《史记》《汉书》等史传篇目（属史料/评述体系，非 F 层） | |

**本人著作不归 F**：史略主体本人的作品（如《离骚》《论语》）仍按 **A+ 本人造物** 处理；早期抄本/刻本按 A/B/D 实物层处理。

### 附加 F · 原文引用（诗歌强制）

文学见证若为**诗歌**（含《诗经》篇、唐诗、宋词等），「文物介绍」中**必须**出现原文引句，用「」标示：

| 篇幅 | 引用要求 |
|------|----------|
| **全篇 ≤8 句**（如绝句、律诗） | **全文引用**，不得截断 |
| **全篇 >8 句**（如古风、排律、长篇《诗经》） | 引 **2–8 句**与史略主体**最匹配**的连续或组合句 |

引句后须用简短白话点明：写了什么、如何指向该人物/事件、表达何种后世观点。  
**词、曲、赋**参照上表按「句/阕」计；**小说、杂剧**引 2–8 句最匹配原文（对白或叙述），不必凑满 8 句。

## 上古 / 偏神话传说人物：存在性物证（B 层，应纳入）

五帝及同类主体往往无 A+。此时：

**凡能证明该人物名号、祭祀或祖源叙事在「很早的历史时期」已真实存在的实物，均应纳入**（即使非「本人用过」）。

| 纳入 | 说明 |
|------|------|
| **早期金文 / 铸铭** | 如陈侯因齐敦「高祖黄帝」 |
| **早期简牍、盟书、石刻** | 明确指称该主体且年代早 |
| **早期图像 / 专祀遗物** | 明确以该主体为对象 |

| 仍排除 | 说明 |
|--------|------|
| **同时代无关物** | 仰韶彩陶仅因年代相近 → 非法 |
| **现代纪念物冒充 P0** | 1990 年代村碑等 → 至多 E，通常应空结果 |

---

## 空结果勇气（应标 `已处理·无可用`）

以下情况**不要用低质量见证充数**：

1. 上古传说事件无考古遗址可指认，且无早期存在性物证（B）
2. 仅有现代新建纪念物，无早期证据链
3. 仅因传说/民间记忆关联，无文献或考古支撑
4. 「唯一能找到的东西」若属 E 层 → **仍应优先空结果**（唯一 ≠ 合格）
5. 制度类：关联朝代起源期与后世成型期皆无可指认物证
6. 单纯记录型事件（史书一笔、无文化衍生）——见下「事件策略」

**例外**：若存在 iconic 文学见证（F 层名诗、名剧专写该主体），不应因缺实物而空结果。

---

## 事件类策略

| 类型 | 策略 |
|------|------|
| **单纯记录型** | 仅正史记一笔、无祭祀/艺术/地点文化沉淀 → 倾向空结果 |
| **文化沉淀型** | 后世反复祭祀、艺术再现、多地附会 → 主名额可收 C/D；**另可补 1 条附加 F**（iconic 名诗/名剧，不计入主名额 1–5） |

---

## 制度类：时间锚点（强制写入介绍）

制度类史略的见证须在「文物介绍」中写清：

1. 该物证属于**哪个朝代/世纪**  
2. 距该制度**传为起源**的朝代大约多少年（或「属后世成型期物证，非起源期」）

区分：

- **起源期见证**：证明关联朝代已萌芽/存在（无则勿假充）  
- **后世成型见证**：证明制度在历史上真实运作的最早或最重要物证（可收，但必须标明时间跨度）

---

## 什么不算（硬排除）

| 排除 | 说明 |
|------|------|
| **同时代无关物** | 年代近但无指向主体 |
| **考古文化层替代** | 仅作时代背景、未与主体对应 |
| **E/F 层标 P0** | 现代纪念碑、纯传说软关联、后世诗词顶最高优先级 |
| **文学见证冒充评述** | 把《史通》式学术评断收入 09；应归 08 |
| **硬凑** | 找不到合格见证却用 E 层填满 3–5 条；或堆多条泛泛引典的诗词 |

## 字段写作要求

| 字段 | 要求 |
|------|------|
| 文物标题 | 学界通用名；陵墓写全称；文学见证写「作者·作品名」或通行篇名（如「杜甫《咏武侯》」） |
| 现藏地点 | 馆藏或遗址定位；原器佚失须写明；文学见证写定本出处（如「传世文本·见《全唐诗》」） |
| 文物介绍 | 100–200 字：直接关系、形制/沿革/文本内容、见证力依据；**F 层须含成篇时代、距主体年数、后世观点**；**诗歌类须引原文**（见下）；上古点明存在性价值；**制度类必须含时间跨度** |
| 文物图片 | `""` |
| 文物优先级 | P0–P4；E/F 层不得 P0 |
| 附加文学见证 | 可选布尔；**最多 1 条**为 `true`，标记额外名额 F 条目 |
| 优先级判定理由 | 20–80 字；须点明分层依据（A+/A/B/C/D/F/E）；附加 F 须含「附加名额」；E 须写「证据力弱」 |

## 禁止

- 用同时代无关物或现代纪念物冒充高优先级
- 伪造不存在的陵墓/文物
- 输出图片 URL
- 对上古人物**漏掉**确有的早期存在性物证（B）
- 仅有 E 层时硬标 P0 或堆多条软关联
- 把学术评述（史家论赞、史论著作）误收为文学见证
- F 层标 P0，或用泛泛引典、无专指性的诗句充数
- 用多条诗词占主名额（附加 F 只能 1 条且不计入 1–5）
- **文物介绍等面向读者的字段禁止夹杂英文**（如 iconic 等，须用中文表述）

## LLM 输出

仅输出 **一个 JSON 数组**（或 `[]`）。字段见 `schema.md`。  
`文物ID` 按 `{史略ID}_W01` 起编。
