# 评述与见证 · 执行纪律（ECC）

## 核心原则

1. **SSOT 优先**：遴选**只认** `reference/评述遴选规则.md` / `见证遴选规则.md`；字段以 `schema.md` 为准。质量偏差见 `质量与常见失败.md`。
2. **子命令隔离**：`commentary-*` 与 `witness-*` 不得在同一次 prompt 中混写。
3. **逐条串行**：一次只完成一条史略的一个 mode；verify 通过后再下一条。
4. **Verify 门禁**：未通过 `--strict` 的文件视为未完成；朝代批量结束后跑 `--dynasty` 配额检查。
5. **评述增量**：详情参考著作主书名不得再作评述；须为**评价性**声音；禁止翻译体；集合须差异化。
6. **见证分层**：A+造物 > A确证陵墓/出土 > B早期存在性 > C专属 > D纪念 > E软关联；E 不得 P0；宁空勿凑。
7. **空结果合法**：确认无合格见证/评述时 `status=已处理·无可用` + `entries=[]`。

## 禁止事项

- 禁止把详情参考文献包装成评述
- 禁止记录性史料、姓氏溯源冒充评述
- 禁止「原文…白话…」分离结构
- 禁止同质化评述堆砌与顾颉刚万能片尾
- 禁止用现代纪念物/软关联标 P0
- 禁止让模型生成文物图片 URL
- 禁止一次 prompt 输出多史略；禁止跳过 verify

## Verify 严重级别

| 级别 | 含义 | 处理 |
|------|------|------|
| **CRITICAL** | 撞详情书目、翻译体、角度重复、教材框架置顶、软关联标 P0、缺必填、ID/字数/优先级非法、朝代顾颉刚占比>50% | 必须修复 |
| **WARN** | 制度缺时间锚点、软关联过多、角度跨文件重复、顾颉刚占比偏高 | 建议修复 |
| **INFO** | 空结果已合法标记 | 仅记录 |

## Definition of Done

- [ ] 文件位于 `08` / `09`，命名符合 schema
- [ ] 评述：评价性；无详情书目撞车；无翻译体；角度互异；框架限用
- [ ] 见证：分层正确；E 非 P0；制度含时间跨度（若适用）
- [ ] verify `--strict` 零 CRITICAL
- [ ] 批量时 manifest 已更新；朝代评述跑过 `verify_cw.py --dynasty`
