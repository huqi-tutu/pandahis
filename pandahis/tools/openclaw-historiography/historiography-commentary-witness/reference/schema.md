# 评述 / 见证 · JSON Schema

`schema_version`: **1**

## 共用信封

```json
{
  "schema_version": 1,
  "mode": "commentary | witness",
  "史略ID": "GLBL_00129",
  "史略名称": "舜",
  "史略分类": "君王",
  "二级朝代坐标": "五帝",
  "status": "done | 已处理·无可用",
  "entry_count": 0,
  "processed_at": "2026-07-19T02:00:00Z",
  "model": "deepseek-v4-pro",
  "entries": []
}
```

| 字段 | 说明 |
|------|------|
| `status` | 有条目 → `done`；确认无可用 → `已处理·无可用`（`entries` 必须 `[]`） |
| `entry_count` | `len(entries)`，与数组长度一致 |
| `mode` | `commentary`（评述）或 `witness`（见证） |

## 评述条目（`mode=commentary`）

```json
{
  "评述ID": "GLBL_00129_P01",
  "评述标题": "舜·禅让典范",
  "史略ID": "GLBL_00129",
  "史略名称": "舜",
  "评述人": "司马迁",
  "评述著作": "《史记·五帝本纪》",
  "评述内容": "……（50–200字）",
  "评述简介": "确立舜为德治典范（≤20字）",
  "评述年代": "西汉（约公元前91年）"
}
```

| 字段 | 约束 |
|------|------|
| `评述ID` | `{史略ID}_P{01..99}`，文件内唯一、序号从 01 连续 |
| `评述标题` | `{史略名称}·{角度2–4字}` |
| `评述简介` | ≤20 汉字（按 CJK 计；可含标点但总长建议 ≤24） |
| `评述内容` | 50–200 字（汉字为主；verify 按汉字计数） |
| `评述著作` | 须带书名号及可考篇目 |
| 排序 | 按评述年代从早到晚（模型保证；verify 不强校验绝对时间） |

建议条数：有正史论赞 → **1（必收）+ 最多 5**（合计 ≤6）；无论赞 → 最多 5。实质分歧不足时可更少；完全无可争评述 → 空数组 + `已处理·无可用`。

## 见证条目（`mode=witness`）

```json
{
  "文物ID": "GLBL_00129_W01",
  "文物标题": "……",
  "史略ID": "GLBL_00129",
  "史略名称": "舜",
  "现藏地点": "中国·某某博物馆",
  "文物介绍": "……（100–200字）",
  "文物图片": "",
  "文物优先级": "P0",
  "优先级判定理由": "……（20–80字）",
  "附加文学见证": false
}
```

| 字段 | 约束 |
|------|------|
| `文物ID` | `{史略ID}_W{01..99}`，文件内唯一、序号从 01 连续 |
| `文物标题` | = 学界通用文物名称，或附加 F 的「作者·作品名」 |
| `文物介绍` | 100–200 字；附加 F 须含成篇时代与后世观点；**诗歌须引原文**（≤8句全文，>8句引2–8句） |
| `文物图片` | **必须**为 `""`（本阶段不由模型填写） |
| `文物优先级` | `P0`–`P4`，同一文件内不重复；按优先级降序排列（**附加 F 排最后**） |
| `现藏地点` | 馆藏/遗址/文学定本出处 |
| `附加文学见证` | 可选；**最多 1 条**为 `true`，标记额外 F 名额（不计入下述 1–5） |

**名额**：实物见证（`附加文学见证` 不为 `true`）**1–5 件**；附加 F **0–1 件**；合计最多 **6 件**。无合格条目 → 空数组 + `已处理·无可用`。

## 文件命名

| mode | 路径 |
|------|------|
| commentary | `data/08评述/{史略ID}_{史略名称}_评述.json` |
| witness | `data/09见证/{史略ID}_{史略名称}_见证.json` |

史略名称中的 `/`、`\`、空格替换为 `_`。

## Manifest（朝代批量）

```json
  "dynasty": "五帝",
  "mode": "commentary",
  "updated_at": "2026-07-19T02:00:00Z",

      "entry_count": 4,
      "verified_at": "2026-07-19T02:01:00Z"
    }
  ]
}
```
