# 事略补全规则（朝代知识）

> SSOT：`historiography-dynasty-knowledge/scripts/dynasty_supplement.py` Step 2。  
> 峰值年见 `historiography-annotate/reference/峰值年规则.md` §事略（`event_climax`）。

---

## 一、定义

**事略** = 朝代时间轴上，具有**完整故事结构**的历史事件或事态进程。

必须能回答：**这个朝代发生了哪些完整的、可讲述的历史故事？**

### 与人物的区别

| 维度 | 事略 | 人物 |
|------|------|------|
| 主语 | 什么事 | 谁 |
| 画布功能 | 朝代时间刻度 | 关键人物节点 |
| 典型载体 | 五要素故事 | 人物标签（名片式切面） |

> 人物标签 = 故事里的一个切面；事略 = 故事本身。

---

## 二、五要素准入（强制）

每条事略候选**必须**填齐五要素，缺一**不入库**：

| 要素 | 含义 | 检验 |
|------|------|------|
| **主语** | 这件事在讲什么 | 主语是「事态/事件」，不是人名 |
| **参与人物** | 关键参与者 | ≥2 方或 ≥2 个可点名角色（人/势力/国家） |
| **动作** | 发生了什么 | 有动词、有过程，非静态局面 |
| **结果** | 怎样收场 | 明确结局或阶段性结局 |
| **影响** | 对后续历史的影响 | 对政局/疆域/格局/制度的可述影响 |

### 候选 JSON 片段（Step 2 输出）

```json
{
  "名称": "七国之乱",
  "主语": "吴楚等诸侯国发动的武装叛乱",
  "参与人物": ["汉景帝", "周亚夫", "吴王刘濞", "梁王刘武"],
  "动作": "诸侯起兵反中央，朝廷派将平叛",
  "结果": "数月内叛乱平定，诸侯军主力瓦解",
  "影响": "中央集权加强，为后续削藩奠定基础",
  "建议年份": -154,
  "建议挂靠帝王": "汉景帝",
  "主要史料出处": "《史记·吴王濞列传》",
  "边界备注": ""
}
```

### Gate 自动驳回

- `参与人物` 仅 1 人且无对立面 → 倾向人物条/标签
- `动作` / `结果` / `影响` 任一为空或空泛 → 驳回
- 主语实为制度名 → 改典制
- 主语实为书名/篇名 → 改论著

---

## 三、不是什么（硬排除）

- ❌ 以**一个人**为主体的生平高光 → 人物 + 人物标签
- ❌ 制度、法令、官制 → **典制**
- ❌ 典籍、诗赋、思想 → **论著**
- ❌ 帝王即位/崩薨 → **君王**
- ❌ 纯局面/评价，无故事链：「文景之治」「国力渐强」「雄才大略」
- ❌ 建筑、工程
- ❌ 野史段子、无史学共识的传闻

### 「文景之治」类局面

缺单一动作与明确结局时，**不建事略**；可拆为具体事件（如七国之乱、匈奴和亲政策节点）或仅作朝代研究报告背景，不入库。

---

## 四、命名

- 2–8 字，事件名
- 不用书名号
- 用史学界通行简称：`七国之乱`、`巫蛊之祸`、`张骞通西域`

---

## 五、时间与坐标

| 字段 | 规则 |
|------|------|
| 史略开始年/结束年 | 短事件：相等；长过程：区间 |
| 峰值年 | 转折/高潮年；`peak_type = event_climax` |
| 四级帝王坐标 | 事件高潮时在位或最直接相关的君主 |

详见 `峰值年规则.md` §5。

---

## 六、优先级（P0–P3）

与同朝**所有分类**横向比较（见 `朝代优先级规则.md`）。下表示例**跨朝代**，仅帮助理解 P 级尺度，非该朝必选清单：

| 级别 | 事略示例 |
|------|----------|
| P0 | 涿鹿之战、七国之乱、楚汉战争、巫蛊之祸 |
| P1 | 鲧禹治水、昭君和亲、盐铁会议、鸿门宴 |
| P2 | 较小规模、史籍有载但非大众核心的事件 |
| P3 | 补充性节点，调高优先级才默认展示 |

---

## 七、与人物标签去重

| 情况 | 处理 |
|------|------|
| 鸿门宴 + 樊哙「鸿门护主」 | 可共存：事略讲事件，标签讲个人切面 |
| 事件仅一人高光、无多方故事 | **不建事略**，保留人物标签 |
| 同一事件拆成多条事略 | **禁止**（一事略一条） |

gate 输出 `重叠审查表`，人工确认 `keep` / `person_tag_only`。
