# 论著补全规则（朝代知识）

> SSOT：`historiography-dynasty-knowledge/scripts/dynasty_supplement.py` Step 4。  
> 峰值年见 `historiography-annotate/reference/峰值年规则.md` §论著（`thought_spread`）。

---

## 一、定义（宽泛口径）

**论著** = 朝代内具有广泛知名度的**文化成果与思想表达**。

主语是**作品**或**学说**，不是人、不是制度、不是事件。

必须能回答：**这个朝代留下了哪些能被点名的文化与思想遗产？**

### 包含范围

| 子类 | 说明 |
|------|------|
| **典籍** | 成书传世的学术、史书、政论 |
| **名篇** | 著名诗赋词、奏疏、书信单篇 |
| **书画名作** | 史籍有载、可考年代、学界公认（门槛高，宁少勿滥） |
| **思想/理论** | 影响深远的学说主张 |

### 明确不含

- ❌ **建筑、工程**
- ❌ 制度、法令 → **典制**
- ❌ 事件、会议 → **事略**
- ❌ 以作者为主体的传记 → **人物**
- ❌ 空泛「文化兴盛」「学术繁荣」

---

## 二、准入标准（强制）

须**同时**满足：

1. 主语是**作品全名**或**独立思想命题**（非制度名、非事件名）
2. **成书 / 创作 / 上呈 / 学说提出**之年落在**本朝时间范围内**（硬约束）
3. 知名度高（史学界或通识可点名）
4. 宁精勿滥

### 2.1 成书年代（硬约束）

**论著条目的时间锚点 = 作品或学说在本朝被创作、写成、提出或定稿之年**，不是：
- ❌ 作品内容写到的史事年代（《尚书·尧典》写尧舜 ≠ 五帝成书）
- ❌ 后世辑录、整理、注释之年（除非本朝首次成书定稿且学界共识）

| 情形 | 处理 |
|------|------|
| 《尚书》主体成书于周代 | 论著归**周**（若做周朝补全），**禁止**归入五帝 |
| 《史记》记五帝事 | 论著归**西汉**（司马迁成书），五帝朝不建《史记》条 |
| 仅知「传说时代提出」、无法落在本朝 | **不建论著** |

gate 校验：`史略开始年` 须落在 `朝代.json` 起止区间内；跨朝成书一律驳回或改挂正确朝代。

### 2.2 典籍：一书一条，禁止拆篇拆卷

| 禁止 | 必须 |
|------|------|
| 《尚书·尧典》《尚书·舜典》各一条 | 整部《尚书》最多一条，且挂**成书朝代** |
| 《史记·五帝本纪》单条 | 《史记》一条，挂西汉 |
| 同一著作按卷/篇/列传拆多条 | **一书名 = 一条论著** |

**名篇**例外：独立于全集、**单独创作且当代流传**的篇章可单条（如《过秦论》《大风歌》），不得从大部头典籍拆篇冒充名篇。

### 2.3 思想理论子类

适用：**有明确主张、但未形成成文制度体系**的政治/伦理/哲学命题。

- 回答「应当如何 / 为何如此」（价值与认识）
- 不能回答「职权如何分、程序如何走、刑名品类」（那是典制）

## 三、命名

| 类型 | 格式 |
|------|------|
| 书、篇、赋 | 书名号：《史记》《大风歌》《过秦论》 |

## 四、与典制、事略的分界

### 4.1 典制 vs 思想理论（核心分界）

详见 `典制与思想分界.md`。

| 维度 | 典制 | 论著·思想理论 |
|------|------|----------------|
| 层面 | **国家/政治**强制落地的规则 | **个人/学派**的认知与价值主张 |
| 约束力 | 官府法定；违制有官方惩罚 | 道德舆论；无律法治罪 |
| 载体 | 律令、官职、流程、礼仪法典 | 典籍、士人论辩、理想模型 |
| 典型 | 禅让制、推恩令、察举制、礼乐制度 | 天人感应、仁政、儒家禅让观 |

**禅让（三分）**：

| 条目 | 归类 | 关系 |
|------|------|------|
| 禅让制 | 典制 | 联盟权力交接规则体系 |
| 尧舜禅让 | 事略 | 制度下的一次具体实践 |
| 禅让思想 / 天下为公 | 思想 | 挂提出朝代；**不与禅让制双条** |

详情正文可交叉叙述另一维度，索引不重复建条。

### 4.2 其他分界

| 条目 | 归类 |
|------|------|
| 《盐铁论》 | 论著（西汉成书） |
| 盐铁会议 | 事略 |
| 盐铁官营 | 典制 |
| 《春秋繁露》 | 论著 |
| 独尊儒术（政策） | 典制 |
| 天人感应（学说） | 论著 |
| 《尚书·尧典》等篇 | **不归论著**（书成于周，且禁止拆篇） |
| 尧舜禅让（故事） | 事略 |
| 禅让制 | 典制 |
| 禅让思想 | 思想（挂提出朝）；不与禅让制双条 |

**独尊儒术 vs 天人感应**：政策落地归典制，学说体系归论著；人审避免双条重复。

## 五、与人物的关系

- 作者 → **人物条**
- 作品/思想 → **论著条**
- **可共存**；不建「某人作某书」事略

| 保留 | 说明 |
|------|------|
| 司马迁 + 《史记》 | 人 + 书 |
| 司马相如 + 《子虚赋》 | 人 + 篇 |

## 八、书画名作

纳入，但门槛高于典籍：

- 有传世名、史籍明确记载、能定创作年代
- 书画史料常依附人物，**少而精**；若仅能挂靠人物生平、无法独立点名作品 → 不建论著

## 十、LLM Prompt 要点（Step 4）

1. 列典籍、名篇、思想理论；**仅当代成书/提出**
2. **典籍一书一条**，禁止《书名·篇名》拆条
3. 不含建筑、制度、事件
4. 勿参考一期人物索引
5. 子类：`典籍` / `名篇` / `书画` / `思想理论`
6. 每条必填 `成书或传播年` 及 `成书年代依据`（为何落在本朝）
