# 朝代补全格式规范（JSON）

> 本模块：`historiography-dynasty-knowledge`。与卷级标注 JSON 无关。  
> 产出须能经 `append_dynasty_supplement.py` 并入 `史略索引_01至02.json`，并由 `import_box_index_json.py` 导入 `historical_box`。  
> **读者交付物定义**：`朝代知识补全总则.md` §零；正文文体见 `详情写作_共用规范.md` §0（《明朝那些事儿》风格、禁止元叙述）。  
> 详情结构与字数见 `详情撰写规则.md` / `人物详情撰写规则.md`（字数下限，无上限）。  
> 字段名与一期 GLBL 条目**保持一致**。

## 一、文件结构

### 候选清单（Step 2–4，不入库）

路径：`data/05工作流中间产物/朝代知识补全/{朝代}_候选清单.json`

```json
{
  "schema_version": 1,
  "朝代ID": "CD_HX_WUDI",
  "朝代名称": "五帝",
  "generated_at": "ISO8601",
  "candidates": {
    "事略": [],
    "典制": [],
    "论著": []
  }
}
```

### 正式条目（Step 6–8，入库前 SSOT）

路径：`data/06朝代知识补全/索引条目/{朝代}_事略典制论著.json`

```json
{
  "schema_version": 1,
  "著作": "朝代知识补全",
  "朝代ID": "CD_HX_WUDI",
  "朝代名称": "五帝",
  "source_phase": "dynasty_supplement_v1",
  "entries": []
}
```

### 详情译文（Step 6，读者交付物 · 入库 SSOT）

路径：`data/06朝代知识补全/详情/{史略ID}_{史略名称}.json`

与 `04史料翻译/` 隔离。字段与翻译编排器兼容，但**不含** `史料原文`。  
**`翻译详情` 原样进小程序详情页**——须为完整流畅的读者正文（见总则 §零），不是锚点说明或质检备注：

```json
{
  "史略ID": "GLBL_00559",
  "翻译详情": "Markdown 正文…\n\n*参考著作：《史记·…》《汉书·…》*"
}
```

汇总（可选）：`data/06朝代知识补全/详情/朝代知识详情_汇总.json`

```json
{
  "schema": "dynasty-knowledge-detail/v1",
  "updated_at": "ISO8601",
  "count": 0,
  "entries": [
    {
      "史略ID": "GLBL_00559",
      "史略名称": "推恩令",
      "翻译详情": "..."
    }
  ]
}
```

## 二、GLBL 条目必填字段

| JSON 字段 | 说明 | 二期约定 |
|-----------|------|----------|
| `史略ID` | `GLBL_*` 递增 | 脚本分配 |
| `史略名称` | 标题 | 见三类命名规则 |
| `史略简介` | ≤20 字 | 必填 |
| `史略分类` | `事略` / `典制` / `论著` | 枚举 |
| `主要史料出处` | 文献名 | LLM 填，如《史记·…》 |
| `史略开始年` | int | 公元前为负；语义见 §2.1 |
| `史略结束年` | int | 见 §2.1 |
| `一级文明坐标` | 如华夏 | fill_fields 解析 |
| `二级朝代坐标` | 如西汉 | 来自朝代.json |
| `三级政权坐标` | | fill_fields 解析 |
| `四级帝王坐标` | | LLM 建议 + 脚本校验 |
| `文明ID` / `朝代ID` / `政权ID` / `帝王ID` | | 脚本解析 |
| `优先级` | P0–P3 | enrichment 阶段 |
| `优先级判定理由` | | 须点名史略名称 |

### 二期留空或固定值

| 字段 | 值 |
|------|-----|
| `原文字句` | **不填** / null |
| `paragraphs` | `[]` 或省略 |
| `母本著作` | `"朝代补全"` |
| `史略来源` | `"模型补全"` |
| `母本史略ID` | `DYKN_{缩写}_{类}_{序}` |
| `来源著作` | `["朝代补全"]` |
| `来源条目数` | `1` |
| `段落域数` | `0` |
| `人物标签` | 二期**人物条必填流程** | 见 `人物补全规则.md`；由 `person_tag.py` enrichment 写入 |

### Enrichment 字段（Step 7）

| 字段 | 事略 | 典制 | 论著 |
|------|------|------|------|
| `峰值年` | ✓ | ✓ | ✓ |
| `峰值原因` | ✓ | ✓ | ✓ |
| `峰值类型` | `event_climax` | `institutional_maturity` | `thought_spread` |
| `峰值置信度` | ✓ | ✓ | ✓ |
| `人物标签` | ✗ | ✗ | ✗ | **人物七类 ✓** |

## 二·一、史略开始年 / 结束年语义（二期）

须落在 `朝代.json` 起止区间内；`峰值年` 须在 [开始年, 结束年]（`峰值年规则.md` §三）。

| 史略分类 | 开始年 | 结束年 | 说明 |
|----------|--------|--------|------|
| **事略** | 事件关键节点年 | 多数与开始年相同 | 单点事件锚定爆发/转折/结果年；长时段事件可取起止跨度 |
| **典制** | 确立或成熟年 | **与开始年相同** | 对应候选字段 `确立或成熟年` |
| **论著** | 成书/创作/提出年 | **与开始年相同** | 对应候选 `成书或传播年`；非内容所写史事年代 |

人物类（二期 `fill-renwu`）遵 `人物年份规则.md`，不在此表。

gate 校验：三类均检查朝代区间；典制/论著检查开始=结束；峰值年区间检查。

---

除 `名称` 外，**五要素必填**：

```json
  "名称": "七国之乱",
  "主语": "",
  "参与人物": [],
  "动作": "",
  "结果": "",
  "影响": "",

  "主要史料出处": "",
  "边界备注": "",

}
```
