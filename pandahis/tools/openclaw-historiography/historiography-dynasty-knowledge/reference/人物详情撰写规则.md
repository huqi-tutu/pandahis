# 人物详情撰写规则

> SSOT：`historiography-dynasty-knowledge` Step 6 人物详情产出。  
> 风格 SSOT 继承：`historiography-compose/references/翻译规则.md`（规则一至九、十一的写作层）。  
> 索引字段来源：`人物补全规则.md`。  
> 产出路径：`data/06朝代知识补全/详情/{史略ID}_{史略名称}.json`（字段 `翻译详情`）。

---

## 〇、总则

本文档适用于二期**人物七类**（君王 / 宗戚 / 文臣 / 武将 / 宦官 / 庶众 / 蕃祚）的专题详情创作。

- 区别于一期「二十四史人物传记顺译」，为基于史学共识的**人物专题原创叙事**
- 无原文直译约束，但叙事风格与一期译文统一
- 试点朝代：五帝（`CD_HX_WUDI`），规则全朝代通用

**核心原则**：不译原文、只讲共识、结构完整、画面通俗、可考据、无 AI 腔、适度趣味。

**字数纪律（重要）**：

- 本文档**只规定字数下限**，**不规定上限，不规定建议区间**
- 达到下限后，按人物重要性与史料丰度**充分展开**；重要 P0 人物写 2000、3000 字均可
- 一期重要人物译文常见 1500–7000+ 字；二期 P0 核心人物应对齐这一阅读预期，而非「卡在下限就收笔」

## 一、与一期翻译规则的关系

### 1.1 完全继承

| 维度 | 要求 |
|------|------|
| 叙事风格 | 口语化、有画面感；参考《明朝那些事儿》；克制通俗、不低俗、不戏说。长短句交替，关键转折用破折号制造停顿，适当用反问 |
| 注音 | **二期默认全文不注音**（见 §1.3；与一期卷级顺译不同） |
| 地名 | 古地名标注今属地；都城、籍贯须标注。格式「幽陵（今北京以北一带）」。古今同名不标，知名地点不标 |
| 引用 | 关键史实绑定正史出处；格式《史记·××》《汉书·××》。详细规范见 §六「引用规范」 |
| 人物刻画 | 不神化、不脸谱化；决策过程写出纠结和无奈；人物指代多样化（见 §三·四「人物刻画深化」） |
| 幽默 | 见 §六·二「幽默规范」的完整细则 |
| 纯叙事 | 无小标题、无列表、无课堂课件感、无空洞抒情 |
| 异说 | 多史冲突不调和，分别列明并标注争议 |
| 数据真实 | 数字年代精确保留——「九年」不写「好几年」；不确定的数字注明「大约」「据记载」；原文没有不编造 |

### 1.2 完全豁免

- 母本顺译、句序守恒、段落召回
- 史料原文展示（详情页不展示原文入口）
- 单一著作视角（可综合多部正史与史学共识）
- Phase1 `draft_mother` 两阶段顺译流程

### 1.3 注音红线（二期 · 默认全文不注音）

与 `详情撰写规则.md` §1.3 完全一致。人物专名（人名、籍贯、封号）中的常见字一律不注音；仅白名单罕用字可保留注音。

## 二、字数与段落标准

### 2.1 优先级定义

| 级别 | 含义 |
|------|------|
| P0 | 朝代标志性人物；首页推荐、高频阅读 |
| P1 | 支撑朝代主线脉络的关键人物 |
| P2 | 重要但非核心的支撑性人物 |
| P3 | 补充性人物节点 |

### 2.2 字数下限（双轴：优先级 × 史料丰度）

正文不含开篇引入、不含文末「参考著作」。

**主约束**：锚点/信息点覆盖；**辅约束**：`effective_floor`（与 `详情撰写规则.md` §2.2 同逻辑，人物类见 `dynasty_supplement_lib.py` 中 `_PERSON_DENSITY_FLOORS` / `_SHUZHONG_DENSITY_FLOORS`）。

| 人物（除庶众） | P0 S0 | P0 S1 | P0 S2 | P0 S3 | P1 S0 | P2 S0 | P3 S0 |
|----------------|-------|-------|-------|-------|-------|-------|-------|
| 下限（字） | 450 | 650 | 950 | 1000 | 350 | 250 | 150 |

庶众 P0 S0=300；S3 上限与旧版单轴一致（P0 君王 1000、P0 文臣等 700，见下表）。

#### 旧版单轴参考（S3）

| 类型 | P0 下限 | P1 下限 | P2 下限 | P3 下限 |
|------|---------|---------|---------|---------|
| **人物** | 1000 字 | 700 字 | 400 字 | 200 字 |

**充分展开指引**（非硬性上限，供写作者判断）：

| 情形 | 建议 |
|------|------|
| P0 君王，功业宏富、评价争议多（如汉武帝、唐太宗） | 常在 **2000 字以上**；复杂者可至 5000+ |
| P0 文臣/武将，生平曲折、代表事件密集（如诸葛亮、韩信） | 常在 **1500 字以上** |
| P0 宗戚/宦官/庶众，叙事丰沛、身份独特（如吕太后、司马迁） | 常在 **1200 字以上** |
| P2/P3 边角人物 | 达到下限 + 信息点齐全即可，不必硬凑篇幅 |
| 上古/传说期P2/P3，史料稀薄（如嫫母） | 史料本身就有限，不存在「精简」空间。须在有限史料内做最大限度的提取和解读——包括后世文化符号形成、后世文人引用、在更大历史脉络中的象征意义。不可为压缩篇幅而砍掉仅有史料（见 §3.6） |

### 2.3 段落与句数下限

| 级别 | 最少段落 | 每段句数 |
|------|----------|----------|
| P0 | 6 段 | 3–8 句，杜绝单句成段 |
| P1 | 4 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

另：**开篇引入**单独 1 段（100–200 字），不计入上表段落数。

禁止连续 3 个以上单句碎段。

## 三、人物叙事骨架（起承转合）

统一采用起承转合。**篇幅占比为结构导向，不是字数封顶**——某一部分史料丰富，可加长，其他部分相应压缩，但四职能须齐全。

### 3.1 通用骨架｜主语：人物本身

| 职能 | 建议侧重 | 写什么 |
|------|----------|--------|
| **起** | ~15% | **出身与时代**：家世门第、出生背景、早年经历、所处时代格局。写出「这个人从哪里来、在什么样的世界里长大」 |
| **承** | ~35% | **生平主线**：按时间线展开主要经历——入仕/从军/即位/受封、关键节点、重要人际关系。写出「这个人一生干了什么」 |
| **转** | ~30% | **最记忆点**：生平中最被后世记住的事——可以是重大事件、关键决断、经典作品、独特个性。这是全文的叙事高潮，篇幅和笔墨应最集中 |
| **合** | ~20% | **退场与评价**：死亡/离场/结局、后世的定评与争议、对历史进程的影响。写出「这个人被怎样记住」 |

### 3.2 六类侧重（分类决定主线）

通用骨架六类共用，但每类的主线侧重不同：

#### 君王

| 职能 | 侧重 |
|------|------|
| **起** | 出身：父祖、即位背景、少年经历 |
| **承** | 治国主线：制度创设、疆域变迁、用人得失、内政外交 |
| **转** | 标志性功过：最著名的一战/一策/一弊。不可回避重大过失 |
| **合** | 崩/退位、庙号谥号、历代评价 |

#### 宗戚

| 职能 | 侧重 |
|------|------|
| **起** | 出身：家族谱系、入宫/册封背景 |
| **承** | 宫廷主线：与君王关系、家族地位、宫廷博弈 |
| **转** | 最记忆点：临朝称制、宫廷事变、独特命运或影响力 |
| **合** | 结局、身后荣辱、历史评价 |

#### 文臣

| 职能 | 侧重 |
|------|------|
| **起** | 出身：家学渊源、科第/入仕途径 |
| **承** | 仕途主线：官职变迁、政绩要务、文章著述、建言献策 |
| **转** | 最记忆点：标志性政绩/奏议/著作，或关键政治斗争中的角色 |
| **合** | 结局（善终/贬谪/罹祸）、历史定评 |

#### 武将

| 职能 | 侧重 |
|------|------|
| **起** | 出身：从军/起家背景、早年征战 |
| **承** | 征战主线：主要战役、用兵风格、功勋升迁 |
| **转** | 最记忆点：最具代表性的战役或军事贡献；如有跨领域成就（诗文、治政），此处重点展开 |
| **合** | 结局（功成身退/战死沙场/功高震主）、军事史评价 |

#### 宦官

| 职能 | 侧重 |
|------|------|
| **起** | 出身：入宫背景、早年近侍经历 |
| **承** | 权力主线：与君王/后妃关系、权力起伏、关键事件 |
| **转** | 最记忆点：干政顶峰、宫廷事变中的角色、独特影响 |
| **合** | 结局、后世评价 |

#### 庶众

| 职能 | 侧重 |
|------|------|
| **起** | 出身：社会阶层、时代背景 |
| **承** | 生平主线：主要事迹、为何青史留名 |
| **转** | 最记忆点：独一无二的经历、身份或行为 |
| **合** | 后世记述、代表意义 |

#### 蕃祚

> 蕃祚不是个人物，是**边陲汗国、方国、域外邦国、西南割据政权**的集体史略（定义见一期标注 `人物标注规则.md`：匈奴/南越/西域诸国/突厥/吐蕃/南诏/西夏/大理/高丽等）。年轴 = 政权立国年～灭亡年，禁止用人物生卒。

| 职能 | 侧重 |
|------|------|
| **起** | 政权起源：地理位置、族源背景、兴起时代格局 |
| **承** | 政权主线：兴衰脉络——与中原王朝的战和关系、内部权力更迭、疆域变迁 |
| **转** | 最记忆点：最具标志性的战争/和亲/制度/文化影响（如匈奴的冒顿单于时代、吐蕃的松赞干布时期、南诏的天宝战争） |
| **合** | 灭亡/被吞并/融入、后世影响 |

### 3.3 记忆点优先原则（强制）

> **分类决定主线，记忆点决定亮点。**

这是本条规则最核心的约束：

1. **不可机械按分类只写一类事**。六类侧重定义了「承」段的主线方向，但**「转」段必须突破分类边界**——写出这个人物在历史上最被记住的东西，无论它是否属于本类标签。

2. 典型示例：

| 人物 | 史略分类 | 分类主线 | 最记忆点（必须在「转」段写） |
|------|----------|----------|------------------------------|
| 曹操 | 君王 | 魏国创立、制度军政 | **诗歌成就**（建安文学领袖）、多疑枭雄性格 |
| 岳飞 | 武将 | 北伐战功 | 《满江红》词作、精忠报国精神、冤狱悲剧 |
| 司马迁 | 文臣 | 太史令仕途 | 宫刑之辱、《史记》创作 |
| 辛弃疾 | 文臣 | 仕途政绩 | **军事才能**（飞虎军、北伐主张）、词作 |
| 王羲之 | 文臣 | 仕宦经历 | **书法成就**（《兰亭序》、「书圣」） |
| 关羽 | 武将 | 征战功勋 | **忠义形象**、民间崇拜（关公） |

3. **反例**：写关羽只写战功不提忠义、写岳飞只写战役不提《满江红》、写曹操只写政治不提诗歌——这都是不及格的写法。

4. 判断标准：写完后问自己——**「如果只能用一个词/一件事让人记住这个人，会是什么？」**——如果这个词/事没有在「转」段充分展开，则重写。

### 3.4 人物刻画深化

> 继承翻译规则 P1.3，适配人物原创叙事场景。

**决策过程的纠结感**：写出人物在做关键决定时的真实处境——两难选择、各方压力、个人局限。不写「尧果断决定……」，写「尧其实不想用鲧——『鲧负命毁族，不可』——但四岳坚持。尧就听了四岳的话，让鲧去治水。结果九年过去，水一点没治好。这不是尧的错，是四岳坚持推荐的。但尧作为君主，承担了用人不当的责任。」

**人物指代多样化**：同一人物在文中不应反复用同一个称呼。

| 指代方式 | 示例 | 使用限制 |
|----------|------|----------|
| 姓名 | 关羽、云长 | 最常用，默认选择 |
| 官职/身份 | 汉寿亭侯、关将军 | 叙事中自然轮换 |
| 代词 | 他 | 连续不超过 2 句只靠代词 |
| 描述性称呼 | 这位爷、这家伙 | **单篇全文总计不超过 3 次，同一人物最多 1–2 次。同一段落内最多出现一次。** |

✅ 「关羽二话不说，提刀上马。这位将军的脾气，曹操是领教过的。」— 姓名+身份，自然轮换
❌ 「这家伙从小就不一般。这家伙长大后更是不得了。这位爷打仗那是一把好手。」— 一段里三次称呼指同一人，像说书

**禁止编造心理活动**：除非正史明确记载（如诏书、对话、书信中包含），否则不写「刘备心想……」「曹操暗想……」等心理描写。人物的动机和情绪通过行动和话语呈现，而非作者的猜测。

### 3.5 人物异说处理

人物传记中存在公认的多版本记载时（如尧舜禅让中舜的角色），遵守与 `详情撰写规则.md` §3.5 一致的结构约束：

**强制要求**：
- 异说必须在**转段独立成块**，不可被压缩为主题叙事的附录脚注
- 异说块篇幅不能明显小于主体叙事块
- 不替读者选边——不对任一版本做「这才是真相」的暗示性表述

### 3.6 史料稀薄人物的展开策略

史料本身稀薄的上古/传说期P2/P3人物（如嫫母），不存在「可以精简」的空间。

**强制要求**：
- 在有限史料内做最大限度的提取和解读，包括但不限于：后世文化符号形成、后世文人引用（如屈原诗句）、在更大历史脉络中的象征意义
- 不可用「缩短篇幅」作为这类人物的优化方向——史料稀薄时，正确策略是榨干剩余价值，而非进一步压缩

## 四、信息点覆盖 Checklist

写完须逐条可勾选；gate 可人工 + 机器对照索引字段验收。

### 4.1 人物通用（必填）

- [ ] **身份定位**：家世、籍贯、所处朝代与时代背景已在文中明确
- [ ] **生平脉络**：关键人生节点（出生/入仕/即位/重要事件）有清晰时间线
- [ ] **最记忆点**：被后世最记住的特质/事件/作品，已在「转」段充分展开
- [ ] **人际关系**：与同时代关键人物（君王、同僚、对手）的关系已点名
- [ ] **结局**：死亡方式、年份、身后处置明确
- [ ] **历史评价**：后世定评与争议已体现（不脸谱化、不神化）
- [ ] **核心列举**：如果该人物的最记忆点/核心贡献是一个有名称的枚举集合（如九德、九功），正文必须逐一列出所有项。不可用「提出了N条标准」一句话概括代过。皋陶篇提到九德却没列出「宽而栗、柔而立、愿而恭、乱而敬、扰而毅、直而温、简而廉、刚而塞、强而义」→ 不及格

### 4.2 分类专属（至少覆盖一项）

#### 君王

- [ ] 即位背景与方式
- [ ] 标志性制度/政策
- [ ] 重大战争或外交事件
- [ ] 用人得失
- [ ] 庙号谥号与史家评价

#### 宗戚

- [ ] 与册封之君的关系
- [ ] 宫廷事件参与
- [ ] 对政局或继承的影响

#### 文臣

- [ ] 入仕途径与官职变迁
- [ ] 代表性政绩/建言/著作（至少一项）
- [ ] 跨领域成就（若有：军事、文学、艺术等）

#### 武将

- [ ] 代表性战役（至少一场）
- [ ] 用兵风格或军事思想
- [ ] 跨领域成就（若有：诗文、治政、书法等）

#### 宦官

- [ ] 入宫与近侍背景
- [ ] 权力起伏关键节点
- [ ] 对朝政的实际影响

#### 庶众

- [ ] 社会身份与阶层背景
- [ ] 青史留名的独特原因
- [ ] 代表意义

#### 蕃祚

- [ ] 地理位置与族源背景
- [ ] 兴衰脉络（立国、全盛、衰亡的时间线）
- [ ] 与中原王朝的关键互动（战争/和亲/朝贡/册封）

### 4.3 完整性兜底

> 人物传记最关键的是——读者读完不会问「然后呢？他后来怎么了？」

**强制检查**：写完合段之前，必须确认下列信息已覆盖：

| 检查项 | 判断 | 缺失时处理 |
|--------|------|------------|
| 结局 | 人物的死亡方式、年份、身后处置是否已写？ | 正史有记载则必须补足（1–3 句，干净利落）。如「据《史记》，黄帝去世后葬在桥山。」 |
| 退场感 | 如果人物没有明确死亡记录，是否有自然的收束？（如辞官归隐、被贬后不知所终、史书无载） | 如实交代，如「此后史书再无记载。」不编造 |
| 不会戛然而止 | 读者读完最后一段，会不会觉得故事没讲完？ | 在合段用一句评价或后续影响自然收尾 |

> **底线**：哪怕这个人物史料极少，也必须交代结局——哪怕只是「卒年不详」。读者不知道史料有限，只知道你写的故事没讲完。

## 五、开篇引入（单独一段）

- **字数**：100–200 字，独立成段
- **素材**：仅取自索引条目字段（名称、史略简介、朝代、史略分类、主要史料出处），禁止编造
- **作用**：定调「这个人是谁、为什么值得读」
- **过渡**：段末须有自然衔接句进入正文

过渡句示例：

- 君王：然而真正让后人反复评说的，是他在位期间的重大作为与复杂遗产。
- 宗戚：她的命运与王朝脉搏紧密相连，个人荣辱折射出整个时代的权力图景。
- 文臣：比起官职品级，后人记住他的，是那份影响深远的政治遗产与人格魅力。
- 武将：他的生平，是一部战争史，更是一个关于忠诚、勇气与命运的个人传奇。
- 宦官：在皇权的阴影中，他走出了一条极不寻常的生命轨迹。
- 庶众：他并非王侯将相，却以一种独特的方式，在正史中留下了自己的名字。
- 蕃祚：这个政权的兴衰，是中原王朝与周边世界博弈的一个缩影。

## 六、引用规范

> 与翻译规则 P1.4 对齐，适配人物原创叙事场景。

### 6.1 引用原则

人物详情是**原创叙事**而非翻译，不需要逐句引原文。引用服务于两个目的：**增强可信度**（史实有出处）和**增强感染力**（金句无法替代）。

**不引用、直接白话叙述**：人物姓名、字号、家世来源、基本身份、官职、封地。

**可以引用原文并注明出处**：品质/能力描述、金句（「鞠躬尽瘁，死而后已」）、关键历史判断（司马迁论赞）、原文措辞极其精妙不可替代。

### 6.2 引用优先级

从高到低：

1. **名句** — 不引会损失情感冲击力（如「既生瑜，何生亮」）
2. **历史评价** — 不引会损失判断精确性（如陈寿评诸葛亮）
3. **原文精彩表达** — 人物对话或描写极其生动
4. **多版本差异** — 不同史书记载不同的生平细节
5. **其他** — 不引

**自检问句**：不引会损失情感冲击力或历史判断精确性 → 必须引。只损失「知道原文怎么说」→ 不引。

### 6.3 引用频率

长篇（P0/P1）约 5–10 处关键引用，短篇（P2/P3）保留最关键的 2–5 处。人物引语（诏书、奏疏、诗文）优先保留，不强制全文。

### 6.4 三种自然引出

1. 「按《史记》的写法，……」— 最常用
2. 「《史记》原文说『……』——」— 引出金句
3. 「《三国志》补了一层意思：……」— 引入补充史料

**禁止**：「据说」「相传」「有资料说」「一般认为」。

### 6.5 文末格式

正文结束后另起：

```markdown
*参考著作：*
1. 《史记·……》
2. 《汉书·……》
```

### 6.6 与索引一致性

文末列表须与索引 `主要史料出处` **100% 匹配**（顺序可调整，书目不可随意增删）。

## 六·二、幽默规范

> 人物传记的幽默比事略更需分寸感——人的生死荣辱不是笑料。

幽默来自人物性格与处境的反差——是自然感叹，不是硬塞笑话。

**密度**：

| 篇幅 | 幽默点数量 |
|------|-----------|
| 短篇（P2/P3，< 400 字） | 1 个 |
| 中篇（P1，400–700 字） | 1–2 个 |
| 长篇（P0，>700 字） | 2–4 个 |

**分布**：均匀撒在中段，不扎堆。

**禁区**：
- 开篇不玩幽默（读者未认识人物）
- 结尾不玩幽默（盖棺定论需要庄重）
- **死亡描写、政治惨案、冤狱悲剧**——绝对的禁区
- 人物最核心的功绩或悲剧——这些是读者来读的理由，不稀释

**克制原则**：如果一段话本身已足够有力（如岳飞之死、司马迁受刑），不加幽默。

✅ 「曹操这一辈子，用人用得轰轰烈烈，疑人也疑得惊天动地。他睡梦中杀人的故事，到底是真多疑还是故意立威——史书没给准话，但曹操要的就是这个效果。」— 自然感叹
❌ 「曹操这人，心眼比针尖还小。看谁不顺眼就杀谁，活脱脱一个职场PUA。」— 轻浮现代化

## 六·三、六类自动触发

写作中遇到以下六类内容，必须自动触发对应处理。规则与 `详情撰写规则.md` §六·三 一致，以下是人物场景补充：

| 类型 | 触发条件 | 处理 |
|------|----------|------|
| **制度类** | 文中出现制度、官职、法令专名 | 首次出现简要解释。如「司徒——三公之一，主管民政」 |
| **地名类** | 文中出现古地名 | 标注现代位置。格式「涿郡（今河北涿州）」。籍贯地首次必标，征战/任职地选重要的标。古今同名不标，知名地点不标 |
| **人名类** | 文中首次出现配角（非本篇主角） | 简要介绍身份。「荀彧——曹操的首席谋士」「周亚夫——绛侯周勃之子，细柳营名将」 |
| **器物类** | 文中出现古代器物 | 解释。「节钺——代表天子征伐权力的符节和斧钺」 |
| **事件类** | 文中提及主角参与的某一事件为背景 | 一两句补充。「赤壁之战——孙刘联军以少胜多、奠定三国格局的决战」 |
| **补充信息类** | 文中引入非主线史料的观点/细节 | 标注出处。格式「《魏略》载……」 |

> 触发过的内容，后文不再重复标注。

## 六·四、神话/传说材料的批判性引用

上古人物条目中常见的獬豸断案、应龙蓄水等材料，带有浓厚的神话/传说色彩，不可当作史实叙述。规则与 `详情撰写规则.md` §六·四 一致：

**引用准则**：
- 神话材料必须标注「传说」或「据传说」前缀，与基于正史的叙事明确区分
- 重点不在于「讲一个好玩的故事」，而在于**分析该神话在当时政治/社会体系中的功能**
- 禁止以浪漫化语气将神话材料当趣事讲。正确写法侧重解构神话的构造逻辑与社会功能

**反例**：
- ❌ 「这简直是上古时代最生动的一台测谎仪」— 把神话当趣事讲
- ✅ 「说穿了，这就是上古版的测谎仪。皋陶未必真的依赖神兽断案，但他太懂人性了」— 分析神话的构造逻辑

## 七、质量红线（verify 可程序化）

任意不达标 → 驳回重写：

### 7.1 表达禁令

| 类别 | 禁止内容 |
|------|----------|
| AI腔词汇 | 历史长河、时代洪流、命运齿轮、拉开序幕、翻开新篇章、历史终将证明、注定、必然、毫无疑问 |
| 书面词堆砌 | 此外、与此同时、值得注意的是、综上所述、堪称、可谓、不啻、则是 |
| 破折号结尾 | 「——」只能用于句中或句首；段落结束须用句号、问号、感叹号或冒号 |
| 【】引文标记 | 任何情况下禁止 |
| 灌鸡汤 | 禁止强行升华、空洞抒情、正能量总结 |
| 编造心理 | **绝对禁止**编造人物心理活动（「心想」「暗想」「内心觉得」），除非正史明确记载（如诏书、对话中明示） |

### 7.2 结构禁令

| 类别 | 禁止内容 |
|------|----------|
| 小标题/列表 | 无小标题、分节号、列表符号（「第一，…」「一、出身 二、功绩…」） |
| 分节符 | 不用 `---` 等分隔符；段落之间自然叙事衔接 |
| 单句碎段 | 禁止连续 3 个以上单句成段 |
| 描述性称呼超限 | 全文「这家伙/这位爷」等不超过 3 次，同一人物不超过 2 次 |

### 7.3 内容红线

| 类别 | 规则 |
|------|------|
| 字数 | 不得低于 §2.2 对应下限 |
| 段落 | 不得少于 §2.4 最少段落 |
| 引用 | 须有文末 `*参考著作：*`；关键史实有《》出处 |
| 格式 | 禁止【】批注体；**默认全文不注音**（见 §1.3 白名单） |
| 数据真实 | 数字年代精确保留——「九年」不写「好几年」。不确定写「大约」「据记载」。不编造 |
| 内容 | 不编造硬史实；不调和异说；多史冲突分别列明；不给无出处发挥写「据说」「相传」 |
| 开篇引入 | 须独立成段（100–200 字），末句有自然过渡；素材仅来自索引字段 |
| 记忆点 | 「转」段须有明确的最记忆点，不可与「承」段平庸平铺无区别 |
| 脸谱化 | 不神化、不丑化、不脸谱化；决策过程写出纠结和无奈 |
| 分类机械 | 不可按分类只写一类事——跨领域成就是强制覆盖项（见 §四.2 分类专属「跨领域成就」字段） |
| 完整性 | 合段必须交代结局——死亡/退场/史书无载，不得戛然而止（见 §四.3「完整性兜底」） |
| 过程禁编 | **原始文献未记载的战斗过程、对话内容、具体年份，一律不准编造。** 人物事迹中的决策细节、心理活动、与他人对话，除非正史明确记载（如诏书、奏疏、对话原文），否则不可补充。本规则适用于全朝代，上古/先秦人物尤须从严。 |
| 核心列举 | 人物的最记忆点定义了一个有名称的枚举集合（如九德），但正文未逐项列明全部项目 → 驳回（见 §4.1 核心列举项）。用「提出了N条标准」一句话概括代过，等同于没写。 |
| 异说处理 | 人物传记中存在公认多版本记载，异说被处理为正文以外的边角料 → 驳回（见 §3.5）。异说必须在转段独立成块，篇幅与主叙事相当。 |
| 史料稀薄 | 上古P2/P3人物史料本就稀薄，不可用「精简」为由进一步压缩。正确方向是在有限史料内做最大限度的提取与解读（见 §3.6）。 |
| 神话材料 | 神话/传说材料被当作史实叙述 → 驳回（见 §六·四）。必须标注「传说」前缀，重点分析其文化功能而非讲述故事本身。 |

## 八、合格 / 不合格对比

### 8.1 武将：关羽（P0）

**❌ 不合格（约 180 字）**

> 关羽，字云长，河东解县人。早年跟随刘备起兵，征战四方。建安五年被曹操俘虏，斩杀颜良解白马之围后回归刘备。镇守荆州期间北伐襄樊，水淹七军威震华夏，后被孙权偷袭荆州，兵败被杀。

缺：家世背景、性格刻画、忠义形象、「转」段缺失（最记忆点——忠义与民间崇拜完全没写）、历史评价、字数远低于 P0 下限 1000 字。

**✅ 合格（≥1000 字，起承转合齐全）**

须包含：家世与早年经历 → 跟随刘备的征战主线 → **忠义形象**（降汉不降曹、千里走单骑）与**民间关公崇拜**作为「转」段重点展开 → 败走麦城与身后哀荣 → 历代追封与关公信仰；六类专属 checklist 可勾选；文末参考著作完整。

### 8.2 文臣：王羲之（P0）

**❌ 不合格（约 150 字）**

> 王羲之，字逸少，琅琊临沂人，东晋官员。曾任右军将军、会稽内史，人称王右军。在官场上并无太大建树，后来辞官归隐。

缺：跨领域成就——**书法**完全没写；这是王羲之被后世记住的唯一原因，不提书法等于没写王羲之。远低于 P0 下限 1000 字。

**✅ 合格（≥1000 字）**

须包含：琅琊王氏家世 → 仕途经历（右军将军、会稽内史）→ **「转」段以书法为核心**（《兰亭序》、书圣地位、对后世影响）充分展开 → 辞官与晚年 → 书法史上的不朽地位。

### 8.3 文臣：皋陶（P1）— 核心列举反例

**❌ 不合格**

> 在《尚书·皋陶谟》里，他系统性地提出为政者的九德，强调只有修养自身的德行，才有资格去评判他人的善恶。

不管篇幅多长，提到九德但没有列出「宽而栗、柔而立、愿而恭、乱而敬、扰而毅、直而温、简而廉、刚而塞、强而义」→ 驳回。读者读完不知道九德是什么。**核心列举未展开，视为不合格。**

**✅ 合格（≥700 字）**

须在转段逐一列出九德全部九项（宽而栗、柔而立、愿而恭、乱而敬、扰而毅、直而温、简而廉、刚而塞、强而义），再分析其对后世儒家「修身齐家治国平天下」思想的前身意义。

```text

         - 自检 §七 红线

Phase C  verify
         - 字数 ≥ 下限（无上限检查）
         - 段落数、禁词、参考著作、信息点覆盖
         - 「转」段记忆点检查（不可与「承」段平庸平铺无区别）
```
