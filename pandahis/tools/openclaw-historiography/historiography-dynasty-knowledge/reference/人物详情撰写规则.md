# 人物详情撰写规则

> compose-detail 注入块之二，与 `详情写作_共用规范.md` 拼接。  
> 事略/典制/论著见 `详情撰写规则.md`。  
> 索引字段来源：`人物补全规则.md`。示例见 `reference/附录/`。

## 一、段落标准

正文不含开篇引入、不含「参考著作」。字数下限见 prompt `## 硬性要求`。

| 级别 | 最少段落（含开篇引入另计 1 段） | 每段句数 |
|------|--------------------------------|----------|
| P0 | 7 段 | 3–8 句 |
| P1 | 5 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

---

## 二、起承转合（通用骨架）

| 职能 | 写什么 |
|------|--------|
| **起** | 出身与时代：家世、早年、所处格局 |
| **承** | 生平主线：关键节点、官职/征战/宫廷关系 |
| **转** | **最记忆点**：后世最记住的事/作品/性格 — 笔墨最集中 |
| **合** | 退场与评价：结局、身后定评、历史影响 |

---

## 三、六类侧重（分类决定「承」段主线）

| 类 | 起 | 承 | 转 | 合 |
|----|----|----|----|-----|
| **君王** | 即位背景、少年 | 制度、疆域、用人、外交 | 标志性功过（含过失） | 崩退、庙谥、史评 |
| **宗戚** | 谱系、册封 | 与君王关系、宫廷博弈 | 临朝/事变/独特命运 | 结局、荣辱 |
| **文臣** | 家学、入仕 | 官职、政绩、著述、建言 | 标志性政绩/著作/政争角色 | 结局、定评 |
| **武将** | 从军起家 | 主要战役、用兵、升迁 | 代表战役；跨领域成就（诗文等） | 结局、军事史评价 |
| **宦官** | 入宫背景 | 与君王/后妃、权力起伏 | 干政顶峰、事变角色 | 结局、史评 |
| **庶众** | 阶层背景 | 为何青史留名 | 独一无二经历 | 后世记述、代表意义 |
| **蕃祚** | 地理、族源 | 兴衰、与中原战和 | 标志性战争/和亲/制度 | 灭亡/融入、影响 |

> 蕃祚 = 边陲政权集体史略（年轴为立国～灭亡，非人物生卒）。

---

## 四、记忆点优先（强制）

**分类决定主线，记忆点决定亮点。**

1. 「转」段须**突破分类边界** — 写出最被记住的东西，无论是否属本类标签
2. 写完后自问：**若只能用一个词/一件事让人记住此人，是什么？** — 须在「转」段充分展开
3. **反例**：关羽只写战功不提忠义；岳飞只写战役不提《满江红》；曹操只写政治不提诗歌

| 人物 | 分类 | 转段必须写到 |
|------|------|-------------|
| 曹操 | 君王 | 诗歌/建安文学、性格 |
| 岳飞 | 武将 | 《满江红》、冤狱 |
| 司马迁 | 文臣 | 宫刑、《史记》 |
| 王羲之 | 文臣 | 书法、《兰亭序》 |

## 五、人物刻画

- **决策纠结感**：写出两难与用人责任，非「果断决定…」
- **指代多样化**：姓名、官职轮换；代词连续不超过 2 句
- **描述性称呼**（「这家伙」「这位爷」）：全文 ≤3 次，同一人 ≤2 次，同段 ≤1 次
- **禁止编造心理**：「心想」「暗想」除非正史明确记载（诏书、对话原文）

---

## 六、异说 / 稀薄 / 开篇

- **异说**：与共用规范 §1.3 一致，块位在**转段**
- **史料稀薄**：用共用规范 §1.1 延伸类型充实；**禁止**编造细节或元叙述凑字
- **开篇引入**：定调「此人是谁、为何值得读」；素材仅索引字段；段末自然进入正文

## 七、信息点 Checklist

### 7.1 通用（必填）

- [ ] 身份定位、生平脉络、最记忆点（转段）、关键人际关系
- [ ] 结局（死亡/年份/处置；无载则如实交代）
- [ ] 历史评价（不神化、不脸谱化）
- [ ] **核心列举**：九德等枚举须逐项列名

### 7.2 分类专属（至少一项）

- **君王**：即位方式、制度/战争、用人、庙谥
- **宗戚**：与君王关系、宫廷影响
- **文臣/武将**：代表成就 + **跨领域成就**（若有）
- **宦官**：权力节点、朝政影响
- **庶众**：阶层、留名原因、代表意义
- **蕃祚**：族源、兴衰线、与中原关键互动

### 7.3 完整性兜底

合段前确认：读者不会问「然后呢？」。哪怕「卒年不详」也须交代，不可戛然而止。

---

## 八、人物专属红线

1. 「转」与「承」不可平庸重复 — 转段必须有独立记忆点
2. 不可按分类机械只写一类事 — 跨领域成就是强制项
3. 合段须交代结局/退场 — 见 §7.3
4. 幽默密度略低于事略：P0 长篇 2–4 点；死亡/冤狱/惨案绝对禁区
