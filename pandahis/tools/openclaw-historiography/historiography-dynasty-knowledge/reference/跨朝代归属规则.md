# 跨朝代归属规则（候选 · 入库硬纪律）

> **SSOT**：补全候选、遗漏审阅、research/candidates prompt、gate 均须遵守。  
> 与 `historiography-annotate/reference/峰值年规则.md`、`人物年份规则.md` 配套；**本规则管「进哪一朝的候选池」**，不单管字段格式。

---

## 一、核心原则

1. 每条史略**只属于一个朝代**（当前跑批的 `{朝代}` 只是其中之一）。
2. **候选阶段须主动剔除**归属相邻朝代的条目；不能等 gate 报错再删。
3. 判定口径：**预估该条若入库，其 pick year（归属判定年）会落在哪个 `朝代.json` 区间**，即归哪一朝。
4. **gate 硬检**：`史略开始年`、`峰值年` 须落在本朝 `开始时间`～`结束时间` 内（君王见 §二例外）。

---

## 二、pick year（归属判定年）按分类

| 史略分类 | pick year | 说明 |
|----------|-----------|------|
| **君王** | **即位年** | **唯一例外**：不以峰值年、不以生卒年；与 `帝王.json` 一致 |
| **诸侯** | **即位年** | 列国国君，同君王逻辑 |
| **蕃祚** | **立国/封制年**（= 史略开始年） | 政权/部族/方国建号、入据之年 |
| **文臣 / 武将 / 宗戚 / 宦官 / 庶众** | **峰值年** | 历史/政治/军事/思想**影响最高峰**所在年；须预估峰值年落入哪一朝。生卒跨朝时，**不以生年默认本朝** |
| **事略** | **事件高潮年**（= 峰值年） | 短事件可用发生年；长过程取转折/决战年 |
| **典制** | **制度成熟/全面推行年** | 实质在本朝萌芽、下朝才体系化者 → **归下朝** |
| **论著** | **成书/创作/提出年** | 史略开始年＝史略结束年；跨朝成书**整书归成书朝** |

**口诀**：除君王/诸侯外，**一律用 pick year 落点定归属**；君王/诸侯**只用即位年**。

---

## 三、操作要求（候选 / 遗漏审阅 / LLM prompt）

生成或审阅 `{朝代}_候选清单`、外部查漏清单时，**每条须自检**：

1. 估算 pick year（见 §二）。
2. 查 `data/01历史坐标数据/朝代.json`：pick year 落在哪个朝代的 `[开始时间, 结束时间]`。
3. 若 **≠ 当前跑批朝代** → **不得列入**本朝候选；改挂正确朝代或删除。
4. 边界年（如战国末 -221）：**统一以 `朝代.json` 区间为准**；pick year 超出本朝结束年 → 归下一朝。

候选 JSON 建议填 `边界备注` 说明归属依据；gate 仍校验年份字段。

---

## 四、典型反例（跑批「战国」时禁止入候选）

战国区间见 `朝代.json`（通常 **前475—前221**）。下列 pick year 主要落在 **秦** 或统一后，**不得**作为战国候选：

| 名称 | 分类 | 为何不属战国 |
|------|------|--------------|
| 李斯 | 文臣 | 主峰为相秦、定法、统一文字度量衡（-221 后） |
| 吕不韦 | 文臣 | 史评主轴为辅政始皇、定秦政；归属 **秦**，非列国争霸期文臣 |
| 蒙恬 | 武将 | 北击匈奴、修长城、守北疆均在统一后 |
| 赵高 | 宦官 | 始皇死后专权，属秦末 |
| 高渐离 | 庶众 | 刺秦在统一后 |
| 秦灭六国统一 | 事略 | 高潮在 -221 灭齐，归属 **秦**（或秦事略），不归战国 |
| 统一度量衡/书同文 | 典制 | 秦制，成于统一后 |

**仍属战国示例**（对照）：商鞅变法、长平之战、胡服骑射、李悝变法、合纵连横、王翦/李牧 **若 pick year 在 -221 前** 可留战国。
