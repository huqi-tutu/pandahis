# 详情撰写规则（事略 / 典制 / 论著）

> compose-detail 注入块之二，与 `详情写作_共用规范.md` 拼接。  
> 人物七类见 `人物详情撰写规则.md`。  
> 示例 / 工作流 / 字数详表：`reference/附录/`。

---

## 一、段落标准

正文不含开篇引入、不含「参考著作」。具体字数下限见 prompt `## 硬性要求`（由优先级 × 史料丰度计算）。

| 级别 | 最少段落（含开篇引入另计 1 段） | 每段句数 |
|------|--------------------------------|----------|
| P0 | 7 段 | 3–8 句 |
| P1 | 5 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

开篇引入 100–200 字，独立一段，不计入上表。

---

## 二、起承转合（三类骨架）

篇幅占比为结构导向，非字数封顶；四职能须齐全。

### 2.1 事略（主语：事件）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代局面、核心矛盾、为何发生 |
| **承** | 时间线：导火索、各方动作、关键节点 |
| **转** | 高潮、战局/政争转折、关键决策与争议 |
| **合** | 结局、即时改变、对后世格局的影响 |

### 2.2 典制（主语：制度）

| 职能 | 写什么 |
|------|--------|
| **起** | 前制弊端、治理痛点、确立刚需 |
| **承** | 制度内核、推行流程、适用范围、配套机制 |
| **转** | 推行阻力、落地变形、史家褒贬争议 |
| **合** | 当朝成效、后续演变、制度史意义 |

### 2.3 论著（主语：作品/思想）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代思潮、社会变局、作者际遇与动机 |
| **承** | 体例结构、核心主旨、代表篇章或命题 |
| **转** | 学界争议、思想局限、时代特殊性 |
| **合** | 传播影响、史学/文化地位 |

---

## 三、内容延伸

**前提**：延伸不得突破 §1 底稿池；维基【核心】写主叙事，【延伸】写合段后世，异说走锚点 `legend_facts`。

| 类型 | 写法 |
|------|------|
| 开篇/起段 | 一两句时代背景；仅当底稿/锚点已有 |
| 中间 | 术语、制度、人物关系 — 一句说清，不扩写底稿未载流程 |
| 合段 | 后世影响、制度史意义、后世诠释（framing 须明确） |

**铁律**：底稿无则叙事性留白（§0.3），不编心理、不生拉典故、不写合规口号。

---

## 四、异说处理（多版本条目）

- 异说在**起段或转段独立成块**，不可压成文末一句脚注
- 异说块篇幅不得明显小于主叙事；不替读者选边
- ✅ 起段同时抛出两套叙事；转段分析张力；合段收束不强行调和
- ❌ 全文以主叙事为主，末尾捎带「另有说法」

---

## 五、史料稀薄条目（P2/P3 上古）

底稿与锚点有限，**不可再压缩**。用 `详情写作_共用规范.md` §1.1 允许延伸（异说并陈、后世诠释、制度史意义、叙事性留白）充实，**禁止**编造流程细节或元叙述凑字。

---

## 六、信息点 Checklist

### 6.1 事略（五要素）

- [ ] 主语、参与人物、动作、结果、影响
- [ ] 异说（若适用）：独立成块，见 §四

### 6.2 典制（四要素 + 列举）

- [ ] 制度类型、核心主旨、确立年（对齐索引）、双向影响
- [ ] **核心列举**：五礼/五刑/九官等枚举须逐项列名

### 6.3 论著（五要素 + 列举）

- [ ] 子类、核心主旨、作者、成书年（对齐索引）、多维影响
- [ ] **核心列举**：九州/九章等枚举须逐项列名

---

## 七、类型专属红线（verify/Kimi 难检，compose 须前置）

1. 事略「承/转」须有可追踪的时间线与节点，不可只有结论
2. 典制「承」须写清运作机制，不可只写「建立了XX制度」
3. 论著「承」须写清体例或核心命题，不可只写「很重要」
4. 与索引 `史略开始年` / 主要史料出处不一致 → 不合格
