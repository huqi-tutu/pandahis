# 朝代知识详情撰写规则

> SSOT：`historiography-dynasty-knowledge` Step 6 详情产出。  
> 风格 SSOT 继承：`historiography-compose/references/翻译规则.md`（规则一至九、十一的写作层）。  
> 产出路径：`data/06朝代知识补全/详情/{史略ID}_{史略名称}.json`（字段 `翻译详情`）。

## 〇、总则

本文档适用于二期**事略 / 典制 / 论著**专题详情创作。

> 人物七类详情规则见 `人物详情撰写规则.md`（本规则的姐妹文档）。

- 区别于一期「二十四史人物传记顺译」，为基于史学共识的**专题原创叙事**
- 无原文直译约束，但叙事风格与一期译文统一
- 试点朝代：五帝（`CD_HX_WUDI`），规则全朝代通用

**核心原则**：不译原文、只讲共识、结构完整、画面通俗、可考据、无 AI 腔、适度趣味。

**字数纪律（重要）**：

- 本文档**只规定字数下限**，**不规定上限，不规定建议区间**
- 达到下限后，按主题重要性与史料丰度**充分展开**；重要 P0 事略写 2000、3000 字均可
- 一期重要人物译文常见 1500–7000+ 字；二期 P0 核心事略应对齐这一阅读预期，而非「卡在下限就收笔」

## 一、与一期翻译规则的关系

### 1.1 完全继承

| 维度 | 要求 |
|------|------|
| 叙事风格 | 口语化、有画面感；参考《明朝那些事儿》；克制通俗、不低俗、不戏说。长短句交替，关键转折用破折号制造停顿，适当用反问 |
| 注音 | **二期默认全文不注音**（见 §1.3；与一期卷级顺译不同） |
| 地名 | 古地名标注今属地；重大战场、都城须标注。格式「幽陵（今北京以北一带）」。古今同名不标（泰山），知名地点不标（长江），特定河段要标（若水→今四川雅砻江） |
| 引用 | 关键史实绑定正史出处；格式《史记·××》《汉书·××》。详细规范见 §六「引用规范」 |
| 人物刻画 | 好人不神化，坏人不脸谱化。决策过程写出纠结和无奈，写出人的复杂性（见 §三 叙事骨架） |
| 幽默 | 见 §六·二「幽默规范」的完整细则 |
| 纯叙事 | 无小标题、无列表、无课堂课件感、无空洞抒情 |
| 异说 | 多史冲突不调和，分别列明并标注争议 |
| 数据真实 | 数字年代精确保留——「九年」不写「好几年」；不确定的数字注明「大约」「据记载」；原文没有不编造 |

### 1.2 完全豁免

- 母本顺译、句序守恒、段落召回
- 史料原文展示（详情页不展示原文入口）
- 人物传记时序（以专题主题重构结构）
- 单一人物视角（可宏观全局叙事）
- Phase1 `draft_mother` 两阶段顺译流程

### 1.3 注音红线（二期 · 默认全文不注音）

**定位**：朝代知识详情面向**具备通识文史素养的成年读者**，不是识字教辅、不是小学生小程序。

**默认规则：全文不得出现「汉字（拼音）」标注。**

下列情况**一律禁止**注音（非穷举）：

| 类别 | 禁止示例 |
|------|----------|
| 通识君王/人物 | 尧、舜、禹、黄帝、许由、皋陶、伯益、夔、鲧、丹朱、巢父 |
| 通识地名 | 箕山、颍水、会稽、阳城（山、水、城等常见字） |
| 常见动物/意象 | 鹪鹩、偃鼠、牛犊 |
| 时代/称谓 | 尧帝、舜帝、五帝时代、华夏、部落联盟 |

**唯一例外（白名单）**：正文出现下列**罕用字**专名时，可保留该词注音（脚本 `fix_pinyin.py` / gate 同步）：

`颛顼、帝喾、瞽叟、瞽瞍、娵訾、妫汭、獬廌、獬豸、饕餮、梼杌、穷奇、浑沌、魑魅、少皞`

**违规示例**：

- ❌ `许由（xǔ yóu）`、`箕山（jī shān）`、`偃鼠（yǎn shǔ）`
- ✅ `许由`、`箕山`、`偃鼠`
- ✅ `颛顼（zhuān xū）`（白名单罕用字专名）

一期卷级顺译仍遵 `翻译规则.md` 规则七；**二期 compose-detail 不适用该宽松口径**。

## 二、字数与段落标准

### 2.1 优先级定义

| 级别 | 含义 |
|------|------|
| P0 | 朝代标志性事件 / 制度 / 典籍；首页推荐、高频阅读 |
| P1 | 支撑朝代主线脉络的关键内容 |
| P2 | 支线事件、细分制度、小众典籍 |
| P3 | 边角知识点、辅助科普 |

### 2.2 字数下限（双轴：优先级 × 史料丰度）

正文不含开篇引入、不含文末「参考著作」。

**主约束**：锚点/信息点覆盖齐全；**辅约束**：`effective_floor`（见下表 + 锚点加成，cap 至 S3 旧版上限）。

#### 2.2.1 史料丰度 S0–S3

| 档位 | 含义 | 典型场景 |
|------|------|----------|
| **S0** | 极薄 | 五帝传说、单条神话、后世附会为主 |
| **S1** | 偏薄 | 先秦上古、数条文献可互证 |
| **S2** | 中等 | 有母本片段或较完整文献链 |
| **S3** | 充沛 | 有母本顺译、史料密集（等同一期译文） |

索引可显式填写 `史料丰度`；未填时 gate 按朝代/锚点推断（五帝补全默认 S0–S1）。

#### 2.2.2 effective_floor 基线（事略 / 典制 / 论著）

| 类型 | P0 S0 | P0 S1 | P0 S2 | P0 S3 | P1 S0 | P1 S1 | P2 S0 | P3 S0 |
|------|-------|-------|-------|-------|-------|-------|-------|-------|
| **事略** | 450 | 650 | 950 | 1000 | 350 | 550 | 250 | 150 |
| **典制** | 350 | 500 | 700 | 700 | 280 | 400 | 200 | 120 |
| **论著** | 350 | 500 | 700 | 700 | 280 | 400 | 200 | 120 |

完整 P1–P3 × S2–S3 表见 `dynasty_supplement_lib.py`；S3 与旧版 §2.2 单轴下限一致。

**锚点加成**（有锚点 JSON 时）：`+30/条 hard_facts`，`+20/条 legend_facts`，`+40/核心列举项`；总和 cap 至 S3 上限。

**S0/S1 豁免**：锚点全覆盖且 `detail_review` 审校通过时，不因「未达旧版 P0=1000」而失败。

#### 2.2.3 旧版单轴参考（S3 / 有母本）

| 类型 | P0 | P1 | P2 | P3 |
|------|----|----|----|-----|
| **事略** | 1000 | 700 | 400 | 200 |
| **典制** | 700 | 500 | 300 | 150 |
| **论著** | 700 | 500 | 300 | 150 |

**充分展开指引**（非硬性上限，供写作者判断）：

| 情形 | 建议 |
|------|------|
| P0 事略，多线博弈、转折密集（如七国之乱、楚汉战争） | 常在 **1500 字以上**；过程复杂者可至 3000+ |
| P0 典制，牵涉制度沿革长（如察举、盐铁政策体系） | 常在 **1000 字以上** |
| P0 论著，体例宏大（如《史记》《汉书》） | 常在 **1200 字以上** |
| P2/P3 边角知识点 | 达到下限 + 信息点齐全即可，不必硬凑篇幅 |
| 上古/传说期P2/P3，史料稀薄（如嫫母） | 史料本身就有限，不存在「精简」空间。须在有限史料内做最大限度的提取和解读——包括后世文化符号形成、文献中每一处可用信息、在更大历史脉络中的象征意义。不可为压缩篇幅而砍掉仅有史料（见 §3.6） |

> verify 只拦「低于下限」，不拦「写太长」。

### 2.3 为何 P0 事略在 S3 下设 1000 字下限

P0 事略在 **S3（有母本/史料充沛）** 时是用户深度阅读的核心。仅 200 字只能写「事件简介」，无法承载：时代背景、各方博弈、过程细节、矛盾转折、成败原因、即时与长远影响。**S0/S1 传说期条目不适用此条**，以锚点覆盖与 effective_floor 为准。

### 2.4 段落与句数下限

| 级别 | 最少段落 | 每段句数 |
|------|----------|----------|
| P0 | 6 段 | 3–8 句，杜绝单句成段 |
| P1 | 4 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

另：**开篇引入**单独 1 段（100–200 字），不计入上表段落数。

禁止连续 3 个以上单句碎段。

## 三、三类叙事骨架（起承转合）

统一采用起承转合；**篇幅占比为结构导向，不是字数封顶**——某一部分史料丰富，可加长，其他部分相应压缩，但四职能须齐全。

> 下列大纲为**写作结构示范**（含五帝、西汉等举例），非每个朝代都须维护专属大纲；试跑朝代外直接按骨架 + 索引字段写即可。

### 3.1 事略｜主语：事件本身

| 职能 | 建议侧重 | 写什么 |
|------|----------|--------|
| **起** | ~20% 起笔，可更长 | 时代局面、核心矛盾、「为什么会发生」 |
| **承** | ~35% 起笔，可更长 | 时间线：导火索、各方动作、关键节点 |
| **转** | ~25% 起笔 | 高潮、战局/政争转折、关键决策与争议 |
| **合** | ~20% 起笔 | 结局、即时改变、对后世格局的影响 |

**五帝试点示例大纲：阪泉之战（P0）**

- 起：黄帝与炎帝部族联盟矛盾、涿鹿前后格局
- 承：阪泉三次交锋、黄帝用兵与联盟整合
- 转：炎帝部族归附、华夏联盟雏形确立
- 合：为后续涿鹿抗蚩尤、联盟扩张奠基

### 3.2 典制｜主语：制度本身

| 职能 | 写什么 |
|------|--------|
| **起** | 前制弊端、治理痛点、确立刚需 |
| **承** | 制度内核、推行流程、适用范围、配套机制 |
| **转** | 推行阻力、落地变形、史家褒贬争议 |
| **合** | 当朝成效、后续演变、制度史意义 |

**五帝试点示例大纲：禅让制（P0）**

- 起：部落联盟权力传承难题、世袭与推举之争
- 承：推举、考察、摄政、即位等运作程序
- 转：丹朱/商均争议、禹后启篡夏终结禅让
- 合：制度史地位；儒家禅让观在详情中作后世解读

### 3.3 论著｜主语：作品 / 思想

| 职能 | 写什么 |
|------|--------|
| **起** | 时代思潮、社会变局、作者际遇与创作动机 |
| **承** | 体例结构、核心主旨、代表篇章或命题 |
| **转** | 学界争议、思想局限、时代特殊性 |
| **合** | 传播影响、史学/文化地位 |

**五帝试点示例大纲：羲和观象授时（P0 典制/论著交界，按典制写）**

- 起：农业立命时代对节气的刚需
- 承：尧命羲和分宅四方、观象授时
- 转：四方观测与闰月校正的技术与政治意义
- 合：上古历法制度雏形，影响后世正朔观念

### 3.4 内容延伸

朝代知识详情是**原创叙事**（非翻译），不存在母本锚点约束。但延伸仍需遵守以下原则：

**延伸来源**：只引确凿史实——同一条目的其他正史记载、后世史学共识、有出处的评价与影响。禁止凭空补充。

**三类延伸**：

| 类型 | 时机 | 写法 |
|------|------|------|
| **开篇延伸** | 起段或开篇引入中 | 用一两句点出时代背景或后续影响，让读者立刻理解「为什么这件事重要」。不另起大段背景介绍 |
| **中间延伸** | 对有理解门槛的描述 | 在叙述中自然补充制度背景、人物关系、术语解释。如「推恩令——这是汉武帝想出来的一招，核心就一句话：诸侯的封地不能只传给嫡长子，庶子也能分。听起来是给庶子们发福利，实际上是让诸侯国越分越小。」 |
| **收尾延伸** | 合段 | 基于史实补后续影响或后世评价。如「后来周武王伐纣成功后，做的第一件事就是封比干之墓。比干被后世尊为『谏臣之祖』。」 |

**延伸铁律**：
- 只引确凿史实，不瞎编历史事件
- 不想象人物心理活动（除非正史明确记载）
- 不生拉硬扯不相干典故
- 不强行升华灌鸡汤
- 无延伸材料时宁可干净利落，不硬凑

### 3.5 异说处理（有争议条目专用）

条目存在公认的多版本记载时（如尧舜禅让的儒家叙事 vs《竹书纪年》政变叙事），必须遵守以下结构约束：

**强制要求**：
- 异说必须在**起段或转段独立成块**，不可被压缩为主体叙事的附录脚注
- 异说块篇幅不能明显小于主体叙事块——不能让读者感觉「主要版本讲了三段，另一个版本只提了一句」
- 不替读者选边——不对任一版本做「这才是真相」的暗示性表述

**正确结构示例**：
- 起段同时抛出两套叙事（如「儒家说天下为公，而《竹书纪年》写了五个字：舜囚尧」）
- 承段按时间线展开事件过程
- 转段对两套叙事的张力做分析（如「不管信哪个版本，推让仪式至少建立了一个政治传统」）
- 合段收束争议，不强行调和

**反例**：
- ❌ 全文以儒家叙事为主线，在末尾一段捎带提一嘴「另有说法认为这是一场政变」
- 这是把异说当边角料处理——读者的认知已被主叙事锚定，异说起不到纠偏作用

### 3.6 史料稀薄条目的展开策略

史料本身稀薄的上古/传说期P2/P3条目（如嫫母），不存在「可以精简」的空间——原文就那几段话，再砍就没了。

**强制要求**：
- 在有限史料内做最大限度的提取和解读，包括但不限于：后世文化符号形成、引用文献的每一处可用信息、该条目在更大历史脉络中的象征意义
- 不可用「缩短篇幅」作为这类条目的优化方向——史料稀薄时，正确策略是榨干剩余价值，而非进一步压缩

## 四、信息点覆盖 Checklist

写完须逐条可勾选；gate 可人工 + 机器对照索引字段验收。

### 4.1 事略（五要素）

- [ ] **主语**：事件主体在正文明确
- [ ] **参与人物**：关键君臣、将领、对立势力代表已点名
- [ ] **动作**：决策、军事、政治、舆论行动可追踪
- [ ] **结果**：胜负、处置、收场明确
- [ ] **影响**：当朝即时 + 长线历史影响
- [ ] **异说**（仅适用有公认多版本记载的条目）：异说已在起段或转段独立成块，篇幅与主叙事相当，未被处理为附录脚注（见 §3.5）

### 4.2 典制（四要素）

- [ ] **制度类型**：政治 / 经济 / 军事 / 选官 / 律法等
- [ ] **核心主旨**：要解决什么问题
- [ ] **确立年**：与索引 `史略开始年` 一致
- [ ] **双向影响**：成效 + 弊端或落地问题
- [ ] **核心列举**：如果该典制的核心内容是一个有名称的枚举集合（如五礼、五刑、九官分职），正文必须逐项列出所有项。不可用「设立了N种官职/礼制/刑罚」一句话概括代过

### 4.3 论著（五要素）

- [ ] **子类**：典籍 / 名篇 / 书画 / 思想理论
- [ ] **核心主旨**：创作内核
- [ ] **作者**：与索引信息一致
- [ ] **成书年**：与索引年份一致
- [ ] **多维影响**：史学、文化、思想传承
- [ ] **核心列举**：如果该论著的核心内容是一个有名称的枚举集合（如九州、九章），正文必须逐项列出所有项。不可用「划分了N个区域/章节」一句话概括代过

## 五、开篇引入（独立一段）—— 策略选择制

### 5.1 核心原则

开篇引入只有一个目的：**三秒内让读者想读下去**。

铺垫要有，但不能用套路铺垫。规则不给模板，给判断框架——你根据主题特征自主选择策略，然后执行。

### 5.2 硬性禁令

以下开头方式**任何一篇都不准用**：

- ❌ 「在上古/远古/XX时期，XX大地……」——时间地点开场白
- ❌ 「在华夏文明的长河中……」——宏大抒情开场
- ❌ 「这是中国历史上最早/第一次/最重要的……」——教科书定性开场
- ❌ 「距离今天XXXX年前……」——编年体开场

### 5.3 八种开头策略

在 Phase A 蓝图阶段选定策略。**相邻 5 篇不得重复同一种策略**。

| # | 策略 | 适合主题特征 | 不适合 | 一期范例 |
|----|------|-------------|--------|----------|
| 1 | **反常切入** | 有戏剧性细节、怪异现象、意外转折 | 平铺直叙的典制说明 | 武丁：「一只野鸡飞到鼎耳上大叫起来」 |
| 2 | **人物判词** | 人物传记、以人物为核心的事件 | 纯制度/论著 | 晋献公：「著名野心家兼内乱制造者」 |
| 3 | **矛盾拆解** | 有内在冲突张力（多版本记载、争议性事件） | 无争议的记述型主题 | — |
| 4 | **具体场景** | 有画面感（战争、工程、重大场合） | 抽象制度论述 | — |
| 5 | **后果倒推** | 影响力深远、后世常提及的制度或事件 | 支线小事 | — |
| 6 | **对比反差** | 有明显对比元素（身份反差、预期vs结果） | 常规平铺叙事 | — |
| 7 | **文化基因** | 与当代读者熟悉的观念/成语有渊源 | 生僻小众主题 | 陶朱公：「提到中国古代的商业天才……」 |
| 8 | **直给开局** | 信息密度高的主题，不需要铺垫 | 复杂多线事件 | 周厉王：「周懿王去世后，继位的不是他儿子……」 |

### 5.4 选择判断流程

Phase A 选定策略后，自问三步，通不过就换策略：

1. **这个主题最独特的钩子是什么？**——不是「它很重要」，而是什么细节/矛盾/反差能让人记住
2. **读者知道这件事吗？**——知道 → 反面/反差切入；不知道 → 场景/细节切入
3. **第一句读出来有没有画面或疑问？**——没有 → 换策略

### 5.5 主题类型 × 策略适配

| 主题类型 | 优先策略 | 可用策略 | 避免策略 |
|----------|---------|---------|---------|
| **战争/冲突** | 具体场景、反常切入 | 矛盾拆解、对比反差 | 直给开局（信息密度不足） |
| **政治事件** | 矛盾拆解、反常切入 | 人物判词、后果倒推 | 文化基因（容易牵强） |
| **制度** | 后果倒推、矛盾拆解 | 对比反差、具体场景 | 反常切入（制度少反常细节） |
| **人物** | 人物判词、反常切入 | 对比反差、直给开局 | 后果倒推（人物应先立形象） |
| **文化/思想** | 文化基因、后果倒推 | 矛盾拆解、具体场景 | 人物判词（主语不是人） |

### 5.6 字数与过渡

- **字数**：100–200 字，独立一段
- **素材**：仅取自索引条目字段，禁止编造
- **过渡**：段末自然衔接正文。**禁止**使用以下过渡模板句：
  - ❌ 「这场看似突发的动荡，实则是数十年矛盾的总爆发，过程跌宕起伏、影响深远」
  - ❌ 「为破解长期困扰王朝的治理难题，这套制度应运而生，成为当朝极具代表性的革新」
  - ❌ 「在时代背景与个人际遇交织下，这部典籍成型问世，深刻改变了后世学术格局」

  过渡句没有固定格式——根据上文内容自然引出即可。写不出来过渡句？说明开头方向不对，回头换策略。

### 5.7 质量自检

写完开头后逐条自检：

- [ ] 这篇开头的**第一句**，换一个主题名还能用吗？→ 能 → 重写
- [ ] 读者读完第一段，知道这篇文章要讲什么吗？→ 不知道 → 太绕
- [ ] 开头有「上古」「华夏」「历史长河」「最早」「最重要的」吗？→ 有 → 违规
- [ ] 相邻的前一篇用的什么策略？→ 相同 → 换策略

## 六、引用规范

> 与翻译规则 P1.4 对齐，适配朝代知识原创叙事的场景。

### 6.1 引用原则

朝代知识详情是**原创叙事**而非翻译，不需要逐句引原文。引用服务于两个目的：**增强可信度**（史实有出处）和**增强感染力**（原文表达无法替代）。

**不引用、直接白话叙述**：人物姓名、字号、家世来源、基本身份、官职、封地、事件基本信息。

**可以引用原文并注明出处**：金句（「终不以天下之病而利一人」）、关键历史判断（「天下明德皆自虞帝始」）、原文措辞极其精妙不可替代。

**引号格式（强制）**：
- **引用史料原文**（正史记载的文字）→ 直角引号。外层用「」，内层用『』。示例：「《史记》原文说『生而神灵』」
- **引用人物对话**（叙事中人物说的话，非史书原文）→ 弯引号。示例：尧说：“试试嘛，不行再换。”
- **禁止混用**：史料原文不能用弯引号，人物对话不能用直角引号

### 6.2 引用优先级

从高到低：

1. **名句** — 不引会损失情感冲击力（如「鞠躬尽瘁，死而后已」）
2. **历史评价** — 不引会损失判断精确性（如司马迁的论赞）
3. **原文精彩表达** — 叙事本身极其生动，白话改写不如原文
4. **多版本差异** — 不同史书记载不同，需要呈现对比
5. **其他** — 不引

**自检问句**：不引会损失情感冲击力或历史判断精确性 → 必须引。只损失「知道原文怎么说」→ 不引。

### 6.3 引用频率

长篇（P0/P1）约 5–10 处关键引用，短篇（P2/P3）保留最关键的 2–5 处。不是每段都要引，只在关键叙事节点或评价处引用。

### 6.4 三种自然引出

以下三种模式为引用**史料原文**的推荐写法，使用直角引号「」『』（引用人物对话时用弯引号“”）：

1. 「按《史记》的写法，……」— 最常用，叙事中自然引入
2. 「《史记》原文说『……』——」— 引出较短的金句或评价
3. 「《汉书·某卷》补了一层意思：……」— 引入补充史料

**禁止**：「据说」「相传」「有资料说」「一般认为」「有观点认为」。

### 6.5 正文引用格式

- 格式：《史记·吴王濞列传》《汉书·地理志》
- 关键决策、年份、人物事迹、制度条文须能对应出处
- 人物引语（诏书、奏疏、诗文）优先保留，不强制全文

### 6.6 文末格式

正文结束后另起：

```markdown
*参考著作：*
1. 《史记·……》
2. 《汉书·……》
```

### 6.7 与索引一致性

文末列表须与索引 `主要史料出处` **100% 匹配**（顺序可调整，书目不可随意增删）。

## 六·二、幽默规范

> 朝代知识详情为**原创叙事**，幽默节奏比翻译更自由，但原则一致。

幽默来自历史事实本身的反差、荒诞、巧合——是自然观察和感叹，不是硬塞笑话。

**密度**：

| 篇幅 | 幽默点数量 |
|------|-----------|
| 短篇（P2/P3，< 400 字） | 1–2 个 |
| 中篇（P1，400–700 字） | 2–3 个 |
| 长篇（P0，>700 字） | 3–5 个 |

**分布**：均匀撒在全文，不扎堆在同一段或相邻两段。

**禁区**：
- 开篇不玩幽默（读者未进入状态）
- 结尾不玩幽默（需要庄重收束）
- 帝王驾崩、战争伤亡、政治惨案
- 制度建设核心论述
- 人物盖棺定论时

**克制原则**：如果一段话本身已足够有力（如「终不以天下之病而利一人」这种），不加幽默去稀释。

✅ 「结果呢？九年过去，水一点没治好。注意这个时间跨度——九年。在那个生产力极其落后的时代，一个工程拖了九年没结果，这要放在今天早被撤职了。」— 自然感叹

❌ 「黄帝一看，这蚩尤也太嚣张了，二话不说就冲上去干他」— 太轻浮

## 六·三、六类自动触发

写作中遇到以下六类内容，必须自动触发对应处理。继承翻译规则 P2.2，但适配朝代知识原创叙事场景。

| 类型 | 触发条件 | 处理 |
|------|----------|------|
| **制度类** | 文中出现制度、官职、法令专名 | 在首次出现时简要解释制度背景。如「禅让——上古时代天子传给最有德行的人而非儿子」 |
| **地名类** | 文中出现古地名 | 标注现代位置。格式「幽陵（今北京以北一带）」。只标确定的位置，不确定写「约在今…」「一说在今…」。古今同名不标（泰山），知名地点不标（长江） |
| **人名类** | 文中首次出现关键人物 | 简要介绍身份定位。如「蚩尤——当时最残暴的部落首领」「四岳——部落首领议事机构」。注意：仅对叙事中首次登场的配角做介绍，主角的身份在起段自然展开 |
| **器物类** | 文中出现古代器物、工具 | 解释是什么。「璿玑玉衡——上古天文仪器，类似浑天仪前身」 |
| **事件类** | 文中提及另一历史事件为背景 | 一两句补充背景。「阪泉之战——中国最早有记载的大规模战役之一」 |
| **补充信息类** | 文中引入非主线史料的观点/细节 | 标注出处。格式「《某书·某卷》载……」 |

> 触发过的内容，后文不再重复标注。

## 六·四、神话/传说材料的批判性引用

上古条目中常见的獬豸断案、应龙蓄水、指南车破迷雾等材料，带有浓厚的神话/传说色彩，不可当作史实叙述。

**引用准则**：
- 神话材料必须标注「传说」或「据传说」前缀，与基于正史的叙事明确区分
- 重点不在于「讲一个好玩的故事」，而在于**分析该神话在当时政治/社会体系中的功能**——如獬豸断案的心理威慑功能、应龙蓄水的王权合法性象征功能
- 禁止以「这是上古时代最生动的测谎仪」之类语气将神话材料浪漫化。正确写法：「说穿了，这就是上古版的测谎仪。皋陶未必真的依赖一头神兽来断案，但他太懂人性了——在证据链不完整的上古时代，引入天理昭昭的神判仪式，本身就是一种让双方心服口服的心理策略。」
- 如果无法确认神话材料在正史中是否有明确出处，必须标注出处来源（如《山海经》《尚书》《淮南子》等）

**反例**：
- ❌ 「这简直是上古时代最生动的一台测谎仪」— 把神话当趣事讲
- ✅ 「说穿了，这就是上古版的测谎仪。皋陶未必真的依赖神兽断案，但他太懂人性了」— 分析神话的构造逻辑

## 七、质量红线（verify 可程序化）

任意不达标 → 驳回重写：

### 7.1 表达禁令

| 类别 | 禁止内容 |
|------|----------|
| AI腔词汇 | 历史长河、时代洪流、命运齿轮、拉开序幕、翻开新篇章、历史终将证明、注定、必然、毫无疑问 |
| 书面词堆砌 | 此外、与此同时、值得注意的是、综上所述、堪称、可谓、不啻、则是 |
| 破折号结尾 | 「——」只能用于句中或句首；段落结束须用句号、问号、感叹号或冒号 |
| 【】引文标记 | 任何情况下禁止 |
| 灌鸡汤 | 禁止强行升华、空洞抒情、正能量总结 |
| 编造心理 | 禁止编造人物心理活动（除非正史明确记载） |

### 7.2 结构禁令

| 类别 | 禁止内容 |
|------|----------|
| 小标题/列表 | 无小标题、分节号、列表符号（「第一，…」「一、背景 二、事迹…」） |
| 分节符 | 不用 `---` 等分隔符；段落之间自然叙事衔接 |
| 单句碎段 | 禁止连续 3 个以上单句成段 |

### 7.3 内容红线

| 类别 | 规则 |
|------|------|
| 字数 | 不得低于 §2.2 对应下限 |
| 段落 | 不得少于 §2.4 最少段落 |
| 引用 | 须有文末 `*参考著作：*`；关键史实有《》出处 |
| 格式 | 禁止【】批注体；**默认全文不注音**（见 §1.3 白名单） |
| 数据真实 | 数字年代精确保留——「九年」不写「好几年」。不确定写「大约」「据记载」。不编造 |
| 内容 | 不编造硬史实；不调和异说；多史冲突分别列明；不给无出处发挥写「据说」「相传」 |
| 开篇引入 | 须独立成段（100–200 字），末句有自然过渡；素材仅来自索引字段 |
| 过程禁编 | **原始文献未记载的战斗过程、战术步骤、对话内容、具体年份，一律不准编造。** 原文只有六个字（如「三战，然后得其志」），就只能在六个字的范围内合理推断，不可往上叠加火攻、隔火沟、侧翼挤压等具体战术细节。本规则适用于全朝代，上古/先秦条目尤须从严。 |
| 核心列举 | 条目定义了一个有名称的枚举集合（N德/N官/N礼/N刑等），但正文未逐项列明全部项目 → 驳回（见 §4.2/§4.3 核心列举项）。用「提出了九条标准」「设立了N种官职」一句话概括代过，等同于没写。 |
| 异说处理 | 有公认多版本记载的条目，异说被处理为正文以外的边角料 → 驳回（见 §3.5）。异说必须在起段或转段独立成块，篇幅与主叙事相当。 |
| 史料稀薄 | P2/P3上古条目史料本就稀薄，不可用「精简」为由进一步压缩。正确方向是在有限史料内做最大限度的提取与解读（见 §3.6）。 |
| 神话材料 | 神话/传说材料（獬豸断案、应龙蓄水等）被当作史实叙述 → 驳回（见 §六·四）。必须标注「传说」前缀，重点分析其文化功能而非讲述故事本身。 |

## 八、合格 / 不合格对比

### 8.1 事略：阪泉之战（P0）

**❌ 不合格（约 150 字）**

> 黄帝和炎帝在阪泉打了几仗，最后黄帝赢了，炎帝归附，华夏联盟更强大了。

缺：背景、过程、转折、影响；仅 1 段；远低于 P0 下限 1000 字。

**✅ 合格（≥1000 字，起承转合齐全）**

须包含：炎黄矛盾背景 → 三次交锋过程 → 炎帝归附转折 → 对华夏联盟与后续涿鹿之战的影响；五要素均可检索；文末参考著作完整。

### 8.2 典制：禅让制（P0）

**❌ 不合格（约 140 字）**

> 五帝时期实行禅让制，天子不把位子传给儿子，而是传给最有德行的人。尧传给了舜，舜传给了禹。

缺：制度痛点、运作机制、争议、制度史地位；远低于 P0 下限 700 字。

**✅ 合格（≥700 字）**

须包含：部落联盟权力传承难题 → 禅让程序与考察机制 → 丹朱/舜继位争议 → 对后世德治政治叙事的影响；可与事略「尧舜禅让」互文但不复述事件细节。

### 8.3 典制：九官制（P2）— 核心列举反例

**❌ 不合格**

> 舜一口气任命了九个人，分管水土、农业、教化、刑罚、制造、山林、祭祀、音乐和舆论。

不管篇幅多长，没有逐一列出九官分别是谁、管什么 → 驳回。读者读完不知道哪九个人、各管什么。**核心列举未展开，视为不合格。**

**✅ 合格（≥300 字）**

须逐一列出：大禹做司空平治水土、后稷管农业、契做司徒掌教化、皋陶做士掌刑罚、垂管共工管制造、伯益做虞管山林水泽、伯夷做秩宗管祭祀礼仪、夔做典乐管诗乐教育、龙做纳言管上传下达。列出全部九项后，再展开考核机制与制度史意义。
