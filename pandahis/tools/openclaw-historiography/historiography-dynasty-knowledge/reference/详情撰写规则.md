# 朝代知识详情撰写规则

> SSOT：`historiography-dynasty-knowledge` Step 6 详情产出。  
> 风格 SSOT 继承：`historiography-compose/references/翻译规则.md`（规则一至九、十一的写作层）。  
> 产出路径：`data/06朝代知识补全/详情/{史略ID}_{史略名称}.json`（字段 `翻译详情`）。

---

## 〇、总则

本文档适用于二期**事略 / 典制 / 论著**专题详情创作。

- 区别于一期「二十四史人物传记顺译」，为基于史学共识的**专题原创叙事**
- 无原文直译约束，但叙事风格与一期译文统一
- 试点朝代：五帝（`CD_HX_WUDI`），规则全朝代通用

**核心原则**：不译原文、只讲共识、结构完整、画面通俗、可考据、无 AI 腔、适度趣味。

**字数纪律（重要）**：

- 本文档**只规定字数下限**，**不规定上限，不规定建议区间**
- 达到下限后，按主题重要性与史料丰度**充分展开**；重要 P0 事略写 2000、3000 字均可
- 一期重要人物译文常见 1500–7000+ 字；二期 P0 核心事略应对齐这一阅读预期，而非「卡在下限就收笔」

## 一、与一期翻译规则的关系

### 1.1 完全继承

| 维度 | 要求 |
|------|------|
| 叙事风格 | 口语化、有画面感；参考《明朝那些事儿》；克制通俗、不低俗、不戏说 |
| 注音 | **二期默认全文不注音**（见 §1.3；与一期卷级顺译不同） |
| 地名 | 古地名标注今属地；重大战场、都城须标注（见翻译规则八） |
| 引用 | 关键史实绑定正史出处；格式《史记·××》《汉书·××》 |
| 幽默 | 每篇 1–3 处；不用于开篇、结尾、战乱伤亡、政治惨案 |
| 纯叙事 | 无小标题、无列表、无课堂课件感、无空洞抒情 |
| 异说 | 多史冲突不调和，分别列明并标注争议 |

### 1.2 完全豁免

- 母本顺译、句序守恒、段落召回
- 史料原文展示（详情页不展示原文入口）
- 人物传记时序（以专题主题重构结构）
- 单一人物视角（可宏观全局叙事）
- Phase1 `draft_mother` 两阶段顺译流程

### 1.3 注音红线（二期 · 默认全文不注音）

**定位**：朝代知识详情面向**具备通识文史素养的成年读者**，不是识字教辅、不是小学生小程序。

**默认规则：全文不得出现「汉字（拼音）」标注。**

下列情况**一律禁止**注音（非穷举）：

| 类别 | 禁止示例 |
|------|----------|
| 通识君王/人物 | 尧、舜、禹、黄帝、许由、皋陶、伯益、夔、鲧、丹朱、巢父 |
| 通识地名 | 箕山、颍水、会稽、阳城（山、水、城等常见字） |
| 常见动物/意象 | 鹪鹩、偃鼠、牛犊 |
| 时代/称谓 | 尧帝、舜帝、五帝时代、华夏、部落联盟 |

**唯一例外（白名单）**：正文出现下列**罕用字**专名时，可保留该词注音（脚本 `fix_pinyin.py` / gate 同步）：

`颛顼、帝喾、瞽叟、瞽瞍、娵訾、妫汭、獬廌、獬豸、饕餮、梼杌、穷奇、浑沌、魑魅、少皞`

**违规示例**：

- ❌ `许由（xǔ yóu）`、`箕山（jī shān）`、`偃鼠（yǎn shǔ）`
- ✅ `许由`、`箕山`、`偃鼠`
- ✅ `颛顼（zhuān xū）`（白名单罕用字专名）

一期卷级顺译仍遵 `翻译规则.md` 规则七；**二期 compose-detail 不适用该宽松口径**。

## 二、字数与段落标准

### 2.1 优先级定义

| 级别 | 含义 |
|------|------|
| P0 | 朝代标志性事件 / 制度 / 典籍；首页推荐、高频阅读 |
| P1 | 支撑朝代主线脉络的关键内容 |
| P2 | 支线事件、细分制度、小众典籍 |
| P3 | 边角知识点、辅助科普 |

### 2.2 字数下限（仅下限，无上限）

正文不含开篇引入、不含文末「参考著作」。

| 类型 | P0 下限 | P1 下限 | P2 下限 | P3 下限 |
|------|---------|---------|---------|---------|
| **事略** | 1000 字 | 700 字 | 400 字 | 200 字 |
| **典制** | 700 字 | 500 字 | 300 字 | 150 字 |
| **论著** | 700 字 | 500 字 | 300 字 | 150 字 |

**充分展开指引**（非硬性上限，供写作者判断）：

| 情形 | 建议 |
|------|------|
| P0 事略，多线博弈、转折密集（如七国之乱、楚汉战争） | 常在 **1500 字以上**；过程复杂者可至 3000+ |
| P0 典制，牵涉制度沿革长（如察举、盐铁政策体系） | 常在 **1000 字以上** |
| P0 论著，体例宏大（如《史记》《汉书》） | 常在 **1200 字以上** |
| P2/P3 边角知识点 | 达到下限 + 信息点齐全即可，不必硬凑篇幅 |

> verify 只拦「低于下限」，不拦「写太长」。

### 2.3 为何 P0 事略下限设为 1000 字

P0 事略是用户深度阅读与知识体系搭建的核心。仅 200 字只能写「事件简介」，无法承载：时代背景、各方博弈、过程细节、矛盾转折、成败原因、即时与长远影响。参考一期译文：中位约 1500 字，重要君王常 3000–7000 字。

### 2.4 段落与句数下限

| 级别 | 最少段落 | 每段句数 |
|------|----------|----------|
| P0 | 6 段 | 3–8 句，杜绝单句成段 |
| P1 | 4 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

另：**开篇引入**单独 1 段（100–200 字），不计入上表段落数。

禁止连续 3 个以上单句碎段。

## 三、三类叙事骨架（起承转合）

统一采用起承转合；**篇幅占比为结构导向，不是字数封顶**——某一部分史料丰富，可加长，其他部分相应压缩，但四职能须齐全。

> 下列大纲为**写作结构示范**（含五帝、西汉等举例），非每个朝代都须维护专属大纲；试跑朝代外直接按骨架 + 索引字段写即可。

### 3.1 事略｜主语：事件本身

| 职能 | 建议侧重 | 写什么 |
|------|----------|--------|
| **起** | ~20% 起笔，可更长 | 时代局面、核心矛盾、「为什么会发生」 |
| **承** | ~35% 起笔，可更长 | 时间线：导火索、各方动作、关键节点 |
| **转** | ~25% 起笔 | 高潮、战局/政争转折、关键决策与争议 |
| **合** | ~20% 起笔 | 结局、即时改变、对后世格局的影响 |

**五帝试点示例大纲：阪泉之战（P0）**

- 起：黄帝与炎帝部族联盟矛盾、涿鹿前后格局
- 承：阪泉三次交锋、黄帝用兵与联盟整合
- 转：炎帝部族归附、华夏联盟雏形确立
- 合：为后续涿鹿抗蚩尤、联盟扩张奠基

### 3.2 典制｜主语：制度本身

| 职能 | 写什么 |
|------|--------|
| **起** | 前制弊端、治理痛点、确立刚需 |
| **承** | 制度内核、推行流程、适用范围、配套机制 |
| **转** | 推行阻力、落地变形、史家褒贬争议 |
| **合** | 当朝成效、后续演变、制度史意义 |

**五帝试点示例大纲：禅让制（P0）**

- 起：部落联盟权力传承难题、世袭与推举之争
- 承：推举、考察、摄政、即位等运作程序
- 转：丹朱/商均争议、禹后启篡夏终结禅让
- 合：制度史地位；儒家禅让观在详情中作后世解读

### 3.3 论著｜主语：作品 / 思想

| 职能 | 写什么 |
|------|--------|
| **起** | 时代思潮、社会变局、作者际遇与创作动机 |
| **承** | 体例结构、核心主旨、代表篇章或命题 |
| **转** | 学界争议、思想局限、时代特殊性 |
| **合** | 传播影响、史学/文化地位 |

**五帝试点示例大纲：羲和观象授时（P0 典制/论著交界，按典制写）**

- 起：农业立命时代对节气的刚需
- 承：尧命羲和分宅四方、观象授时
- 转：四方观测与闰月校正的技术与政治意义
- 合：上古历法制度雏形，影响后世正朔观念

## 四、信息点覆盖 Checklist

写完须逐条可勾选；gate 可人工 + 机器对照索引字段验收。

### 4.1 事略（五要素）

- [ ] **主语**：事件主体在正文明确
- [ ] **参与人物**：关键君臣、将领、对立势力代表已点名
- [ ] **动作**：决策、军事、政治、舆论行动可追踪
- [ ] **结果**：胜负、处置、收场明确
- [ ] **影响**：当朝即时 + 长线历史影响

### 4.2 典制（四要素）

- [ ] **制度类型**：政治 / 经济 / 军事 / 选官 / 律法等
- [ ] **核心主旨**：要解决什么问题
- [ ] **确立年**：与索引 `史略开始年` 一致
- [ ] **双向影响**：成效 + 弊端或落地问题

### 4.3 论著（五要素）

- [ ] **子类**：典籍 / 名篇 / 书画 / 思想理论
- [ ] **核心主旨**：创作内核
- [ ] **作者**：与索引信息一致
- [ ] **成书年**：与索引年份一致
- [ ] **多维影响**：史学、文化、思想传承

## 五、开篇引入（单独一段）

- **字数**：100–200 字，独立成段
- **素材**：仅取自索引条目字段（名称、简介、朝代、主要史料出处、五要素/典制/论著字段），禁止编造
- **作用**：定调「这是什么、为什么值得读」
- **过渡**：段末须有自然衔接句进入正文

过渡句示例：

- 事略：这场看似突发的动荡，实则是数十年矛盾的总爆发，过程跌宕起伏、影响深远。
- 典制：为破解长期困扰王朝的治理难题，这套制度应运而生，成为当朝极具代表性的革新。
- 论著：在时代背景与个人际遇交织下，这部典籍成型问世，深刻改变了后世的学术格局。

## 六、引用与参考著作

### 6.1 正文引用

- 格式：《史记·吴王濞列传》《汉书·地理志》
- 关键决策、年份、人物事迹、制度条文须能对应出处
- 禁止「据说」「相传」「有资料说」

### 6.2 文末格式

正文结束后另起：

```markdown
*参考著作：*
1. 《史记·……》
2. 《汉书·……》
```

### 6.3 与索引一致性

文末列表须与索引 `主要史料出处` **100% 匹配**（顺序可调整，书目不可随意增删）。

## 七、质量红线（verify 可程序化）

任意不达标 → 驳回重写：

| 类别 | 规则 |
|------|------|
| 禁词 | 综上所述、由此可见、众所周知、不得不说、历史长河、命运齿轮、注定、必然等 AI 腔 |
| 字数 | 不得低于 §2.2 对应下限 |
| 段落 | 不得少于 §2.4 最少段落；禁止连续 3+ 单句碎段 |
| 引用 | 须有文末 `*参考著作：*`；关键史实有《》出处 |
| 格式 | 禁止【】批注体；**默认全文不注音**（见 §1.3 白名单） |
| 内容 | 不编造硬史实；不调和异说；无原文直译堆砌 |

## 八、合格 / 不合格对比

### 8.1 事略：阪泉之战（P0）

**❌ 不合格（约 150 字）**

> 黄帝和炎帝在阪泉打了几仗，最后黄帝赢了，炎帝归附，华夏联盟更强大了。

缺：背景、过程、转折、影响；仅 1 段；远低于 P0 下限 1000 字。

**✅ 合格（≥1000 字，起承转合齐全）**

须包含：炎黄矛盾背景 → 三次交锋过程 → 炎帝归附转折 → 对华夏联盟与后续涿鹿之战的影响；五要素均可检索；文末参考著作完整。

### 8.2 典制：禅让制（P0）

**❌ 不合格（约 140 字）**

> 五帝时期实行禅让制，天子不把位子传给儿子，而是传给最有德行的人。尧传给了舜，舜传给了禹。

缺：制度痛点、运作机制、争议、制度史地位；远低于 P0 下限 700 字。

**✅ 合格（≥700 字）**

须包含：部落联盟权力传承难题 → 禅让程序与考察机制 → 丹朱/舜继位争议 → 对后世德治政治叙事的影响；可与事略「尧舜禅让」互文但不复述事件细节。

## 九、撰写工作流（建议两阶段）

```text
Phase A  撰写蓝图（中间产物，不入 翻译详情）
         - 信息点 checklist（来自索引字段）
         - 起承转合各段要点
         - 建议引用书目
         - 标注「须充分展开」的段落（如多线战局）

Phase B  成稿
         - 先写开篇引入（100–200 字）
         - 按骨架写正文，**超过下限仍继续写**，直到信息点饱满
         - 文末参考著作
         - 自检 §七 红线

Phase C  verify
         - 字数 ≥ 下限（无上限检查）
         - 段落数、禁词、参考著作、信息点覆盖
```
