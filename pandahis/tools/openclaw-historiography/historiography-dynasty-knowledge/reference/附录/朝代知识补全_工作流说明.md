# 朝代知识补全 · 详情工作流（人类参考，不进 compose prompt）

## 拓展认知路（2026-07 现行）

```
anchor-research（coverage_claims 主张锚点）
    → bibliography-plan → fetch-snippets → verify-bibliography
    → compose-detail
    → verify-detail（仅格式/纪律，不做字面覆盖）
    → coverage-check（语义：主张是否 conveyed）
    → review-detail（Kimi · warn/fail 不阻断）
    → review-warns-summary（汇总人工关注清单）
```

| 步骤 | 执行方 | 阻断？ |
|------|--------|--------|
| verify-detail | Python | 是（格式/引用/漂移等 error） |
| coverage-check | LLM | 否（fail → needs_human + logs/coverage/） |
| review-detail | Kimi | **否**（见 `logs/review_warns_汇总.md`） |

**人工裁定入口**：
- `data/05工作流中间产物/朝代知识补全/logs/review_warns_汇总.md`（可读）
- `data/05工作流中间产物/朝代知识补全/logs/review_warns_汇总.json`（程序读）

重生成汇总：
```bash
python3 dynasty_supplement.py --dynasty 五帝 --step review-warns-summary
```

## Phase A — 主张锚点

- `coverage_claims`：5–8 条须传达的主张（自然语言，非 keywords）
- `forbidden_inventions` / `legend_facts`：compose + 审校边界

## Phase B — compose-detail

- 注入 `须传达的主张` + 书目 plan；不注入 full anchor JSON

## Phase C — 质检

| 产物 | 路径 |
|------|------|
| verify | `logs/verify/{id}_verify.json` |
| coverage | `logs/coverage/{id}_coverage.json` |
| review | `logs/reviews/{id}_review.json` |
