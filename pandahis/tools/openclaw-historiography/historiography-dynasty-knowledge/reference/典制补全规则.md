# 典制补全规则（朝代知识）

> SSOT：`historiography-dynasty-knowledge/scripts/dynasty_supplement.py` Step 3。  
> 峰值年见 `historiography-annotate/reference/峰值年规则.md` §典制（`institutional_maturity`）。

---

## 一、定义

**典制** = 面向**国家/联盟强制落地**的规则体系：朝廷或共主颁布、有配套官职/流程/奖惩，是客观存在的治理工具。

必须能回答：**这个朝代定下了什么须强制遵守的规矩？**

主语是**制度/政策/规矩**，不是人、不是单次事件、不是文献、不是无强制的学说主张。

> 典制 vs 思想权威分界见 `典制与思想分界.md`。

### 1.1 制度结构（硬门槛）

典制须具备**可描述的制度结构与运作流程**（谁管什么、程序如何、违制后果）：

| 维度 | 典制 ✓ | 非典制 ✗ |
|------|--------|----------|
| 约束力 | 王权/官府/联盟强制 | 仅道德舆论、个人价值认同 |
| 载体 | 律令、官职、流程、礼仪法典 | 仅有典籍论述、理想模型 |
| 能回答 | 「怎么组织、怎么执行、违制怎么办」 | 「应当如何、为何如此」 |

**史前朝（如五帝）**：可建传说期典制（禅让制、九官制等），`边界备注` 标注「传说期 / 后出文献追述」；须能述推举、考察、摄政等**运作程序**，不因缺成文法典而否。

### 1.2 年代判定原则：实质 > 命名（强制）

典制条目**不要求制度名称在本朝已被正式使用**。判定标准是：**制度实质**是否在本朝有可描述的运作结构与落地实践。

| 情形 | 判定 | 说明 |
|------|------|------|
| 制度实质存在于本朝，但名称后世才出现 | **归入本朝** | 如五礼：五帝已有礼仪实践，吉凶军宾嘉体系化命名在周代 |
| 制度实质在本朝不存在，仅被后世追述 | **不建条** | 如察举制归五帝：荐举→考核→任用流程在五帝时期不存在 |
| 制度名称与实质均在后世 | **不建条** | 不因后世文献提及而入库 |

**配套约束**：
- 名称使用了后世词汇的典制条目，必须在详情 **转** 段中**明确说明**制度名称的实际起源年代与五帝时期的实质差异
- `边界备注` 标注「制度实质存在于本朝，体系化命名在×代」
- LLM Step 3 候选阶段须评估：推荐条目的运作结构是否真的存在于本朝，不能仅凭《尚书》等后世追述文本直接断定

**五帝示例**：

| 条目 | 实质在五帝？ | 判定 |
|------|-------------|------|
| 五礼制度 | ✅ 祭祀/丧葬/军事/朝聘/婚冠等礼仪实践已各有雏形 | 归入五帝，详情转段说明周代体系化 |
| 五刑制度 | ✅ 象刑/肉刑等惩戒体系雏形已存在 | 归入五帝，详情转段区分象刑与后世五刑 |
| 九官制 | ✅ 舜任命诸臣分掌各职的实践存在 | 归入五帝，详情注明"九官"为后世归纳称呼 |
| 科举制 | ❌ 考试选官的完整制度流程不存在 | 不建五帝条 |

## 二、准入标准

同时满足：

1. 能**独立命名**（制度名或政策名）
2. 能定位**建立、成熟或全面推行**的年份（多数单年）
3. 对该朝或后世**制度史**有代表性
4. 不是人物传记里无法单独成条的小制度碎片
5. 通过 §2.1 典制判定决策树

### 候选 JSON 片段（Step 3 输出）

```json
{
  "名称": "推恩令",
  "制度类型": "政治/削藩",
  "主旨": "命诸侯王子弟封列侯，分化王国领地",
  "确立或成熟年": -127,
  "建议挂靠帝王": "汉武帝",
  "主要史料出处": "《史记·孝武本纪》",
  "影响": "实质削弱藩国势力，加强中央集权",
  "边界备注": ""
}
```

### 2.1 典制判定决策树

详见 `典制与思想分界.md` §六。简版：

```text
1. 有强制推行+行政落地流程？
   是 → 典制（须通过 §1.2 年代判定：实质在本朝存在）
   否 → 2
2. 仅学派/士人理论主张？
   是 → 论著·思想（须当代提出）
   否 → 3
3. 完整事件故事（五要素）？
   是 → 事略
   否 → 丢弃
```

**典制 vs 事件（不互斥）**：典制条介绍规则体系；事略条讲该制度下的一次实践。  
例：**禅让制**（典制）与 **尧舜禅让**（事略）**可同时存在**。

**典制 vs 思想（互斥）**：同一概念只建一条，第一属性优先。判定优先级：典制 > 思想。  
例：五帝建 **禅让制**（典制），不另建 **禅让思想**（思想在详情中作后世解读）。

### 2.3 跨朝代建条规则（强制）

同一典制概念**允许多个朝代各自独立建条**，不互斥。

**理由**：典制不是静态的——察举制在汉武帝确立、东汉完善、魏晋演变为九品中正。每个朝代对同一制度有不同的贡献与形态。

**跨朝代建条时的约束**：

| 维度 | 要求 |
|------|------|
| 索引字段 | 年代/帝王/特色均聚焦**本朝**对该制度的贡献 |
| 详情 **起**段 | 简述前朝沿革（制度从何而来） |
| 详情 **承**段 | 重点写**本朝**对该制度的改造、丰富、独特实践 |
| 详情 **合**段 | 提后世演变方向，形成制度史链条 |
| 关联字段 | 建议通过「前身制度」「后续演变」字段跨条目串联 |

**典型示例**：

| 制度 | 朝代 | 本朝侧重 |
|------|------|----------|
| 科举制 | 隋 | 创制：废九品中正，设进士科 |
| 科举制 | 唐 | 完善：诗赋取士、武举 |
| 科举制 | 宋 | 革新：糊名誊录、扩大取士 |
| 科举制 | 明 | 定型：八股文、三级考试 |
| 均田制 | 北魏 | 创制：计口授田 |
| 均田制 | 唐 | 演变：从均田到两税法过渡 |

### 2.2 五帝常见条目裁定（示范）

| 条目 | 归类 | 理由 |
|------|------|------|
| 禅让制 | **典制** | 联盟法定权力交接：推举、考察、摄政、即位（传说期） |
| 尧舜禅让 | **事略** | 禅让制下尧传舜这一次完整故事 |
| 禅让思想 / 天下为公 | **不建五帝条** | 儒家学说，挂提出朝代；详情可互文 |
| 九官制 | **典制** | 九官分工与考绩程序 |
| 羲和观象授时 | **典制** | 设官观象、定历授时 |
| 五礼制度 | **典制** | 吉凶军宾嘉礼仪体系 |
| 五刑制度 | **典制** | 象刑/五刑品类与司法职能 |
| 四岳议事制度 | **典制** | 联盟议事程序（P2） |
| 部落联盟共主制 | **典制** | 征伐—盟誓—共主权责 |
| 五行 | **论著·思想** | 宇宙观学说，无强制落地；须当代提出 |
| 《尚书·尧典》等 | **不归本朝论著** | 成书在周，禁止拆篇 |

## 三、不是什么（硬排除）

- ❌ 单次事件、会议、战争 → **事略**（如盐铁**会议**）
- ❌ 典籍、诗赋、思想学说 → **论著**
- ❌ 以人为主体 → **人物**
- ❌ **建筑、工程**（宫殿、陵墓、长城段落等）
- ❌ 志书细目堆砌（「百官公卿表」式碎条）
- ❌ 空泛「礼乐兴盛」「吏治清明」

## 四、与事略、论著的分界

| 条目 | 归类 | 理由 |
|------|------|------|
| 推恩令 | 典制 | 政策制度 |
| 盐铁会议 | 事略 | 事件性辩论 |
| 盐铁官营 | 典制 | 经济制度 |
| 《盐铁论》 | 论著 | 文献 |
| 察举制 | 典制 | 选官制度 |
| 独尊儒术（政策面） | 典制 | 文化政策落地 |
| 天人感应（学说） | 论著 | 理论命题 |
| 商鞅变法 | 典制 | 制度变革（人物商鞅走武将/文臣） |
| 尧舜禅让 | 事略 | 制度下的一次实践 |
| 禅让制 | 典制 | 联盟权力交接规则体系 |
| 儒家禅让观 | 论著·思想 | 挂提出朝代，不与禅让制双条 |

约定：

- **强制落地的治理规则** → 典制
- **无强制的学说/价值主张** → 论著·思想（须当代提出）
- **围绕制度的会议/辩论/单次实践** → 事略
- **典制 + 事略** 同主题可并存；**典制 + 思想** 同概念不双条

## 五、命名

- 制度/政策通行名，**不加书名号**
- 示例：`推恩令`、`察举制`、`盐铁官营`、`刺史制度`、`郡国并行制`

## 六、时间与坐标

| 字段 | 规则 |
|------|------|
| 史略开始年/结束年 | **多数相等**（单年锚定）；长时段制度取本朝最关键制度化年份 |
| 峰值年 | 制度成熟或全面推行年；`peak_type = institutional_maturity` |
| 四级帝王坐标 | 制度确立或关键改革时在位君主 |

## 八、与人物的关系

- 制度创立者（如商鞅）→ **人物条**
- 制度本身（如变法措施名）→ **典制条**
- 不建「某人推行某制」事略，除非该推行过程本身是完整五要素故事且制度条已存在

## 十、LLM Prompt 要点（Step 3）

1. 基于朝代研究报告，列**国家/联盟强制落地的制度/政策**
2. 排除单次事件、文献、人物、建筑、无强制的学说
3. 勿参考一期人物索引
4. 制度与事略可同主题并存（如禅让制 + 尧舜禅让）
5. 史前朝须在 `边界备注` 标注传说期/后出文献
6. 不要求 `原文字句`
