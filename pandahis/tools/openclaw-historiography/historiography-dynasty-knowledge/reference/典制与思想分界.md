# 典制与思想分界(朝代知识 · 权威)

> 适配事略 / 典制 / 论著三分体系。
> 典制规则见 `典制补全规则.md`;思想理论见 `论著补全规则.md` §思想理论。

---

## 一、总分界公理

| 类型 | 面向 | 约束力 | 载体 |
|------|------|--------|------|
| **典制** | 国家强制落地的规则体系 | 王权/官府法定强制;违则有官方惩罚 | 律令、官职、流程、礼仪法典、财政税收、军队编制 |
| **思想** | 人的认知、价值主张、理论学说 | 道德舆论、学派共识;无国家强制处罚 | 典籍、士人言论、学派主张、理想政治模型 |

**口诀**:有法令、有官府、有奖惩、全国(或联盟)强制落地 → **典制**;无法条、无行政、仅主张、跨朝流传学说 → **思想**。

二者重合时按**第一属性**只归一类建索引;次要属性在详情正文交叉提及,**不拆重复条**。

## 二、四大判定维度

### 1. 约束力来源(最核心)

| 典制 | 思想 |
|------|------|
| 不遵守→贬官、赋税、刑罚、削地、治罪 | 不认同→士人非议,无律法治罪 |
| 全国统一/联盟全体推行,有执行链条 | 无官方强制推行义务 |

### 2. 存在载体与落地形态

**典制**须至少其一:官府律令、官职体系、财政税收、礼仪法典、选官流程、土地分配规则、可述操作流程。

**思想**须至少其一:诸子典籍、士人论辩、学派观点、社会价值观念;无标准化行政执行流程。

### 3. 核心主语与目标

| 典制 | 思想 |
|------|------|
| 主语:国家治理规则 | 主语:认知/价值理论 |
| 目标:解决现实行政问题(收税、选官、规范祭祀...) | 目标:回答世界观(天下归谁、君主当如何、理想社会) |

### 4. 时间线与存续

- **典制**:有推行/废除年,依附政权;政权灭亡常即失效。
- **思想**:无强制起止,可跨朝流传;政权覆灭学说仍可被研读改造。

## 三、与事略的关系(制度 ≠ 事件)

| 层级 | 问句 | 示例 |
|------|------|------|
| **典制** | 定下了什么规则体系? | 禅让制、察举制、推恩令 |
| **事略** | 发生了哪件完整故事? | 尧舜禅让、盐铁会议、七国之乱 |

**同一主题可同时存在典制条 + 事略条**:制度介绍制度结构与运作;事略讲具体一次实践。
例:**禅让制**(典制)+ **尧舜禅让**(事略)✅ 不互斥。

## 四、重合内容归类

### 规则 1:第一属性,只建一条

1. **先有官方强制实施的制度形态** → 典制;思想层面写入详情背景。
   例:西周礼乐制度 → 典制;孔子复礼 → 详情补充,不另建思想条。

2. **仅有理论主张,从未被朝廷完整立法落地** → 论著·思想。
   例:大同小康、儒家「天下为公」禅让观 → 思想(挂提出朝代)。

### 规则 2:极少双条(理论 vs 实操完全割裂且均达 P0/P1)

仅当同名词同时存在**成熟官方制度** + **独立完整学派体系**,且时代/主体/落地性割裂,才分两条。
例:西周井田制(典制) vs 孟子井田理想(战国思想)。

### 规则 3:后世伪制度

汉魏「禅让」改朝仪式 → **典制**(官方法定流程、玉玺祭天退位诏);儒家禅让传贤观在正文作思想背景。

## 六、可执行判定流程（LLM / gate）

```text
第一层：主语判定
  主语是人？ → 人物（不进三类）
  主语是制度/理论/事件？ → 进入第二层

第二层：论著判定（边界最清晰，优先判定）
  有独立的文献/书名/理论命题，且成书/提出于本朝？
    → 是 → 论著（典籍/名篇/书画/思想子类）
    → 否 → 进入第三层

第三层：典制判定
  有制度化结构（强制落地、可述流程、有奖惩）？
    且制度实质在本朝存在（见典制补全规则 §1.2 年代判定原则）？
    → 是 → 典制
    → 否 → 进入第四层

第四层：事略判定
  满足五要素（多方角色、有动作、有结果、有影响）？
    → 是 → 事略
    → 否 → 丢弃
```

**判定优先级说明**：
- 论著边界最清晰（书就是书、理论就是理论），因此**优先于典制判定**
- 典制优先于事略（制度结构比事件故事更基础）
- 同一概念同时满足典制和思想时 → **典制优先**（见下述去重约束）

**去重约束**：

- ✅ 典制「禅让制」+ 事略「尧舜禅让」
- ❌ 典制「禅让制」+ 论著「禅让思想」（同一概念第一属性取典制）
- ❌ 事略与事略、典制与典制同名重复

## 七、史前朝（五帝）补充

传说期典制（禅让制、九官制、五礼制度、五刑制度等）可建条，但须同时满足：

1. `边界备注` 标注「传说期 / 后出文献追述」
2. gate 不因缺成文法典驳回，但须能述**制度结构与运作程序**（推举、考察、摄政、即位等）
3. 制度**实质**须在本朝的运作实践中存在（见典制补全规则 §1.2 年代判定原则）
4. 详情 **转** 段必须说明：该制度的名称/体系化分类是后世完成的，与五帝时期的实质差异

**典制 vs 论著·思想在五帝的特别约束**：

| 条目 | 归入 | 理由 |
|------|------|------|
| 禅让制 | 典制 | 联盟权力交接的运作程序存在于五帝 |
| 尧舜禅让 | 事略 | 禅让制下的一次完整实践 |
| 儒家禅让观 / 天下为公 | 不建五帝条 | 战国儒门学说，非五帝时期提出 |
| 五礼制度 | 典制 | 礼仪实践实质存在于五帝，体系化在周代 |
| 五刑制度 | 典制 | 惩戒体系实质存在于五帝，"五刑"之名后出 |
| 九官制 | 典制 | 设官分职实践存在于五帝，"九官"为后世归纳 |
| 五行 | 论著·思想 | 宇宙观学说，无强制落地 |
