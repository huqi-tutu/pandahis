## 二、人物分类（8 类，`史略分类` 唯一）

| 史略分类 | 对象 | 门槛摘要 |
|----------|------|----------|
| **君王** | 天子、皇帝、霸王级本纪共主 | 本纪主轴；天下共主或准皇帝级（如项羽） |
| **诸侯** | 封国 / 列国世袭君主 | 世家诸侯世系主轴；秦本纪始皇前国君；名称对齐 `帝王.json` |
| **宗戚** | 宗室亲属与同姓藩王 | 皇后、嫔妃、太后、公主；同姓诸侯王（挂册封之君） |
| **宦官** | 以阉人 / 内官 / 近幸为主轴的人物 | **不含**受宫刑的士人（如司马迁） |
| **文臣** | 以行政、刑名、外交、儒学、文学仕宦为主轴的官员士人 | 曾任官；本卷叙事主轴在文事 |
| **武将** | 以军功、征战、将帅为主轴的官员 | 史名最著角色为武将时唯一归类 |
| **蕃祚** | 边陲汗国、方国、域外邦国、西南割据政权集体 | 见 `reference/卷型补充/蕃祚卷型.md` |
| **庶众** | 非上述体系人物 | 游侠、刺客、方士、商人、民间列女、起义未称帝者等 |

### 分类唯一性（强制）

```
君王 ＞ 宗戚 ＞ 诸侯 ＞ 宦官 ＞ 文臣 / 武将 ＞ 蕃祚 ＞ 庶众
```

- **君王 vs 诸侯**：天子 / 皇帝 / 霸王级本纪 → **君王**；封国世袭君主 / 列国国君 → **诸侯**（准入见 `诸侯准入与灰区判定表.md`）
- **宗戚 vs 诸侯**：同姓藩王 → **宗戚**（优先于诸侯）
- **文臣 vs 武将**：同一人兼有文武经历时，取 **史名最著** 一侧
- **蕃祚 vs 君王**：域外政权君主 **默认不升格为君王**；华夏诸侯世系归 **诸侯**

### 典型边界

- 游侠、刺客 → **庶众**
- 酷吏、廷尉、博士、丞相类 → **文臣**
- 将帅、军功封侯 → **武将**
- 匈奴/南越/西域诸国合传 → **蕃祚**
- 孔子世家 → **文臣**（`GLOBAL_CATEGORY_FORCE`）
- 佞幸列传：士人宠臣 → **文臣**；李延年类 → **宦官**
- 卫康叔、齐桓公、周公旦、秦孝公 → **诸侯**
- 周武王、秦始皇、项羽 → **君王**

> **⚠️ 此链只用于「某人已是 entry 后定其分类」，不用于「猜本卷写谁」。**

## 一、目标

按**卷**提取**人物**，为每人召回**尽可能连续**的叙事段落，支撑深度阅读。

- **要**：卷内主人公 / 合传传主的独立叙事段，段落集群连续、可通读  
- **不要**：事略、典制、民录、论著四类（二期由大模型补全）  
- **不要**：世系链、一笔带过、无独立行动的人物  

### 1.1 定量补充（厚度门 · merge 阶段）

- Step1–4 **仍标注**合传/群像等薄条目（保留 skeleton）  
- **merge** 时若母本+补充合计 **< 100 汉字**，**不升 GLBL**（见 `reference/史料厚度门规则.md`；**君王无例外**）  
- 未升 GLBL 者 → 薄标注注册表 → 朝代知识补全（君王走帝王表强制 + 薄标注优先候选）

---

### 附：卷主轴判定 vs 分类优先级（两步，勿混）

| 步骤 | 输入 | 输出 | 禁止 |
|------|------|------|------|
| **① 卷主轴判定**（Step1a） | 著作 + 卷名 + 史学常识 | 主人公清单 | 勿用分类链代替卷名判断 |
| **② 回原文划块**（Step1b） | 段落索引 + ① | blocks → skeleton | 块主人必须来自 ① |

编排器：**Step1a protagonists → Step1b blocks** → 展开 skeleton。

## 三、卷型策略

| 卷型 | 是否标注 | 提取规则 |
|------|----------|----------|
| **本纪** | ✅ | 只出 **君王**；一纪可多人。**不出**文臣/武将/宦官/庶众/宗戚/蕃祚 |
| **列传 · 单人** | ✅ | 传主必提取；卷内其他达门槛人物按七类提取 |
| **列传 · 合传** | ✅ | 传名中人物 **逐个**提取；世系链、一笔带过忽略 |
| **世家 · 诸侯世系** | ✅ | 见下节「世家 · 诸侯世系」专则；**禁止**卷名始祖独占全卷 |
| **世家 · 功臣/外戚/宗室** | ✅ | 传主主轴 + 达门槛副人物；外戚/五宗/三王见 `纪传叙事.md` 专则 |
| **表** | 视情况 | **无卷主人公 → 整卷 skip**（不写 skeleton / 不标 done） |
| **志** | 视情况 | 同上 |
| **书** | 视情况 | 同上 |

### 本纪 · 多人示例（五帝本纪）

- 5 个 **君王** entry，各自 `paragraphs` 覆盖该帝在本纪中的叙事段  
- 段间过渡、世系链、`太史公曰` → `exclude_reason`，不归任何 entry  
- 尧舜禅让等段：按**段内叙事主角**归对应君王（舜段归舜，尧段归尧），**不建事略条**

### 表 / 志 / 书 · skip

- pipeline Step 0 识别卷型后，若判定 **无人物主人公**，标记 `skipped` / `not_applicable`  
- 不要求 segment_attribution / entries  

### 世家 · 诸侯世系（统一专则 · 031–046 等）

适用：《史记》吴/齐/鲁/燕/卫/宋/晋/楚/赵/魏/韩/郑/田齐等**诸侯世袭编年**世家，以及汉书同类卷。**不适用**孔子/陈涉/外戚/五宗/三王/功臣相国类世家（另有专则）。

**提取（建 entry · 诸侯）**

1. 卷内每位在 `帝王.json` 有标准「帝王名称」的君主  
2. 且至少 **1 段独立叙事**（含决策、战争、外交、政变、制度；**非**纯立/卒/崩谱系一句）  
3. → 每人一块，`史略分类=诸侯`；`paragraphs` 尽量连续  

**排除（`exclude_reason` · 不建 entry）**

1. **世系链**：纯「X 立 / 卒 / 崩，Y 立」、多代姓名连缀**无独立行动**；前后均无该君独立叙事块时方可标  
2. 块内若前后段已归同一君王，中间短段（子嗣概数、婚配收束）**归该君王**，不得挖洞 exclude（见 §五）  
3. `太史公曰`、卷首标题、纯纪年总述（如「凡三十四世」）  

**块边界**

- 段首「……是为 **X**」→ 通常归 **X**  
- **两主轴直连交接**：同段同时写清「前主轴卒/崩」与「后主轴立/是为」，且二人皆为本卷 entry → `owners` **双挂**（前君末段 ∩ 后君首段）；不得只挂后立一方  
- **隔代禁止**：`立` 的是中间君（非下一主轴）→ 不可把该段双挂到「上一主轴 + 隔代主轴」；中间君无独立叙事则世系链 / 单挂前君收束  
- 嵌入制度 / 战争 / 他人名 → **整段归块主人**  

**禁止**

- ❌ 卷名始祖（如周公旦、齐太公）**吞并**后世全部编年  
- ❌ 用「3–5 位关键君主」等人为上限省略有叙事段的君主  
- ❌ 为**同一卷**写 `identity_gate` 卷级特例（孔子/陈涉/外戚等已列专则除外）  
- ❌ 把「X 卒，中间君立」双挂成 X + 隔代主轴 Y  

**厚度门（merge 阶段，非标注阶段）**

- skeleton 可保留薄条；母本合计 **<100 字** 不升 GLBL → 朝代知识补全（见 `史料厚度门规则.md`）

## 四、段落归属（块优先 · 边界精判）

**工作流详见** `reference/人物归因.md`。摘要：

### 操作顺序（非「全文逐段分类」）

```
人物清单 + entry 级史略分类
  → 叙事块（paragraph_from / to）
  → 合传 / 多人本纪：块边界精判
  → 展开 segment_attribution（块内机械填充）
  → entries + paragraphs
```

### 核心原则

1. **完整段落集**：传主块内尽量全收；嵌入制度 / 事件 / 他人提及**整段归块主人**，不轻易 exclude  
2. **分类在 entry 级**：段上不必单独判四类；`owners[].category` 与 entry 一致即可  
3. **每人一条 entry**；`segment_attribution` 中 `owners` **仅含人物**  
4. **不再**为事略 / 典制 / 民录 / 论著建 entry  
5. **单段归属**：默认单段单人物；例外——（a）合传同段共写多位传主且正文均涉及；（b）**两主轴世系交接**（同段前君卒 + 后君立）可双挂。分段独立合传仍须单段单人物  
6. **连续性**：优先合并为连续 `paragraph_from`–`paragraph_to`；交接双挂段计入**双方** entry 的段落覆盖（边界可重叠）；中间夹 exclude 段时叙事块可分段列出  
7. **退场**：人物死亡 / 离场**之后**的后续段落不再归该人；含「本君卒 + 后君立」的**同一交接段**仍归本君（并双挂后君）。`太史公曰` 等论赞 → exclude  
8. **召回下限**：有名字但无独立事迹、或仅世系链 / 一笔带过 → 不建 entry  
9. **合传**：传名人物均尝试提取；块边界须精读防张冠李戴；块内批量归属  

### 边界精判问句（仅块边界 / 疑难段）

> 这段的**叙事主角**是谁？（行动 / 决策 / 言语的承担者）

### 本纪内互见其他君王

- 甲纪中叙述乙：**段落仍归本纪主轴君王**（或该段实际叙事主角对应的**本纪内君王**之一）  
- **不在本纪**为乙另建君王条；乙的专条留到乙的本纪或乙的列传

## 五、排除（从严 · `exclude_reason` 不变）

**默认归属人物**；仅下列情形 exclude。块内叙事**不因**含制度 / 他人名字而 exclude。

| exclude_reason | 说明 |
|----------------|------|
| 世系链 | 仅族谱式「X 生 Y」无独立事迹；**非**子嗣概数 / 婚配收束段 |
| 无故事弧 | 有名字无独立行动；一笔带过 |
| 太史公曰 | 论赞 |
| 纯纪年 | 仅时间节点 |
| 志书数据 / 艺文目录 | 表志书数据卷 |
| 卷首标题 | 篇首卷名行 |
| 过渡叙事 | **极少用**；合传块间过渡优先判给下一位传主或上一位收束 |

嵌入人物叙事中的制度 / 事件描述：**整段归该人物**，不拆事略、不 exclude。

### 块内中间段落（强制复核）

**定义**：前后相邻段落已归**同一** entry（同一 `owners`），中间段却被 `exclude` → 称「块内中间段落 / 夹心 exclude」。

**原则**：**不要轻易 exclude 中间段落**。默认仍归该人物，避免叙事块被挖洞、人物内容丢失。

| 情形 | 处理 |
|------|------|
| P(n−1)、P(n+1) 均归黄帝，P(n) 写「二十五子，得姓者十四人」 | **归黄帝**，非世系链 |
| P(n−1)、P(n+1) 均归传主，P(n) 为纯「A 生 B 生 C」谱系 | 方可 `世系链` exclude |
| 块内制度 / 用人 / 子嗣 / 婚配短段 | **整段归块主人** |

Step 2 / Step 3 预检会对「前后同 owner + 中间世系链/过渡叙事 exclude」发出**警告**，须人工复核。

**样例（五帝本纪 P7）**：「黄帝二十五子，其得姓者十四人」紧接 P6 土德之瑞、P8 娶嫘祖生子——**归黄帝**，不得标世系链。
