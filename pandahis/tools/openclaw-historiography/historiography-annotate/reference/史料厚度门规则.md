# 史料厚度门规则（SSOT）

> **定位**：merge 全局索引（GLBL）与翻译准入的定量门；标注阶段仍保留著作级 skeleton。  
> **关联**：`标注索引条目合并规则.md` §五、`人物标注规则.md` §1.1、`人物补全规则.md` §2.3。

---

## 一、阈值

| 常量 | 值 | 含义 |
|------|-----|------|
| `THIN_SOURCE_THRESHOLD` | **100** | 母本+全部补充史料合计汉字数硬线 |

**计字**：对 `段落索引/*.json` 中 `text` 字段计 **汉字**（`\u4e00-\u9fff`），按 entry / block 的 `paragraph_from`～`paragraph_to` 闭区间累加。  
**不计**：`原文字句` 摘句字段、exclude 段、翻译阶段外部补全。

---

## 二、规则

### R1　合计不足 → 不产 GLBL

同一史略主题（merge 分组键：归一名称 + 史略分类）下，**母本 + 所有补充**合计汉字 **< 100**：

- **不写入** `史略索引_01至02.json`（不分配/不占用 GLBL）
- **保留** 各卷 `SHIJI_*` / `HANSHU_*` skeleton 及 `paragraphs[]`
- **写入** `data/05工作流中间产物/薄标注待补全/registry.json`
- **不进入** 一期翻译流水线

**例外（warn-only，仍产 GLBL）**：**本纪 + 君王**（卷型=纪 且 史略分类=君王）。

### R2　母本过薄 → 补充升格

merge 在按卷型/时序 rank 之后：

1. 若当前母本候选 **< 100** 汉字  
2. 且存在补充源 **≥ 100** 汉字  
3. → **将该补充源 swap 为母本**（原母本降为补充）

叙事字段（名称、简介、原文字句等）随 **新母本** skeleton；分类/坐标仍按 `标注索引条目合并规则.md` §五 SSOT。

---

## 三、分流

```
Step1–4 标注 → skeleton 保留
       ↓
merge：rank → R2 swap → 计字
       ↓
  ≥100（或本纪君王例外）→ GLBL → 一期翻译
  <100                  → 薄标注注册表 → 朝代知识补全候选池（非 100% 自动成稿）
```

**朝代补全**：薄标注条目 **不在 GLBL** → 一期去重不挡；若 `candidates-renwu` + 人审选中，则走二期 compose，分配 **新 GLBL**（`母本著作=朝代补全`）。

---

## 四、各阶段职责

| 阶段 | 行为 |
|------|------|
| Step2 `check_format` | 单卷 **<100 字 warn**（不硬删 entry） |
| merge `merge_global_entries.py` | **R1/R2 硬门** + 写注册表 |
| translate `verify.py` | 召回后 **<100 硬拒**（`史略来源=史料提取`） |
| dynasty `candidates-renwu` | 读注册表本朝条目 → **优先候选**（人审可删） |

---

## 五、与旧门槛关系

- 文臣/武将/宦官 **≥20 字** Step2 硬门：**保留**（极低质量拦截）
- **100 字硬线** 在 **merge / 翻译** 生效；20–99 字 skeleton 可存在，但不升 GLBL
