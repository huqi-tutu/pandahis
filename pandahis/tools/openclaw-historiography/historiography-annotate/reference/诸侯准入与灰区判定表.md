# 诸侯准入与灰区判定表（v4 草案）

**状态**：规则草案，待 v4 分类落地后生效。  
**配套**：《人物标注规则》v4（新增 `史略分类=诸侯`）、《朝代详情泳道规范-v4-诸侯栏.md》。  
**原则**：`君王` = 天下共主（天子 / 皇帝 / 本纪级最高统治者）；`诸侯` = 封国 / 独立国世袭君主（世家·诸侯世系主轴）。

---

## 一、准入总则（三条同时满足 → 诸侯）

| # | 条件 | 说明 |
|---|------|------|
| A | **国别君主** | 某一政权（侯 / 公 / 伯 / 王号）内的最高统治者，叙事主轴为在位治国 |
| B | **非天下共主** | 不对天下秩序承担天子 / 皇帝位；名义上臣属于更高共主（周天子、皇帝），或处于列国并列格局 |
| C | **卷型匹配** | 主要来自《世家》诸侯世系，或本纪中**灭国称帝前**的国君段（见灰区表） |

**一票否决（不归诸侯）**

- 本纪主轴且为 **天子 / 皇帝 / 霸王级共主** → `君王`
- **同姓藩王**（汉及以后宗室封王）→ `宗戚`（优先于诸侯）
- 列传主轴为军功 / 仕宦，封王仅为结局 → `武将` / `文臣`
- 域外 / 蛮夷政权君主 → `蕃祚`（华夏分封体系外的另议）

---

## 二、分类优先级链（v4）

```
君王 ＞ 宗戚 ＞ 诸侯 ＞ 宦官 ＞ 文臣 / 武将 ＞ 蕃祚 ＞ 庶众
```

- 同一人兼具「宗室封王」与「封国统治」→ **宗戚**（如楚元王刘交）
- 异姓封王且主轴为封国统治 → **诸侯**（如张耳封赵王，若单独立国君条）

## 四、灰区扩展说明（硬案例外的规则）

### 4.1 本纪内的国君段

| 情形 | 判定 |
|------|------|
| 《秦本纪》秦孝公～秦庄襄王 | **诸侯**（每人独立 entry 时） |
| 《秦本纪》秦始皇、秦二世 | **君王** |
| 《周本纪》周公摄政段 | 归 **周公旦** 诸侯条（鲁国 / 摄政），不归周王 |
| 《项羽本纪》 | 整体 **君王**（见上表 #15） |

### 4.2 战国「称王」

楚武王、齐湣王等称王 → 仍为 **诸侯**（本国君主头衔升级，非统一天下）。

### 4.3 三国及以后（预留）

| 情形 | 判定 |
|------|------|
| 魏 / 蜀 / 吴皇帝 | **君王**（割据政权的皇帝位） |
| 十国君主 | **君王**（与项目「实质独立割据负责人」旧君王定义一致，v4 收紧为皇帝级） |
| 五代十国某国国君 | **君王** 若称帝；未称帝的节度使割据另议 |

### 4.4 蕃祚 vs 诸侯

| 情形 | 判定 |
|------|------|
| 匈奴单于、南越武王 | **蕃祚** |
| 吴太伯立国前在荆蛮 | 叙事块仍归 **吴太伯** 诸侯条；蕃祚不抢华夏诸侯世系 |

### 4.5 厚度门

诸侯与君王相同：**母本合计 &lt; 100 字不升 GLBL**，进薄标注注册表（如管叔鲜、蔡叔度）。

## 七、判定流程（实施时用）

```
1. 是否宗戚专则命中（后妃 / 同姓藩王 / 公主）？ → 宗戚
2. 是否蕃祚卷型？ → 蕃祚
3. 是否列传主轴（文臣 / 武将 / 庶众）？ → 对应类
4. 是否天子 / 皇帝 / 霸王级本纪共主？ → 君王
5. 是否封国 / 列国世袭君主？ → 诸侯
6. 否则 → 不建 entry 或薄标注
```
