# 卷型补充：纪传叙事

适用：本纪、世家、列传（默认卷型）。

---

## 密度参考（audit 预检）

- 反密度阈值：**N/8**
- 密度警示：**M > N/3** 时逐条复核

---

## 块优先策略

| 类型 | 切块 | 精判重点 |
|------|------|----------|
| **本纪 · 单人** | 除 exclude 外整卷归该君王 | `太史公曰`、卷首标题 |
| **本纪 · 多人** | 按段内叙事主角分块（如五帝本纪） | **块边界**（禅让、过渡） |
| **列传 · 单人** | 传主主块尽量全收；副人物独立小块 | exclude 候选 |
| **列传 · 合传** | 按传内「X者… Y者…」分块，**块内全归该传主** | **块边界**、交叉叙述、退场后段落 |
| **太史公曰** | 一律 exclude，不归任何 entry | 勿误标叙事段 |

---

## 标注要点

| 类型 | 规则 |
|------|------|
| **本纪** | 只出 **君王**（**例外**：《吕太后本纪》主轴为 **宗戚**）；一纪可多人；不为臣子另建条 |
| **列传 · 单人** | 传主必提取；达门槛的其他人物按四类提取 |
| **列传 · 合传** | 传名人物逐个提取；块边界精读；块内段落尽量全收 |
| **世家 · 诸侯世系** | **统一专则**（见 `人物标注规则.md` §三）：有独立叙事段的历代君主逐人成块；纯世系链 exclude；禁止始祖吞卷 | 鲁/齐/晋/楚/卫/宋… |
| **外戚世家** | 宗戚主轴（吕太后、薄太后…），禁止帝王为 protagonist | 块按后妃时代 |
| **五宗世家** | 宗戚主轴（栗姬/程姬/贾夫人/唐姬/儿姁五母宗支）；禁止藩王、汉景帝为 protagonist | 块按母系五宗 |
| **三王世家** | 宗室藩王合传；禁止汉武帝为 protagonist | 齐王刘闳、燕王旦、广陵王刘胥 |
| **孔子 / 陈涉世家** | 孔子=士臣；陈涉=庶众 | 勿因帝王表升格为君王 |
| **嵌入叙事** | 制度 / 战争 / 他人名字 → 整段归块主人，不 exclude |
| **块内中间段落** | 前后段同 owner 时，中间段默认也归该 owner；勿挖洞 exclude |

---

## 审计

- 合传：**块边界段**已检视，无张冠李戴；传名人物均有 entry
- 本纪：每位君王 `paragraphs` 连续可读
- exclude：`太史公曰` 未误标为叙事段
- **夹心 exclude**：段落表中出现「A–exclude–A」模式须复核（脚本预检会警告）
