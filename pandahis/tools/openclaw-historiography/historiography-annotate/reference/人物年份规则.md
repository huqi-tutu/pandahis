# 人物年份规则

适用：**文臣 / 武将 / 宦官 / 庶众 / 宗戚**（君王、蕃祚见下）。

---

## 语义

| 分类 | 史略开始年 | 史略结束年 |
|------|------------|------------|
| 君王 | 即位年 | 退位/崩年 |
| 蕃祚 | **政权立国年**（建号、入据） | **政权灭亡年**（被灭、丧失独立） |
| 文臣 / 武将 / 宦官 / 庶众 / 宗戚 | **出生年** | **去世年** |

人物生卒**与卷内是否有君王无关**。蕃祚年轴**与卷内叙事起止无关**，须据著作+卷名+政权名考订兴亡。

---

## 优先级

1. **大模型**据史学界主流观点填写（最高优先级，脚本不得覆盖已有 `_年LLM依据`）
2. **脚本兜底**（仅 LLM 未填完整时）

蕃祚：LLM 据【著作+卷名+史略名称（政权名）】独立考订；脚本兜底见 `collective_volume_subjects.py` 政权表。

---

## 脚本兜底链（人物类）

1. **学界有推测生卒**（含仅生年推测、卒年确定）→ 填完整 `出生年～去世年`（写入 `_年LLM依据`）  
2. **完全无出生年推测、仅知去世年** → `史略开始年` = `史略结束年` = 去世年  
3. **不知去世年、知活跃期**（四级帝王已锚定）→ 取该帝王在 `帝王.json` 中的在位起止年  
4. **活跃期亦未知** → 取 `二级朝代坐标` 对应朝代在 `朝代.json` 中的**开始年**（两年相同）

## 脚本兜底（蕃祚）

1. `collective_volume_subjects.COLLECTIVE_SUBJECTS` 已录入政权 → 填立国年～灭亡年  
2. 未录入 → 留空待 LLM 考订；禁止退化为人物生卒或本卷叙事跨度

> 例：李斯卒年前208确定、生年学界推测约前284 → 填 `-284～-208`，**不得**因生年推测而退为 `-208～-208`。

---

## 跨时期人物

- 仍**一条 entry**；四级帝王 = 本卷叙事主轴（与年份独立）
- 跨度 ≥30 年或共段坐标冲突时，填 `_auto_filled._坐标主轴说明`

详见 `reference/跨时期人物坐标.md`。
