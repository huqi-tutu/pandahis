# 史略人物标签（person_tag）标注规则

> 脚本：`person_tag.py`  
> 字段：`人物标签` / `人物标签判定理由` / `人物标签置信度`  
> **仅在全局 enrichment 阶段写入**（`run_global_enrichment.py`），卷级 Step4 不产标签。

## 一、定义

**人物标签** = 后世提及该史略主体时，最具辨识度的一个记忆锚点（**2～5 个汉字**）。

- 与 `史略简介` 分工：简介讲发生了什么；标签讲「被怎样记住」
- 与 `优先级` 分工：优先级是朝代内排序；标签是公众辨识度
- 与 `峰值年` 分工：峰值是时间锚点；标签是记忆锚点（可不一致）

**允许留空**：若无通行典故、标志性事件、传世标识或不可替代的历史角色，**不要硬凑标签**，`人物标签` 留空即可。

## 二、适用范围

`君王` / `宗戚` / `文臣` / `武将` / `宦官` / `庶众` / `蕃祚` 均适用。  
未来首页帝王标签从君王史略的 `人物标签` 读取，不使用 `historical_emperor.tags` 占位数据。

## 三、输入分层（LLM 综合裁决）

### L1 主体锚点（必填）

- `判定对象` = `史略名称`
- `史略分类`
- `史略开始年` / `史略结束年`
- `二级朝代坐标`、`四级帝王坐标`（人物类）

### L2 内容证据（必填至少一项）

- `史略简介`
- `母本原文字句`（≤300 字）
- `考订依据`·年 / 坐标主轴

### L3 参考信号（可选，不强制采纳）

- `峰值年` / `峰值原因` / `峰值类型`
- `优先级` / `优先级判定理由`

峰值/优先级有误时，标签仍可从 L2 独立判定；须在判定理由中说明是否采纳峰值建议。

## 四、选题原则（与史略分类无关）

按优先级取**一条**最具代表性的记忆点：

1. 通行典故/成语核心词（如「背水一战」）
2. 单一标志性事件（如「鸿门宴」）
3. 唯一传世标识：著作、制度、封号（如「史记」「推恩令」）
4. 不可替代的历史角色（如「托孤」「废立」）
5. **兜底**：笼统但指向本人的角色词（如「守边名将」「直谏名臣」）——仅当 1–4 均无时可用
6. **再不行则留空**：不得用「缺载/无闻/不详」类元描述凑数

**禁止：**

- 泳道分类词：`文臣`、`武将`、`宦官`、`庶众`、`宗戚`、`君王`、`蕃祚`
- 元描述/缺载标签：`史载寡闻`、`事迹不详`、`载籍无闻`、`六年无事` 等——**应留空**
- 标签主题为他人：`破羌之子`、`平帝之父`（除非判定对象本人仅以此关系被后世记住，且理由明确）
- 朝代名、姓名本字、空泛褒义（`伟人`）
- 与 `史略简介` 简单重复

**允许：**

- 多人同标签（如汉赋四大家可共享「汉赋名家」）
- 笼统角色词：`名将`、`名臣`、`权臣`、`奸臣`、`贤臣`、`功臣` 等——**仅作兜底**

## 五、硬约束（脚本）

- 有标签时须满足 `^[\u4e00-\u9fff]{2,5}$`
- 标签须描述 `判定对象` 本人（不得主要描述他人）
- 无合适锚点时 `人物标签` 可为空字符串
- 低置信（<0.4）或守门失败 → `_人物标签待审`，不阻断全局 enrichment

## 六、幂等与锁定

- `_人物标签指纹` 未变则跳过（含「已判定留空」）
- `_人物标签人工锁定=true` 永不被覆盖
