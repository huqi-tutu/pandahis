## Step 1 工作流（块优先）

1. 人物清单 + entry 级 `史略分类`  
2. 叙事块 `paragraph_from` / `paragraph_to`  
3. 合传 / 多人本纪：块边界精判  
4. 展开 `segment_attribution`（1..N 每段一行）  
5. 归纳 `entries.paragraphs`

块草稿 → 段表可用 `expand_blocks.py`（见下）。

### 块草稿格式（expand_blocks 输入）

```json
{
  "total_paragraphs": 47,
  "excludes": [
    {"paragraph_from": 47, "paragraph_to": 47, "exclude_reason": "太史公曰"}
  ],
  "blocks": [
    {"name": "黄帝", "category": "君王", "paragraph_from": 1, "paragraph_to": 10},
    {"name": "颛顼", "category": "君王", "paragraph_from": 11, "paragraph_to": 20}
  ]
}
```

```bash
python3 .../historiography-annotate/expand_blocks.py draft.json -o attr.json --merge-entries
```

## JSON 骨架格式（Step 1）

```json
{
  "volume": "卷名",
  "source_file": "01史记_001_五帝本纪第一.txt",
  "total_paragraphs": 45,
  "segment_attribution": [
    {"paragraph": 1, "owners": [{"name": "黄帝", "category": "君王"}]},
    {"paragraph": 44, "owners": [], "exclude_reason": "太史公曰"}
  ],
  "entries": [
    {
      "史略ID": "SHIJI_001_01",
      "史略名称": "黄帝",
      "史略简介": "≤20字",
      "原文字句": "原文逐字引用",
      "史略分类": "君王",
      "主要史料出处": "《史记·卷一·五帝本纪》",
      "paragraphs": [{"volume": "五帝本纪", "paragraph_from": 2, "paragraph_to": 8}]
    }
  ]
}
```

Step 4 补全后在 entries 中增加：一级文明坐标、**文明ID**、二级朝代坐标、**朝代ID**、三级政权坐标、**政权ID**、四级帝王坐标、**帝王ID**、史略开始年、史略结束年、**原文出处**、**五级细坐标**、**六级段落锚点**、峰值年四字段。

**不在卷级 Step4 填写**：`优先级` / `优先级判定理由` / `人物标签`（见全局 `run_global_enrichment.py`）。
