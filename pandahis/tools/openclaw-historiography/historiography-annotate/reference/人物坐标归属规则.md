# 人物坐标归属规则

适用：**宗戚 / 文臣 / 武将 / 宦官 / 庶众 / 蕃祚** 的四级帝王坐标（`四级帝王坐标`）。

**由大模型判定四级帝王**；**一～三级坐标由编排器据 `帝王.json` 自动反推**，不要求 LLM 填写。

**不依赖本卷是否出现对应君王条目**——卷内可能没有该帝王的本纪，仍须据史略主题与史学常识判定。

脚本仅提供 `帝王.json` 枚举与 `_主轴参考` 提示（可推翻），**不替代**四级帝王判定。

---

## 基本原则

一人一条 entry；跨朝代、跨政权、跨帝王时，**只选一个**四级帝王（二 / 三级随该帝王从 `帝王.json` 反推）。

---

## 判定优先级（大模型）

当人物一生或本卷叙事跨越多个朝代 / 政权 / 帝王时，四级帝王取：

1. **主政、仕宦、最高官职、历史功业** 最突出所在的那位帝王及其政权、朝代  
2. 若在多位帝王下均有重要功绩、**难以划分主次** → 取**更早**能匹配上的那位帝王（及其政权、朝代）

### 宗戚专则（与士臣 / 庶众不同）

宗戚的**四级帝王坐标**不看「功业主轴」，而看**血缘 / 婚姻 / 册封归属**。二 / 三级随所选帝王从 `帝王.json` 反推。

#### 分类型取轴

| 宗戚类型 | 四级帝王取谁 | 说明 |
|----------|--------------|------|
| **嫔妃、皇后、太后、太皇太后** 等配偶 / 尊号女性 | **册封自己的君主**，即其**丈夫**（在位或追尊时的配偶之君） | 立后、立妃、入宫为妃、尊为太后，均在**该君临朝**时发生；**不**因子嗣后来即位改挂其子朝 |
| **公主、翁主、县主** 等宗室女 | **生父**（在 `帝王.json` 中的标准名） | 以父系宗室身份定位；出嫁后亦**不**改挂驸马 |
| **同姓藩王 / 诸侯王**（汉初及以后刘氏宗室封王） | **册封之君**（在 `帝王.json` 中的标准名） | 如楚元王→汉高祖，梁孝王→汉文帝；**不**挂藩王自身。**异姓诸侯王**（韩信、英布等）不归宗戚，仍按君王或士臣处理 |

#### 理解要点

- **册封之君 = 丈夫**：景帝妃、武帝生母 → 挂 **汉景帝**，不因后来以子临朝改挂汉武帝。  
- **太后 / 太皇太后**：尊号发生在**丈夫为帝**或**以夫之谥追尊**的脉络下，仍挂**丈夫**，不因「临朝称制」改挂儿子。  
- **公主类**：挂**父亲**；驸马、夫家政权**不**替代父系帝王坐标。  
- 若同卷叙事块内兼有妃嫔与公主，**各 entry 按上表各自取轴**，不得统一挂「本卷最显赫之君」。

#### 示例

| 人物 | 不宜 | 宜取 | 理由 |
|------|------|------|------|
| 王太后（王娡） | 汉武帝（因子即位、临朝） | **汉景帝** | 景帝妃、生太子；册封与入宫均在景帝世 |
| 窦太后 | 汉景帝（因子临朝） | **汉文帝** | 文帝朝册立为皇后 |
| 卫子夫 | — | **汉武帝** | 武帝朝立为皇后，丈夫即武帝 |
| 薄太后 | 汉高祖（误） | **汉文帝** | 文帝生母 / 尊宠在文帝朝，丈夫系文帝 |
| 馆陶长公主 | 汉武帝（因子） | **汉文帝** | 文帝女，以**生父**为轴 |

#### 与士臣 / 庶众的边界

士臣、庶众、宦官仍按上文「主政 / 仕宦 / 功业」取轴；**宗戚一律优先适用本专则**，不得套用「叙事后半段所在之朝」。

| 维度 | 取谁 |
|------|------|
| 主要仕宦 | 官职最高、任用最久、事迹最著之朝 |
| 历史功业 | 后世概括其人生标签时关联最深之君（如「佐高祖定天下」→ 汉高祖） |
| 难以平分 | **早者**优先（非「本卷后半」优先） |

### 示例

| 人物 | 不宜 | 宜取 | 理由 |
|------|------|------|------|
| 张良 | 仅因卒于惠帝朝而挂惠帝 | **汉高祖** | 功业在佐汉定策；惠帝朝事为晚年余绪 |
| 李斯 | 仅因死于二世朝而挂二世 | **秦始皇** | 相业、郡县、统一在始皇朝；二世段为结局 |
| 蒙恬 | — | **秦始皇** | 筑长城、北击匈奴在始皇朝；沙丘死于二世朝见共段 |
| 春申君黄歇 | 秦昭王（误） | **楚考烈王** | 令尹执政于楚考烈世；早年说秦为前段 |
| 张耳 | 项羽（误：仅因早年从项楚） | **汉高祖** | 本传终局为归汉封赵王，最高爵位与政治归属在汉高祖朝确立 |
| 陈馀 | 项羽（误：仅因楚汉前段） | **汉高祖** | 与张耳合传，败亡于汉军征伐，本卷叙事归于汉初天下格局 |

## `_坐标主轴说明`

当生卒跨度 ≥30 年，或共段他人坐标与所选帝王明显不一致时，在 `_auto_filled._坐标主轴说明` 写 1～2 句：

- 为何按上表规则取该帝王  
- 其他朝代 / 帝王下的事略如何处置（「见共段事略」「早年仕某王见前段」等）

---

## 与年份的关系

- **坐标归属**（四级帝王等）← 本规则，大模型判定  
- **史略开始年 / 结束年** ← 学界主流生卒或即位 / 退位，见 `人物年份规则.md`  
- 二者独立：可生卒跨多帝，但坐标只挂一个主轴帝王

---

## 禁止

- ❌ 把史略名称、人物本名写入四级帝王坐标  
- ❌ 因卷内无君王本纪而默认挂本卷出现的第一位帝王  
- ❌ 用帝王在位起止年替代人物生卒年  
- ❌ 使用非标准帝王名（如 **汉高帝** → 须用 **汉高祖**，见 `帝王命名规范.md`）
