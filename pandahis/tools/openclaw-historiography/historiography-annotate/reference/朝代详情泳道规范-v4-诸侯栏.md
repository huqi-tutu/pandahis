## 三、视觉 token（绢帛六色 · 按泳道序循环）

实现：`chip-badge-tokens.ts` 中 `SWIM_LANE_CATEGORY_KEYS` 与 `SILK_TONES` 按下标 `index % 6` 自动派生；`BoxCategorySupport` 边框色与 `solid` 一致。

| 泳道 | 绢帛色 | solid | deep | bg（14% 标签底） |
|------|--------|-------|------|------------------|
| 诸侯（第 2 泳道） | c2 黛青 | `#63899C` | `#4B6877` | `#E3E7E6` |

```typescript
// 按序循环，勿手写跳色
SWIM_LANE_CATEGORY_KEYS.forEach((key, i) => {
  CATEGORY_TONES[key] = SILK_TONES[i % 6]
})
```

## 五、朝代页展示逻辑

### 5.1 泳道数据聚合

- `UnitSwimMatrixService` 按 `category_key` 分栏；`zhuhou` 条目进入第 2 泳道。
- **不做**按 `三级政权坐标` 二次拆栏（一期）；卫国 / 晋国国君同在「诸侯」泳道，以时间条并列。
- 二期可选：诸侯泳道内按政权分组折叠（产品另议）。

### 5.2 典型朝代页效果

| 朝代页 | 君王栏 | 诸侯栏 |
|--------|--------|--------|
| **西周** | 周文王～周幽王 | 卫康叔、燕召公、宋微子、周公旦（鲁）… |
| **春秋** | 东周天子（若有条目） | 齐桓公、晋文公、楚庄王… |
| **战国** | （通常为空或仅周王） | 秦孝公、赵武灵王… |
| **秦** | 秦始皇、秦二世 | （统一后为空） |
| **西汉** | 高祖～平帝 | （异姓王若单立诸侯条则出现；同姓藩王在宗戚栏） |

### 5.3 本地回退（`swim-local-fallback`）

- 现行：API 不可达时仅合成「君王」单泳道。
- v4：回退仍 **仅君王**；诸侯依赖 GLBL / API，不做帝王表离线合成。
