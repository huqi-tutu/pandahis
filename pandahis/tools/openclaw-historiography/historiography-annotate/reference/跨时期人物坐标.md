# 跨时期人物坐标

适用：**士臣 / 庶众 / 宗戚** 一生跨多帝王、多政权时。完整判定规则见 **`reference/人物坐标归属规则.md`**。

---

## 原则

- **一条人物 entry**（不在同卷拆两条）
- **四级帝王由大模型判定**；二 / 三级从所选帝王 `帝王.json` **反推**
- **史略开始年 / 结束年** 独立判定，见 `人物年份规则.md`

---

## 四级帝王怎么选（大模型）

**宗戚**不适用下列「功业 / 仕宦」规则，须先读 **`人物坐标归属规则.md` · 宗戚专则**：嫔妃 / 皇后 / 太后 → 挂**丈夫（册封之君）**；公主 / 翁主等 → 挂**生父**。

**士臣 / 庶众 / 宦官**跨朝代 / 政权 / 帝王时：

1. 以其**主要主政、仕宦、最高官职、历史功业**所在的帝王、政权、朝代为准  
2. 若在多个帝王下均有功绩、**难以划分** → 取**更早**能匹配上的帝王、政权、朝代  

---

## 何时填 `_auto_filled._坐标主轴说明`

- 生卒跨度 ≥30 年，或  
- 共段其他人物坐标与所选帝王明显不一致  

须 1～2 句说明：为何取该帝王（主政/功业依据），其他朝代/帝王段落如何处置。

示例：「本卷以佐汉定策为主线，四级帝王取汉高祖；惠帝朝留侯事见共段事略。」
