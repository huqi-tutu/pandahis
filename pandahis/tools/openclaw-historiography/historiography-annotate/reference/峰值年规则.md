# 史略 Peak Year（峰值年）标注规则

> 本文件是 `peak_year.py` 的判定规则 SSOT（供 LLM prompt 引用与人工审核对照）。
> 字段：`峰值年` / `峰值原因` / `峰值类型` / `峰值置信度`。

## 一、定义

**峰值年 = 该史略实体在历史影响、政治影响、军事影响、思想影响或社会影响达到最高峰的时间节点。**

它是时间轴上的**横向锚点**，不是简单的出生年 / 建立年 / 死亡年。

## 二、通用判定原则

优先寻找（自上而下）：

1. 历史影响最大节点
2. 权力 / 地位最高节点
3. 改变历史进程节点
4. 最大成就节点
5. 最具代表性的事件节点

**禁止直接使用**（除非该年份本身就是历史意义最高点）：出生年、单纯死亡年、单纯成立年。

## 三、硬约束（脚本强制）

- `史略开始年 <= 峰值年 <= 史略结束年`。越界 → clamp 到区间并降低置信度、打审核标记。
- `峰值年` 为整数，公元前为负。
- `峰值类型` 必须是下方枚举之一。
- `峰值置信度` ∈ [0, 1]。
- 同一实体（内容指纹不变）重跑结果必须一致：LLM 层 temperature=0 + 指纹缓存。

## 四、峰值类型枚举（peak_type）

| 枚举值 | 含义 | 默认适用分类 |
|---|---|---|
| `political_peak` | 政治高峰 | 君王 / 宗戚 / 宦官 |
| `military_peak` | 军事高峰 | 武将 |
| `career_peak` | 功业 / 治绩巅峰 | 文臣 |
| `institutional_maturity` | 制度成熟 | 典制 |
| `thought_spread` | 思想传播 / 成书 | 论著 |
| `territorial_peak` | 疆域 / 国势鼎盛 | 蕃祚 |
| `event_climax` | 事件高潮 | 事略 / 庶众 |
| `founding` | 立国 / 开创（兜底） | 任意 |

## 五、分类判定优先级

### 1. 君王 → political_peak
1）统一天下 / 完成重大扩张年 2）开创盛世 / 重大改革年 3）权力巅峰年 4）统治稳定期中段 5）登基年（兜底）6）崩年（最后兜底）
> 例：秦始皇=前221（统一六国）；唐太宗=贞观中段。

### 2. 宗戚 → political_peak
1）实际掌权年 2）参与重大政治事件年 3）获最高爵位 / 身份年 4）进入皇室体系年 5）死亡年兜底

### 3. 文臣 → career_peak
1）主持重大改革年 2）任核心职位年 3）完成重大政治贡献年 4）获最高官职年 5）入仕年兜底

### 4. 武将 → military_peak
1）决定性战争胜利年 2）最大军事成就年 3）封侯拜将年 4）掌最高军权年 5）死亡年兜底

### 5. 事略 → event_climax
1）关键爆发年 2）决定历史走向的转折年 3）重大结果形成年 4）开始年 5）结束年
> 长跨度事件（战争 / 改革 / 朝代变迁）取「改变历史结构的关键节点」，而非简单取起止。

### 6. 典制 → institutional_maturity
1）制度成熟并广泛运行年 2）重大改革完善年 3）正式建立年 4）首次实施年
> 例：科举 → 取成熟推广阶段，非最初建立。

### 7. 论著 → thought_spread
1）成书年 2）思想体系形成年 3）首次大规模传播年 4）作者思想成熟期
> 无明确年份 → 取作者创作高峰期。

### 8. 宦官 → political_peak
1）掌最高政治权力年 2）影响重大政治事件年 3）获最高职位年 4）进入权力中心年 5）死亡年兜底

### 9. 庶众 → event_climax
1）参与重大历史事件年 2）社会影响最大年 3）代表性活动年 4）历史记录出现年
> 群体 → 取群体历史存在感最高阶段。

### 10. 蕃祚 → territorial_peak
1）疆域最大年 2）军事最强年 3）国际影响最大年 4）政权鼎盛年 5）建立年兜底

## 六、冲突处理

一个实体有多个合理峰值年时，**不随机选择**，按序：
1. 对历史影响最大 → 2. 改变历史进程程度最高 → 3. 教科书认可程度最高 → 4. 时间明确程度最高。

仍无法确定 → 取区间中间年，并把置信度降到 ≤ 0.4（触发人工审核）。

## 七、置信度参考带

- 0.85–1.00：教科书级明确节点（统一、决定性战役、成书年）。
- 0.60–0.84：主流史学可锚定，但存在小范围争议。
- 0.40–0.59：只能大致锚定活跃期中段。
- ≤ 0.39：脚本兜底中点，**必须人工审核**。
