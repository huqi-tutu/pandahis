# 人物归因（块优先 · 边界精判）

与 `人物标注规则.md` 配合。Step 1 **先切块、再展开** `segment_attribution`，**不在块内逐段做分类判断**。

---

## 核心原则

1. **完整段落集**：传主叙事块内段落**尽量全收**，嵌入的制度 / 事件 / 他人提及**整段归块主人**
2. **分类在 entry 级**：`史略分类` 每人定一次；段上 `owners[].category` 与 entry 一致即可，**段内不必单独判四类**
3. **exclude 从严**：仅 `太史公曰`、卷首标题、**明确**世系链、纯纪年等；**慎用** `过渡叙事` / `无故事弧`
4. **合传防张冠李戴**：块边界必须精读；块内批量归属

---

## 五步工作流

```
Step 0  段落索引准确（total_paragraphs = 原文段数）
  ↓
Step A  人物清单（传主 + 合传名单 + 卷内其他达门槛者）+ 每人 entry 级「史略分类」
  ↓
Step B  叙事块划分（paragraph_from / paragraph_to，按卷型策略）
  ↓
Step C  边界精判（合传 / 多人本纪：块交接 3–5 段；exclude 候选段）
  ↓
Step D  展开 segment_attribution（块内机械填充；可用 expand_blocks.py）
  ↓
Step E  归纳 entries.paragraphs + 原文字句
```

---

## 卷型 · 切块策略

| 卷型 | 切块方式 | 精判重点 |
|------|----------|----------|
| **列传 · 单人** | 传主 = 卷内主块（除 exclude 外尽量全收）；副人物 = 独立小块 | `太史公曰`；卷首标题 |
| **列传 · 合传** | 按「X者… Y者…」分块，**块内全归该传主** | **块边界**、交叉叙述、退场后段落 |
| **本纪 · 多人** | 按段内叙事主角分块（尧段 / 舜段） | 块边界、禅让过渡段 |
| **本纪 · 单人** | 整卷归该君王（除 exclude） | `太史公曰` |

---

## 边界精判（合传 / 多人本纪 · 必读）

以下段落**必须逐段阅读原文**，不可仅靠块机械展开：

1. **块与块之间**：「X 既死，Y ……」「其後 Y ……」类过渡
2. **交叉叙述**：上一传末回顾下一人、并列对比
3. **退场后**：人物死亡 / 离场后的段落是否仍归前人（默认不归，除非整段仍收束其生平）
4. **exclude 候选**：看似世系链 vs 仍有行为的短段 → 优先归邻近传主，不轻易 exclude
5. **块内中间段落**：前后段已归**同一 owner**，中间段**默认也归该 owner**；仅当确认为纯谱系 / 论赞 / 纯纪年时才 exclude（见规则「块内中间段落」）

### 退场/即位切分（过渡句 · 强制）

同一段内若兼有**前帝退场**与**新帝即位**，须按子句切分归属，**禁止**整段只挂新帝：

| 子句类型 | 示例 | 归属 |
|----------|------|------|
| 退场 | `黄帝崩，葬桥山。` | **前帝**（黄帝） |
| 即位 | `其孙昌意之子高阳立，是为帝颛顼也。` | **新帝**（颛顼） |
| 身世铺垫 | `昌意娶蜀山氏女…生高阳…` | 新帝（颛顼） |

**gate 校验**：君王条目的 `原文字句` 若含他人 `X崩/葬` 且 X≠本传主，须报错或拆段修正。翻译召回侧会过滤非本传主退场句，并在前帝条目尾部补入缺漏退场信息。

### 合传边界自检（Step 1 结束前）

- [ ] 传名中每位传主至少一块连续 `paragraphs`
- [ ] 块边界段已精读，无「张冠李戴」
- [ ] 各传主块内无漏段（中间 exclude 须复核：前后同 owner 时默认不 exclude）
- [ ] `太史公曰` 已 exclude，未误标叙事段

---

## 单段归属（强制 · 产出格式不变）

- 展开后 `segment_attribution` 仍须 **1..N 每段一行**
- **非合传**：同一段只归一个人物（或无 owner + `exclude_reason`）
- **合传**：若同段共写多位传主，可同段多归属，但段内正文须涉及所挂全部传主；若为「写完一人再写另一人」、段落各自独立，则仍须单段单人物
- 每个 `owners[].name + category` 必须在 `entries` 中有对应条目
- `segment_attribution` 与 `entries.paragraphs` **双向一致**（Step 2 硬门）

---

## exclude 速查

| exclude_reason | 何时使用 |
|----------------|----------|
| **太史公曰** | 卷末论赞（及汉书「赞曰」、后汉书「论曰」等同理） |
| **卷首标题** | 篇首卷名行 |
| **世系链** | 纯「X 生 Y」无独立行动（子嗣概数 / 婚配收束 ≠ 世系链） |
| **纯纪年** | 仅时间节点、无叙事 |
| **过渡叙事** | **极少用**；块间过渡优先判给下一位传主开篇或上一位收束 |

**块内中间段落**：P(n−1) 与 P(n+1) 已归同一 owner 时，P(n) **默认也归该 owner**，勿轻易 exclude（预检会警告「夹心 exclude」）。

嵌入人物叙事中的制度 / 事件：**不归 exclude**，整段归该人物。

## 辅助脚本（可选）

块划分完成后，用 `expand_blocks.py` 机械展开段表，减少块内手工逐段写入：

```bash
python3 pandahis/pandahis/tools/openclaw-historiography/historiography-annotate/expand_blocks.py \
  draft_blocks.json -o segment_attribution.json
```

草稿 JSON 格式见脚本 `--help` 或 `reference/格式规范.md` · 块草稿格式。
