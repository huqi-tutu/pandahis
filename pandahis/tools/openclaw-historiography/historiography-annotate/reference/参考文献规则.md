# 参考文献规则（已废止）

> **2026-06 起**：标注流水线已取消 Step5 参考文献环节，本文件仅作历史存档，不再执行。

## 目的

整合多个著作对同一史略主题的不同描写，做全量跨著作召回。
未来参考文献也会被拆分标注，最终在翻译阶段针对某一史略主题做跨著作整合，
产出像历史研究者一样的综合叙述。

## 范围限制

### 排除：26 部主要史料

二十四史（史记、汉书……明史）+ 资治通鉴 + 清史稿，不列参考文献。
这些是主要标注对象，本身就在流水线里。

### 排除：过度相似的引用

如果某著作的内容与《史记》对应段落高度相同（如史记五帝时代直接引用《尚书》），
不再列为参考文献。只列有实质差异的材料。

### 准入：三类信息增量

| 类型 | 说明 | 示例 |
|------|------|------|
| 细节补充 | 比《史记》更详细的叙事 | 《左传》记城濮之战前因后果远详于《史记》 |
| 视角差异 | 同一事件的不同叙述角度或评价 | 《竹书纪年》"舜囚尧" vs《史记》禅让 |
| 观点差异 | 不同的历史判断或理论 | 《韩非子》以重耳故事讲法家 vs《史记》儒家叙事 |

## 格式规范

- **单一 MD 文件**：`data/03索引标注条目/参考文献/参考资料清单.md`
- **以著作为单位**：每部著作一条，下列卷/篇 + 关联条目 + 补充原因
- **标完一卷补一卷**，无参考文献的卷标注"（暂无）"
- 不要求每条史略都有参考文献——缺就缺，不凑

## 更新时机

每卷 check_format 通过后，**立即更新参考资料清单**。
