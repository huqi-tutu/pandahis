# Step：Enrich Plan（D 前置 · 基于 C 初稿重新规划）

## 任务

阅读 **C 阶段 baseline 成稿**（`翻译详情` 全文，含引入/正文/结尾）与 `recalled`。  
基于**当前初稿**重新规划 D 阶段要插入的延伸内容——**勿参考任何旧 plan 补全项**。

## 你要规划的内容

1. **制度/官职/术语**：初稿读者可能不懂、且一句白话能讲清的背景。
2. **异说 / 不同史书记载**：与初稿叙述有差异或补充的其他出处说法。
3. **必要背景 / 母本未载细节**：初稿因顺译约束未展开、但有出处可依的信息。
4. **索引补充 block**（recalled 中 `role=补充`）：如何引入、是否异说、是否与初稿去重。

**通假字、地名今址**等「六类触发」标注：在 plan 中标记需在 D 正文执行的句段即可（类型 `标注`），不必单独列外部补全。

## 原则

1. 初稿**已完整展开**（含句群引用/背景/今址）→ 禁止再用他书重复；**压缩句、单句带过** → 仍须在 enrich plan 中规划插入。
2. **须响应 enrich gap ledger** 中每条缺口；索引补充 seed 中「引入」项不得删除。
3. 每项 `采用:true` 须给出：
   - `初稿锚点`：初稿中可定位的一句原文或「第 N 段后」
   - `出处`：《书名·卷篇》
   - `补全类型`：制度解释 | 异说 | 冲突观点 | 背景 | 补充细节 | 评价差异 | 标注
   - `插入说明`：用什么语气插入（与全书口语风格一致、不突兀）
   - `与初稿关系`：相对初稿新增什么
3. 写不出卷篇 → `采用:false`。
4. plan 是**插入蓝图**，不是重写全文。

## 输出

更新 plan JSON（**保留**程序生成的 `母本逐句清单`，**重写**以下字段）：

```json
{
  "外部补全": [ … ],
  "索引补充处理": [ … ],
  "参考著作": [ "母本…", "预计将引用的他书…" ],
  "D阶段插入风格": "一句说明：插入句须与初稿口语一致、挂锚点后即回主线"
}
```

不要写 `翻译详情` 正文。
