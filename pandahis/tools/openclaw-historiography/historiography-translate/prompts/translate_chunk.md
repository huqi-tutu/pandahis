# Step：分块翻译（translate chunk）

## 任务

只撰写**本分块**正文 Markdown，落盘到消息头 `分块正文路径`（`.chunk-XX.md`）。不写最终 API JSON。

## 分块纪律

- 本分块序号与总数见 `recalled._chunk`（如第 2/7 块）
- 按 `source_plan` 本分块计划：**母本逐句清单每一编号的信息点必须体现**，句序不乱，不得写清单外内容
- **不要写开篇总起**（第 1 块除外）；**不要写全篇总结**（最后一块除外）
- **不要写** `*参考著作：*`（由编排器在全文合并时统一添加）
- 禁止译者元叙述；已顺译今字不加通假标注
- **太史公曰 / 论赞**：第三人称史家 framing（见翻译规则），禁止「司马迁说」
- 若提供了「上一分块结尾」，衔接自然，不重复上一块已写内容

## 输入

- `recalled`：本分块原文
- `source_plan`：本分块计划
- `上一分块结尾`（可选）：仅用于衔接

## 完成

正文写入 `.md` 文件后回复 `CHUNK_DONE` + 分块序号 + 约字数。
