# Step：外部补全 · 宏观选题（轻输入）

## 任务

你只拿到**史略名称**与**母本著作**。先检索、再严选。

> 除母本外，古代文献里有没有**值得写进史略**的真增量？  
> 宁缺毋滥：少而重要，好过多为凑通道灌水。

**禁止**：读母本段落雕花；今人论文/演义/网络说法。  
**原则**：先古代材料；通道只是**找材料的路径**，不是「每条通道都要交作业」。

---

## 一、增量门槛（有没有「新东西」）

采用:true 至少满足其一：更新信息 / 更丰富信息 / 不一样视角 / 实质另说。  

**不算补充：** 更简平行纪；仅用字/通假/称谓异写而史实相同；自承略同仍标 true；同情节雕花。  
跨书要的是**有意义的**冲突/另说/背景/异评，不是写法对照。

---

## 二、检索通道（第一层 · 如何找）

按需使用，**不为覆盖通道而凑 true**：

| 通道 | 在找什么 |
|------|----------|
| A | 同典籍非本传（书/表/世家/列传/志）的另一镜头 |
| B | 近时杂史、别史及其辑佚/引文中的早期异闻 |
| C | 外传、故事集、子部杂纂中的另类叙事与舆论 |
| D | 近古议论/批判（政策辩论、功过争议、神异辩驳） |
| E | 类书·注疏引佚（慎用，多作叙事异闻） |

顺序建议 A→B→C→D→E；平行本纪/通鉴类仅当确有未载或异评。  
通道是搜索雷达，**不是评分表**：挖不到重要增量的通道可以整层跳过。

---

## 三、重要性门槛（第二层 · 回形针效应防护）

> 若只优化「多通道、多书目、多采用」，会产出大量琐闻、野史神异、无关轶事。  
> **第二层专门拦这些。**

### 3.1 什么叫「重要」（采用:true 还必须过这一关）

该条须能改变或加深读者对传主的**主轴理解**，至少挂住下面一轴：

| 重要轴 | 问法 |
|--------|------|
| 开国/权力合法性 | 是否影响「凭什么得天下 / 凭什么当皇帝」的理解 |
| 重大制度与政策 | 分封、诛伐、约法、都城、功臣安排、休养等 |
| 关键战局与用人 | 决定性战役、核心谋臣/将领关系的实质分歧或未载关键 |
| 历史评价冲突 | 当时人或近古史家对功过的对立判断（非碎嘴轶事） |
| 政治神话的构造/拆解 | 神异传说仅当涉及合法性叙事，或有系统批判（辩伪），禁止为猎奇复述 |

**一票否决（重要轴挂不上 → false）：**

- 微时碎闻、酒色玩笑、无制度含义的私房话  
- 仅为「更热闹」的场面加戏  
- 野史神异堆砌（龙光、赤帝白帝扩写等）而无评价/批判功能  
- 配角八卦、与主轴无关的类书零句  
- 为满足「再用一个通道」而硬凑的条目  

### 3.2 质量优先于数量

- 长文也**不要求**凑满多条采用:true；**1–5 条真正重要的**优于 8 条灌水  
- 候选可以多、`采用:false` 可以多；true 必须经得起「删掉它，史略主轴理解会变弱吗？」  
- 若答「不会变弱」→ false  

### 3.3 神话 / 杂史使用纪律

- 默认：神话传说、志怪扩写 → false  
- 例外：① 母本已涉的政治神话需要**异说分述或批判视角**；② 近古文献明确辩伪/争论其真伪  
- 类书引佚（通道 E）：默认叙事异闻、从严；无助于主轴理解 → false  

---

## 四、输出 JSON

每条须填：`史料通道`（A–E|其他）、`重要轴`（合法性|制度政策|战局用人|历史评价|神话构造或辩伪|其他）。

```json
{
  "史略ID": "...",
  "史略名称": "...",
  "母本著作": "...",
  "外部补全": [
    {
      "采用": true,
      "史料通道": "D",
      "重要轴": "历史评价",
      "补全类型": "评价差异|冲突观点|异说|背景|必要上下文|补充细节",
      "主题": "...",
      "出处": "《书·卷》",
      "与母本关系": "相对母本多了什么/冲在何处（禁止略同）",
      "理由": "删掉后主轴理解会弱在哪里"
    }
  ],
  "参考著作": ["《…》"],
  "风险提示": ["..."]
}
```

- `外部补全` 数组非空（可大量 false）；**不要求**采用:true 条数下限。  
- **`参考著作` 硬上限 ≤10**：只列最重要的书目（通常含母本 + 真正采用的他书）；宁可少，禁止罗列次要/凑数书目。  
- 本步不必填 `母本锚点`；勿输出 `母本逐句清单`。
