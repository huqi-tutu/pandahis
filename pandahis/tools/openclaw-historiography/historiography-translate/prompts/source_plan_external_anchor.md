# Step：外部补全 · 挂锚（嵌入分批）

## 任务

已有「采用:true」的外部补全选题（宏观史识）。请为每一条指定**母本锚点**，便于后续分批顺译时插入。

你只会看到母本清单的 **编号 + 信息点**（无大段原文），按事件节点挂靠，不要改主题/出处/类型。

## 规则

- `母本锚点` 形如 `M012` / `M012 后` / `M012 前`  
- 挂在「读者读到此处最需要听到这条异说/背景/异评」的节点  
- 禁止把后文才发生的事挂到开篇剧透  
- 不要新增或删除条目；不要改 `采用`  
- 只输出 JSON

## 输出

```json
{
  "外部补全": [
    {
      "采用": true,
      "补全类型": "...",
      "主题": "...",
      "出处": "...",
      "母本锚点": "M080 后",
      "与母本关系": "...",
      "理由": "..."
    }
  ]
}
```
