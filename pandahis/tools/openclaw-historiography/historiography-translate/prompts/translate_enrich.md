# Step：补全成稿（Phase 2）

## 任务

在 Phase 1 **母本顺译稿** 基础上，穿插索引补充与外部补全，写出最终 `翻译详情` 并落盘 JSON。

## 规则

**只遵守**消息中已注入的规则节选（唯一 SSOT：`翻译规则.md`）。以下为 Phase2 特有硬约束：

## 纪律

1. **母本骨架不可重写**：保留 Phase 1 的句序、原词锚点与信息点；只允许在 plan 锚点处 **插入** 或 **轻量扩写**，禁止大段删改母本已译内容。
2. **外部补全准入**：只采用 `source_plan.外部补全` 中 `"采用": true` 的项；每项须：
   - 挂 `母本锚点`（某 M 编号前/后）；
   - 写明出处（《书名·卷篇》）；
   - 提供 **母本没有** 的信息：异说、冲突观点、背景、细节、评价差异；
   - **禁止** 把母本已述事实换说法再写一遍。
3. **索引补充**：按 `索引补充处理` 中「引入|异说」项融入；「去重不用」的不得写入。
4. **异说独立**：多版本须分述，禁止调和为一个版本。
5. 文末必须有「参考著作」节（母本 + 实际引用的他书），格式：

```
参考著作：
1. 《书名·卷篇》
```

（勿用 `*` 包裹标题。）
6. **二手表述（传说/据说/有人说等）**：无《书名》锚点时宜克制，全篇触发词合计 P1 ≤5 次（P3 ≤7）；连续传说层段落 ≤1 段。他书信息优先写「《书名·卷》载：…」。同句已有《》时可转述（如「《史记》载，相传……」）。
7. **引用白名单**：撰写时优先使用 `source_plan.允许引用白名单` 中的著作；plan 未列书目若出现，质检记**警告**不阻断。
8. **禁止元叙述**：不得写「本条 N 段…已读完」等喊数/进度汇报。

9. **禁止编造心理活动**：不得写「心想」「暗想」「内心挣扎」等虚构心理；一切须有原文或他书出处依据。

10. **前置引入**（建议 60–250 字，能过渡即可；**无程序质检、无固定过渡句式**）：
   **作用**：避免正文一上来就扎进具体事迹，给读者一个笼统定位，再自然进入母本叙事。
   **写作要求**：笼统说，不展开——可提人物名、时代、出处，但**不写**正文即将展开的具体事件、情节、对话、因果链。接进正文的方式不限，自然即可；**禁止**「原文如下」「附原文」。
   薄母本可 2–3 句。素材限 `前置引入素材`，勿编造索引未载信息。

11. **收尾纪律**：
   - 正文尾部须有自然收束，但**禁止**单独成段写「《史记》又记…」或「一生的收束」「世系承续的节点」等模板句。
   - 收尾须**承接上一段情节自然过渡**（如「至此…」「太史公记到这里…」「这样一来…」），再落 1–2 句对本传主历史分量的简短概括；不机械补崩葬、继位等母本未载细节，正文已写过的不重复。

12. **防幻觉（事实边界）**：
   - **三层材料**：① Phase1 母本顺译（主线）② plan 中 `"采用": true` 的外部补全/索引补充（须挂 M 锚点 + 《书名·卷篇》）③ 六类触发的一句式解释（制度/地名等，不扩写流程）。
   - **禁止第四层**：plan 未列、出处写不出、或 `"采用": false` 的内容 — **不得**凭模型常识写入（含对话、礼制步骤、战役战术、年号、亲属关系）。
   - **留白**：母本与已采用他书均未载 → 写「母本未载…」或省略；若用传说/据说/有人说等无《》表述，须遵守全篇频次配额，不可当家叙事。
   - **跨时代**：他书补全不得引入与母本时代不符的同名制度/事件细节（如本传为上古，不得拼入汉魏/清末同名典故的流程）。
   - **异说**：多版本分块并陈，挂锚点后立即回母本；禁止调和为一个版本。

## 他书引用格式

每条外部补全必须包含：
- 出处句：「《书名·卷》载：…」
- 关系说明：「此（与母本不同/为母本所无）…」
- 禁止：「据《某书》」而不给卷数
- 禁止：在母本已述事实后接「《某书》也记载…」（纯重复）

## 六类自动触发（在正文中执行）

| 触发条件 | 处理方式 |
|----------|---------|
| 古地名首次出现 | 标注「（今××）」 |
| 生僻字 | 直接写汉字，不加注 |
| 制度/官职术语首次出现 | 简要一句话解释，不打断叙事 |
| 通假字 | 保留原文「×（通×）」 |
| 数字/序号 | 保留原样，不强制转换 |
| 明显有出处的议论 | 挂「《书名》评曰：…」 |

## 输入

- Phase 1 `母本顺译` 全文
- `source_plan`（外部补全、索引补充、参考著作）
- `recalled`（核对锚点）

## 输出

```json
{ "史略ID": "…", "翻译详情": "…\n\n参考著作：\n1. 《书名》\n2. …" }
```

**仅写 `史略ID` 与 `翻译详情`。** `史料原文` 由编排器写入。

完成后回复 `TRANSLATE_DONE` + 史略ID + 约字数。
