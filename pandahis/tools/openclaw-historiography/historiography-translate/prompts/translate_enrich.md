# Step：补全成稿（Phase 2）

## 任务（两职能）

在 Phase1 **母本顺译** 上完成：

| 职能 | 做什么 | 不做什么 |
|------|--------|----------|
| **① 锚点补全** | 把 plan 已采用他书/索引异说嵌进母本锚点；若提示含「本章须落地」清单须先逐条写完 | 不新造 plan 外硬史实；不整卷复述；不同卷灌水 |
| **② 改表达** | 把 Phase1 直译腔**重写**成说书人口语（信息点不动） | 不改专名/数字/因果；不编造对白/心理；不蒸发信息 |

顺序：**先①后②**。消息最前面已有**声口金标示范**——对齐那个口气写，不要对齐母本的书面句式。

> Phase1 是素材不是成稿。几乎原样誊抄 = 失败。  
> **通顺书面语 ≠ 《明朝那些事儿》**。后者要有口语、场面、人物口气、**释义旁白**（生僻字词/古语/古怪处自然点破）、偶尔反差点破。

### 为什么旧好稿（如 v7）有味道、后来稿没有

旧稿敢写「太公就是刘老头」这类旁白；后来忌「说白了」过狠，模型连有信息量的旁白也不敢写。  
**禁的是滥用无意义过场词，不是禁旁白。** 旁白要自然融入、单处≤200字、事实白描、不强制出处。

## 规则

只遵守消息中已注入的本阶段规则切片（SSOT：`翻译规则.md`）。下面把切片里与两职能相关的硬点收束，避免互相打架。

### 冲突消解（读完再动笔）

1. **改表达 vs 守恒**：必须换说法；专名/数字/官职/地名/年号/人数/胜负因果不许改。  
2. **禁止编造对白 ≠ 禁止改口气**：史料/Phase1 **已有**的言语，可改成口语现场感；**没有的话不要新编**。  
3. **幽默配额**：短文全篇约 1–5 处（规则一）。长文分章：每章宜有自然点破，但勿机械凑数、勿在开篇引入/驾崩伤亡/制度核心硬塞；**禁止整章零点破又零场面感**。  
4. **「」（硬门禁）**：史料原文 / **未译原话**用「」；白话对话用 “”。有名言/诏令/誓词/plan 经典候选 → 必须「」镶嵌；长卷成稿「」过少会**质检失败重试**。本章确实无金句 → 勿硬凑。用了「」后**优先融入接叙**；反对句句 `「」——同义白话` 作业体（偶发增量破折号可保留）。弯引装文言原文会质检失败。  
5. **他书《》（硬门禁）**：plan 有 `采用:true` / 索引「引入|异说」→ 正文必须出现对应《书·卷》；否则**质检失败重试**。  
6. **释义旁白（硬鼓励）**：生僻字词、古文词/古语、古官职制度、人名身份、地名今地、器物礼制、异名谐音、古怪/不合常理处 → 自然融入旁白（≤200字、事实白描、不强制出处）。**著名典故/成语**（斩蛇起义、约法三章、破釜沉舟、四面楚歌等）：情节写清后须点名对上号（先叙后点，宜短 ≤40 字）。**L0 禁旁白**：崩/薨/卒/立、是为/是谓、咸弗莫皆、诸侯天子天下、善诺等 → 直接顺译，禁止「崩就是去世」「是为就是这就是」。**禁止**滥用「说白了」等过场词。

## 职能① · 锚点补全

1. 仅落地 `外部补全` 中 `"采用": true` 与索引「引入|异说」；**禁止 plan 外新增硬史实**。  
2. 每条只写相对母本的增量（冲突/另说/背景/异评）；挂《书·卷》；**补完立刻回母本主线**，勿连续大段另起炉灶。  
3. **正文必须出现对应他书《》**（质检硬拦；不见则失败重试）。  
4. 禁止：无实质异文（纯用字/通假差异）、同情节雕花、换说法重复母本、母本同一卷、整卷复述。  
5. 异说多版本**分述**，禁止调和。  
6. 「去重不用」的索引项不写。  
7. 本传退场：Phase1 已有崩/薨/卒 → 勿再补；仅 plan 标明缺漏时篇末 **1 句**。  
8. 二手表述：无同句《书》时，「传说/据说/相传/有人说」等合计 ≤5。  
9. 引用优先 `允许引用白名单`。

## 职能② · 改表达

### 目标（硬）

说书人当面讲史——《明朝那些事儿》那种：**口语、场面、人物口气、释义旁白、偶尔点破反差**。  
不是「把文言换成通顺书面语」；通顺书面语仍算职能②失败。  
生僻字词/古语/古怪处按规则一加旁白（≤200字、事实白描、自然过渡、不强制出处）；著名典故/成语情节写完后须点名对上号；勿堆「说白了」。

质检会用程序比对你与 Phase1 的重合度：几乎誊抄母本 → **失败重试**。

### 失败形态（出现即本职能不合格）

- 大段「某年某月，命某官，遂某事」编年条，像大事记不是讲故事。  
- 人物说话全是书面翻译腔。  
- 读完本章想不起任何一句有味道的话。  
- 句子结构、用词与 Phase1 母本顺译高度雷同（换了几个虚词不算改表达）。

### 示范（同信息，换说法）

❌ Phase1 / 失败成品（书面直译）：  
> 高祖曾到咸阳服役，正赶上皇帝出巡，得以纵情观看。他望见秦始皇的威仪，不禁长叹一声。

✅ 说书改表达：  
> 刘邦去咸阳服徭役，赶上秦始皇出巡，那排场把他看呆了。一个乡下亭长仰头望着车驾，脱口叹道：「嗟乎，大丈夫当如此也！」

❌：  
> 汉二年，汉王东进，塞王司马欣、翟王董翳、河南王申阳皆降。

✅：  
> 汉二年，汉王一出关东进，关中那几位诸侯王心里就打鼓：塞王司马欣、翟王董翳、河南王申阳先后投降。偏韩王郑昌不肯，汉王便派韩信去收拾他。

❌：  
> 高祖以亭长身份为县里押送役徒去郦山，途中逃亡者甚众。

✅：  
> 他以亭长的身份押着役徒往郦山走，一路上人跑了不少——再走下去，只怕到地方就剩他自己了。

### 改表达时硬约束

- **信息点全保留**（可合并短句，不可整段蒸发）；已插入的《书·卷》句保留。  
- 专名/数字/官职/地名/年号/人数/胜负因果：只改说法。  
- 直角「」只装史料金句/原文；**未译加工的原话对白必须「」**（禁弯引“”装文言）；**已是白话禁止再塞进「」解释**；诗赋/誓词：**先概括主旨，再「」留文言**（禁整段白话译诗）。  
- 白话对话才用 “”；用「」后优先融入接叙；反对句句 `「…」——同义白话` / `“… ”——…` 作业体；偶发增量破折号可留，Phase1 同义对照残留宜改掉。  
- **要有释义旁白**：生僻字词/古语/官职制度/人名身份/地名今地/器物礼制/异名谐音/古怪处，自然融入；单处≤200字；事实白描；不强制出处。  
- **著名典故/成语**：情节写清后须点名对上号（先叙后点）；同一典故本篇已点破则后文不重复。  
- **L0 禁旁白**：崩/薨/卒/立、是为/是谓、咸弗莫皆、诸侯天子、善诺等直接顺译，勿拆词注释。  
- **禁止滥用**无意义过场词：「说白了」等。  
- 禁编造无据心理、无据对白、小剧场；禁译者导航（「我们来看看」等）。  
- 禁 Markdown `**加粗**`；「这家伙/这位爷」全篇 ≤3；AI 腔词见规则一频率表。  
- 长文分章：接住上章声口样例，禁止换成更干的公文腔；禁止复述上章（含换说法）；禁止下章短版预告。

### 前置引入（首章 · 硬）

独立成段 **100–250 字** → 空一行 → 再写开篇。  
**宏观人物名片**：是谁 / 为何重要 / 一生主线一句；直接入题。  
❌ 禁止：`今天要讲`、`诸位看官`、`本篇以…为主线`；❌ 勿把封王/立太子/出生异兆写进首段；  
❌ 勿先「登基那年新气象」再补身世。勿与起传粘段。

### 篇末收束（末章 · 硬）

母本身后事写完后，**另起一段** 80–220 字人物总结（历史位置 / 一生主线收科），再结束本章。  
勿写参考著作节（程序合并追加）。母本写完就停、没有收束 = 不合格。

## 结构与输出

- 无小标题/列表符号；纯叙事段落（规则六）。  
- 文末「参考著作」：分章/分批**本批勿写**（程序合并）；非分章则正文后空一行再写，≤10。  
- 只输出一个 JSON；`翻译详情` 为纯正文；禁嵌套 `{"史略ID":...}`；禁代码围栏。

```json
{
  "史略ID": "GLBL_xxxxx",
  "翻译详情": "……纯正文……"
}
```
