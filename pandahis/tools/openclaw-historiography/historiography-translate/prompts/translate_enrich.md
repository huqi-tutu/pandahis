# Step：补全成稿（Phase 2）

## 任务

在 Phase 1 **母本顺译稿** 基础上，穿插索引补充与外部补全，写出最终 `翻译详情` 并落盘 JSON。

## 规则

**只遵守**消息中已注入的规则节选（唯一 SSOT：`翻译规则.md`）。以下为 Phase2 特有硬约束：

## 纪律

1. **母本骨架不可重写**：保留 Phase 1 的句序、原词锚点与信息点；只允许在 plan 锚点处 **插入** 或 **轻量扩写**，禁止大段删改母本已译内容。
2. **外部补全准入**：只采用 `source_plan.外部补全` 中 `"采用": true` 的项；每项须：
   - 挂 `母本锚点`（某 M 编号前/后）；
   - 写明出处（《书名·卷篇》）；
   - 提供 **母本没有** 的信息：异说、冲突观点、背景、细节、评价差异；
   - **禁止** 把母本已述事实换说法再写一遍。
3. **索引补充**：按 `索引补充处理` 中「引入|异说」项融入；「去重不用」的不得写入。
4. **异说独立**：多版本须分述，禁止调和为一个版本。
5. 文末必须有「参考著作」节（母本 + 实际引用的他书），格式：

```
参考著作：
1. 《书名·卷篇》
```

（勿用 `*` 包裹标题。）
6. **模糊出处**：禁止**同句无《书名》**使用「据说」「相传」「传说」「有人说」「有资料说」等；他书信息须写「《书名·卷》载：…」。同句已有《》时可转述（如「《史记》载，相传……」）。地理传说要么删除，要么挂出处。
7. **引用白名单**：仅可使用 `source_plan.允许引用白名单` 中的著作；不得自行添加 plan 未列书目。
8. **禁止元叙述**：不得写「本条 N 段…已读完」等喊数/进度汇报。

9. **禁止编造心理活动**：不得写「心想」「暗想」「内心挣扎」等虚构心理；一切须有原文或他书出处依据。

10. **前置引入**（建议 100–400 字，**硬上限 400 字**，超长将质检驳回并重试）：
   概括、精炼的**阅读框架** + 末句**一句过渡**进母本；不写正文将展开的事件细节。
   写法按 `前置引入档位`：薄母本→一句过渡；中母本→短而准；厚母本→100–400字框架。
   末句须自然过渡到正文（如「《史记·夏本纪》这样记载——」）；**禁止**「原文如下」「附原文」等暗示未译文言的表述。

11. **归因纪律**：正文前部**不得**展开非本传主的退场/葬地（如颛顼篇不写黄帝崩）；本传主母本缺漏的退场句，在**正文尾部**补入（见 `本传缺漏补全`）。

12. **防幻觉（事实边界）**：
   - **三层材料**：① Phase1 母本顺译（主线）② plan 中 `"采用": true` 的外部补全/索引补充（须挂 M 锚点 + 《书名·卷篇》）③ 六类触发的一句式解释（制度/地名等，不扩写流程）。
   - **禁止第四层**：plan 未列、出处写不出、或 `"采用": false` 的内容 — **不得**凭模型常识写入（含对话、礼制步骤、战役战术、年号、亲属关系）。
   - **留白**：母本与已采用他书均未载 → 写「母本未载…」或省略，**禁止**无《》锚点的「据说/相传/有资料说」填坑。
   - **跨时代**：他书补全不得引入与母本时代不符的同名制度/事件细节（如本传为上古，不得拼入汉魏/清末同名典故的流程）。
   - **异说**：多版本分块并陈，挂锚点后立即回母本；禁止调和为一个版本。

## 他书引用格式

每条外部补全必须包含：
- 出处句：「《书名·卷》载：…」
- 关系说明：「此（与母本不同/为母本所无）…」
- 禁止：「据《某书》」而不给卷数
- 禁止：在母本已述事实后接「《某书》也记载…」（纯重复）

## 六类自动触发（在正文中执行）

| 触发条件 | 处理方式 |
|----------|---------|
| 古地名首次出现 | 标注「（今××）」；括注内禁止拼音 |
| 难读字 / 生僻字 | **禁止**正文注音；读者通过字典查读音 |
| 制度/官职术语首次出现 | 简要一句话解释，不打断叙事 |
| 通假字 | 保留原文「×（通×）」 |
| 数字/序号 | 保留原样，不强制转换 |
| 明显有出处的议论 | 挂「《书名》评曰：…」 |

## 输入

- Phase 1 `母本顺译` 全文
- `source_plan`（外部补全、索引补充、参考著作）
- `recalled`（核对锚点）

## 输出

```json
{ "史略ID": "…", "翻译详情": "…\n\n参考著作：\n1. 《书名》\n2. …" }
```

**仅写 `史略ID` 与 `翻译详情`。** `史料原文` 由编排器写入。

完成后回复 `TRANSLATE_DONE` + 史略ID + 约字数。
