# Step：长文史料计划（仅跨书决策）

> **默认已切换**：`TRANSLATE_EXTERNAL_MACRO=1` 时走「宏观选题 → 判重 → 挂锚」两步法  
> （见 `source_plan_external_macro.md` / `source_plan_external_anchor.md`）。  
> 本文件仅在 `TRANSLATE_EXTERNAL_MACRO=0` 回退旧整包 plan 时使用。

## 任务

本条是**长文**。母本逐句清单已由编排器生成，**禁止**输出整表。

你只输出一个决策 JSON，写入消息头指定的 `.plan.json`。

## 核心产出（必须）

1. **`外部补全`**（本阶段主责 · 读者价值优先）  
   - 问自己：这条补全让读者**多懂了什么**？若只是把母本已有故事写得更细、更热闹 → **采用:false**。  
   - **当用三类（硬优先，采用:true 几乎只允许这些）**：  
     1. **异说 / 冲突记载** — 他书与母本对同一事的说法**实质不同**（因果、结果、人物角色、制度结论有分歧）  
     2. **背景** — 母本未交代或一句带过的时势、制度前提、人物关系、政局语境  
     3. **评价差异** — 史家臧否/论赞/后世史评与母本立场不同  
   - **默认 false / 禁止当 true**：  
     - 场面雕花（鸿门、斩蛇、约法三章等母本已有完整情节，他书只加对话/动作）  
     - 无实质异文（蛟龙↔交龙、称谓/通假异写而史实相同）  
     - 把《史记》《汉书》同一故事换出处再讲一遍  
   - **检索须发散**：按通道（同书非本传 / 近时杂史辑佚 / 外传故事 / 近古议论批判 / 类书引佚）选题，勿锁死平行纪对读；以冲突/另说/背景/异评为准入。须可标《书·卷》。  
   - **禁止**更简平行纪冒充补充；**禁止**现代评述。  
   - **补充范围**：对照**全书母本**（全部 M 信息点，不是只看锚点附近）。禁止补母本后文已有的同事件同结果；禁止前锚剧透后文。  
   - **禁止**母本同一卷；**禁止空数组 `[]`**。先列候选再标采用。  
   - 消息头若要求不少于 N 条 `采用:true`，须用**当用三类**凑满，禁止用雕花凑数。

2. **`索引补充处理`**  
   - 只裁决 recalled 里已有的 role=补充块：`引入` / `异说` / `去重不用`。  
   - 平行正史勿一律去重；叙事接近时标「异说」，**只筛有实质分歧的点**（仅异字/同情节 → 去重不用）。

3. **`参考著作`**（硬上限 ≤10，只交最重要）、**`写作结构`**、**`风险提示`**

## 外部补全示例（形态参考 · 有知识增量）

```json
{
  "采用": true,
  "补全类型": "评价差异",
  "主题": "班固赞对高祖开国规模的总评",
  "出处": "《汉书·高帝纪赞》",
  "母本锚点": "M460 后",
  "与母本关系": "母本太史公曰侧重……；班固赞另有「规摹弘远」等评价立场，非同义换字",
  "理由": "评价差异，读者可得第二史家视角"
}
```

反例（须 `采用:false`）：「汉书作交龙、史记作蛟龙」——史实相同，仅用字差，无阅读价值。

## 输出 JSON（仅这些字段）

```json
{
  "史略ID": "...",
  "史略名称": "...",
  "母本著作": "...",
  "外部补全": [ /* 非空；采用:true 须属当用三类 */ ],
  "索引补充处理": [ /* 对召回补充块逐条裁决 */ ],
  "写作结构": [{ "小节": "本传", "说明": "..." }],
  "参考著作": ["《…》", "《…》"],
  "风险提示": ["..."]
}
```

## 硬纪律

- **禁止**输出 `母本逐句清单`（整表会被丢掉；编排器已有清单）。  
- `采用:true` 须：补全类型合法 + 《书·卷》+「与母本关系」写清**冲突/另说/背景/异评**（勿写「补充场面更细」）。  
- 禁止出处写成 `GLBL_xxxxx` / `·过渡段` /「原文翻译」。  
- 禁止母本同一卷；禁止与全书母本重复的补全（含「前锚后文已有」）；禁止无实质异文与雕花。  
- **`参考著作` 硬上限 ≤10**：只返回最重要的；超限门禁拒收。  
- 写完确认 JSON 可解析，再回复 `SOURCE_PLAN_DONE`。
