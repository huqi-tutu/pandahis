# Step：母本顺译（Phase 1）

## 任务

撰写 **仅含母本顺译** 的 JSON，落盘到消息头指定路径。

**本阶段禁止**：引用母本以外任何著作（不得出现《国语》《山海经》等书名）；不得写 `*参考著作*` 节。

## 规则

**只遵守**消息中已注入的规则节选（来自 `historiography-compose/references/翻译规则.md`）。动笔前按【第四层】验收标准自检。

## 口语与轻度幽默（Phase1 文风主战场）

母本顺译决定全文口气——**不要写成论文摘要或百科条目**，也**不要满篇段子**。

1. **默认口气**：像给朋友讲《史记》里的故事；短句、自然转折（——）、偶尔反问。
2. **轻度幽默**：全篇 **1–3 处**（母本较短时 1–2 处）即可；来自史实反差/荒诞/巧合，白描一句，不硬塞笑话。
3. **分布**：落在中段叙事里；开篇第一句、崩薨退场、盖棺定论处保持庄重。
4. **禁止油腻口语**：「这位爷」「二话不说就冲」「全成了他的小弟」「威慑力拉满」等网络玩梗。
5. **与顺译并存**：口语化是**表达层**重写，不能跳句、漏信息、改事实。

**对照：**
- ✅ 「轩辕没有坐等。他『习用干戈，以征不享』——练兵备战，谁不来朝贡就打谁。这招很管用。」
- ❌ 「轩辕采取了军事手段进行征讨，这使得诸侯纷纷归附。」（太论文）
- ❌ 「这位爷一看形势不对，二话不说就抄家伙干仗。」（太油腻）

## 段落节奏（Phase1 主战场）

顺译的**分段**决定全文呼吸感——Phase2 会保留你的分段，勿写成百科长条。

1. **偏分不碎**：按 M 句群与场景切换分段；读者能感到「一块母本一块白话」的节奏。
2. **必须分段**：`parallel_cluster` / `appraisal` / `genealogy` 整句「」引用后，白话解释**另起段**（或段内明显停顿）。
3. **场景切换必分**：如乱世背景 → 练兵征伐 → 阪泉 → 涿鹿 → 巡狩 → 官制历法 → 家族退场。
4. **巨段红线**：单段超过约 **120–150 字**且已含两个以上独立事件 → **拆段**。
5. **勿过度合并**：同场景 2–3 句短叙事可一段；勿把东征西狩 + 官制 + 历法 + 土德称号揉成**单一巨段**。
6. **勿刷屏**：不要每句 narrative 都单独成段（满屏一两句像聊天）。

## 顺译范式（必须）

1. **句序**：严格按 `source_plan.母本逐句清单` 的 M001→M… 顺序推进，不得跳号、不得把多条 M 揉进一段后跳过中间编号。
2. **引用粒度**（见每条 M 的 `引用粒度` / `母本提示`）：
   - `narrative` 叙事句：专名、数字、制度词融入白话叙述，自然写进正文。
   - `parallel_cluster` 并列句群：先整簇或整句引用原文，再作一段白话解释。
   - `genealogy` 世系句：整句引用后串讲谱系。
   - `appraisal` 品评句：对称句群整段引用后作一段品评。
3. **必现词**：plan 中的 `必现词` 是覆盖校验锚点，须在白话正文中自然出现即可；「」留给完整史料摘句、人物对话、并列句群。
   - 示例：公子光开始暗中招揽贤士，准备找机会除掉吴王僚。
4. **禁释词（L0）**：崩/薨/卒/立/咸/弗/莫不/诸侯/天子/寡人/朕/谥号/庙号等通识文言直接顺译（如「去世」「都来归附」），不写「X就是Y」式注释。
5. **引用档位**：`narrative` 句以白话顺译为主；`parallel_cluster` / `appraisal` / `genealogy` 句以整句或句群引用为主。
6. **内嵌注释**：可在顺译中穿插无出处的常识性解释（如制度、地名今址），但不得写成他书引述。
7. **《史记》 framing**：可用「《史记》原文说…」「按《史记》的写法…」，不得伪造他书。
8. **退场句**：母本若含本传主崩/薨/卒/自沈等，在本阶段**自然顺译**即可；Phase2 **不得**再补同义退场（见规则二「本传主退场完整性」）。
9. **交接段（双挂/更替句）**：按本传主镜头写——开篇若是「前君卒 + 本君立」，前君侧只作一两句过渡，**不要**展开别人的故事；收尾若是「本君卒 + 后君立」，详写本君退场，后君「立」点到为止（见规则二「交接双挂段 · 角色不对称」）。

## 虚词陷阱（常见硬译错误）

| 文言 | 错误直译 | 正确顺译 |
|------|----------|---------|
| 以（表示原因） | 用/凭借 | 因为/由于 |
| 以（表示方式） | 用 | 通过…方式/以… |
| 所以 | 所以（因果） | …的方法/…的原因 |
| 于是 | 于是（然后） | 在这种情况下/于是 |
| 乃 | 才 | 于是/就/才 |
| 因 | 因为 | 于是/趁机/因袭 |
| 故 | 故意 | 所以/旧/缘故 |
| 是 | 是（判断词） | 这/这个/因此 |

## 输入

- `recalled`：母本段落原文
- `source_plan`：母本逐句清单（信息点、必现词、母本提示）

## 输出

```json
{ "史略ID": "…", "母本顺译": "…" }
```

**仅写上述两字段。** 不要写 `翻译详情`、`史料原文`、`参考著作`。

完成后回复 `MOTHER_DRAFT_DONE` + 史略ID + 约字数。
