# Step：母本顺译（Phase 1）

## 任务

撰写 **仅含母本顺译** 的 JSON，落盘到消息头指定路径。

**本阶段禁止**：引用母本以外任何著作（不得出现《国语》《山海经》等书名）；不得写 `*参考著作*` 节。

## 规则

**只遵守**消息中已注入的规则节选（来自 `historiography-compose/references/翻译规则.md`）。动笔前按【第四层】验收标准自检。

## 顺译范式（必须）

1. **句序**：严格按 `source_plan.母本逐句清单` 的 M001→M… 顺序推进，不得跳号、不得把多条 M 揉进一段后跳过中间编号。
2. **引用粒度**（见每条 M 的 `引用粒度` / `母本提示`）：
   - `narrative` 叙事句：专名/数字/制度词用「」锚点，普通动词融入白话，**禁止逐词引号**。
   - `parallel_cluster` 并列句群：先**整簇或整句**引用原文，再统一白话解释；**禁止**「修德」「振兵」「治五气」各引各释。
   - `genealogy` 世系句：整句引用后串讲，禁止拆到四字一段。
   - `appraisal` 品评句：对称句群整段引用后作一段品评。
3. **禁释词（L0）**：崩/薨/卒/立/咸/弗/莫不/诸侯/天子等通识文言直接顺译（如「去世」「都来归附」），**禁止**「「崩」就是去世」式注释。
4. **dense 句**：仅当 `引用粒度` 未标 `parallel_cluster` 时，方适用一词一释；并列排比一律句群处理。
5. **内嵌注释**：可在顺译中穿插无出处的常识性解释（如制度、地名今址），但不得写成他书引述；**禁止**解释 L0 通识字。
6. **《史记》 framing**：可用「《史记》原文说…」「按《史记》的写法…」，不得伪造他书。

## 输入

- `recalled`：母本段落原文
- `source_plan`：母本逐句清单（信息点、必现词、母本提示）

## 输出

```json
{ "史略ID": "…", "母本顺译": "…" }
```

**仅写上述两字段。** 不要写 `翻译详情`、`史料原文`、`参考著作`。

完成后回复 `MOTHER_DRAFT_DONE` + 史略ID + 约字数。
