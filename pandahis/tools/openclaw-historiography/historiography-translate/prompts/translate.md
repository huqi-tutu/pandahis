# Step：全局史略翻译（Legacy 单阶段）

> **编排器默认已改为两阶段**：Phase1 `translate_mother.md` → Phase2 `translate_enrich.md`。  
> 仅当 `TRANSLATE_TWO_PHASE=0` 时使用本 prompt。

## 任务

撰写 `翻译详情` 并落盘 JSON（路径见消息头）。

## 规则

**只遵守**消息中已注入的规则节选（来自 `historiography-compose/references/翻译规则.md`）。

## 输入

母本与索引补充来自 `recalled.blocks[].paragraphs[].text`；禁止自行切 `.txt`。外部补全只按已注入规则使用，必须标明具体著作与卷/篇名。

消息中还会附上 `source_plan` JSON。正文必须按这个计划写：

- **母本逐句清单**：清单中每一编号（M001…）的「信息点」必须在正文中体现，**严格按编号顺序**推进，不得跳号、不得合并、不得写清单外母本句
- **一句一编号**：plan 中每条 M 对应母本一个分句；正文须按 M001→M029 顺序逐条展开，**每条至少一个自然段或句群**，不得把多条 M 揉进一段后跳过中间编号
- **信息点不得省略**：plan 中「信息点」列出的数字、专名、制度、动作、结果须全部写入正文；允许白话改写，禁止跳过（如「不享/平者去之/降居/与为多焉」等须传达原意）
- 索引补充按计划锚点融入；**不得用外部补全替代母本句**
- 外部补全只采用 `source_plan.外部补全` 中 `"采用": true` 且有出处的项目；每条须挂母本锚点，补完立即回到母本主线
- 禁止译者元叙述（「注意，司马迁…」「这里需要补一句…」）
- **太史公曰 / 论赞**：按翻译规则「太史公曰 / 司马迁评述」节——直引顺译，用「司马迁在《史记》中写到…」等第三人称史家 framing，**禁止**「司马迁说」及把司马迁写成历史参与者
- 已顺译为今字的通假字不再标注（禁止 `擒（通『擒』）`）
- 发现计划与 recalled 冲突时，以 recalled 原文为准，并在回复中说明

## 输出

```json
{ "史略ID": "…", "翻译详情": "…\n\n*参考著作：*\n1. …" }
```

**仅写 `史略ID` 与 `翻译详情` 两字段。** `史料原文` 由编排器在落盘后自动从 `recalled` 写入，勿自行添加或改写。

完成后回复 `TRANSLATE_DONE` + 史略ID + 约字数。
