# Step：史料计划（source plan）

## 任务

读取 `recalled` JSON，为这一条史略生成史料计划，并写入消息头指定的 `.plan.json`。

## 目标

先分析，不写正文。计划必须帮助 **Phase1 母本顺译** 与 **Phase2 补全成稿** 分工：

- **母本逐句清单**：长文由编排器按母本分句**程序生成**；你可省略整表。短文若手写，须 100% 覆盖、句序不乱、含 `必现词` 锚点
- **外部补全**（跨书选题 · plan 主责）：只补有**读者知识增量**的内容；先列候选再标 `采用`
  - **当用三类（硬优先）**：① 异说/冲突记载（说法实质不同）② 背景（时势/制度/关系母本略）③ 评价差异（史家臧否不同）  
  - **默认 false**：场面雕花；仅用字/通假异文（蛟龙↔交龙）；《史记》《汉书》同情节换出处再讲一遍  
  - **补充范围限定（硬）**：对照**全书母本**（整份 M / 全卷，不是只看锚点附近）  
    - ✅ 记载冲突须分述；母本未交代的必要背景；他书另有评价立场  
    - ❌ 母本后文已有的同事件同结果（含前锚剧透）；❌ 同情节细描「雕花」；❌ 无实质分歧的异文  
  - 候选须按**检索通道**发散（同书非本传 / 近时杂史辑佚 / 外传故事 / 近古议论批判 / 类书引佚），勿锁死平行纪对读；以冲突/另说/背景/异评为准入  
  - **禁止**母本同一卷；**禁止**空数组；**禁止**用索引书目顶替跨书选题；**禁止**更简平行纪冒充补充  
  - `与母本关系` 须写清属哪一类增量（冲突/另说/背景/异评）及相对哪段母本；若只是雕花或异字 → `采用:false`
- **索引补充处理**：只裁决 recalled 里已有的 role=补充块（「引入|异说|去重不用」）——与外部补全分工，**不是**外部补全书单来源  
  - 平行正史勿一律「去重不用」；叙事接近时标「异说」**只筛实质分歧**（仅异字/同情节 → 去重不用）
- **经典引用**：编排器会为部分 M 标注 `经典引用候选`；plan 勿删该字段。写作时默认白话，仅候选句镶嵌史料「」原文
## 必现词提取规范

> **落盘时由编排器程序化重算**（`extract_must_phrases`），LLM 可不填或填写后被覆盖。  
> **L0 禁释词**（崩/薨/卒/立/是为/是谓/莫不从服/诸侯/天子等，见 `gloss_rules.L0_GLOSS_WORDS`）**不得**作为必现词，也**不得**在成稿里旁白拆词解释。

| 锚点类型 | 示例 | 强制要求 |
|----------|------|---------|
| 数字 | 九年、三日 | 必须提取 |
| 「氏」结尾專名 | 少典氏、陈锋氏 | 必须提取（**≤5 字**） |
| 1–3 字专名/称号 | 放勋、涿鹿、景公 | 优先提取 |
| 引号内原文 | 「习用干戈」 | ≤3 字；更长则拆核心词 |

- 每条最多 **4 个**必现词（`MAX_MUST_PHRASES`）；**默认每项 1–3 字**（氏名 ≤5）
- **禁止** 4 字及以上整段分句块作为必现词（易误拦白话意译；句意写入 `信息点`）
- 来源：仅从 `原文摘句` 按规则提取，不得凭空编造
- 禁止：L0 禁释词、虚词碎片、从词中间截断的 n-gram

## 输出 JSON

顶层字段固定如下：

```json
{
  "史略ID": "...",
  "史略名称": "...",
  "母本著作": "...",
  "母本逐句清单": [
    {
      "编号": "M001",
      "段落": "01史记 卷008 P1",
      "原文摘句": "...",
      "信息点": "...",
      "必现词": ["..."],
      "引用粒度": "narrative|parallel_cluster|genealogy|appraisal",
      "经典引用候选": false,
      "母本提示": "仅母本顺译写法提示，不含他书",
      "补全提示": "可选；仅说明 enrich 阶段可补什么"
    }
  ],
  "索引补充处理": [ ... ],
  "外部补全": [
    {
      "采用": false,
      "补全类型": "异说|冲突观点|背景|评价差异|必要上下文|补充细节",
      "主题": "...",
      "出处": "《资治通鉴·汉纪…》或《汉书·…赞》等（勿只盯史记/汉书本纪）",
      "母本锚点": "M010 前",
      "与母本关系": "属冲突/另说/背景/异评：相对母本…他书…",
      "理由": "读者知识增量：…"
    }
  ],
  "写作结构": [ ... ],
  "参考著作": [ "《…》" ],
  "风险提示": [ "..." ]
}
```

> `补充细节` 仅当细节本身构成**另说/改变理解**时可用；同情节雕花 → false。


> 注意：`前置引入素材` 字段由编排器在 plan 落盘时自动注入（基于索引结构化数据），
> LLM 不需要生成此字段。

## 纪律

- **短文**：母本逐句清单须与 recalled 句号分句一一对应；每条一个分句；条数 ≥95%
- **长文**：勿输出整份母本清单；编排器合并决策字段到程序清单。消息头「决策 JSON」模式优先
- 每条 `信息点` 须列全该句实质信息；`必现词` 可留空，**落盘时程序自动生成**
- `写作提示` 若含外部补全，须拆到 `补全提示`；`母本提示` 不得要求他书
- 外部 `"采用": true` 时 **必须** 填：
  - `补全类型` ∈ `异说|冲突观点|背景|评价差异|必要上下文`（`补充细节` 仅限另说性细节）
  - `与母本关系`：写清属冲突/另说/背景/异评哪一类及相对哪段母本；勿只写「与母本相同 / 补充场面更细 / 异字」；与后文 M 重合 → false
  - `出处`：可核验 `《书·卷》`；禁止占位书名；禁止母本同一卷；宜开拓编年/政书/志传，勿只堆史记+汉书同情节
- `参考著作`、`写作结构` 为硬必填（长文决策 JSON 也须有）
- **`参考著作` 硬上限 ≤10**：只返回最重要的书目；超限门禁拒收并重试
- 不确定出处 → `"采用": false`（仍保留候选项）
- **长文**：不少于 N 条采用:true，且须属当用三类；禁止空数组、禁止雕花凑数
- 写完确认 JSON 可解析，再回复 `SOURCE_PLAN_DONE`
