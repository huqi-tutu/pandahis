# Step：史料计划（source plan）

## 任务

读取 `recalled` JSON，为这一条史略生成史料计划，并写入消息头指定的 `.plan.json`。

## 目标

先分析，不写正文。计划必须帮助 **Phase1 母本顺译** 与 **Phase2 补全成稿** 分工：

- **母本逐句清单**：100% 信息覆盖、句序不乱；每条含 `必现词`（母本原词锚点）
- **外部补全**：默认 `"采用": false`；**仅当**相对母本有 **异说 / 冲突观点 / 必要背景 / 母本未载细节 / 评价差异** 时标 `true`
- **禁止**计划与母本完全相同的「外部补全」

## 必现词提取规范

> **落盘时由编排器程序化重算**（`extract_must_phrases`），LLM 可不填或填写后被覆盖。  
> **L0 禁释词**（崩/薨/卒/立/莫不从服/诸侯/天子等，见 `gloss_rules.L0_GLOSS_WORDS`）**不得**作为必现词。

| 锚点类型 | 示例 | 强制要求 |
|----------|------|---------|
| 数字 | 九年、三日 | 必须提取 |
| 「氏」结尾專名 | 少典氏、陈锋氏 | 必须提取（**≤5 字**） |
| 1–3 字专名/称号 | 放勋、涿鹿、景公 | 优先提取 |
| 引号内原文 | 「习用干戈」 | ≤3 字；更长则拆核心词 |

- 每条最多 **4 个**必现词（`MAX_MUST_PHRASES`）；**默认每项 1–3 字**（氏名 ≤5）
- **禁止** 4 字及以上整段分句块作为必现词（易误拦白话意译；句意写入 `信息点`）
- 来源：仅从 `原文摘句` 按规则提取，不得凭空编造
- 禁止：L0 禁释词、虚词碎片、从词中间截断的 n-gram

## 输出 JSON

顶层字段固定如下：

```json
{
  "史略ID": "...",
  "史略名称": "...",
  "母本著作": "...",
  "母本逐句清单": [
    {
      "编号": "M001",
      "段落": "01史记 卷008 P1",
      "原文摘句": "...",
      "信息点": "...",
      "必现词": ["..."],
      "母本提示": "仅母本顺译写法提示，不含他书",
      "补全提示": "可选；仅说明 enrich 阶段可补什么"
    }
  ],
  "索引补充处理": [ ... ],
  "外部补全": [
    {
      "采用": false,
      "补全类型": "异说|冲突观点|补充细节|背景|评价差异|必要上下文",
      "主题": "...",
      "出处": "《史记·项羽本纪》",
      "母本锚点": "M010 前",
      "与母本关系": "母本未载…；他书补充…",
      "理由": "..."
    }
  ],
  "写作结构": [ ... ],
  "参考著作": [ "《史记·…》" ],
  "风险提示": [ "..." ]
}
```


> 注意：`前置引入素材` 字段由编排器在 plan 落盘时自动注入（基于索引结构化数据），
> LLM 不需要生成此字段。

## 纪律

- **母本逐句清单**须与 recalled 母本 block 的句号分句 **一一对应**
- 每条 `原文摘句` 只能含 **一个** 句号级分句
- 清单条数须 ≥ 母本分句数的 **95%**
- 每条 `信息点` 须列全该句实质信息；`必现词` 可留空，**落盘时程序自动生成**（专名、数字、制度词；排除 L0 禁释词）
- `写作提示` 若含外部补全，须拆到 `补全提示`；`母本提示` 不得要求他书
- 外部 `"采用": true` 时 **必须** 填 `补全类型` 与 `与母本关系`（说明相对母本的新增信息，非重复）
- 不确定出处 → `"采用": false`
- 写完确认 JSON 可解析，再回复 `SOURCE_PLAN_DONE`
