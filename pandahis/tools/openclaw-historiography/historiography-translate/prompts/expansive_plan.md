# Step：发散式史料计划（方案 A · 程序 M 清单 + LLM 补全规划）

## 任务

`母本逐句清单` **已由编排器程序生成**，你**不得修改** M 编号、原文摘句、必现词。

你的任务：在读懂 `recalled` 与现有 M 清单后，**尽量发散**地规划成稿时要融入的内容——不限于 recalled 已召回的 block，可结合通晓的正史、注释、史论提出候选。

## 须规划的内容（尽量列全，默认多数为 采用:false）

1. **索引补充**（`role=补充`）：异说、评价差异、母本未载故事/视角；与母本去重说明。
2. **外部补全**（发散）：必要背景、人物小传、制度/官职、地理今址、他书异说、母本未载但有卷篇可查的细节、学界常引的延伸。
3. **通假/地名/六类触发**：挂对应 M 锚点，`补全类型` 用下方枚举（地名/通假 → `补充细节`；人物首现 → `背景`）。
4. **参考著作**：母本 + 预计将引用的他书（仅列书名卷篇形态）。

## 原则

- **发散在 plan，严谨在正文**：plan 可大胆列候选；`采用:true` 仅给**能写出《书名·卷篇》**且相对母本**非重复**的项。
- 写不出卷篇 → `采用:false`（仍可保留在 plan 作备忘）。
- 异说/冲突观点须单独列项；禁止「调和成一个版本」。
- 每项 `采用:true` 须有：`母本锚点`（如 M012 后）、`出处`、`补全类型`、`与母本关系`。
- **`补全类型` 枚举（只能用其一）**：`异说` | `冲突观点` | `必要上下文` | `背景` | `补充细节` | `评价差异`
- **禁止**计划与母本完全相同的「外部补全」。

## 输出

**更新** plan JSON，**保留**程序字段 `母本逐句清单`，**重写/新增**：

```json
{
  "外部补全": [ … ],
  "索引补充处理": [ … ],
  "参考著作": [ … ],
  "写作结构": [ … ],
  "风险提示": [ … ]
}
```

不要写 `翻译详情` 正文。完成后回复 `SOURCE_PLAN_DONE`。
