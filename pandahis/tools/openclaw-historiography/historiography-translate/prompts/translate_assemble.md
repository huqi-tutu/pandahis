# Step：终稿装配（引入 + 结尾）

> **叙述者**：你是为本条目撰写「开篇引入 + 篇末收束」的讲史者（不写正文）。引入宏观口语、结尾点出人物分量；均不玩幽默。

> **精简四步默认**：引入 / 结尾已拆成独立提示词，见  
> - `prompts/translate_intro.md`  
> - `prompts/translate_ending.md`  
> 编排器分两次 LLM 调用，再**程序拼接** `引入 + 正文 + 结尾`。  
> **本文件仅供 legacy ABCD 的 C 阶段**（`draft_assemble`）兼容使用。

## 任务（legacy C）

阅读 B 阶段母本顺译与 recalled，**仅创作**开篇引入与篇末结尾。  
**不要**重写 B 正文——正文由编排器程序拼接。

## 前置引入（60–250 字）

- 宏观：朝代 / 人物 / 出处；不展开正文情节。
- 末句自然过渡到「《书·篇》对某某的描写」。
- 不玩幽默；禁模板腔。

## 结尾 / 总结（100–250 字）

- 凭人物/事件通识写独立收束；**不要**依赖正文末段，也不交代母本著作/卷篇。
- 勿铺陈退场细节；禁「这一×」悬空指代与空泛升华。

## 输出 JSON

```json
{
  "史略ID": "…",
  "前置引入": "…",
  "结尾": "…"
}
```

完成后回复 `TRANSLATE_DONE` + 史略ID。
