# Step：分块史料计划（source plan chunk）

## 任务

本消息只覆盖**一个分块**（见 `recalled._chunk`）。读取该分块 `recalled` JSON，写入消息头指定的 `.chunk-XX.plan.json`。

## 分块纪律

- `母本逐句清单` 编号从 `sentence_id_start` 起，格式 `M001`、`M002`…（三位数字，与消息头一致）
- 只分析本分块母本与落入本分块的索引补充；不要规划其他分块内容
- 索引补充：主体/事件/结果一致则「去重不用」
- 外部补全：仅本分块必要上下文；挂母本锚点；有出处

## 输出 JSON

字段与完整 `source_plan` 相同（`史略ID`、`史略名称`、`母本著作`、`母本逐句清单`、`索引补充处理`、`外部补全`、`写作结构`、`参考著作`、`风险提示`）。

## 完成

JSON 可解析后回复 `CHUNK_PLAN_DONE` + 分块序号。
