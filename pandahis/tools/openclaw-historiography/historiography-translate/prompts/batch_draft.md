# Step：分批成稿（顺译 + 成稿时他书补充 · 一次完成）

> 叙述者定位见上方规则包 **「叙述者」** 段（编排器自动注入）。

## 任务

**严格按本批 plan「母本逐句清单」（M 编号 + 原文摘句）顺译**；写法见同块内 **「引用粒度说明」**（按句型分组，勿逐条重复）。顺译的同时，须以 **历史研究者** 的钻研精神 **主动检索、写入** 他书可核实材料（见 P2「跨著作补充」专节，含异说分述）。

**一次 call 完成**：
1. 本批母本 **顺译**（按 M 顺序、信息 100%、口语叙事；《明朝那些事儿》笔调；母本原文以 M 清单为准，勿超前翻译后续 M）；**名句/金句/关键评价**须「」摘录原文再白话（见 P2「何时引/何时不引」，非每句都引）
2. **跨著作补充**（与顺译同步）：通过 **母本去重门禁** 后，在对应母本句后插入 1–3 句他书材料，须 **《书名·卷篇》**；补完立即回母本主线（见 P2「跨著作补充」= 外部补全与多源融入的执行入口）

## 补充纪律（成稿时执行）

- **母本去重（写前必问）**：拟补内容在 **当前母本著作、当前卷** 原文中是否已有？已有且够清楚 → **不补**；未载或仅一笔带过 → 可从他书补
- **研究姿态**：母本只是主线；**主动**从同条目相关卷篇及确知出处的正史中找补，不要只译母本一句不改
- **何时可补**：通过去重门禁后的背景｜异说/冲突观点｜母本未载但理解必需的细节｜人物首现与关系｜有出处的传说/故事｜史家评价差异
- **怎么补**：挂母本句后，短句切入；异说须母本先述再分述他书；禁止另起百科大段、禁止「此外《某书》还记载…」
- **出处**：每条他书补充须有 **《书名·卷篇》**；写不出卷篇则不写该硬史实
- **禁止**：母本已有详述的重复叙述；无《》的「据说/相传/有人言」

## 禁止

- 前置引入、篇末总结/结尾、参考著作列表
- 删 M 信息点；翻译本批 M 清单以外的母本句
- AI 腔词堆砌；论文体；百科条目感

## 批间衔接（多批时必读）

若 prompt 含 **批次定位 / 母本前情 / 上批末段白话**：

- **第 1 批**：从本批首句顺译，不写全书引入；批末留自然口气给下批。
- **第 2 批起**：第一句须像上批同一段叙述的延续；勿复述母本前情或上批白话；人称、年号与上批一致。
- 母本前情摘句仅作**事实锚点**，勿把摘句再完整译一遍。

## 段落

- 按场景分段；单段约 120–150 字；引用句群后白话另起段
- 批末可与下批自然衔接，但不要写「下文」「接下来」

## 引号

- 引用母本/史料原文 → 直角引号「」；白话改写、术语 → 弯引号“”；书名 → 《》。
- 落盘时程序会对照母本自动校正引号开闭符，模型不必纠结引号形态细节。
- **引用母本原文时写母本卷全名**（如《史记·孝武本纪》），勿泛称《史记》；参考著作由程序拼接，裸母书名不会入列。

## 禁止再写

- 参考著作列表（成稿由程序按「母本卷 + 正文《》」拼接，并去重裸母书名）

## 输出 JSON

```json
{
  "史略ID": "…",
  "母本顺译": "本批正文（纯 Markdown 段落，\\n\\n 分段）"
}
```

也可使用字段 `翻译详情`，二者等价。**不要** markdown 代码块包裹 JSON。

完成后回复 `TRANSLATE_DONE` + 史略ID。
