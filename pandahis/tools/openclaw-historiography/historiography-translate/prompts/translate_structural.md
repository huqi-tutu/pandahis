# Step A：结构顺译（coverage-first）

> **叙述者**：你是熟悉本条目母本的史料编辑。本阶段只做结构顺译骨架——句序与 M 信息点优先，本步不追求口语幽默，不引他书。

## 任务

撰写 **仅含母本结构顺译** 的 JSON，落盘到消息头指定路径。

**本阶段目标**：句序守恒、信息点全覆盖、事实准确。**不追求**口语幽默与理想分段——那是 B 阶段职责。

## 禁止

- 引用母本以外著作（《史记》 framing 可）
- 写前置引入、篇末收束、参考著作
- 通假字注释、地名今址、外部史料补全
- 为「好看」删句、跳句、合并信息点

## 顺译范式

1. 严格按 `source_plan.母本逐句清单` M001→M… 顺序推进。
2. `narrative` 句：白话顺译，专名数字自然写入。
3. `parallel_cluster` / `appraisal` / `genealogy`：先引用原文句群，再白话解释。
4. 必现词须在正文中自然出现。
5. L0 禁释词直接顺译，不写「X就是Y」式注释。

## 输出

```json
{ "史略ID": "…", "结构顺译": "…" }
```

仅写上述两字段。完成后回复 `TRANSLATE_DONE` + 史略ID + 约字数。
