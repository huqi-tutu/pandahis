# 史略翻译流水线：编排说明 + 各环节提示词（优化用快照）

> **用途**：给其他模型做提示词/编排优化时的自包含说明书。  
> **快照日期**：2026-08-20（含 Structure/Annotation Ledger + **质量宪法八大守恒**）  
> **代码根**：`tools/openclaw-historiography/historiography-translate/`  
> **规则 SSOT**（勿在优化时与提示词打架）：  
> - 写作细则：`../historiography-compose/references/翻译规则.md`  
> - 内容 QA：`../historiography-compose/references/历史内容编辑合同.md`（十条合同 · L1–L5 · A–G）  
> - **质量宪法**：`../historiography-compose/references/历史翻译质量宪法.md`（八大守恒 · Phase2 新增三条 · Evidence Backtrace）  
> 提示词里的规则切片由 `lib/rule_bundle.py` / `lib/quality_constitution.py` 按阶段注入。

## 0. 产品目标与已知失败

| 目标 | 含义 |
|------|------|
| Phase1 | 只把核心原典译成准确白话**骨架**；不补他书、不说书发挥 |
| Phase2（默认 polish） | 短卷整篇 / 长卷分章说书润色；L1 守恒 + 改表达硬门禁；偏薄与长卷高重合硬拦；L3/L4 按需加厚 |
| Phase3 | 只找问题，不改正文 |
| Phase4 | 只改清单已确认项，禁止整篇重生成 |
| Phase5 | 验收修复是否真正解决 + 有无新伤 |
| 程序门禁 | 漏段 / 地名今地 / 纪年公元 / 覆盖账本 / 引号 autofix；提示词无法单独兜底 |

**已知真实失败（回归）**：汉高祖 Phase2 曾用概括句顶替，蒸发「随何说英布 / 立太子 / 井陉」等连续段落。根因是 Phase2 任务竞争（写厚 vs 写全），不是单纯「禁止漏译」写得不够。

**本轮已落地的对策**：
1. 改 Phase2 优化目标：去掉「明显长于母本」「L3+L4 占相当比重」  
2. **Structure Ledger**（程序生成 S001→S…）注入 Phase2  
3. **Annotation Ledger**（表内地名 + 纪年规则）注入 Phase2，出口硬检  
4. 体量比默认改软警告；漏段仍硬拦 + 夹缝补洞（程序不塞原文）  
5. **质量宪法**（八大守恒 + Phase2 新增三条 + Evidence Backtrace）按阶段切片注入 Phase1/2/3

## 1. 默认编排（主路径）

```
GLBL 索引
  → recall
  → source_plan（程序 M 清单；外部补全视环境变量）
  → Phase1 母本顺译 → *.mother.json → verify_mother
  → 【程序】Structure Ledger + Annotation Ledger（由母本生成）
  → Phase2 说书润色（短卷整篇 / 长卷分章；注入两份账本 + 声口）
       · verify_polish_draft_light：
           漏段硬拦 · 地名/纪年硬拦 · 誊抄硬拦（长卷≈0.85）· 偏薄默认硬拦 · 旧优稿回归
       · 整篇偏薄/高重合耗尽 → 自动降级分章
       · 漏段 → locate_span_backfill_slots 标夹缝 → LLM 局部补洞
       · 成功 → clear_ledger
  → Phase3 质检 → Phase4 定向修复 → Phase5 复检（建议入库对齐程序门禁）
  → verify / sync
```

### 1.1 阶段 I/O

| 阶段 | 主要输入 | 主要输出 | 完成信号 / 机器块 |
|------|----------|----------|-------------------|
| recall | GLBL 索引 | recalled JSON | — |
| source_plan | recalled | `*.plan.json` | `SOURCE_PLAN_DONE` |
| Phase1 | recalled 本批窗 + plan | `母本顺译` JSON | `MOTHER_DRAFT_DONE` |
| Structure/Annotation Ledger | 母本全文 + 对照表 | 注入 Phase2 的文本块 | 程序，无 LLM |
| Phase2 polish | 母本 + 两账本 | `翻译详情` 成稿 | 落盘 JSON |
| Phase2 backfill | 成稿 + 夹缝说明 | 完整翻译详情 | — |
| Phase3 | 母本 + 成稿 + 程序预检 | QA Markdown + JSON | `<<<QA_JSON` |
| Phase4 | 成稿 + 问题清单 | 修复全文 | `<<<REPAIRED` / `<<<REPAIR_JSON` |
| Phase5 | 修前/修后 + 清单 | 验收报告 | `<<<RECHECK_JSON` |

### 1.2 关键环境变量

| 变量 | 默认 | 作用 |
|------|------|------|
| `TRANSLATE_PHASE2_MODE` | `polish` | `polish` 整篇润色；`enrich`/`chapter`/`legacy_batch` 旧路径 |
| `TRANSLATE_MOTHER_SPAN_GATE` | `1` | 母本连续漏段硬检 |
| `TRANSLATE_PLACE_NOW_GATE` | `1` | 对照表内地名首次今地硬检（仅母本已出现） |
| `TRANSLATE_ERA_YEAR_GATE` | `1` | 显式纪年缺公元并注硬检 |
| `TRANSLATE_PHASE2_MIN_LENGTH_RATIO` | `1.15` | 成稿/母本字数比；**默认仅警告** |
| `TRANSLATE_PHASE2_MIN_LENGTH_RATIO_HARD` | `0` | `1` 时字数比不足改硬失败 |
| `TRANSLATE_PHASE2_MAX_MOTHER_OVERLAP` | `0.95` | 几乎誊抄母本 → 硬失败 |
| `TRANSLATE_PHASE2_TEMPERATURE` | `0.5` | 润色温度 |
| `TRANSLATE_PHASE3_QA` / `TRANSLATE_AUTO_REPAIR` | `1` | 质检与自动修复 |
| `DEEPSEEK_MAX_TOKENS` | `50000` | 防长卷截断 |

### 1.3 程序门禁（Ledger / Gate）

1. **Structure Ledger** `lib/structure_ledger.py`  
   - 母本 `\n\n` 段 → S001…（anchors、sequence_lock、occurrence）  
   - 注入 Phase2；顺序明显倒挂 → ⚠️（不单独硬失败）  
2. **母本段落漏段** `lib/mother_span.py`  
   - 连续 ≥2 段锚点对不上 → 硬失败；夹缝补洞，**禁止程序塞母本散文**  
3. **Annotation Ledger** `lib/annotation_ledger.py`  
   - 母本 × `古地名今地对照.md` → 必标清单  
   - Phase2 出口：地名漏标、纪年缺公元 → 硬失败（可 env 关）  
4. **覆盖账本** Phase2 通过后 `clear_ledger`  
5. **引号 autofix** 风格纠偏；经典候选等仍靠规则/质检  

### 1.4 刻意不做的事

- 不回退「M001 打卡作文」进 polish  
- 不把 Phase2 一次拆成 A/B/C/D 四轮 LLM（可作中期；当前用账本+目标改写）  
- 不程序硬塞原文补洞

## 3. 优化关注点（给后续改提示词的模型）

1. **漏段 vs 压缩**：允许删字；禁止概括顶替多段；与结构账本/漏段门禁一致。  
2. **L3/L4**：按需，不是占比 KPI；勿恢复「明显长于母本」硬目标。  
3. **格式**：地名/纪年以 Annotation Ledger + Gate 为准，少堆提示词细则。  
4. **SSOT 同步**：改合同/规则须同步阶段切片与本文件。  
5. **勿把单篇病例写成全局 if-else**。

## 4.1 source_plan.md

文件：`prompts/source_plan.md`

### source_plan.md

```markdown
# Step：史料计划（source plan）

## 任务

读取 `recalled` JSON，为这一条史略生成史料计划，并写入消息头指定的 `.plan.json`。

## 目标

先分析，不写正文。计划必须帮助 **Phase1 母本顺译** 与 **Phase2 补全成稿** 分工：

- **母本逐句清单**：长文由编排器按母本分句**程序生成**；你可省略整表。短文若手写，须 100% 覆盖、句序不乱、含 `必现词` 锚点
- **外部补全**（跨书选题 · plan 主责）：只补有**读者知识增量**的内容；先列候选再标 `采用`
  - **当用三类（硬优先）**：① 异说/冲突记载（说法实质不同）② 背景（时势/制度/关系母本略）③ 评价差异（史家臧否不同）  
  - **默认 false**：场面雕花；仅用字/通假异文（蛟龙↔交龙）；《史记》《汉书》同情节换出处再讲一遍  
  - **补充范围限定（硬）**：对照**全书母本**（整份 M / 全卷，不是只看锚点附近）  
    - ✅ 记载冲突须分述；母本未交代的必要背景；他书另有评价立场  
    - ❌ 母本后文已有的同事件同结果（含前锚剧透）；❌ 同情节细描「雕花」；❌ 无实质分歧的异文  
  - 候选须按**检索通道**发散（同书非本传 / 近时杂史辑佚 / 外传故事 / 近古议论批判 / 类书引佚），勿锁死平行纪对读；以冲突/另说/背景/异评为准入  
  - **禁止**母本同一卷；**禁止**空数组；**禁止**用索引书目顶替跨书选题；**禁止**更简平行纪冒充补充  
  - `与母本关系` 须写清属哪一类增量（冲突/另说/背景/异评）及相对哪段母本；若只是雕花或异字 → `采用:false`
- **索引补充处理**：只裁决 recalled 里已有的 role=补充块（「引入|异说|去重不用」）——与外部补全分工，**不是**外部补全书单来源  
  - 平行正史勿一律「去重不用」；叙事接近时标「异说」**只筛实质分歧**（仅异字/同情节 → 去重不用）
- **经典引用**：编排器会为部分 M 标注 `经典引用候选`；plan 勿删该字段。写作时默认白话，仅候选句镶嵌史料「」原文
## 必现词提取规范

> **落盘时由编排器程序化重算**（`extract_must_phrases`），LLM 可不填或填写后被覆盖。  
> **L0 禁释词**（崩/薨/卒/立/是为/是谓/莫不从服/诸侯/天子等，见 `gloss_rules.L0_GLOSS_WORDS`）**不得**作为必现词，也**不得**在成稿里旁白拆词解释。

| 锚点类型 | 示例 | 强制要求 |
|----------|------|---------|
| 数字 | 九年、三日 | 必须提取 |
| 「氏」结尾專名 | 少典氏、陈锋氏 | 必须提取（**≤5 字**） |
| 1–3 字专名/称号 | 放勋、涿鹿、景公 | 优先提取 |
| 引号内原文 | 「习用干戈」 | ≤3 字；更长则拆核心词 |

- 每条最多 **4 个**必现词（`MAX_MUST_PHRASES`）；**默认每项 1–3 字**（氏名 ≤5）
- **禁止** 4 字及以上整段分句块作为必现词（易误拦白话意译；句意写入 `信息点`）
- 来源：仅从 `原文摘句` 按规则提取，不得凭空编造
- 禁止：L0 禁释词、虚词碎片、从词中间截断的 n-gram

## 输出 JSON

顶层字段固定如下：

```json

  "史略ID": "...",
  "史略名称": "...",
  "母本著作": "...",
  "母本逐句清单": [
    {
      "编号": "M001",
      "段落": "01史记 卷008 P1",
      "原文摘句": "...",
      "信息点": "...",
      "必现词": ["..."],
      "引用粒度": "narrative|parallel_cluster|genealogy|appraisal",
      "经典引用候选": false,
      "母本提示": "仅母本顺译写法提示，不含他书",
      "补全提示": "可选；仅说明 enrich 阶段可补什么"
    }
  ],
  "索引补充处理": [ ... ],
  "外部补全": [
    {
      "采用": false,
      "补全类型": "异说|冲突观点|背景|评价差异|必要上下文|补充细节",
      "主题": "...",
      "出处": "《资治通鉴·汉纪…》或《汉书·…赞》等（勿只盯史记/汉书本纪）",

      "与母本关系": "属冲突/另说/背景/异评：相对母本…他书…",

```

> `补充细节` 仅当细节本身构成**另说/改变理解**时可用；同情节雕花 → false。


> 注意：`前置引入素材` 字段由编排器在 plan 落盘时自动注入（基于索引结构化数据），
> LLM 不需要生成此字段。

## 纪律

- **短文**：母本逐句清单须与 recalled 句号分句一一对应；每条一个分句；条数 ≥95%
- **长文**：勿输出整份母本清单；编排器合并决策字段到程序清单。消息头「决策 JSON」模式优先
- 每条 `信息点` 须列全该句实质信息；`必现词` 可留空，**落盘时程序自动生成**
- `写作提示` 若含外部补全，须拆到 `补全提示`；`母本提示` 不得要求他书
- 外部 `"采用": true` 时 **必须** 填：
  - `补全类型` ∈ `异说|冲突观点|背景|评价差异|必要上下文`（`补充细节` 仅限另说性细节）
  - `与母本关系`：写清属冲突/另说/背景/异评哪一类及相对哪段母本；勿只写「与母本相同 / 补充场面更细 / 异字」；与后文 M 重合 → false
  - `出处`：可核验 `《书·卷》`；禁止占位书名；禁止母本同一卷；宜开拓编年/政书/志传，勿只堆史记+汉书同情节
- `参考著作`、`写作结构` 为硬必填（长文决策 JSON 也须有）
- **`参考著作` 硬上限 ≤10**：只返回最重要的书目；超限门禁拒收并重试
- 不确定出处 → `"采用": false`（仍保留候选项）
- **长文**：不少于 N 条采用:true，且须属当用三类；禁止空数组、禁止雕花凑数
- 写完确认 JSON 可解析，再回复 `SOURCE_PLAN_DONE`
```

## 4.2 source_plan_longform.md（回退）

### source_plan_longform.md

```markdown
# Step：长文史料计划（仅跨书决策）

> **默认已切换**：`TRANSLATE_EXTERNAL_MACRO=1` 时走「宏观选题 → 判重 → 挂锚」两步法  
> （见 `source_plan_external_macro.md` / `source_plan_external_anchor.md`）。  
> 本文件仅在 `TRANSLATE_EXTERNAL_MACRO=0` 回退旧整包 plan 时使用。

## 任务

本条是**长文**。母本逐句清单已由编排器生成，**禁止**输出整表。

你只输出一个决策 JSON，写入消息头指定的 `.plan.json`。

## 核心产出（必须）

1. **`外部补全`**（本阶段主责 · 读者价值优先）  
   - 问自己：这条补全让读者**多懂了什么**？若只是把母本已有故事写得更细、更热闹 → **采用:false**。  
   - **当用三类（硬优先，采用:true 几乎只允许这些）**：  
     1. **异说 / 冲突记载** — 他书与母本对同一事的说法**实质不同**（因果、结果、人物角色、制度结论有分歧）  
     2. **背景** — 母本未交代或一句带过的时势、制度前提、人物关系、政局语境  
     3. **评价差异** — 史家臧否/论赞/后世史评与母本立场不同  
   - **默认 false / 禁止当 true**：  
     - 场面雕花（鸿门、斩蛇、约法三章等母本已有完整情节，他书只加对话/动作）  
     - 无实质异文（蛟龙↔交龙、称谓/通假异写而史实相同）  
     - 把《史记》《汉书》同一故事换出处再讲一遍  
   - **检索须发散**：按通道（同书非本传 / 近时杂史辑佚 / 外传故事 / 近古议论批判 / 类书引佚）选题，勿锁死平行纪对读；以冲突/另说/背景/异评为准入。须可标《书·卷》。  
   - **禁止**更简平行纪冒充补充；**禁止**现代评述。  
   - **补充范围**：对照**全书母本**（全部 M 信息点，不是只看锚点附近）。禁止补母本后文已有的同事件同结果；禁止前锚剧透后文。  
   - **禁止**母本同一卷；**禁止空数组 `[]`**。先列候选再标采用。  
   - 消息头若要求不少于 N 条 `采用:true`，须用**当用三类**凑满，禁止用雕花凑数。

2. **`索引补充处理`**  
   - 只裁决 recalled 里已有的 role=补充块：`引入` / `异说` / `去重不用`。  
   - 平行正史勿一律去重；叙事接近时标「异说」，**只筛有实质分歧的点**（仅异字/同情节 → 去重不用）。

3. **`参考著作`**（硬上限 ≤10，只交最重要）、**`写作结构`**、**`风险提示`**

  "与母本关系": "母本太史公曰侧重……；班固赞另有「规摹弘远」等评价立场，非同义换字",

- **纪年并注公元（硬）**：凡正文写出**年号年 / 帝纪年 / 国号纪年**（如「汉二年」「秦二世元年」「建元六年」「贞观三年」），**每一次出现该年**都必须紧随并注公历年份；禁止只标少数关键年、其余干写年号。  
- **认知层级**：**L1** 史源事实 · **L2** 原典转述/传闻（须保留限定）· **L3** 他书补充（勿冒充核心原典）· **L4** 编辑解释 · **L5** 说书评论。  
- **压缩不改结构（E）**；可删字、压缩描写，**禁止整段删母本情节**；**重复要标记**，勿误删原典回合（结构账本若标「第 N 次出现」，须保留并点明回合）  

### 纪年写法（统一）

**格式（全文统一）：** `年号/帝纪 + 年序（前N年）` 或公元后 `（公元N年）`。

- 公元前：`汉元年（前206年）`、`秦二世三年（前207年）`、`建元六年（前135年）`  
- 公元后：`贞观三年（公元629年）`  
- 同句可写月份：`汉元年十月（前206年）`；若紧接同场景只写「十一月」且年已明，月份本身不必再注公元。  
- **「汉二年」「汉三年」…每一个新出现的年序都要注**，不能只在「汉五年」偶注一次。  
- 「次年 / 是岁 / 这年秋天」若读者无法对上公历，尽量改成或补出明确纪年+公元。  
- 换算须准确；拿不准标【待核实】，禁止瞎编公元年。

## 讲解与加料（按需 · 不是篇幅 KPI）

母本顺译是骨架。成稿要让读者读懂；L3/L4 是**补充维度，不是占比指标**。

- **L1 主线**：信息齐全、**按结构账本顺序**正确（不可削、不可重排）  
- **L3 / L4**：仅在读者理解当前事件确实需要时插入 1–3 句（制度、地理、人物关系、异说、评价）；补完立刻回主线  
- **L5 说书评论**：调味即可，勿压过讲解与主线  

**每一段 L3/L4 都必须建立在对应母本事件已经写清之后**；禁止先写长讲解再把多段情节压成一句带过。

### 何时宜延伸（优先 L4；有据则加 L3）

1. **制度 / 官职 / 礼仪 / 年号改元** — 第一次出现时说明是什么、管什么  
2. **地名 / 路线 / 都城 / 封国** — 首次标今地，只用括号：`废丘（今陕西兴平一带）`。消息中的**标注账本**列出的表内地名必须标；表外不猜。  
3. **次要人物登场** — 身份、与主角关系、为何出场  
4. **战争 / 政变 / 重大政策转折** — 前因后果、各方立场（勿事后诸葛写成当事人已预知）  
5. **原典一笔带过、读者会懵的关节** — 用 L4 讲清；若他书有实质异说，用 L3 点明并区分来源  
6. **评价冲突 / 史家臧否不同** — 分述，不调和  

### L3 跨书补充怎么用

- **鼓励**：平行正史、同书他卷、通行可靠记载中的**增量**（异说、背景、细节、评价差异）  
- **禁止**：无依据编造；把 L3 写成好像核心原典原文；为凑书名硬塞《》；把后面才发生的情节提前插进来当解释  
- 用过的书文末 **参考著作** 必须列出  

## 做什么

1. **按 S 顺序说书改写**：当面讲史——口语、场面、人物口气、释义旁白、适度幽默；不得跳号重排。  
2. **按需延伸**：按上文「何时宜延伸」加 L3/L4；该讲则讲，不该讲不硬凑。  
3. **时间线与事件链（G）**：严格按真实先后与结构账本。  
4. **纪年并注公元（硬）**：按上文「纪年写法」；润色时补齐 Phase1 漏注。  
5. **去重与覆盖**：禁止同义双写；重复历史回合保留并标记；母本关键信息不许蒸发。**可以压缩措辞、删形容词，不可以整段删情节**。  
6. **引号**：对照 `史料原文`——框内是本篇著作原文用「」；已译白话用 “”。消息中标注账本若列有经典摘句，须落地直角「」。  
7. **守恒**：专名、官职、地名、年号、人数、胜负因果以母本为准（公元注为助读，不改年号本身）。  
8. **参考著作（硬）**：有 L3 则列出实际用书；至少列出核心母本。  
9. **体裁**：连续说书，禁止 Markdown 章节标题（`#` / `##`）和论文提纲。

## 不要做什么

- 场次元开场；近誊抄 Phase1（几乎不改表达）  
- 为凑书名硬塞《》；无增量的平行纪再讲一遍；预支后文  
- 把 L2/L5 写成 L1；把后见之明写成当时动机  
- 用一句概括顶掉母本里连续好几段的情节；为加讲解而挤掉母本事件  
- 把「写得更长」当成目标  
- 输出 JSON / 代码围栏 / Markdown 章节标题  
- 只写正文「翻译详情」；文末：正文收束后空一行，再写 `参考著作：` + 条目  

## 旁白

制度、典故、生僻处：读者跟不上时再讲；著名典故先叙后点名。  
禁滥用空过场套话；崩/薨/卒、是为等常见词勿过度解释。
```

## 职能① · 锚点补全

1. 仅落地 `外部补全` 中 `"采用": true` 与索引「引入|异说」；**禁止 plan 外新增硬史实**。  
2. 每条只写相对母本的增量（冲突/另说/背景/异评）；挂《书·卷》；**补完立刻回母本主线**，勿连续大段另起炉灶。  
3. **正文必须出现对应他书《》**（质检硬拦；不见则失败重试）。  
4. 禁止：无实质异文（纯用字/通假差异）、同情节雕花、换说法重复母本、母本同一卷、整卷复述。  
5. 异说多版本**分述**，禁止调和。  
6. 「去重不用」的索引项不写。  
7. 本传退场：Phase1 已有崩/薨/卒 → 勿再补；仅 plan 标明缺漏时篇末 **1 句**。  
8. 二手表述：无同句《书》时，「传说/据说/相传/有人说」等合计 ≤5。  
9. 引用优先 `允许引用白名单`。

## 职能② · 改表达

### 目标（硬）

说书人当面讲史——《明朝那些事儿》那种：**口语、场面、人物口气、释义旁白、偶尔点破反差**。  
不是「把文言换成通顺书面语」；通顺书面语仍算职能②失败。  
生僻字词/古语/古怪处按规则一加旁白（≤200字、事实白描、自然过渡、不强制出处）；著名典故/成语情节写完后须点名对上号；勿堆「说白了」。

质检会用程序比对你与 Phase1 的重合度：几乎誊抄母本 → **失败重试**。

### 失败形态（出现即本职能不合格）

- 大段「某年某月，命某官，遂某事」编年条，像大事记不是讲故事。  
- 人物说话全是书面翻译腔。  
- 读完本章想不起任何一句有味道的话。  
- 句子结构、用词与 Phase1 母本顺译高度雷同（换了几个虚词不算改表达）。

### 示范（同信息，换说法）

❌ Phase1 / 失败成品（书面直译）：  
> 高祖曾到咸阳服役，正赶上皇帝出巡，得以纵情观看。他望见秦始皇的威仪，不禁长叹一声。

✅ 说书改表达：  
> 刘邦去咸阳服徭役，赶上秦始皇出巡，那排场把他看呆了。一个乡下亭长仰头望着车驾，脱口叹道：「嗟乎，大丈夫当如此也！」

❌：  
> 汉二年，汉王东进，塞王司马欣、翟王董翳、河南王申阳皆降。

✅：  
> 汉二年，汉王一出关东进，关中那几位诸侯王心里就打鼓：塞王司马欣、翟王董翳、河南王申阳先后投降。偏韩王郑昌不肯，汉王便派韩信去收拾他。

❌：  
> 高祖以亭长身份为县里押送役徒去郦山，途中逃亡者甚众。

✅：  
> 他以亭长的身份押着役徒往郦山走，一路上人跑了不少——再走下去，只怕到地方就剩他自己了。

### 改表达时硬约束

- **信息点全保留**（可合并短句，不可整段蒸发）；已插入的《书·卷》句保留。  
- 专名/数字/官职/地名/年号/人数/胜负因果：只改说法。  
- 直角「」只装史料金句/原文；**未译加工的原话对白必须「」**（禁弯引“”装文言）；**已是白话禁止再塞进「」解释**；诗赋/誓词：**先概括主旨，再「」留文言**（禁整段白话译诗）。  
- 白话对话才用 “”；用「」后优先融入接叙；反对句句 `「…」——同义白话` / `“… ”——…` 作业体；偶发增量破折号可留，Phase1 同义对照残留宜改掉。  
- **要有释义旁白**：生僻字词/古语/官职制度/人名身份/地名今地/器物礼制/异名谐音/古怪处，自然融入；单处≤200字；事实白描；不强制出处。  
- **著名典故/成语**：情节写清后须点名对上号（先叙后点）；同一典故本篇已点破则后文不重复。  
- **L0 禁旁白**：崩/薨/卒/立、是为/是谓、咸弗莫皆、诸侯天子、善诺等直接顺译，勿拆词注释。  
- **禁止滥用**无意义过场词：「说白了」等。  
- 禁编造无据心理、无据对白、小剧场；禁译者导航（「我们来看看」等）。  
- 禁 Markdown `**加粗**`；「这家伙/这位爷」全篇 ≤3；AI 腔词见规则一频率表。  
- 长文分章：接住上章声口样例，禁止换成更干的公文腔；禁止复述上章（含换说法）；禁止下章短版预告。

### 前置引入（首章 · 硬）

独立成段 **100–250 字** → 空一行 → 再写开篇。  
**首段即主题**：精简概括「是谁 / 为何重要 / 主要出处」，直接入题。  
❌ 禁止：`今天要讲的这位`、`咱们今天讲`、`下面来讲`、`接下来要说`、`咱们就按着…一件件说来`。  
勿与出生、起事等正文情节粘段。

### 篇末收束（末章 · 硬）

母本身后事写完后，**另起一段** 80–220 字收束全文（历史位置 / 一生主线收科），再结束本章。  
勿写参考著作节（程序合并追加）。母本写完就停、没有收束 = 不合格。
