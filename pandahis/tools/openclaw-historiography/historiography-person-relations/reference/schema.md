# 人物关系 JSON Schema

产出路径：`data/07人物关系/{关联史略名称}关系表.json`

文件为 **JSON 数组**，每条记录对应图谱中的一个节点（含二级分类枢纽）。

## 记录字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `关联史略名称` | 是 | 主题人物（与文件名 `{名称}关系表.json` 一致） |
| `关系ID` | 是 | 文件内唯一；建议前缀见下表 |
| `关系类别` | 是 | `家庭` \| `同僚` \| `敌对` \| `师徒` \| `好友` |
| `关系层级` | 是 | `一级` \| `二级` \| `三级` \| `四级` |
| `关系节点标题` | 是 | 二级分类名，或**具体人物**名；家族/氏姓可；禁止国家/政权/民族/「××国君」空名 |
| `上级连接线标题` | 是 | 与上一节点的边标签；无标题时填 `""` |
| `关系简述` | 是 | 1–2 句，含史料依据要点；二级枢纽可简述该支用途 |
| `节点类型` | 条件 | 二级分类枢纽必填 `二级分类`；人物可省略 |
| `所属一级关系` | 条件 | 层级 ≥ 二级时必填；值为**上一级节点标题** |
| `所属二级关系` | 条件 | 层级 ≥ 三级时必填 |
| `所属三级关系` | 条件 | 层级 ≥ 四级时必填 |
| `record_id` | 否 | 外部系统 ID；新建可省略 |

### 关系ID 前缀建议

| 前缀 | 关系类别 | 示例 |
|------|----------|------|
| `HD-FAM-` | 家庭 | `HD-FAM-001` |
| `HD-COL-` | 同僚 | `HD-COL-001` |
| `HD-FOE-` | 敌对 | `HD-FOE-001` |
| `HD-MAS-` | 师徒 | `HD-MAS-001` |
| `HD-FRI-` | 好友 | `HD-FRI-001` |

## 入库映射（`box_graph_*`）

07 JSON 为 **SSOT**。导入脚本 `import_relations_lib.build_import_sql` 将其转为图结构：

| 07 JSON 字段 | `box_graph_node` | `extra_json`（原样保留 + 衍生） |
|--------------|------------------|----------------------------------|
| `关系ID` | `component_id` | `关系ID` |
| `关系节点标题` | `name` | — |
| `关系类别` | — | `关系类别` |
| `关系层级` | — | `关系层级` |
| `节点类型` | 二级分类 → `node_type=subcategory` | `节点类型`；二级分类另写 `isSubCategoryNode: true` |
| `上级连接线标题` | `box_graph_edge.label`（可空） | `上级连接线标题` |
| `关系简述` | — | `关系简述` |
| `所属一级/二级/三级关系` | 用于解析父边 | 同字段 |
| — | — | `关系链`（自动：`主题 › 父 › …`） |

额外写入：

- **中心节点**：`node_key=center`，`node_type=event`，`name=关联史略名称`
- **一级分类节点**：按出现的 `关系类别` 自动生成（`cat_fam` 等），`isCategoryNode: true`（**前端不绘制**，仅作分组）
- **二级分类枢纽**：来自 JSON 中 `节点类型=二级分类` 的记录（图谱圈1）
- **node_key**：由 `关系ID` 派生（如 `HD-FAM-001` → `hd_fam_001`）
- **边方向**：父 → 子；一级节点从对应一级分类节点连出

| 展示位置 | 读取字段 |
|----------|----------|
| 关系 Tab 扇区主题色 | `extra_json.关系类别`（家庭/同僚/敌对/师徒/好友） |

### 二级枢纽人数上限

每个二级分类枢纽下的**直接人物**（`关系层级=二级` 且 `所属一级关系=该枢纽标题`）**≤ 10**。超限时只保留最重要 10 人；前端展示亦截断至 10。

## Taxonomy → JSON 映射

二级分类为**显式枢纽节点**（`关系层级=一级`，`节点类型=二级分类`）。`所属*关系` 存**节点标题链**。

### 好友

须有二级枢纽「好友」。人物 `关系层级=二级`，`所属一级关系=好友`，`上级连接线标题=""`。

## 层级与 `所属*关系` 链

- **一级**：无 `所属*关系`（二级枢纽）。
- **二级**：`所属一级关系` = 直接上级节点标题。
- **三级**：`所属一级关系` + `所属二级关系`。
- **四级**：`所属一级关系` + `所属二级关系` + `所属三级关系`。

链上每一环的 `关系节点标题` 必须在该文件中存在且层级递增一致。

## 互斥

见 [`关系数据整理提示词.md`](../../../../关系数据整理提示词.md)：家庭排斥同僚/好友/师徒；同僚排斥好友；敌对可与他类共现。

## legacy 样例迁移说明

| 旧写法 | 新写法 |
|--------|--------|
| `关系类别: 师从` | `师徒` |
| `关系类别: 外敌`（一级） | `敌对` + 二级枢纽「外敌」 |
| `同僚` + 边「政敌」 | `敌对` + 二级枢纽「内敌」 |
| `妻妾` / `正室` / `正妃` / `正妻` / `小妾` / `儿子` | `配偶` / `妻` / `妻` / `妻` / `妾` / `子` |
| `父亲` / `母亲` / `丈夫` / `嫔妃` | `父` / `母` / `夫` / `妃` |
| `关系类别: 君臣` | `同僚` |
| 好友人物直挂一级 | 二级枢纽「好友」+ 人物二级 |
| 禁止孙辈 | **允许**四级孙辈 |
