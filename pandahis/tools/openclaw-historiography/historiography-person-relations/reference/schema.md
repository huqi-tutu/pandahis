# 人物关系 JSON Schema

产出路径：`data/07人物关系/{关联史略名称}关系表.json`

文件为 **JSON 数组**，每条记录对应图谱中的一个节点。

## 记录字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `关联史略名称` | 是 | 主题人物（与文件名 `{名称}关系表.json` 一致） |
| `关系ID` | 是 | 文件内唯一；建议前缀见下表 |
| `关系类别` | 是 | `家庭` \| `同僚` \| `师从` \| `外敌` \| `好友` |
| `关系层级` | 是 | `一级` \| `二级` \| `三级` \| `四级` |
| `关系节点标题` | 是 | 人物或实体的展示名 |
| `上级连接线标题` | 是 | 与上一节点的关系边标签（见下节） |
| `关系简述` | 是 | 1–2 句，含史料依据要点 |
| `所属一级关系` | 条件 | 层级 ≥ 二级时必填；值为**上一级节点标题** |
| `所属二级关系` | 条件 | 层级 ≥ 三级时必填 |
| `所属三级关系` | 条件 | 层级 ≥ 四级时必填 |
| `所属四级关系` | 条件 | 新 schema **不使用**（最大层级为四级节点本身） |
| `record_id` | 否 | 外部系统 ID；新建可省略 |

### 关系ID 前缀建议

| 前缀 | 关系类别 | 示例 |
|------|----------|------|
| `HD-FAM-` | 家庭 | `HD-FAM-001` |
| `HD-COL-` | 同僚 | `HD-COL-001` |
| `HD-MAS-` | 师从 | `HD-MAS-001` |
| `HD-FOE-` | 外敌 | `HD-FOE-001` |
| `HD-FRI-` | 好友 | `HD-FRI-001` |

## 入库映射（`box_graph_*`）

07 JSON 为 **SSOT**。导入脚本 `import_relations_lib.build_import_sql` 将其转为图结构：

| 07 JSON 字段 | `box_graph_node` | `extra_json`（原样保留 + 衍生） |
|--------------|------------------|----------------------------------|
| `关系ID` | `component_id` | `关系ID` |
| `关系节点标题` | `name` | — |
| `关系类别` | — | `关系类别` |
| `关系层级` | — | `关系层级` |
| `上级连接线标题` | `box_graph_edge.label` | `上级连接线标题` |
| `关系简述` | — | `关系简述` |
| `所属一级/二级/三级关系` | 用于解析父边 | 同字段 |
| — | — | `关系链`（自动：`主题 › 父 › 祖…`） |

额外写入：

- **中心节点**：`node_key=center`，`node_type=event`，`name=关联史略名称`
- **node_key**：由 `关系ID` 派生（如 `HD-FAM-001` → `hd_fam_001`）
- **边方向**：父 → 子；一级节点从 `center` 连出

## Taxonomy → JSON 映射

SSOT（`关系数据整理提示词.md`）中的**子类**通过 `上级连接线标题` 表达；`所属*关系` 字段存**人物节点名链**，不存子类名。

### 家庭

| 子类 | 一级节点写法 | 上级连接线标题示例 |
|------|--------------|-------------------|
| 父母 | 父亲/母亲直接为**一级** | `父亲`、`母亲` |
| 配偶 | 各配偶为**一级** | `妻子`、`丈夫`、`正妃`、`侧室` |
| 兄弟姐妹 | 各兄弟姐妹为**一级** | `兄弟`、`姐妹`、`兄`、`弟`、`姐`、`妹` |
| 配偶下游 | 二级起 | `儿子`、`女儿` → 三级 `儿子`/`女儿`（孙辈） |
| 兄弟姐妹下游 | 二级起 | `儿子`、`女儿` → 三级 → 四级（孙辈） |

**配偶支示例**（黄帝 · 嫘祖 · 昌意 · 颛顼）：

```json
{
  "关联史略名称": "黄帝",
  "关系ID": "HD-FAM-002",
  "关系类别": "家庭",
  "关系层级": "一级",
  "关系节点标题": "嫘祖",
  "上级连接线标题": "妻子",
  "关系简述": "西陵氏女，黄帝正妃，发明养蚕，生玄嚣、昌意二子"
}
{
  "关联史略名称": "黄帝",
  "关系ID": "HD-FAM-004",
  "关系类别": "家庭",
  "关系层级": "二级",
  "关系节点标题": "昌意",
  "上级连接线标题": "儿子",
  "所属一级关系": "嫘祖",
  "关系简述": "黄帝次子，封于若水，娶蜀山氏女生颛顼"
}
```

### 同僚

| 子类 | 上级连接线标题（推荐） | 层级 |
|------|------------------------|------|
| 君王 | `君王` | 一级 |
| 臣子 | `臣子`、`大臣`、`相`、`史官` 等职务边 | 一级 |
| 同僚 | `同僚` | 一级 |
| 敌对（共事之敌） | `敌对`、`政敌` | 一级 |

`关系类别` 统一为 **`同僚`**，子类靠边标签区分。

### 师从

| 子类 | 一级边标签 | 下游 |
|------|-----------|------|
| 老师 | `老师`、`问医`、`问道` | 二级起：该老师门下 → 最多至四级 |
| 徒弟 | `徒弟`、`弟子` | 二级起：徒孙链 → 最多至四级 |

### 外敌

| 层级 | 写法 |
|------|------|
| 一级 | 边标签：`外敌`、`阪泉之战`、`涿鹿之战` 等事件边；节点为外部对手 |
| 二级 | **禁止**（外敌不向下展开） |

`关系类别` 为 **`外敌`**（勿与 `同僚·敌对` 混用）。

### 好友

| 层级 | 写法 |
|------|------|
| 一级 | 边标签：`好友`、`知交`、`游伴`、`契友` 等；节点为私交人物 |
| 二级 | **禁止**（好友不向下展开） |

`关系类别` 为 **`好友`**（勿与 `同僚` 政治盟友、`师从` 师徒混用）。

## 层级与 `所属*关系` 链

- **一级**：无 `所属*关系` 字段。
- **二级**：`所属一级关系` = 其直接上级**节点标题**（如 `嫘祖`）。
- **三级**：`所属一级关系` + `所属二级关系` 构成完整链。
- **四级**：填至 `所属三级关系`；**不要**再出现 `所属四级关系` 或 `关系层级: 五级`。

链上每一环的 `关系节点标题` 必须在该文件中存在且层级递增一致。

##  legacy 样例迁移说明

`黄帝关系表.json` 为历史导入样例，存在：

- `关系类别: 君臣` → 新产出改为 **`同僚`**（边标签保留 `大臣` 等）
- `关系类别: 敌对` 且为炎帝/蚩尤 → 新产出改为 **`外敌`**
- `关系层级: 五级` → **禁止**；四级为叶节点，更远后代由该人物自有关系表承担

新文件 `--strict` 校验按新 schema；旧文件可不带 `--strict` 仅作格式参考。
