## Step 4 任务（LLM 只补缺失正式字段）

编排器已执行 `fill_fields.py` + `--merge-auto`。

### 知识性字段（必须 LLM 考订，禁止脚本代写）

以下须由**你**据史料与 `_needs_llm` / 待补清单填写，编排器**不会**用脚本静默补齐：

- `史略名称` / `史略分类`（Step1 已定者勿改，Step4 只补缺失）
- `史略开始年` / `史略结束年`
- `四级帝王坐标`（归属帝王）
- `_auto_filled._坐标主轴说明`（跨时期人物）

脚本仅做：一～三级坐标 + 各 ID 据帝王表**反推**、格式校验、删除临时字段。

### 你必须做的

对「待补字段清单」中**每一条**补全：

- `优先级` / `优先级判定理由`（**仅允许** `P0` | `P1` | `P2` | `P3`；列传核心人物通常 `P0` 或 `P1`，禁止 `A`/`1` 等自创值）
- `史略开始年` / `史略结束年`（整数，公元前为负）
- **非君王主轴**：仅 `四级帝王坐标`（须为 `帝王.json`「帝王」标准名）
- **君王主轴**：优先级与年份（坐标由帝王表对齐，一般无需你填）

### 四级坐标（重要）

**不依赖本卷是否出现对应君王条目。** 据史略主题、人物身份与史学常识判定四级帝王。

| 分类 | 你填什么 | 脚本做什么 |
|------|----------|------------|
| 君王 | 通常只补年/优先级 | 整条坐标链从帝王表对齐 |
| 宗戚/文臣/武将/宦官/庶众/蕃祚 | **只填 `四级帝王坐标`** | 一～三级 + 各 ID 由编排器据帝王.json **自动反推** |

❌ 不要填写 `一级文明坐标` / `二级朝代坐标` / `三级政权坐标`（非君王条目）  
❌ 不要把史略名称本人写入四级帝王坐标

### 坐标归属

**宗戚**（见 `reference/人物坐标归属规则.md` · 宗戚专则）：

- **嫔妃、皇后、太后、太皇太后** → 四级帝王挂**册封之君（丈夫）**
- **公主、翁主、县主** → 四级帝王挂**生父**

**文臣 / 武将 / 宦官 / 庶众**：以其**主要主政、仕宦、最高官职、历史功业**所在帝王为准；难分主次 → 取**更早**帝王。

**禁止**：仅因人物**卒于某帝在位年**、或**晚年一度归附**某政权，就把四级帝王取为该帝——须据**主政/仕宦/封爵/军功主轴**判定，而非结局段落。

**命名**：西汉开国君主标准名为 **汉高祖**，禁止「汉高帝」（见 `reference/帝王命名规范.md`）。

**蕃祚**：落主要对抗、交往的帝王；交往最深的一位。

### 时间坐标

**人物生卒年与卷内是否有君王无关**；须据史学界主流观点填写。

**禁止**将 `_auto_filled` 中的 `帝王开始年` / `帝王结束年`（或帝王表在位起止）直接抄入人物 `史略开始年` / `史略结束年`。

考订后**每条**须在 `_auto_filled._年LLM依据` 写 1 句依据（君王写即位/退位出处，人物写生卒学界观点；禁止只留脚本 `年规则备注` 模板）。

| 分类 | 开始年 | 结束年 |
|------|--------|--------|
| 君王 | 即位年 | 退位/崩年 |
| 文臣 / 武将 / 宦官 / 庶众 / 宗戚 | 出生年 | 去世年 |
| 蕃祚 | 政权开始年 | 灭亡年 |

### 跨时期主轴说明

`_needs_llm` 含 **`_坐标主轴说明`** 时，须在 `_auto_filled._坐标主轴说明` 写 1～2 句（为何四级帝王取所选帝王；见 `reference/跨时期人物坐标.md`）。**禁止**接受或使用「本卷以…主要功业/仕宦事…为最著」类模板句；须据本传史实独立撰写。finalize 前必填，否则 final 质检不通过。

### 禁止

- ❌ 删除 `_auto_filled` / `_needs_llm`（编排器 finalize 处理）
- ❌ 旧分类（事略 / 典制 / 民录 / 论著 / 君纪）
- ❌ 非君王条目填写一～三级坐标

### 落盘方式（必做）

**OpenClaw agent**：编排器传入的 skeleton 文件路径须**直接编辑并保存**；回复 `STEP4_DONE` + 已补 **史略ID** 列表（须与文件内容一致）。

**DeepSeek 模式**：优先在回复中给出**按史略ID索引的 JSON 对象**（每项仅含待补字段），编排器合并；勿输出巨型完整 skeleton 以免截断。若环境要求整份 skeleton，须含 `segment_attribution` + `entries` 全结构。

**汉书文臣合传**：五人卷须逐条补全；四级帝王西汉开国君主用 **汉高祖**（禁止汉高帝）。
