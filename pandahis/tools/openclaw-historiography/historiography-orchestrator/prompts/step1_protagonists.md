## Step 1a · 主轴人物理解（先于 blocks / skeleton）

**本步只做一件事**：据 **著作名 + 本卷卷名 + 史学常识**，判断本卷应建史略的 **主人公是谁**（可多人）。  
**不要**读段落、**不要**因正文里出现某位皇帝就认定他是主轴；**不要**输出 blocks / segment_attribution / entries。

### 工作流位置（必读）

```
Step1a  著作 + 卷名 → 主人公清单（本步）→ 脚本 identity_gate 硬检
Step1b  读原文段落 → 按清单划 blocks → 展开史略
定类    主人公已锁定后 → 为每人填 category（见下「史略分类 v3」）
```

### 史略分类 v3（定 entry 时用，不是选主轴）

仅：`君王` · `宗戚` · `宦官` · `文臣` · `武将` · `蕃祚` · `庶众`

**同一人**多重身份冲突时，按下列链取唯一 `史略分类`（**不用于**判断「这一卷写谁」）：

`君王 ＞ 宗戚 ＞ 宦官 ＞ 文臣/武将 ＞ 蕃祚 ＞ 庶众`

### 任务

1. 从 **著作 + 卷名** 判断卷型（本纪 / 世家 / 列传 / 表 / 书 / 志）及叙事模式。
2. 填写 **`narrative_mode`**：
   - `skip`：表 / 书 / 志 → `protagonists: []`，须写 `skip_reason`
   - `single`：单人传或单人本纪（1 位主人公）
   - `fanzuo`：蕃祚整卷（1 个政权/部族主题，如南越）
   - `hezhuan`：多人合传（须逐段划块，排除名册段）
3. 列出本卷应独立成「史略条目」的 **核心主人公**（合传可 3–30 人）。
4. 为每位主人公给出 **category** 与 **rationale**（依据卷名与常识，**非**依据正文）。
5. 君王类 `name` 须对照 `reference/帝王.json`「**帝王**」字段逐字一致。
6. **表 / 志 / 书** → `narrative_mode: skip`，`protagonists: []`，`skip_reason` 必填。

### narrative_mode 与划段策略

| narrative_mode | 划段 | 说明 |
|----------------|------|------|
| skip | 无 | 不建条目 |
| single / fanzuo | 整卷一块 | 排除卷首标题（**汉书有、史记无**）、论赞段（史记`太史公曰`/汉书`赞曰`）；**勿逐段 LLM** |
| hezhuan | 逐段 blocks | 按传记段首划界；注意同段接力；名册段不提取 |

### 返工反例（禁止再犯）

| 卷 | 错误 | 正确 |
|----|------|------|
| 仲尼弟子列传 | 孔子为卷主轴 | 仅有独立叙事段的各弟子；孔子禁止 protagonist |
| 外戚世家 | 吕太后为主轴之一 | 吕太后主轴在 009 本纪 / 汉书 004 高后纪；本卷从薄太后起，P1–3 exclude |
| 秦本纪 | 秦始皇为条目 | 始皇主轴仅在 006 本纪；005 末段总述 exclude |
| 礼书 / 乐书 | 汉高祖、汉武帝为条目 | 志书 skip，entries 为空 |

### 世家 · 主轴人数（依卷名，非依正文帝王）

| 子类型 | 主轴策略 | 示例 |
|--------|----------|------|
| **始祖贯卷** | 卷名始祖 1 人 | 齐太公世家、鲁周公世家 |
| **多代重点** | 3–5 位关键君主分块 | 晋世家、楚世家 |
| **合传世家** | 卷名多人各一块 | 管蔡、陈杞、荆燕 |
| **宗室合传** | 按卷名宗支分块 | 三王世家（刘闳/刘旦/刘胥） |
| **五宗世家** | 五母宗戚分块 | 栗姬、程姬、贾夫人、唐姬、儿姁 |
| **外戚世家** | 薄后→窦后→王太后→卫子夫（**不含**吕后） | 外戚世家 |
| **文臣世家** | 卷名功臣为文臣 | 孔子世家、萧相国世家 |
| **起义世家** | 陈涉等为庶众 | 陈涉世家 |
| **弟子列传** | 各弟子为文臣 | 仲尼弟子列传 |

### 常见误把皇帝当主轴（禁止）

| 卷名 | 禁止 protagonist | 应使用 |
|------|------------------|--------|
| 五宗世家 | 汉景帝、藩王 | 栗姬、程姬、贾夫人、唐姬、儿姁（宗戚） |
| 三王世家 | 汉武帝 | 齐王刘闳、燕王刘旦、广陵王刘胥 |
| 外戚世家 | 吕太后、汉高祖、汉武帝 | 薄太后、窦太后、王太后、卫子夫 |
| 孔子世家 | 君王 | 孔子（文臣） |
| 陈涉世家 | 君王 | 陈涉（庶众） |
| 仲尼弟子列传 | 孔子、君王 | 颜回、子路等弟子（文臣） |

### 输出 JSON

```json
{
  "work": "<著作 ID>",
  "vol": "<三位卷号>",
  "volume_name": "<本卷卷名>",
  "volume_type_guess": "列传",
  "narrative_mode": "single",
  "skip_reason": null,
  "protagonists": [
    {
      "name": "颜回",
      "category": "文臣",
      "rationale": "《仲尼弟子列传》以孔子弟子各传为主轴，本卷禁止孔子为 protagonist。"
    }
  ],
  "excluded_kinds_hint": ["卷首标题", "赞曰", "太史公曰", "其他"]
}
```

`excluded_kinds_hint` 按著作择用：**汉书**填 `卷首标题`+`赞曰`；**史记**填 `太史公曰`（通常无卷首标题）。

```json
{

  "vol": "<三位卷号>",

  "volume_type_guess": "列传",
  "narrative_mode": "hezhuan",
  "skip_reason": null,

      "name": "郦食其",
      "category": "文臣",
      "rationale": "《郦陆朱刘叔孙传》卷名首姓，合传主人公之一。"
    }
  ],
  "excluded_kinds_hint": ["卷首标题", "赞曰", "其他"]
}
```
