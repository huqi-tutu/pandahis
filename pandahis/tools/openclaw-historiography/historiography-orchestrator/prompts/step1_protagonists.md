## Step 1a · 主轴人物理解（先于 blocks / skeleton）

**本步只做一件事**：据 **著作名 + 本卷卷名 + 史学常识**，判断本卷应建史略的 **主人公是谁**（可多人）。  
**不要**读段落、**不要**因正文里出现某位皇帝就认定他是主轴；**不要**输出 blocks / segment_attribution / entries。

### 工作流位置（必读）

```
Step1a  著作 + 卷名 → 主人公清单（本步）→ 脚本 identity_gate 硬检
Step1b  读原文段落 → 按清单划 blocks → 展开史略
定类    主人公已锁定后 → 为每人填 category（见下「史略分类 v3」）
```

### 史略分类 v4（定 entry 时用，不是选主轴）

**八类（须逐字使用，禁止自造）**：`君王` · `诸侯` · `宗戚` · `宦官` · `文臣` · `武将` · `蕃祚` · `庶众`

> ⚠️ **`帝王.json` 有名 ≠ 分类=君王**。帝王表含天子与诸侯国君；分类按下表准入，**禁止**「能在帝王表解析 → 默认君王」。

#### 准入标准（填 category 时逐条对照）

| 史略分类 | 准入（须同时满足直觉上的主轴角色） | 禁止误填 |
|----------|-----------------------------------|----------|
| **君王** | **天下共主**：天子 / 皇帝 / 霸王级本纪共主（如周武王、秦始皇、项羽） | 封国国君、未即位宗室、同姓藩王 |
| **诸侯** | **封国/列国世袭君主**，非天下共主；世家诸侯世系主轴；秦本纪始皇前国君 | 周天子、汉皇帝；汉以后同姓藩王 |
| **宗戚** | 后妃/太后/公主；**同姓藩王**；武王弟等未以「在位国君治国」为卷主轴者（管蔡→宗戚） | 卫康叔等始封在位国君（应用诸侯） |
| **宦官** | 阉人 / 内官 / 近幸为主轴 | 受宫刑士人（司马迁→文臣） |
| **文臣** | 行政、刑名、外交、儒学、文学仕宦为主轴（孔子世家→文臣） | 仅因封侯/封王结局 |
| **武将** | 军功、征战、将帅为主轴 | 列传军功主轴却填诸侯 |
| **蕃祚** | 边陲/域外政权或部族**集体**主题（匈奴、南越等） | 华夏诸侯世系国君 |
| **庶众** | 游侠、刺客、方士、起义未称帝者等 | 国君、天子 |

#### 判定流程（按序，命中即停）

```
1. 宗戚专则（后妃 / 同姓藩王 / 管蔡类武王弟）？ → 宗戚
2. 蕃祚卷型？ → 蕃祚
3. 列传主轴偏文/武/庶？ → 文臣 / 武将 / 庶众
4. 天子 / 皇帝 / 霸王级本纪共主？ → 君王
5. 封国 / 列国世袭君主（含世家国君、秦孝公等）？ → 诸侯
6. 否则 → 不列入 protagonists
```

**同一人**多重身份冲突时，取唯一分类（**不用于**判断「这一卷写谁」）：

`君王 ＞ 宗戚 ＞ 诸侯 ＞ 宦官 ＞ 文臣/武将 ＞ 蕃祚 ＞ 庶众`

#### 硬案例（禁止再填错）

| 人物 | 正确 category | 错误 |
|------|---------------|------|
| 卫康叔、燕召公、吴太伯、齐桓公、秦孝公 | **诸侯** | 君王 |

| 管叔鲜、蔡叔度、楚元王刘交、吕太后 | **宗戚** | 君王/诸侯 |

### 任务

1. 从 **著作 + 卷名** 判断卷型（本纪 / 世家 / 列传 / 表 / 书 / 志）及叙事模式。
2. 填写 **`narrative_mode`**：
   - `skip`：表 / 书 / 志 → `protagonists: []`，须写 `skip_reason`
   - `single`：单人传或单人本纪（1 位主人公）
   - `fanzuo`：蕃祚整卷（1 个政权/部族主题，如南越）
   - `hezhuan`：多人合传（须逐段划块，排除名册段）
3. 列出本卷应独立成「史略条目」的 **核心主人公**（合传可 3–30 人）。
4. 为每位主人公给出 **category** 与 **rationale**（依据卷名与常识，**非**依据正文；rationale 须点明为何符合上表准入）。
5. **君王 / 诸侯** 的 `name` 须对照 `reference/帝王.json`「**帝王**」字段逐字一致。
6. **表 / 志 / 书** → `narrative_mode: skip`，`protagonists: []`，`skip_reason` 必填。

### narrative_mode 与划段策略

| narrative_mode | 划段 | 说明 |
|----------------|------|------|
| skip | 无 | 不建条目 |
| single / fanzuo | 整卷一块 | 排除卷首标题（**汉书有、史记无、三国志有**）、论赞段（史记`太史公曰`/汉书`赞曰`/三国志`评曰`）；**勿逐段 LLM** |
| hezhuan | 逐段 blocks | 按传记段首划界；注意同段接力；名册段不提取 |
