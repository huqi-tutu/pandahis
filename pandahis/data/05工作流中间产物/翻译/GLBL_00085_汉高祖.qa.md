# 一、总体评价

**准确度**：整体叙事忠实于《史记·高祖本纪》主线，事件顺序、主体、因果基本守恒，说书风格生动且边界大体清晰。但存在若干**新增事实无母本依据**（如“五千人”“项羽三万骑兵”“六十二岁”“大火烧了三个月”等）、**认知层级升级**（将传说/祥瑞写成确定史实）、**纪年公元注大量漏注**、**个别地名今注缺失或存疑**，以及**L3/L4 插入点脱离 S 锚点**等问题。

**最大问题**：P0 级新增事实与认知层级混淆（如“斩蛇起义”被写成“天命所归”的确定结论、项羽年龄、刘邦年龄等），以及“白登之围”地名今注缺失（程序预检已标 P1）。

**时间线**：整体顺序正确，但“汉五年”后“十月”事件（臧荼反）与“汉六年”顺序需注意（母本如此，成稿未错，但公元注缺失）。

**原典覆盖**：覆盖率高，母本连续情节无整段蒸发；但“汉王本想就此西还”后张良陈平劝进一段，成稿将劝进理由（“汉有天下太半……”）插入，属 L3 合理补充，但未标来源。

**史源/认知层级**：L1 为主，L3/L4 插入较多且多数有锚点；但“斩蛇起义”“龙气”“相面”等传说框在成稿中被部分写成确定史实（D 类），需降级处理。

**说书边界**：说书口吻自然，但部分“心理描写”“评价断语”无母本依据（F 类），需立项。

**是否达上线**：**未达上线**。存在 P0 级问题（新增事实、认知升级、纪年错注），必须修改后方可通过。

# 二、P0｜必须修改

【P0-1】类型：D（认知地位丢失）/ ⑦认知 / ⑧来源  
**原文摘录**：“斩蛇起义——刘邦是赤帝之子，斩了白帝之子，天命所归。”  
**问题**：将“斩蛇”传说直接写成“天命所归”的确定结论，且“赤帝之子”是传说框内内容，成稿用破折号引出“天命所归”作为史实结论，属认知层级升级。  
**为什么错**：母本中“白帝子”“赤帝子”是老妇人之言（传说框），《史记》并未以作者口吻确认“天命所归”。成稿将传说框内容熔接为作者判断，违反⑦⑧。  
**正确情况或建议边界**：应保留传说框，如“据说”“传说中”，或明确标注“这是当时人的说法/刘邦集团的政治宣传”。  
**依据**：《史记·高祖本纪》：“老妪曰：‘吾子，白帝子也，化为蛇，当道，今为赤帝子斩之，故哭。’”  

【P0-2】类型：F（作者越权）/ ⑦认知  
**原文摘录**：“项羽十万大军，全军覆没。”  
**问题**：成稿在垓下之战后加“项羽十万大军，全军覆没”，母本无“十万”之数，属新增事实。  
**为什么错**：母本仅言“大破之”“斩首八万”，未提项羽总兵力“十万”。成稿以作者口吻断言，无依据。  
**正确情况或建议边界**：删除“十万大军”或改为“项羽军大败，被斩首八万”。  
**依据**：《史记·高祖本纪》：“韩信乃从齐往，刘贾军从寿春并行，屠城父，至垓下。大破项羽。”  

【P0-3】类型：F（作者越权）/ ⑦认知  
**原文摘录**：“项羽三万骑兵，把刘邦五十六万大军打得溃不成军。”  
**问题**：母本未载彭城之战项羽兵力“三万”，成稿新增具体数字。  
**为什么错**：母本仅言“项羽乃西从萧，晨击汉军而东，至彭城，日中，大破汉军”，未提“三万骑兵”。  
**正确情况或建议边界**：删除“三万骑兵”或改为“项羽率精骑突袭”。  
**依据**：《史记·高祖本纪》：“项羽乃西从萧，晨击汉军而东，至彭城，日中，大破汉军。”  

【P0-4】类型：F（作者越权）/ ⑦认知  
**原文摘录**：“这时的刘邦，已经六十二岁了。”  
**问题**：母本未载刘邦生年，成稿断言“六十二岁”无依据。  
**为什么错**：刘邦生年史无明文（前256或前247两说），成稿直接断言“六十二岁”属新增事实。  
**正确情况或建议边界**：删除年龄，或标注“约”并说明史无定论。  
**依据**：待核实（《史记》《汉书》均未载刘邦生年）。  

【P0-5】类型：F（作者越权）/ ⑦认知  
**原文摘录**：“项羽，这位力能扛鼎、横扫天下的西楚霸王，终年三十一岁。”  
**问题**：母本未载项羽生年，成稿断言“终年三十一岁”无依据。  
**为什么错**：项羽生年史无明文（前232说为后世推算），成稿直接断言属新增事实。  
**正确情况或建议边界**：删除年龄，或标注“约”并说明史无定论。  
**依据**：待核实（《史记·项羽本纪》未载生年）。  

【P0-6】类型：G（时间/事件链）/ ⑤时间  
**原文摘录**：“汉元年十月（前206年）”  
**问题**：汉元年十月对应公元前206年，但汉元年十月实为前207年十月（秦历以十月为岁首，汉元年十月在公元前207年）。  
**为什么错**：秦及汉初以十月为岁首，汉元年十月在公元前207年，非前206年。  
**正确情况或建议边界**：改为“汉元年十月（前207年）”。  
**依据**：《史记·高祖本纪》：“汉元年十月，沛公兵遂先诸侯至霸上。”  

【P0-7】类型：G（时间/事件链）/ ⑤时间  
**原文摘录**：“汉五年（前202年）”  
**问题**：汉五年对应公元前202年，但垓下之战在汉五年十二月（前203年底），成稿将“汉五年”直接注为“前202年”不精确。  
**为什么错**：汉五年十二月在公元前203年（秦历以十月为岁首），成稿注“前202年”可能误导读者以为整年都在前202年。  
**正确情况或建议边界**：可注“汉五年（前203—前202年）”或“汉五年十二月（前203年）”。  
**依据**：《史记·高祖本纪》：“五年，高祖与诸侯兵共击楚军，与项羽决胜垓下。”  

【P0-8】类型：A（实体串并）/ ③主体  
**原文摘录**：“齐王田广又逃去找彭越。”  
**问题**：母本为“齐王田广亡去”，未言“去找彭越”。成稿新增“去找彭越”属主体行为改写。  
**为什么错**：母本未载田广投奔彭越，成稿断言其去向，属新增事实。  
**正确情况或建议边界**：改为“齐王田广逃走”或“齐王田广败走”。  
**依据**：《史记·高祖本纪》：“齐王田广亡去。”  

【P0-9】类型：D（认知地位丢失）/ ⑦认知  
**原文摘录**：“刘邦听了，心里那叫一个高兴——有云气罩着，这是天子气象啊！”  
**问题**：将吕后“云气”之说直接解释为“天子气象”，并以作者口吻确认，属认知升级。  
**为什么错**：母本中吕后言“季所居上常有云气”，是吕后之言（人物观点），成稿以作者口吻断言“这是天子气象”，将人物观点升级为作者判断。  
**正确情况或建议边界**：改为“刘邦听了，心里暗暗高兴——他当然愿意相信这是天子气象”。  
**依据**：《史记·高祖本纪》：“吕后曰：‘季所居上常有云气，故从往常得季。’”

# 五、P3｜语言体验（仅误导或明显不通；纯品味不立项）

【P3-1】类型：语言表达  
**原文摘录**：“他爹人称“太公”——听着像称呼，其实就是“刘老头”；他娘更简单，叫“刘媪”，翻过来就是“刘老太婆”。连个正经名字都没留下，可见这家人在乡间实在不起眼。”  
**问题**：“翻过来就是”表述略拗口，但不误导。  
**正确情况或建议边界**：可改为“就是‘刘老太婆’的意思”。
