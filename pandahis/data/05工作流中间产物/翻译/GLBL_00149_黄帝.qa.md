# 三、P1｜重要事实问题

【P1-1】类型 B 制度 / 原文摘录  
“官职都以云命名，军队也称作云师——据说这与上天显现的祥云有关。”

问题：  
“云师”不是“军队”。《史记》原文作“官名皆以云命，为云师”，《左传·昭公十七年》亦云“黄帝氏以云纪，故为云师而云名”，这里的“师”指官长/官名，整句是说黄帝以云纪官、设立云官，而不是把军队称作“云师”。

正确情况：  
宜表述为“官职都以云命名，称为云师／云官”；若涉及军队，那是后文“以师兵为营卫”的事，不应与“云师”混在一起。

依据：  
《史记·五帝本纪》  
《左传·昭公十七年》

# 四、最终事实修改清单

1. 将“军队也称作云师”的表述改为“官职以云命名，称为云师／云官”一类说法。
