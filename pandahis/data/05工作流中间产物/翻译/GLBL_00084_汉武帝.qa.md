# 一、总体评价

本篇成稿与母本重合度极高（约98%），润色不足，近乎誊抄。在仅有的少量改写中，出现了若干实质性错误：**新增的导语/过渡段存在认知层升级与史实错误**（如“在位时间最长”“巫蛊之祸”等表述与母本叙事范围不符），**正文中出现了明显的文本断裂与漏译**（如“又不止，所以把瑟破开改为二十五弦”一句严重残缺），**部分段落存在整段蒸发**（如“群臣中又见”后内容缺失）。此外，程序预检已指出弯引号未配对问题，成稿中多处引号使用混乱（「」与“”混用），且存在“空桐山（今甘肃平凉崆峒山）”等今地标注错误。整体上，成稿未达到“说书叙述”的改写要求，需进行实质性修订。

# 二、P0｜必须修改

【编号】P0-1
【类型】G（时间/事件链）+ ③（主体四元组）
【原文摘录】“汉武帝刘彻，是西汉第七位皇帝，也是中国历史上在位时间最长的君主之一。他在位五十四年……晚年更因巫蛊之祸酿成骨肉相残的悲剧。”
【问题】成稿开篇新增导语，将母本未涉及的“巫蛊之祸”作为武帝生平总结，且“在位时间最长”表述不准确（汉世宗孝武皇帝在位54年，但“中国历史上在位时间最长”需加限定——若指“西汉”则正确，若泛指“中国历史”则错误，因清圣祖在位61年、清高宗在位60年）。
【为什么错】① 母本（《史记·孝武本纪》）叙事止于武帝晚年求仙，未涉及巫蛊之祸；导语将后事（巫蛊）预支为总结，违反“禁止预支后文”原则，且将L1史实范围外内容混入。② “在位时间最长”若泛指中国历史则事实错误（清圣祖61年、清高宗60年均长于54年）。
【正确情况或建议边界】若需导语，应限定为“西汉在位时间最长的皇帝”，且不应提及母本未载的巫蛊之祸；或删除导语，直接进入母本叙事。
【依据】核心原典（《史记·孝武本纪》未载巫蛊事）；其他史料（《汉书·武帝纪》载巫蛊之祸，但属L3，不应混入L1主线）。
