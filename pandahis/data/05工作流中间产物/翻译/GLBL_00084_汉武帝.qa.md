# 一、总体评价

**准确度**：整体叙事忠实于《史记·孝武本纪》主线，事件顺序、主体四元组、因果链条大体守恒，说书体改写未破坏核心史实框架。但存在若干**认知层级升级**（将母本中的传闻/方士之言写成确定史实）、**说书人评论越权**（以全知视角断言人物心理或事件性质）、**纪年公元注缺失**、以及**个别新增事实无母本依据**等问题。

**最大问题**：① 多处将母本中“方士之言/传闻”直接写成确定事实（如“斗旗”磁石解释、鼎为“朝廷安排人埋的”等），违反⑦认知守恒；② 说书人频繁以“后世有明白人点破”“有人怀疑”等口吻插入无史源依据的评论，属F类越权；③ 全文纪年公元注严重缺失，仅个别年份有注。

**时间线**：事件先后顺序与母本一致，无倒置；但“元光元年”“元狩元年”“元封元年”“太初元年”等纪年多处缺公元并注。

**原典覆盖**：母本连续情节无整段蒸发，覆盖完整；但个别处有“概括顶替多段情节”的倾向（如封禅后巡行部分）。

**史源/认知层级**：L1（《史记》）为主，L5（说书评论）大量存在，但部分L5评论与L1史实未做清晰区隔，有熔接风险。

# 二、P0｜必须修改

**【P0-1】类型：D / ⑦认知守恒**
- **原文摘录**：“其实这斗旗的把戏，后世有明白人点破：旗杆底下埋着磁石，铁制的旗子自然相吸。可在当时，这一手就把天子唬住了。”
- **问题**：将“斗旗”解释为磁石把戏，属新增事实，母本及允许史源均无此记载；且以“后世有明白人点破”的口吻，将推测写成确定史实。
- **为什么错**：母本仅记“斗旗，那旗子竟真的自行相互碰撞起来”，未解释其原理。此处为说书人凭空添加的“揭秘”，违反⑦认知守恒（推测升级为事实）与Evidence Backtrace（无依据）。

- **依据**：核心原典《史记·孝武本纪》无此内容；【待核实】无任何史料支持。

# 三、P1｜重要问题（遗漏/时间线/史源/制度/实体…）

**【P1-1】类型：G / ⑤时间守恒（纪年并注缺失）**
- **原文摘录**：“过了三年，也就是元光元年（前134年）”“到了元狩元年（前122年）的冬天”“十一月辛巳日（前113年）”“这一年就被定为太初元年（前104年）”“五月里，汉武帝銮驾回了甘泉宫……改元为「元封元年（前110年）」”
- **问题**：全文仅上述几处有公元并注，其余大量纪年（如“即位元年”“第二年”“又过了一年”“过了三年”“第二年冬天”“这年春天”“这年夏天”“又过了一年”“第二年冬天”“此后过了两年”“这年十一月”“第二年”等）均无公元注。
- **为什么错**：按纪年并注专项规则，所有“汉×年/年号+年序”均应标注公元年份；缺注属P1。
- **正确情况或建议边界**：对全文所有纪年补充公元并注，至少覆盖关键年份（即位元年、元光、元狩、元鼎、元封、太初等）。
- **依据**：纪年并注专项规则。

**【P1-2】类型：E / ⑥范围守恒**
- **原文摘录**：“这年夏天，汉朝改定历法，以正月为一年的开始，服色崇尚黄色，官名和印章也改为五个字，这一年就被定为太初元年（前104年）。就在这一年，汉朝向西讨伐大宛，同时蝗灾大起。丁夫人、雒阳人虞初等人，用方术祭祀，诅咒匈奴和大宛。第二年，主管官员上奏说，雍地的五畤祭祀缺少熟食祭品，香气也不完备。于是命令祠官进献牛犊等祭品，按五行相克的颜色搭配，并用木偶马代替幼马。只有祭祀五帝和天子亲行郊祀时才用幼马，其余各处名山大川祭祀所用的幼马，也全部改用木偶马代替。天子出巡经过时，才用幼马祭祀。这祭祀的规矩，也随着新政，一并改换了新颜。”
- **问题**：母本中“第二年，主管官员上奏说……”至“天子出巡经过时，才用幼马祭祀”为独立段落，成稿将其与太初元年改历、伐大宛、蝗灾等事件压缩在同一段，且“这祭祀的规矩，也随着新政，一并改换了新颜”一句将祭祀改革与太初新政强行关联，属压缩失真。
- **为什么错**：母本中祭祀改革是独立事件，与太初改历无直接因果；成稿以“随着新政”建立因果，违反④因果守恒。
- **正确情况或建议边界**：将祭祀改革单独成段，删除“随着新政”的因果关联。
- **依据**：核心原典《史记·孝武本纪》原文顺序。

**【P1-3】类型：C / ⑦⑧认知来源混淆**
- **原文摘录**：“公孙卿所说的寒门，就是谷口——这谷口，在如今陕西礼泉东北一带，是泾河出山的地方，两山夹峙，地势险要。黄帝采首山之铜——这首山，在如今河南偃师一带；在荆山下铸鼎——这荆山，在如今河南灵宝一带，不是湖北那个荆山。鼎铸成后，有龙垂下胡须来迎接黄帝……”
- **问题**：母本中“公孙卿所说的寒门，就是谷口”是L1史实（太史公注释），但“黄帝采首山之铜……百姓仰望黄帝已经升天，便抱着他的弓和龙须号哭”是公孙卿转述的传说（L3他书/方士之言），成稿将两者连续叙述，未做认知层级区隔，读者会误以为“黄帝乘龙升天”是史实。
- **为什么错**：母本中“公孙卿曰”之后的内容均为方士转述的传说，属L3；成稿未加“据说”“传说”等标记，直接以叙述口吻写出，违反⑦⑧认知来源不混淆。
- **正确情况或建议边界**：在“黄帝采首山之铜”前加“据说”或“按公孙卿的说法”，明确其为传说。
- **依据**：核心原典《史记·孝武本纪》原文为公孙卿转述。

**【P1-4】类型：A / ③主体守恒**
- **原文摘录**：“又听了都禁受不住，所以把瑟破开，改成二十五弦。”
- **问题**：此句明显缺主语，且与上文“公卿们赶紧附和：‘古时候祭祀天地都有音乐……’”衔接断裂。母本原文为“泰帝使素女鼓五十弦瑟，悲，帝禁不止，故破其瑟为二十五弦”，主语是“泰帝”，成稿压缩后主语丢失。
- **为什么错**：主体四元组中“谁—做什么”被破坏，读者无法判断是谁“听了都禁受不住”。
- **正确情况或建议边界**：补全主语，如“据说泰帝让素女弹五十弦瑟，声音太悲，泰帝自己都禁受不住，才把瑟破成二十五弦”。
- **依据**：核心原典《史记·孝武本纪》。

**【P1-5】类型：G / ⑤时间守恒**
- **原文摘录**：“武帝登基那年，宫里宫外都是一股新气象。要说这位孝武皇帝，乃是孝景皇帝排行居中的儿子，母亲是王太后。孝景四年（前153年），他还只是个皇子，被封为胶东王。到了孝景七年（前150年），栗太子被废，降为临江王，胶东王便顺理成章地被立为太子。”
- **问题**：母本开篇为“孝武皇帝者，孝景中子也，母王太后。孝景四年，以皇子为胶东王。孝景七年，栗太子废为临江王，以胶东王为太子。”成稿在“武帝登基那年”之后插入“要说这位孝武皇帝……”的倒叙，但“武帝登基那年”与“孝景四年”之间时间跳跃，读者易混淆“登基那年”与“被封胶东王”的先后。
- **为什么错**：时间顺序虽未颠倒，但“登基那年”作为开篇时间锚点，与后文倒叙的“孝景四年”之间缺乏过渡，易误导读者以为“登基那年”即“被封胶东王”之年。
- **正确情况或建议边界**：在“要说这位孝武皇帝”前加“且说”或“话说”，明确为倒叙。
- **依据**：核心原典《史记·孝武本纪》。

**【P1-6】类型：E / ①事件守恒**
