## 3. 审校要点（须逐段检查）

### 3.1 幻觉与底稿一致性

- 段落中出现底稿【核心】、锚点 hard_facts、索引「主要史料出处」**均未载**的：典籍名、对话、礼制步骤、战役细节、具体官职/年份 → **fail**
- 为凑字数编造流程（如禅让全套仪式、战阵开合）而底稿无支撑 → **fail**
- 核心列举（九官、五礼等）用「提出了 N 条」概括、未逐项列名 → **fail**
- 「据说」「相传」等同句**无《书名》锚点**的发挥 → **warn 或 fail**；同句已挂《书名·卷》载则允许

### 3.2 过程禁编

- 无史料支撑的心理活动、对话、战术步骤 → **fail**
- 原文仅六字概括，正文却写火攻、阵法、兵器细节 → **fail**

### 3.3 异说、传说与史料边界

- 多版本须分述具体内容并标注来源；与正史混写为单一叙事 → **fail**
- 异说被压成一句边角料、主叙事未交代分歧 → **warn**
- 传说/神话被当作史实、无「传说/据传说」 framing → **fail**
- 只写「有后世附会」却不交代附会内容，而 anchor/维基已载 legend → **warn**
- **跨时代拼接**：其他朝代同名制度/事件细节写入本条目主叙事 → **fail**

### 3.4 整体可读性（读者视角）

- 通篇是否**完整、流畅**，读完能回答「这人/这事/这制度是什么、为何重要」 → 否则 **warn/fail**
- 是否像**在读文章**，而非质检说明、写作指南、史料边界备忘录 → **fail**
- 口语化现代政治隐喻（如「退居二线」）用于上古语境，破坏阅读感 → **warn**
- 主轴是否围绕**史略名称 + 所属朝代**；写成通史年表或枝节喧宾夺主 → **warn/fail**

**不做**：因 AI 腔词频未达 verify 阈值（≥5）而 fail（频次由 verify 管）；因缺参考著作、字数不足而 fail。

## 4. 段级 verdict 标准

| verdict | 含义 |
|---------|------|
| **pass** | 该段无实质问题 |
| **warn** | 可读性或边界有可改进处 |
| **fail** | 知识性硬伤（幻觉/禁编/异说混写）或文体严重不合格 |

`suggested_fix`：fail/warn 时给出可操作的修改方向（一句到两句），勿重写整篇。

**流水线纪律**：`overall_verdict` 的 warn/fail **均不阻断**落库与 gate；结果写入 `logs/reviews/` 并汇总至 **`logs/review_warns_汇总.md`**，由人工裁定是否改稿。
