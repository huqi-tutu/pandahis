## 0. 交付物定义（读者成稿）

### 0.1 唯一交付物

`翻译详情` 字段 = **小程序详情页直接展示给读者的正文**。不是撰写蓝图、不是锚点说明、不是质检报告。

成稿须是一篇**完整的、流畅的、适合移动端阅读**的历史专题介绍，主题可以是：

- **人物**（谁：生平、抉择、记忆点）
- **事略**（发生了什么：矛盾、经过、结果、影响）
- **典制**（定了什么规矩：痛点、运作、争议、制度史意义）
- **论著**（留下了什么：背景、主旨、影响）

### 0.2 文体标杆：《明朝那些事儿》

对齐 `historiography-compose/references/翻译规则.md` 的叙事纪律，二期在此基础上**原创编排**（无母本顺译）：

| 维度 | 要求 |
|------|------|
| 人称 | 史家第三人称；太史公是作者/叙述者，不是现场参与者 |
| 语气 | 口语化、有画面、有节奏；长短句交替；关键处可用破折号 |
| 幽默 | 来自史实反差，克制；见 §7；开篇/惨案/盖棺段不加 |
| 结构 | **像在读一篇文章**；无小标题、无列表、无百科条目感、无课件感 |
| 完整 | 读完能回答「这人/这事/这制度是什么、为何重要」；合段不悬空 |

**读者测试**（compose 自检）：把正文朗读一遍——若听起来像「编辑在给作者下指令」或「质检员在列 checklist」，即不合格。

### 0.3 禁止元叙述（编辑腔 / 说明文）

下列句式属于**工作语言**，**禁止**出现在 `翻译详情` 正文：

| 禁止类型 | 示例（勿写） |
|----------|--------------|
| 对「正文」的自指 | 「正文不载…」「正文不宜补写…」「本文硬事实…」 |
| 对「读者」的教程 | 「读者能把握的是…」「对读者而言…」「阅读的基本前提」 |
| 对「本条/本条目」的自检 | 「本条须落定…」「须覆盖…」「应留空或标注…」 |
| 对「史实边界」的方法论 | 「若谈史实边界…」「并不采此写法…」「不得当作硬事实」 |
| 对模型的禁令 | 「后世亦不得凭空补绘…」「禁止把…写入正文」 |

**允许的留白**（融入叙事，全文 **≤2 处**）：

- ✅ 「太史公只记『战于涿鹿之野，遂禽杀蚩尤』，六字带过，排兵布阵已不可考。」
- ✅ 「《史记》于此戛然而止，具体怎么打，后世只能猜测。」
- ❌ 「史料无明确记载各次交锋细节，正文不宜补写战斗场面。」

### 0.4 中间产物与交付物分离

| 产物 | 路径 / 阶段 | 是否入库展示 |
|------|-------------|--------------|
| 锚点 JSON | `06/锚点/` | 否 |
| 维基摘录 | `06/维基摘录/` | 否 |

## 1. 事实底稿与防幻觉

本流程**不是**自由发挥写通史，也**不是**仅复述单部正史。在 §0 读者文体之下，事实来源模型如下：

```
维基底稿【核心】层  →  叙事骨架与主体事实（compose 默认写作底池）
        ↓ 编排、白话化、起承转合
锚点 hard_facts   →  必须覆盖；与索引「主要史料出处」共同构成事实上限
        ↓ 冲突时以锚点/索引为准
维基底稿【延伸】层 + 锚点 legend_facts  →  合段后世影响、异说、传说（须标注）
        ↓
原创叙事（口语、画面、幽默）  →  仅改变表述，不新增无出处硬史实
```

**材料优先级**（高 → 低）：索引「主要史料出处」≈ 锚点 ＞ 维基底稿【核心】＞ 【延伸】；**【排除】层不得写入正文**。

### 1.1 可以写什么（延伸边界）

在底稿与锚点已覆盖的主线之外，**允许**用下列方式充实篇幅（尤其 S0/S1 史料稀薄条目）：

| 延伸类型 | 来源 | 写法 |
|----------|------|------|
| 制度/术语一句解释 | 维基【核心】或锚点已有专名 | 首次出现白话解释，不扩写流程 |
| 合段后世影响 | 维基【延伸】或锚点 checklist | 简略、可选；不写成通史 |
| 异说并陈 | 锚点 `legend_facts` 或维基已载分歧 | **独立成块，写出异说内容**；传世文献系 vs 出土/异说系分述 |
| 后世诠释与制度史意义 | 维基【延伸】或学界共识表述 | 须用「后世」「儒家叙述」「制度史上」等 framing，不作当时史实 |
| 叙事性留白 | 底稿与锚点均无过程细节 | 用 §0.3 允许句式，**禁止**堆叠合规口号 |

**薄史料事略**（如涿鹿、阪泉）：承/转段写**史料所记 + 政治后果 + 异说内容（若 anchor 有 legend）**，不得用整段「不能写什么」代替叙事。

### 1.2 禁止写什么（防幻觉）

- **禁止**在维基【核心】、锚点、索引出处**均未出现**处，新增：典籍名、年号、人物对话、礼制操作步骤、战役战术、具体年份
- **禁止**为达标字数编造「考察—摄政—即位」等流程细节；字数不足时改写**已有**信息点，或走 §1.1 允许的延伸类型
- **禁止**把维基【延伸】/【排除】中的**其他朝代**制度细节，拼进本条目所属朝代的主叙事
- **禁止**无锚点模糊词凑字：「有人说」「有资料说」「一般认为」「后世认为」等**单独出现、同句无《书名》**时禁止
- **传说/相传/据说**：**允许**出现（可无书名），但须克制——全文传说层触发 **≤5 处**（P3 人物 **≤7**），连续传说主叙事 **≤1 段**，合段优先；不得整篇以传说撑主体（verify `legend_dominance`）
- **禁止**用 §0.3 所列元叙述句式凑字数

### 1.3 异说（传世 vs 出土/异说系）

底稿或锚点存在多版本时（如禅让：`《尚书》《史记》` 叙述 vs `《竹书纪年》` 等）：

- 须**分块并陈**，写出各版本**具体内容**，不单方面采信，不暗示「这才是真相」
- 传说、神话须标「传说/据传说」，**可以简述传说情节**（若 anchor `legend_facts` 或维基已载），不与 hard_facts 混写为史实
- **禁止**只写「后世有附会但不采」而完全不交代附会了什么

## 3. 风格继承（一期）

| 维度 | 要求 |

## 3.5 AI 腔词频（verify 硬检，撰写时须自控）

下列词**允许偶现**，用于克制 AI 散文腔；**不是 100% 禁用**。

**词表**（与 `shared/ai_flavor_words.py` 并集，翻译+朝代共用）：  
综上所述、由此可见、众所周知、历史长河、命运齿轮、毫无疑问、此外、与此同时、值得注意的是、堪称、可谓、不啻、则是、时代洪流、拉开序幕、翻开新篇章、历史终将证明、注定、必然

**频次上限**（全文正文，不含参考著作）：

| 规则 | 阈值 | 超过则 |
|------|------|--------|
| 单词 | 每词 **≥ 5** 次 | verify **error** |
| 合计 | 全文 **≥ 5** 次 | verify **error** |

**Kimi 审校不因 AI 腔词频 fail**——频次只由 verify 管。

## 4. 注音（默认全文不注音）

面向通识文史读者，**不是**识字教辅。

- **禁止**给常见字、通识人名/地名/动物/器物注音

## 5. 开篇引入（独立一段）

- **100–200 字**，素材**仅**取自索引字段，禁止编造
- **目的**：第一句要有画面或疑问，三秒内让人想读下去
- **禁止开头**：时间地点开场白（「在上古/远古…」）、宏大抒情（「历史长河…」）、教科书定性（「最早/第一次/最重要…」）、编年体（「距离今天XXXX年前…」）
- **禁止**：以「史料很少/后世能确定的是…」开篇（元叙述）
- **策略**（择一，勿套模板）：反常切入 / 人物判词 / 矛盾拆解 / 具体场景 / 后果倒推 / 对比反差 / 文化基因 / 直给开局
- **过渡**：段末自然衔接正文；禁止空泛模板句

## 6. 引用

对齐一期 **史料翻译详录**（`historiography-compose/references/翻译规则.md` §引文）：有典籍出处时，**经典描述须引原文再译述**，不可只写白话转述。

### 6.1 原文 + 译述（撰写时即须遵守）

引用**金句、史家判断、异说原文、原文表述精妙不可替代**的句子时，须：

1. 用《书名·卷篇》或《书名》**标明出处**
2. 用**直角引号「」**（或嵌套『』）**写出史料原文**
3. 紧接**白话译述**（破折号、「意思是…」、展开画面均可）

**标准句式**（择一，勿机械套模板）：

- ✅ 「《史记》原文说『生而神灵，弱而能言』——生下来就带着一股灵气，还不会走路就能开口说话。」
- ✅ 「《吕氏春秋·贵公》用一句话点到了极致：「天下非一人之天下也，天下之天下也。」——天下不是某个人的私产。」
- ✅ 「太史公只记「战于涿鹿之野，遂禽杀蚩尤」，六字带过，排兵布阵已不可考。」
- ❌ 「《史记》只用一句话交代：黄帝居轩辕之丘，而娶于西陵之女，是为嫘祖。」（有出处、有经典句，却**缺「」原文**）
- ❌ 「《山海经》里写的是"黄帝妻雷祖，生昌意"」（**弯引号**误标史料原文）

**不必引原文**（直接白话即可）：姓名官职家世、基本身份、通识背景——见翻译规则「引用选择口诀」。

**书目 plan A 档**：`snippet_verified` 的「原文摘句」**必须**以「」写入正文并展开译述；B/C 档无 verified 摘句时不得编造原文。

### 6.2 引号分工

- **直角引号「」『』** = **史料原文**（含出土文献、异说摘句）
- **弯引号""** = 叙事中的**现代比喻、术语强调、非史书原文**的对话感表述
- **禁止**：史料原文用弯引号；把《书名》后的经典句纯白话转述而不给「」

### 6.2.1 加粗展示（小程序 SSOT）

- **唯一加粗**：直角引号「」『』**及其中的史料原文**由小程序详情页自动加粗（引号与原文同一行、不换行）
- **禁止**在 `翻译详情` 中使用 Markdown `**…**` 或其它手动加粗标记
- 强调史料原句 → 写入「」/『』；**不要**用 `**` 加粗白话、书名《》或弯引号""内容
- 与一期翻译规则「加粗展示」一致；postprocess 会剔除误写的 `**`

### 6.3 频率与其它

- **原创叙事**为主，不需逐句引原文；但**凡引则须原文+译述**（§6.1）
- **可引**：金句、史家论赞、多版本差异、关键历史判断
- **引出**：「按《史记》的写法…」「《史记》原文说…」「《汉书·某卷》补了一层意思…」
- **禁止**（无出处凑字）：「据说」「相传」「有资料说」「一般认为」
- **留白**：见 §0.3，全文 ≤2 处
- **频率**：P0/P1 约 5–10 处《》引用，其中**经典句多数应带「」**；P2/P3 约 2–5 处
- **文末**：`*参考著作：*` 须包含索引「主要史料出处」**以及正文实际引用的全部典籍**（顺序可调；正文出现过的《书名》不可遗漏；参考著作项须在正文有对应引用）
- **双端一致（撰写时即须遵守，verify 硬检）**：
  - 正文写出《书名·卷篇》时，参考著作段须**同名同卷**，禁止正文《吕氏春秋·贵公》而参考书目写《吕氏春秋·去私》
  - 成稿阶段勿手写与正文矛盾的参考著作；`compose-detail` 落盘时会按正文引用**自动合并**参考书目，模型只需保证正文引用准确
  - 若正文中某母书仅写《书名》未写卷篇，参考著作可列具体卷名，但不得与正文已写卷篇冲突

## 7. 幽默

- 来自史实反差与荒诞，非硬塞笑话
- **密度**：短篇 1–2 点；中篇 2–3 点；长篇 3–5 点（人物传记略减，见专属规则）
- **禁区**：开篇、结尾、帝王驾崩/战争伤亡/政治惨案、制度核心论述、盖棺定论段
- 有力金句处不加幽默稀释

---

## 8. 六类自动触发（首次出现须处理，后文不重复）

| 类型 | 处理 |
|------|------|
| 制度 | 简要解释，如「禅让——传给有德者而非儿子」 |
| 地名 | 标今位置；不确定写「约在今…」 |
| 人名（配角） | 一句身份定位 |
| 器物 | 解释用途 |
| 事件（背景） | 一两句背景 |
| 补充史料 | 标注出处「《某书·某卷》载…」 |

## 9. 神话/传说材料

- **可以写**传说/相传/据说（**不必**每句带《》）；须与 hard_facts 分层，不与正史混写为当时史实
- **主次**：起承转以有出处记载为主；传说宜在**合段**或段末补充，**不可当家**
- **配额**：传说触发词全文 ≤5（P3 ≤7）；连续传说主叙事 ≤1 段（verify 硬检）；传说层篇幅 **>20%** 仅 **warn** 提示，不阻断；**允许**开篇以传说切入
- 重点写**政治/社会功能**，非讲趣事；禁止浪漫化
- ✅ 「《史记》未载教蚕；相传嫘祖始教养蚕，后世尊为先蚕——此属后出说法。」
- ❌ 整篇多段都在讲相传情节、几乎无史料主干

---

## 10. 写作红线（verify/审校补充；写作时须自检）

1. **交付物**：§0 读者成稿；**禁止元叙述**（verify 可程序化检测）
2. **底稿外编造**：维基【核心】+ 锚点 + 索引出处均未载的内容 — 一律不准写（见 §1.2）
3. **过程禁编**：战斗过程、战术、对话、仪式步骤、心理活动 — 原文/底稿未载则不准编
4. **核心列举**：九德、九官、五礼等须**逐项列名**（须来自锚点或底稿，不可自造项目）
5. **异说**：多版本须在起/转段（人物：转段）**独立成块**，写出内容，不选边（见 §1.3）
6. **跨时代拼接**：不得把其他朝代同名制度/事件细节写入本条目主叙事
7. **史料稀薄**：用 §1.1 延伸类型充实，**禁止**元叙述或编造细节凑字
8. **表达**：AI 腔词频见 §3.5（verify 硬检）；禁【】、禁 `**` 加粗（见 §6.2.1）、禁小标题与列表符号、禁连续 3 段以上单句碎段；元叙述见 §0.3

## 一、段落标准

正文不含开篇引入、不含「参考著作」。具体字数下限见 prompt `## 硬性要求`（由优先级 × 史料丰度计算）。

| 级别 | 最少段落（含开篇引入另计 1 段） | 每段句数 |
|------|--------------------------------|----------|
| P0 | 7 段 | 3–8 句 |
| P1 | 5 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

开篇引入 100–200 字，独立一段，不计入上表。

## 二、起承转合（三类骨架）

篇幅占比为结构导向，非字数封顶；四职能须齐全。

### 2.1 事略（主语：事件）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代局面、核心矛盾、为何发生 |
| **承** | 时间线：导火索、各方动作、关键节点 |
| **转** | 高潮、战局/政争转折、关键决策与争议 |
| **合** | 结局、即时改变、对后世格局的影响 |

### 2.2 典制（主语：制度）

| 职能 | 写什么 |
|------|--------|
| **起** | 前制弊端、治理痛点、确立刚需 |
| **承** | 制度内核、推行流程、适用范围、配套机制 |
| **转** | 推行阻力、落地变形、史家褒贬争议 |
| **合** | 当朝成效、后续演变、制度史意义 |

### 2.3 论著（主语：作品/思想）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代思潮、社会变局、作者际遇与动机 |
| **承** | 体例结构、核心主旨、代表篇章或命题 |
| **转** | 学界争议、思想局限、时代特殊性 |
| **合** | 传播影响、史学/文化地位 |

---

## 三、内容延伸

**前提**：延伸不得突破 §1 底稿池；维基【核心】写主叙事，【延伸】写合段后世，异说走锚点 `legend_facts`。

| 类型 | 写法 |
|------|------|
| 开篇/起段 | 一两句时代背景；仅当底稿/锚点已有 |
| 中间 | 术语、制度、人物关系 — 一句说清，不扩写底稿未载流程 |
| 合段 | 后世影响、制度史意义、后世诠释（framing 须明确） |

**铁律**：底稿无则叙事性留白（§0.3），不编心理、不生拉典故、不写合规口号。

---

## 四、异说处理（多版本条目）

- 异说在**起段或转段独立成块**，不可压成文末一句脚注
- 异说块篇幅不得明显小于主叙事；不替读者选边
- ✅ 起段同时抛出两套叙事；转段分析张力；合段收束不强行调和
- ❌ 全文以主叙事为主，末尾捎带「另有说法」

---

## 五、史料稀薄条目（P2/P3 上古）

底稿与锚点有限，**不可再压缩**。用 `详情写作_共用规范.md` §1.1 允许延伸（异说并陈、后世诠释、制度史意义、叙事性留白）充实，**禁止**编造流程细节或元叙述凑字。

- [ ] **核心列举**：九州/九章等枚举须逐项列名

## 七、类型专属红线（verify/Kimi 难检，compose 须前置）

1. 事略「承/转」须有可追踪的时间线与节点，不可只有结论
2. 典制「承」须写清运作机制，不可只写「建立了XX制度」
3. 论著「承」须写清体例或核心命题，不可只写「很重要」
4. 与索引 `史略开始年` / 主要史料出处不一致 → 不合格


## 硬性要求
- **交付物**：`翻译详情` = 小程序读者正文；完整、流畅、可读；《明朝那些事儿》口语叙事（见共用规范 §0）；**禁止**编辑备注、质检说明、元叙述入正文
- 分类 论著（论著），优先级 P1，史料丰度 S0，**撰写温度 0.2**
- 正文（不含开篇引入、不含参考著作）字数不得低于 **300** 字
- **事实底稿**：书目 plan A/B 档 + 锚点 hard_facts 为叙事主体；不得在未授权材料处新增硬史实
- 起承转合齐全；开篇引入 100-200 字（独立一段）
- 段落数：P0≥7段、P1≥5段（均含开篇引入）
- 文末 *参考著作：* 须包含：**索引「主要史料出处」** + **正文实际引用的全部《书名》**（compose 落盘时会自动合并；**禁止**手写与正文卷篇矛盾的参考书目）
- **引用 ↔ 参考著作双端一致**：正文出现《书名·卷篇》时，文末须**同名同卷**；改正文典籍名须同步改参考著作（fix-detail 亦同；fix 后会按正文重合并参考书目）
- **史料原文 + 译述**（对齐一期翻译详录）：经典句、金句、异说原文须 `《书名》…「原文」——白话译述`；**禁止**仅有出处而无「」原文；**禁止**用弯引号""标史料原文（术语/比喻可用弯引号）
- 书目 plan **A 档 verified 摘句**须完整写入「」并展开译述
- 底稿无载处：用叙事性留白（§0.3），全文 ≤2 处；禁止「正文不宜…」式合规口号
- 传说/相传/据说可写但须克制（§9；verify legend_dominance）；其余模糊词仍须同句《》或删除
- 禁止【】、小标题、列表符号；**AI 腔词**（此外/综上所述/堪称 等，见共用规范 §3.5）全文合计与单词均 **< 5 次**（≥5 次 verify fail）
- 禁止编造人物心理活动（除非正史明确记载）
- **注音纪律（二期 · 默认全文不注音）**：
  - 本产品面向具备通识文史素养的读者，**不是**识字教辅/小程序
  - **禁止**给常见字、通识人名、通识地名、动物名、器物名注音
  - **仅当**正文出现下列罕用字专名时，可保留该词注音：妫汭、娵訾、少皞、帝喾、梼杌、浑沌、獬廌、獬豸、瞽叟、瞽瞍、穷奇、颛顼、饕餮、魑魅
  - 除上述白名单外，全文不得出现任何「汉字（拼音）」标注
- **书目 plan 材料档 B**：锚点 hard_facts 必覆盖；A 档可展开 verified 摘句，B 档仅书目级异说，C 档留白；**禁止** B/C 档写过程细节；字数不足用异说并陈/后世诠释/留白，**禁止**编造细节凑 300 字
