词条：禅让制

URL：https://zh.wikipedia.org/wiki/%E7%A6%85%E8%AE%A9%E5%88%B6

【核心 · 摘要】
禅让制，中国统治者更迭的一种方式，指在位君主生前便将统治权让给他人。形式上，禅让是在位君主自愿进行，是为了让更贤能的人统治国家。通常，禅让是将权力让给异姓（也包括外亲），这会导致朝代更替，称为“外禅”；而让给自己的同姓血亲，则被称为“内禅”，让位者通常称“太上皇”，不导致朝代更替。没有血缘关系的禅让更是不把权位当作一家人私有，让其给贤能的人，是一种理想的政治制度，由部落推选出来。

【核心 · 章节】（起承转主体，须充分改写）

### 起源
起源
由于远古时代生产力极为落后，人类必须依靠集体的力量，共同劳动、平均分配食物才能生活下去，因此，人们需要选举出贤能、公正的人当首领，以带领大家抵御外来侵袭，进行生产劳动和平均分配食物。

### 中国传说中的禅让
中国传说中的禅让
中国上古时期的“禅让”制度，是部落联盟推举首领或帝王让位给别人的一种方式，即部落各个诸侯表决，以多数决定。

禅让制度最早记载于《尚书》之中，但其是否真实一直存在争议。相传尧为部落联盟领袖时，四岳推举舜为继承人，尧对舜进行三年考核后，使帮助为事。尧死后，舜继位，同样用推举方式，经过治水考验，以禹为继承人。禹继位后，又举皋陶为继承人，皋陶早死，又以伯益为继承人，最后族人拥戴禹之子启为王。启继承禹而确立夏朝家天下的开始，使上古时代的禅让制度结束。

王莽新政时期，扬雄在《蜀王本纪》中记载蜀王杜宇禅让于开明。

1993年郭店一号墓出土的〈唐虞之道〉与2002年出版的《上海博物馆藏战国楚竹书》收录的〈子羔〉、〈容成氏〉三篇都记载上古的禅让。《唐虞之道》推崇禅让，指出“不禅而能化民者，自生民未之有也”。

### 对禅让传说的怀疑
对禅让传说的怀疑
许多学者与书籍质疑远古禅让传说是否真实，怀疑是后起之秀以暴力夺权，并冠上“禅让”的虚名。

《山海经·海内西经》记载：“苍梧之山，帝舜葬于阳，帝丹朱葬于阴”，亦称呼尧的儿子丹朱为“帝”。
荀子在《正论》中说：“夫曰尧舜禅让，是虚言也，是浅者之传，是陋者之说也。”
韩非子在《说疑》一文中说：“舜逼尧，禹逼舜，汤放桀，武王伐纣，此四人者，人臣弑其君者也，而天下誉之。察四王之情，贪得人之意也；度其行，暴乱之兵也。然四王自广措也，而天下称大焉；自显名也，而天下称明焉。则威足以临天下，利足以盖世，天下从之。”
《汲冢琐语》云：“舜放尧于阳，而书云某地有城，以囚尧为号识者，凭斯异说，颇以禅受为疑”。
《广弘明集》十一引《汲冢竹书》云：“舜囚尧于平阳，取之帝位，今见有囚尧城”
曹丕篡位汉献帝后，跟群臣说：“舜、禹之事，吾知之矣。”（《三国志·文帝纪·魏氏春秋注》）

### 中国历史上的禅让
中国历史上的禅让
最早信史有记载的禅让，发生在燕国，由燕王哙禅让王位于宰相子之，这次是一次自愿禅让，动机是燕王哙希望效法尧禅让的故事。

中国历史上的王朝更替，也有以禅让之名，行夺权之实。此等所谓禅让，都是朝中权臣胁迫皇帝退位，而由于继承者是当政者的臣子，为避免“不忠”的骂名，就打着禅让之旗号，以取得正统。

因此，以禅让而灭亡某一朝代，史书中也多表述为“篡”（如“王莽篡汉”、“曹丕篡汉”），而若外部武力直接推翻某一朝代，则用“灭”（如“元灭宋”）、（如“清灭明”），以表明某种价值判断。

## 0. 事实底稿与防幻觉（本流程核心）

本流程**不是**自由发挥写通史，也**不是**仅复述单部正史。成稿模型如下：

### 0.1 可以写什么（延伸边界）

在底稿与锚点已覆盖的主线之外，**允许**且**鼓励**用下列方式充实篇幅（尤其 S0/S1 史料稀薄条目）：

| 制度/术语一句解释 | 维基【核心】或锚点已有专名 | 首次出现白话解释，不扩写流程 |

### 0.2 禁止写什么（防幻觉）

- **禁止**在维基【核心】、锚点、索引出处**均未出现**处，新增：典籍名、年号、人物对话、礼制操作步骤、战役战术、具体年份
- **禁止**为达标字数编造「考察—摄政—即位」等流程细节；字数不足时改写**已有**信息点，或走 §0.1 允许的延伸类型

- **禁止**无出处模糊词凑字：「据说」「相传」「有资料说」「一般认为」
- **允许**有出处的明确留白：「史料无明确记载」「《某某》未载」

### 0.3 异说（传世 vs 出土/异说系）

底稿或锚点存在多版本时（如禅让：`《尚书》《史记》` 叙述 vs `《竹书纪年》` 等）：

## 4. 开篇引入（独立一段）

- **100–200 字**，素材**仅**取自索引字段，禁止编造
- **目的**：第一句要有画面或疑问，三秒内让人想读下去
- **禁止开头**：时间地点开场白（「在上古/远古…」）、宏大抒情（「历史长河…」）、教科书定性（「最早/第一次/最重要…」）、编年体（「距离今天XXXX年前…」）
- **策略**（择一，勿套模板）：反常切入 / 人物判词 / 矛盾拆解 / 具体场景 / 后果倒推 / 对比反差 / 文化基因 / 直给开局
- **过渡**：段末自然衔接正文；禁止「这场看似突发的动荡，实则是…」「为破解长期困扰…」等空泛模板句

---

## 5. 引用

- **原创叙事**，不需逐句引原文；引用为增信或保留金句
- **直角引号「」『』** = 史料原文；**弯引号""** = 叙事中人物对话（非史书原文）；禁止混用
- **可引**：金句、史家论赞、原文无法替代的精彩表达、多版本差异
- **不引**：姓名官职家世等基本身份信息（直接白话）
- **引出**：「按《史记》的写法…」「《史记》原文说『…』——」「《汉书·某卷》补了一层意思…」
- **禁止**（无出处凑字）：「据说」「相传」「有资料说」「一般认为」
- **允许**（诚实留白，见 §0.2）：「史料无明确记载」「传世文献未载…」——须与 §0 底稿约束联用，不可接编造内容
- **频率**：P0/P1 约 5–10 处；P2/P3 约 2–5 处
- **文末**：`*参考著作：*` 列表须与索引 `主要史料出处` **100% 匹配**（顺序可调，书目不可增删）

---

## 6. 幽默

- 来自史实反差与荒诞，非硬塞笑话
- **密度**：短篇 1–2 点；中篇 2–3 点；长篇 3–5 点（人物传记略减，见专属规则）
- **禁区**：开篇、结尾、帝王驾崩/战争伤亡/政治惨案、制度核心论述、盖棺定论段
- 有力金句处不加幽默稀释

---

## 7. 六类自动触发（首次出现须处理，后文不重复）

| 类型 | 处理 |
|------|------|
| 制度 | 简要解释，如「禅让——传给有德者而非儿子」 |
| 地名 | 标今位置；不确定写「约在今…」 |
| 人名（配角） | 一句身份定位 |
| 器物 | 解释用途 |
| 事件（背景） | 一两句背景 |
| 补充史料 | 标注出处「《某书·某卷》载…」 |

---

## 8. 神话/传说材料

- 须标「传说」/「据传说」，与正史叙事区分
- 重点写**政治/社会功能**，非讲趣事；禁止浪漫化
- ✅ 「说穿了，这就是上古版的测谎仪。皋陶未必真靠神兽断案，但他太懂人性了…」

---

## 9. 写作红线（verify/审校补充；写作时须自检）

下列项 **verify 或 Kimi 会拦**，compose 阶段须前置遵守：

1. **底稿外编造**：维基【核心】+ 锚点 + 索引出处均未载的内容 — 一律不准写（见 §0.2）
2. **过程禁编**：战斗过程、战术、对话、仪式步骤、心理活动 — 原文/底稿未载则不准编
3. **核心列举**：九德、九官、五礼等须**逐项列名**（须来自锚点或底稿，不可自造项目）
4. **异说**：多版本须在起/转段（人物：转段）**独立成块**，不选边（见 §0.3）
5. **跨时代拼接**：不得把其他朝代同名制度/事件细节写入本条目主叙事
6. **史料稀薄**：不可再压缩；用 §0.1 允许延伸类型充实，**禁止**用编造细节凑字
7. **表达**：禁 AI 腔、禁【】、禁小标题与列表符号、禁连续 3 段以上单句碎段

## 一、段落标准

正文不含开篇引入、不含「参考著作」。具体字数下限见 prompt `## 硬性要求`（由优先级 × 史料丰度计算）。

|------|--------------------------------|----------|
| P0 | 7 段 | 3–8 句 |
| P1 | 5 段 | 3–8 句 |
| P2 | 3 段 | 2–6 句 |
| P3 | 2 段 | 2–6 句 |

开篇引入 100–200 字，独立一段，不计入上表。

## 二、起承转合（三类骨架）

篇幅占比为结构导向，非字数封顶；四职能须齐全。

### 2.1 事略（主语：事件）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代局面、核心矛盾、为何发生 |
| **承** | 时间线：导火索、各方动作、关键节点 |
| **转** | 高潮、战局/政争转折、关键决策与争议 |
| **合** | 结局、即时改变、对后世格局的影响 |

### 2.2 典制（主语：制度）

| 职能 | 写什么 |
|------|--------|
| **起** | 前制弊端、治理痛点、确立刚需 |
| **承** | 制度内核、推行流程、适用范围、配套机制 |
| **转** | 推行阻力、落地变形、史家褒贬争议 |
| **合** | 当朝成效、后续演变、制度史意义 |

### 2.3 论著（主语：作品/思想）

| 职能 | 写什么 |
|------|--------|
| **起** | 时代思潮、社会变局、作者际遇与动机 |
| **承** | 体例结构、核心主旨、代表篇章或命题 |
| **转** | 学界争议、思想局限、时代特殊性 |
| **合** | 传播影响、史学/文化地位 |

---

## 三、内容延伸

**前提**：延伸不得突破 §0 底稿池；维基【核心】写主叙事，【延伸】写合段后世，异说走锚点 `legend_facts`。

| 类型 | 写法 |
|------|------|
| 开篇/起段 | 一两句时代背景；仅当底稿/锚点已有 |
| 中间 | 术语、制度、人物关系 — 一句说清，不扩写底稿未载流程 |
| 合段 | 后世影响、制度史意义、后世诠释（framing 须明确） |

**铁律**：底稿无则留白（「史料无明确记载」），不编心理、不生拉典故。

---

## 四、异说处理（多版本条目）

- 异说在**起段或转段独立成块**，不可压成文末一句脚注
- 异说块篇幅不得明显小于主叙事；不替读者选边
- ✅ 起段同时抛出两套叙事；转段分析张力；合段收束不强行调和
- ❌ 全文以主叙事为主，末尾捎带「另有说法」

---

## 五、史料稀薄条目（P2/P3 上古）

底稿与锚点有限，**不可再压缩**。用 `详情写作_共用规范.md` §0.1 允许延伸（异说并陈、后世诠释、制度史意义、诚实留白）充实，**禁止**编造流程细节凑字。

## 七、类型专属红线（verify/Kimi 难检，compose 须前置）

1. 事略「承/转」须有可追踪的时间线与节点，不可只有结论
2. 典制「承」须写清运作机制，不可只写「建立了XX制度」
3. 论著「承」须写清体例或核心命题，不可只写「很重要」
4. 与索引 `史略开始年` / 主要史料出处不一致 → 不合格


## 硬性要求
- 分类 典制（典制），优先级 P0，史料丰度 S1，**撰写温度 0.2**
- 正文（不含开篇引入、不含参考著作）字数不得低于 **700** 字
- **事实底稿**：维基底稿【核心】+ 锚点 hard_facts 为叙事主体；不得在三者（底稿核心/锚点/索引出处）均未载处新增硬史实
- 起承转合齐全；开篇引入 100-200 字（独立一段）
- 段落数：P0≥7段、P1≥5段（均含开篇引入）
- 文末 *参考著作：* 与主要史料出处一致
- 底稿无载处：「史料无明确记载」；禁止「据说/相传」及编造流程凑字
- 禁止【】、禁止 AI 腔、禁止禁词（此外/与此同时/则是/必然 等）
- 禁止编造人物心理活动（除非正史明确记载）
- **注音纪律（二期 · 默认全文不注音）**：
  - 本产品面向具备通识文史素养的读者，**不是**识字教辅/小程序
  - **禁止**给常见字、通识人名、通识地名、动物名、器物名注音
  - **仅当**正文出现下列罕用字专名时，可保留该词注音：妫汭、娵訾、少皞、帝喾、梼杌、浑沌、獬廌、獬豸、瞽叟、瞽瞍、穷奇、颛顼、饕餮、魑魅
  - 除上述白名单外，全文不得出现任何「汉字（拼音）」标注
- **史料丰度 S1**：以维基底稿【核心】+ 锚点为主；字数不足时用异说并陈、后世诠释、制度史意义、诚实留白充实，**禁止**编造礼制步骤/对话/战役细节凑 700 字
