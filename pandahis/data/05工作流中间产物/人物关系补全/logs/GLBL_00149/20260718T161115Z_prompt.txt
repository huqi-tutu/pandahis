# 硬性要求

1. **只输出一个 JSON 数组**，不要 markdown 说明、不要代码块外的文字。
2. 每条记录字段：`关联史略名称`、`关系ID`、`关系类别`、`关系层级`、`关系节点标题`、`上级连接线标题`、`关系简述`；层级 ≥ 二级时填 `所属一级关系` 等链字段（见 schema）。
3. `关联史略名称` 固定为 **黄帝**。
4. `关系类别` 只能是：**家庭、同僚、师从、外敌**（禁止 君臣/敌对 旧名）。
5. 任意路径 **最多四级**；禁止五级与 `所属四级关系`。
6. 无可靠史料不编造；`关系简述` 1–2 句写依据要点。
7. `关系ID` 建议前缀：HD-FAM / HD-COL / HD-MAS / HD-FOE。

# 关系 taxonomy（SSOT）

# 关系数据整理提示词

## 适用范围

**仅适用于人物类史略**：君王、宗戚、文臣、武将、宦官、庶众。

以下类型**不收集、不整理**关系数据：事略、典制、论著、蕃祚。

---

## 总则

1. 关系图谱只收 **四大关系类别**：**家庭、同僚、师从、外敌**。
2. 从**史略主题人物**起算，任意一条展开路径**最多四级**（一级 → 二级 → 三级 → 四级）。
3. **关系类别**（家庭 / 同僚 / 师从 / 外敌）是分组字段，**不计入**上述四级。
4. 同层可并列多个节点（多位配偶、多位子女、多位臣子等），**不得**为凑层级而机械扩展。
5. 无可靠史料支撑的节点**不写入**；不适用的子类**留空**。

### 字段对应

| 字段 | 含义 |
|------|------|
| `关系类别` | 家庭 / 同僚 / 师从 / 外敌 |
| `关系层级` | 一级 / 二级 / 三级 / 四级 |
| `所属一级关系` | 该类别下的子类（见下文各节） |
| `所属二级关系` | 上一级节点名称 |
| `所属三级关系` | 上两级节点名称 |
| `所属四级关系` | 上三级节点名称 |

---

## 一、家庭

家庭下设三个**平行**子类：**父母、配偶、兄弟姐妹**。

### 1.1 父母

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 父母 | — |
| 二级 | 父亲、母亲 | **否**（叶节点） |

### 1.2 配偶

每位配偶各走一条独立分支。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 配偶 | — |
| 二级 | 各配偶（丈夫 / 妻子 / 正妻 / 侧室 / 妃嫔等，有几位写几位） | 是 |
| 三级 | 该配偶所属之子嗣（每位子女单独成节点） | 是 |
| 四级 | 该子女的子女（孙辈） | **否**（叶节点） |

### 1.3 兄弟姐妹

兄弟姐妹**不与父母合并**，与父母、配偶**平行**成类；以其后代向下展开。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 兄弟姐妹 | — |
| 二级 | 各位兄弟姐妹（并列） | 是 |
| 三级 | 该兄弟姐妹的子女 | 是 |
| 四级 | 该子女的子女（孙辈） | **否**（叶节点） |

### 家庭示例

**黄帝 · 配偶支**

```
关系类别：家庭
一级：配偶 → 二级：嫘祖 → 三级：昌意 → 四级：（昌意之子，若有可靠史料）
```

**某人物 · 兄弟姐妹支**

```
关系类别：家庭
一级：兄弟姐妹 → 二级：×× → 三级：××之子 → 四级：××之孙
```

---

## 二、同僚

适用于在朝政 / 政治体系中与他人产生共事关系的人物。下设四个**平行**子类：**君王、臣子、同僚、敌对**。

> **与同僚·敌对的区别**：本节「敌对」指**共事体系内部**的敌人；**外部阵营**的对手归入 **外敌**（第四节）。

### 2.1 君王

主题人物**曾作为臣子**时所效忠的君主。

- 例：舜既是君王，也是尧的臣子 → 在舜的图谱中，**君王**子类下写 **尧**。
- 若主题从未为臣，此子类留空。

### 2.2 臣子

主题人物**作为君主**时的臣属。

- 例：舜为君时，**臣子**子类下写禹等大臣。
- 若主题从未为君，此子类留空。

### 2.3 同僚

与主题**共事**、且**非敌对**的人物（同朝同僚、同阵营合作者等）。  
**判定**：在同一政治 / 共事体系内，只要不是敌对，就归入同僚。

### 2.4 敌对

与主题**共事**（同一政治体系 / 同一职场），但属**明确敌对关系**的人物（政敌、权斗对手、同朝相争者等）。

### 同僚层级（四类通用）

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 君王 / 臣子 / 同僚 / 敌对 | — |
| 二级 | 具体人物（可并列多位） | **否**（叶节点） |

同一人物可同时出现在不同子类（如舜：君王子类填尧，臣子子类填禹）。

---

## 三、师从

下设两个**平行**子类：**老师、徒弟**。

### 3.1 老师

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 老师 | — |
| 二级 | 各位老师（并列） | 是 |
| 三级 | 该老师的徒弟 | 是 |
| 四级 | 上述徒弟的徒弟 | **否**（叶节点） |

### 3.2 徒弟

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 徒弟 | — |
| 二级 | 各位直接徒弟（并列） | 是 |
| 三级 | 该徒弟的徒弟 | 是 |
| 四级 | 上述徒弟的徒弟 | **否**（叶节点） |

### 师从示例

**孔子 · 徒弟支**

```
关系类别：师从
一级：徒弟 → 二级：子路 → 三级：子路门下某弟子 → 四级：该弟子之徒弟
```

**孔子 · 老师支**

```
关系类别：师从
一级：老师 → 二级：老子 → 三级：老子门下某弟子 → 四级：该弟子之徒弟
```

---

## 四、外敌

**外部**敌对阵营人物，与 **同僚·敌对**（身边共事之敌）严格区分。

| 层级 | 内容 | 是否继续展开 |
|------|------|--------------|
| 一级 | 外敌 | — |
| 二级 | 具体外敌人物（敌国君主、敌营将领、明确属外部阵营的对手；可并列多位） | **否**（叶节点） |

适用：敌国、敌营、明确外部阵营的对立者。  
不适用：同朝政敌、同朝权斗对手 → 归入 **同僚·敌对**。

---

## 停止展开规则

满足任意一项，即停止继续向下展开：

1. 已达到四级。
2. 该子类规则规定为叶节点（父母二级、同僚二级、外敌二级等）。
3. 后续节点无可靠史料。
4. 后续节点已有独立人物史略，可由其自身关系图继续展开。
5. 继续展开不能增加对当前主题人物的理解。

---

## 完整性要求

- 遵循 **「宁可完整，不可无限扩张」** 原则。
- 每个适用子类优先保证 **一级、二级** 完整（该写的直接关联人物不遗漏）。
- 家庭、师从按上表规则决定是否展开至三级、四级。
- 同僚、外敌以 **二级人物并列** 为主，不向下递归。
- 不得为凑满四级而编造节点；不得因机械套用模板而遗漏关键人物。


# JSON 字段说明

# 人物关系 JSON Schema

产出路径：`data/07人物关系/{关联史略名称}关系表.json`

文件为 **JSON 数组**，每条记录对应图谱中的一个节点。

## 记录字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `关联史略名称` | 是 | 主题人物（与文件名 `{名称}关系表.json` 一致） |
| `关系ID` | 是 | 文件内唯一；建议前缀见下表 |
| `关系类别` | 是 | `家庭` \| `同僚` \| `师从` \| `外敌` |
| `关系层级` | 是 | `一级` \| `二级` \| `三级` \| `四级` |
| `关系节点标题` | 是 | 人物或实体的展示名 |
| `上级连接线标题` | 是 | 与上一节点的关系边标签（见下节） |
| `关系简述` | 是 | 1–2 句，含史料依据要点 |
| `所属一级关系` | 条件 | 层级 ≥ 二级时必填；值为**上一级节点标题** |
| `所属二级关系` | 条件 | 层级 ≥ 三级时必填 |
| `所属三级关系` | 条件 | 层级 ≥ 四级时必填 |
| `所属四级关系` | 条件 | 新 schema **不使用**（最大层级为四级节点本身） |
| `record_id` | 否 | 外部系统 ID；新建可省略 |

### 关系ID 前缀建议

| 前缀 | 关系类别 | 示例 |
|------|----------|------|
| `HD-FAM-` | 家庭 | `HD-FAM-001` |
| `HD-COL-` | 同僚 | `HD-COL-001` |
| `HD-MAS-` | 师从 | `HD-MAS-001` |
| `HD-FOE-` | 外敌 | `HD-FOE-001` |

## Taxonomy → JSON 映射

SSOT（`关系数据整理提示词.md`）中的**子类**通过 `上级连接线标题` 表达；`所属*关系` 字段存**人物节点名链**，不存子类名。

### 家庭

| 子类 | 一级节点写法 | 上级连接线标题示例 |
|------|--------------|-------------------|
| 父母 | 父亲/母亲直接为**一级** | `父亲`、`母亲` |
| 配偶 | 各配偶为**一级** | `妻子`、`丈夫`、`正妃`、`侧室` |
| 兄弟姐妹 | 各兄弟姐妹为**一级** | `兄弟`、`姐妹`、`兄`、`弟`、`姐`、`妹` |
| 配偶下游 | 二级起 | `儿子`、`女儿` → 三级 `儿子`/`女儿`（孙辈） |
| 兄弟姐妹下游 | 二级起 | `儿子`、`女儿` → 三级 → 四级（孙辈） |

### 同僚

| 子类 | 上级连接线标题（推荐） | 层级 |
|------|------------------------|------|
| 君王 | `君王` | 一级 |
| 臣子 | `臣子`、`大臣`、`相`、`史官` 等职务边 | 一级 |
| 同僚 | `同僚` | 一级 |
| 敌对（共事之敌） | `敌对`、`政敌` | 一级 |

`关系类别` 统一为 **`同僚`**，子类靠边标签区分。

### 师从

| 子类 | 一级边标签 | 下游 |
|------|-----------|------|
| 老师 | `老师`、`问医`、`问道` | 二级起：该老师门下 → 最多至四级 |
| 徒弟 | `徒弟`、`弟子` | 二级起：徒孙链 → 最多至四级 |

### 外敌

| 层级 | 写法 |
|------|------|
| 一级 | 边标签：`外敌`、`阪泉之战`、`涿鹿之战` 等事件边；节点为外部对手 |
| 二级 | **禁止**（外敌不向下展开） |

`关系类别` 为 **`外敌`**（勿与 `同僚·敌对` 混用）。

## 层级与 `所属*关系` 链

- **一级**：无 `所属*关系` 字段。
- **二级**：`所属一级关系` = 其直接上级**节点标题**（如 `嫘祖`）。
- **三级**：`所属一级关系` + `所属二级关系` 构成完整链。
- **四级**：填至 `所属三级关系`；**不要**再出现 `所属四级关系` 或 `关系层级: 五级`。

链上每一环的 `关系节点标题` 必须在该文件中存在且层级递增一致。

##  legacy 样例迁移说明

`黄帝关系表.json` 为历史导入样例，存在：

- `关系类别: 君臣` → 新产出改为 **`同僚`**（边标签保留 `大臣` 等）
- `关系类别: 敌对` 且为炎帝/蚩尤 → 新产出改为 **`外敌`**
- `关系层级: 五级` → **禁止**；四级为叶节点，更远后代由该人物自有关系表承担

新文件 `--strict` 校验按新 schema；旧文件可不带 `--strict` 仅作格式参考。

## 04史料翻译 · GLBL_00149_黄帝.json

把一个人写进史书的第一页，这事本身就有分量。两千多年前，司马迁翻遍残简、访遍故老，最终决定让黄帝来打这个头阵。那一刻他就知道：信史和神话搅在一起，有些事没法考证，但必须有个人站出来，把一个民族的根给扎下去。从黄帝开始，历朝历代的家谱有了源头，这片土地上的人，也有了同一个祖先的名字。

翻开《史记》，第一篇就是「五帝本纪」，而五帝打头阵的，正是黄帝。在那个神话与信史还没完全分开的时代，司马迁选择以黄帝作为这部伟大史书的起点——从此，散落在各处的碎片传说，被整合进了一个有血有肉的始祖形象里。我们如今说自己是炎黄子孙，这根情感纽带，最早就是从这里系上的。

黄帝，是少典的儿子，姓公孙，名字叫轩辕。这个人的出生就透着不寻常。《史记》原文说他「生而神灵，弱而能言，幼而徇齐，长而敦敏，成而聪明」——生下来就带着一股灵气，还不会走路的时候就能开口说话；幼年时思维敏捷、反应极快，长大后朴实又机敏，成年以后更是耳聪目明、通达事理，总之不是一般人。

轩辕生活的年代，正赶上神农氏那一套不行了。《史记》说「轩辕之时，神农氏世衰」，炎帝后裔的权威已经罩不住场子。当时的天下乱成什么样子呢？「诸侯相侵伐，暴虐百姓，而神农氏弗能征」——各地诸侯你打我、我打你，老百姓的日子苦不堪言，而名义上的共主神农氏呢？管不了，也打不过，只能眼睁睁看着天下一天天烂下去。

既然别人靠不住，那就自己来。轩辕的办法简单粗暴，但管用——「於是轩辕乃习用干戈，以征不享，诸侯咸来宾从」。他开始练兵备战，谁敢不听话、不来朝贡，就带兵打谁。效果立竿见影，诸侯们纷纷跑来归顺投降，全成了他的小弟。

不过这时候还有个更大的麻烦在等着他。「而蚩尤最为暴，莫能伐」——蚩尤是当时最凶悍的一个，谁也不敢惹，谁也打不赢。就连轩辕此时也没对他动手，这个人到底有多猛，可想而知。《述异记》载：蚩尤这个人身子上长着人的躯干却顶着一双牛蹄，脑袋上长了四只眼睛、身上长了六条胳膊，铜头铁额，坚硬无比，连沙子和石子都能当饭吃。这幅形象搁在战场上一摆，谁见了不头皮发麻？别说打了，光站那儿就足够瘆人。

与此同时，原来的老大哥炎帝也不甘寂寞，「炎帝欲侵陵诸侯」，想在这个乱世里重新抖一抖威风。诸侯们权衡了一下利弊，与其被炎帝欺负，不如投靠能打的轩辕——于是「诸侯咸归轩辕」。这样一来，轩辕手里有了足够的兵，也有了出兵的名义。

面对炎帝这个对手，轩辕不是光蛮干的。他在动手之前做了一套非常扎实的准备工作。《史记》用了一串四字短句来描述：「轩辕乃修德振兵，治五气，蓺五种，抚万民，度四方，教熊罴貔貅貙虎，以与炎帝战於阪泉之野」。什么意思呢？对内修德政、整治军队，研究四时五行之气，推广五谷耕种以保障后勤，安抚民众稳定后方，丈量规划四方的土地；对外呢，训练了一支以「熊」「罴」「貔」「貅」「貙」「虎」这些猛兽为图腾的部队。这事听着玄乎，难道真拉了一群熊和老虎上战场？《列子·黄帝》载：黄帝与炎帝战于阪泉之野，的确是以熊、罴、狼、豹、貙、虎这些猛兽为前驱，但同时还以雕、鹖、鹰、鸢这些猛禽为旗帜。说白了，这不是真赶着野兽去咬人，而是各部落把自己的图腾顶在头上、画在旗上，熊部落的勇士就是「熊」，虎部落的精兵就是「虎」，旗帜一打出来，远远望去就是一队虎狼之师压过来，威慑力拉满。带着这支虎狼之师，跟炎帝在阪泉的旷野上展开决战。

仗打得很艰苦，「三战，然后得其志」——打了三次（这里的「三」很可能不是正好三次，而是多次的意思），才终于打赢，把炎帝打服了。

但事情还没完。刚解决了炎帝，那个最难缠的蚩尤开始动手了。「蚩尤作乱，不用帝命」——他不服从轩辕的号令，公然掀桌子造反。这时候的轩辕已经不再是当初那个地方领袖了，他有了实质性的权威，所以蚩尤不听，就等于挑战整个秩序。

「於是黄帝乃徵师诸侯，与蚩尤战於涿鹿之野，遂禽杀蚩尤。」轩辕——现在该叫他黄帝了——调集了各路诸侯的军队，在涿鹿（今河北涿鹿）的旷野上和蚩尤展开了一场决定性的战役。结果是大获全胜，活捉了蚩尤，当场斩杀。不过关于这场仗到底怎么打赢的，还有另一个版本。《山海经·大荒北经》载：蚩尤在战场上请来了风伯和雨师，掀起漫天狂风暴雨，黄帝的军队被打得睁不开眼、站不住脚。这时候黄帝从天上请下了一位叫「魃」的天女，这位天女是旱神，她一落地，风雨立刻停歇，水汽蒸干，蚩尤的狂风暴雨阵就这么被破了，黄帝趁机进兵，遂杀蚩尤。司马迁写《史记》的时候把这段删了，但删之前的上古传说就是这么讲的。

此战之后，再没有人敢叫板了。「而诸侯咸尊轩辕为天子，代神农氏，是为黄帝」——诸侯们共同推举轩辕做天子，取代神农氏，这就是黄帝。注意「是为黄帝」四个字，「是」是「这」，「为」是「成为」，整个意思就是「这就成了黄帝」。他正式拥有了这个称号，成了天下共主。

但坐天下可不比打天下轻松。「天下有不顺者，黄帝从而征之，平者去之，披山通道，未尝宁居」——总有些人不服气，黄帝二话不说，带兵就去征讨；打平了就撤，从不赖在那儿不走；为了行军的需要，他一路开山修路、打通各处险阻，忙得脚不沾地，从来没有在一个地方安安稳稳地住过。

来看看他这一生到底跑了多少地方。往东走，「东至于海，登丸山，及岱宗」——一直到了大海边上，登上了丸山，还到了泰山（也就是岱宗，五岳之尊）。往西走，「西至于空桐，登鸡头」——最西边到了空桐山（也就是今天甘肃平凉的崆峒山），登上了鸡头山。往南走，「南至于江，登熊、湘」——最南边到了长江，登上了熊山和湘山（大概在今天的湖南益阳一带）。

往北就更热闹了。「北逐荤粥，合符釜山，而邑于涿鹿之阿」——北边驱逐了荤粥（xūn yù，这两个字念「熏预」，是后来匈奴人的祖先），然后在釜山召集诸侯会盟验符信，确立权力关系，最后在涿鹿山脚下建了自己的都邑。关于他征伐四方的足迹，《帝王世纪》还补充了不少细节：黄帝往东到了海边，往西到了崆峒山，往南到了长江，往北逐走了荤粥，东南西北跑了个遍，每到一处都亲自登山勘察地形、接见部落首领，路上遇到过瘴气，遇到过叛乱的部落，遇到过高山阻路，全凭一身硬本事一关一关闯过来，没有一天不是在行军和扎营之间度过的。

不过你可别以为黄帝从此就住进了宫殿、过上了安稳日子。「迁徙往来无常处，以师兵为营卫」——他照样带着人马到处迁徙，没有一个固定的住处，走到哪儿，军队就在哪儿扎营，营帐就是他的宫殿，士兵就是他的护卫。这完全还是一种游牧时代的行国作风，创业者的本色一点没变。

治理的架子搭起来后，黄帝开始给这个新国家打上自己的烙印。他的第一个动作，是把整个官僚系统的名字都给改了。《史记》原文说「官名皆以云命，为云师」——所有官职，一律用「云」来命名。比如春官叫青云，秋官叫白云，就连军队也统称为「云师」。这个做派带着浓厚的图腾崇拜色彩，也让人一眼就能看出，这是一个以云为徽号的族群在当家作主。

光改名字当然不够，还得有人去盯着那些散布各地的部落方国。于是黄帝又「置左右大监，监于万国」——在中央设置了左大监和右大监，他们的活儿就是分片包干，监察管理天下数以万计的部落。「万国」自然不是实数，但说明管理的疆域和复杂度已经远超从前。

这套制度一运转，效果就出来了。「万国和」——各部落之间实现了罕见的和睦，谁也不轻易跟谁动手了。而伴随和平而来的，是「鬼神山川封禅与为多焉」，祭祀鬼神山川的活动、在泰山上举办的封禅大典，都比以往任何一个时代更频繁、更盛大。封禅这玩意儿，向来是帝王功业大成之后才有资格搞的最高规格仪式。搞得多，本身就等于在宣告：天下太平了。

典礼搞得多，手里也得有硬家伙。司马迁接着写了四个字：「获宝鼎，迎日推筴」。宝鼎在当时可不只是值钱的青铜器，它是受命于天的祥瑞，拿到它，意味着你这个位子坐得名正言顺。有了宝鼎撑腰，黄帝又着手搞了件更务实的大事：「迎日推筴」——通过观测太阳运行来推算历法，制定出一套指导农业生产的身时体系。在那个靠天吃饭的年代，这比什么都实在。

历法有了，还得有人去推行。黄帝物色了四个能人，史书上记下了他们的名字：「举风后、力牧、常先、大鸿以治民。」风后是军师，善于谋略；力牧是战将，能征善战；常先和大鸿也各有各的本事。这四大贤臣分头操持政务，替黄帝把国家机器运转得顺顺当当。

好，到了这里，《史记》的笔锋突然从制度、历法、人事上抬了起来，写了四组八个字，给黄帝的思维方式盖了个章：「顺天地之纪，幽明之占，死生之说，存亡之难。」这四句话讲的是黄帝作为思想家的那一面——他顺应天地自然运转的根本法则，探究阴阳变化背后那些隐微的征兆，把生命的规律琢磨透，把安危存亡的关键掰扯清楚。他在思考的问题，已经超出了柴米油盐，触到了世界怎么运转、人怎么活着这类根本性的命题。

想得深，干得也踏实。在具体事务上，司马迁又给出一组排比：「时播百穀草木，淳化鸟兽虫蛾，旁罗日月星辰水波土石金玉，劳勤心力耳目，节用水火材物。」意思是黄帝带领大家按农时播种百谷草木，驯化各种鸟兽昆虫；他的视野不止是脚下那块地，还广撒网地观测日月星辰、水波土石金玉这些自然界的运行；他自己呢，劳心劳力，眼观六路耳听八方，累是真累；但在用度上，又极其克制，水、火、木材这些自然资源，从来不糟蹋。

这么一套组合拳打下来，天意也开始表态。「有土德之瑞，故号黄帝。」按五德终始说的逻辑，每个朝代都对应五行中的一德。黄帝的时代出现了土德的祥瑞——传说是黄龙现身、或者大地冒出巨大的蚯蚓——既然跟土德对上了号，而土在五行中对应黄色，那么「黄帝」这个尊号就再合适不过了。

功业讲完，该交代香火了。「黄帝二十五子，其得姓者十四人。」黄帝一共有二十五个儿子，其中获得正式姓氏的有十四个。在上古社会组织的规矩里，「得姓」不只是户口本上有个名，而是意味着另建一个独立的氏族、开枝散叶出去。没得姓的那十一个，大概就留在了核心部落里。

最后一段，司马迁把镜头推近到了黄帝的家室。「黄帝居轩辕之丘，而娶於西陵之女，是为嫘祖。」黄帝的居所在轩辕之丘，娶了西陵氏的女儿——这就是嫘祖。注意，「是为嫘祖」的「是为」，意思是「这就是」，不是什么古怪的名字。这位嫘祖可不是一般的妃子，「嫘祖为黄帝正妃，生二子，其后皆有天下」——她是正妻，生了两个儿子，而后来的天下，正是从这两个儿子的血脉中传下去的。一个是玄嚣，也就是青阳，被分封到了江水流域；一个是昌意，分封到了若水。这里的「降居」是分封外放、到封地去住的意思，不是被贬斥。兄弟俩一东一西，把黄帝的基因撒在了长江和雅砻江两岸，也给后面帝位传承的故事埋下了伏笔。嫘祖这辈子干的最被人记住的事，是教老百姓养蚕缫丝。《蚕经》载：嫘祖首创种桑养蚕之法，教民抽丝织帛之术，从此人们才有了柔滑的丝衣可穿，后世把她尊为「先蚕」，年年祭祀，香火一直没断过。

那么黄帝本人最后怎么样了？《史记·五帝本纪》没有在开篇就交代他的结局，但《史记·封禅书》补上了两种说法。一种说法是：黄帝采首山之铜，在荆山脚下铸鼎，鼎铸成的那天，天上有龙垂下胡须来接他，黄帝骑上龙背，群臣和后宫跟着爬上去的有七十多人，龙腾空而去，没来得及上去的小臣们只抓住了龙须，龙须被扯断，黄帝的弓也掉了下来，百姓抱着弓和龙须放声大哭，后来那地方就叫「鼎湖」，那把弓叫「乌号」。这是升仙的说法。另一种说法就朴实多了：黄帝死了，葬在桥山（今陕西黄陵）。这两种结局哪个是真的，司马迁自己也没下结论，都记下来，留给后人自己品。
