# 项目长期记忆：09见证

## 见证图片采集规范

- **目标**：为每个 JSON 的每条 witness entry 找到一张清晰、无水印的真实照片/拓片，以 `文物ID` 命名保存。
- **当前可行路线**（因 Wikimedia Commons 被墙）：
  1. 必应 async 图片接口搜索 `文物标题`；
  2. 按可信图源排序（百度图床、知乎、新浪、凤凰、腾讯新闻）；
  3. 带 Referer 下载候选；
  4. 视觉核验相关性、清晰度、水印；
  5. 落盘到 `见证图片/<文物ID>.<ext>` 并回填 JSON `文物图片` 字段。
- **失败模式**：罕见器物名会被必应拆解成单字返回字帖；此时 fallback 到网页搜索 + WebFetch 提取文章内图片 URL。
- **文学类**（如《诗经》）：用 ctext.org 或搜索“善本 书影”。
- **已生成 skill**：`witness-image-collector`（用户级）。
